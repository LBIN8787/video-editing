# AI 활용 쇼츠 자동화·콘텐츠 형식 점검

점검일: 2026-11-06. 범위: 기존 코드, 제작 대본·장면, 완성 MP4 일부 프레임, 공개 API 연결, 임시 큐 시험. 새 영상·유료 음성 생성·예약 실행·업로드는 하지 않았다.

## 결론

정기 제작은 기술적으로 가능하다. 현재는 소재 탐색부터 새 대본·새 영상까지 무인 제작하는 시스템이 완성된 상태가 아니다. 현재 실행 코드는 정해진 세 저장소의 메타데이터 수집과, 검토한 명세 이후의 렌더링·파일 검사·업로드 묶음을 처리한다. 기존 구성을 다시 렌더링하는 것은 새 소재로 새 영상을 만드는 것과 다르다.

## 실제 상태

| 단계 | 확인한 상태 | 정기 운영에 필요한 연결 |
|---|---|---|
| 소스 탐색 | discover는 고정 GitHub 3개 저장소만 수집 | GitHub 신규 후보·릴리스, 공식 블로그, HF 모델·Spaces 등으로 확장 |
| 접근 시험 | GitHub 저장소·릴리스, HF 모델·Spaces 공개 API 모두 HTTP 200 | 릴리스 목록은 이번 시험에서 0건. 접근 성공을 새 소식 발견으로 해석하지 않음 |
| 소재 선정 | 고정 후보 브리프가 있음 | 신규성·일반인 활용 가치·실행 조건 확인, 중복 소재 제거 |
| 대본 | 기존 샘플은 대화 중 작성 | 예약 실행 에이전트 또는 독립 LLM API 연결, 출처별 주장 검증 |
| ElevenLabs | 직전 영상에서 실제 생성 성공 | 예약 실행에서도 같은 커넥터와 자격을 쓸 수 있는지 검증. 독립 실행용 API 키는 현재 환경에 없음 |
| 장면 생성 | 영상별 React 구성, 수동 조립 코드 | 새 대본·장면 JSON을 공통 템플릿에 전달하는 자동 연결 필요 |
| 자막 | 로컬 Whisper 사용 가능, 샘플에서 실행 | 새 음성 완료 → 전사 → 대본 대조 → 자막 생성 연결 |
| MP4/파일 QA | Remotion·Chromium·FFmpeg 설치, 샘플 렌더와 검사 완료 | 새 장면 명세와 자동 연결. 기술 검사 외 화면·발음·내용 검수도 필요 |
| 정기 실행 | 로컬 cron/crontab 없음, runner 중지 | 에이전트 예약 도구 또는 상시 실행 호스트 설정 및 첫 실행 검증 |
| YouTube | 두 채널 미생성, 업로더 미연결 | 사용자 피드백 이후 채널 생성·인증·게시 연결 |

ChatGPT/Codex의 예약 실행 도구는 이 대화에서 발견됐다. 이 도구가 있어도 파일·커넥터를 사용할 실행 환경과 완료 결과를 별도로 검증해야 한다. 이번 요청은 가능 여부 점검이므로 새로운 정기 실행을 만들지 않았다.

## 채널별 고정 음성

두 채널 모두 우선 ElevenLabs Han Aim, voice_id `8jHHF8rMqMlg8if2mOUe`, model_id `eleven_v4`로 고정했다. 두 채널의 음성이 반드시 서로 달라야 한다는 요구는 없으므로 현재는 동일하게 두고 설정은 채널별로 분리했다. 향후 한 채널의 보이스를 변경하기로 결정한 경우에만 해당 설정을 명시적으로 변경한다.

- 영상마다 보이스·모델을 임의로 선택하지 않는다.
- 생성 실패·사용 불가·잔액 부족 시 다른 TTS로 자동 대체하지 않고 대기한다.
- 1대본 1회 생성을 기본으로 하고 유료 재시도를 자동으로 반복하지 않는다.
- 설정과 다른 보이스·모델, 대체 음성, 변경된 원본 음성 파일은 bind/build/approve/export에서 거부한다.
- 고정 보이스를 확인하지 않은 기존 Remotion 구성도 차단한다. 현재 확인한 구성은 AIRadar003뿐이다.
- 검사는 명세·음성 파일 해시·확인한 구성에 대한 검사다. 최종 MP4의 화자 정체성과 자연스러움을 자동으로 판별한다는 뜻은 아니다.
- 과거 AI 1·2편과 퀴즈 2편은 Supertonic 음성이다. 고정 음성이 소급 적용된 것은 아니며, 게시 후보로 쓸 경우 재녹음·타이밍 조정이 필요하다. 최신 엑셀 3편만 현재 고정 음성과 일치한다.

공식 요금표에는 무료 크레딧 한도와 플랜별 조건이 있다. 하루 AI 3편, 두 채널 합계 6편을 ElevenLabs로 계속 제작하는 것을 무료라고 보장할 수 없다. 지난 커넥터 1회 견적은 351 credits / $0.0351였으나 이는 해당 호출 견적이며 구독 요금제와 동일한 과금 풀이라고 가정하지 않는다. 실제 운영 전 연동 방식·한도·이용 조건을 확인한다. 이번 점검에서는 추가 결제나 음성 생성을 하지 않았다.

## AI 채널의 편집 기준: 안내문을 영상으로 풀기

시청자는 AI 커뮤니티를 직접 찾아보지 않는 일반 사용자로 가정한다. 새 툴·스킬·업데이트 또는 기존 도구의 유용한 활용법을 소개하되, 제목에서 신규 출시·업데이트·기존 스킬 발굴을 구분한다. 누적 별 수만으로 최근 급상승을 주장하지 않는다.

기본 45~60초 구성:

1. 0~4초: 해결할 불편 한 가지.
2. 4~10초: 어떤 툴·스킬인지, 무엇이 새롭거나 소개할 만한지.
3. 10~18초: 핵심 기능 1~3개와 누구에게 필요한지.
4. 18~38초: 준비물·환경과 구체적인 사용 단계, 그대로 쓸 입력 예시.
5. 38~50초: 적용 사례의 입력 → 요청 → 결과. 실제 실행 결과가 있으면 보여주고 설명용 예시는 그 사실을 표시.
6. 50~60초: 결과 확인 방법과 주요 비용·계정·지원 조건.

분량은 소재에 맞춰 조정한다. 짧게 담기 어려운 설치 절차는 별도 자세한 안내로 연결하되, 영상에서 무엇을 생략했는지 분명히 한다. 전환 효과음은 넣지 않는다. 글을 읽기만 하는 화면보다 실제 조작·파일 변화·전후 비교를 우선한다.

`ai-guide-v1` 명세에는 소식 맥락, 기능, 활용 단계, 적용 사례, 결과 확인, 사용 조건, 소스 확인일이 필요하다. 입력·요청·예상 결과가 없는 사례와 표시 없는 모의 화면은 통과시키지 않는다. 이 검사는 필수 내용 누락 방지이며 사실 확인·설명의 질·영상 표현까지 자동 승인하지 않는다.

## 기존 AI 3편 검토

| 영상 | 요청 형식과 부합하는 부분 | 부족한 부분 | 판정 |
|---|---|---|---|
| 1. last30days | 기능, 사용 명령, PPT 도구 조사 요청 예시, 연결 조건 | 실제 수집 결과와 결과물 읽는 방법 없음. 신규 출시 속보가 아니라 기존 스킬 발굴 | 소개형 입문편으로 부분 부합 |
| 2. PPT Master | 편집 가능한 PPT 기능, 문서 → 5장 발표자료 요청, 파일 수정 안내 | 실제 입력 문서와 완성 PPT 전후 비교 없음. 설치 절차가 추상적 | 활용 안내 방향에 부합하나 실전 사례 보강 필요 |
| 3. xlsx | 표·수식·차트 기능, 준비·첨부·요청·검사, 매출 파일 사례. 예시 화면 명시 | 지원 서비스와 설치 경로가 구체적이지 않음. 완성 xlsx를 실제 생성해 검증한 화면 없음 | 세 편 중 요청 형식에 가장 가까우나 따라 하기 튜토리얼로는 미완성 |

세 편 모두 실제로 도구를 실행해 얻은 결과를 보여주는 실증 영상은 아니다. 대본·설명용 모션 그래픽 중심의 안내 영상이다. 현재 방향은 유지할 수 있지만 앞으로는 가능하면 동일한 예제 파일과 실제 출력물을 확보해 결과 장면을 강화해야 한다. 기존 영상 파일은 이번 점검에서 수정하지 않았다.

## 하루 3편 제작 운영안

AI 채널은 새 소식 1편, 구체적인 활용법 1편, 적용 사례 1편을 기본 편성 후보로 둔다. 이는 반드시 매일 새 출시 3개를 확보해야 한다는 뜻은 아니다. 확인할 만한 소식이 부족하면 검증한 기존 활용법으로 구성하고 신규 출시처럼 포장하지 않는다.

탐색 → 원문 보관·확인일 기록 → 소재 선정·중복 검사 → 안내형 대본 → 사실·실행 조건 검토 → 고정 음성 → 장면·자막 → MP4 → 기술·내용 QA → 피드백 대기 순서다.

정기 실행 에이전트 방식과 독립 API 방식 중 한 가지를 선택해 연결한 뒤, 새 소재 1개가 실제 새 MP4로 완성되는 전체 시험이 필요하다. 그 뒤 3편 연속 제작 및 중단·재실행 시 중복 생성·이중 과금 방지 시험을 한다. 현재 임시 큐 시험만으로 이 단계들이 완료됐다고 주장하지 않는다.

## 이번에 실행한 검증

- 큐 및 콘텐츠 정책 테스트 8개 통과.
- 임시 DB에서 계획 → 최신 명세 연결 → 기존 MP4 전체 디코딩 검사 → review 상태 도달.
- 이 시험은 기존 완성 MP4를 재사용했으며 새 대본·음성·영상을 생성하지 않았다.
- 실제 운영 DB의 작업 상태·승인·게시 상태는 변경하지 않았다.
- runner는 sample_review / automation_enabled=false 조건에서 중지되는 것을 확인했다.
- 증거 파일: automation-audit-dry-run.json, source-connectivity-audit.json, test_content_policy.py.
