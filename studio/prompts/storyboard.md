# storyboard

승인된 대본을 장면별로 나눠 내레이션, 화면, 출처 ID, 실제 실행/설명용 구분, 자막과 길이를 기록하라. 가능한 경우 실제 파일과 결과를 보여라. 사용하지 않은 UI를 실제 조작한 것처럼 만들지 마라. 채널 고정 보이스를 사용하며 전환 효과음을 넣지 마라.

채널 설정과 styles/<id>/STYLE.md를 먼저 읽는다. 결과는 topic 원장 또는 해당 episode 기록에 남긴다.

AI 채널은 실제 작업 사례가 우선이다. work-cases/의 작업 목적·실제 결과·검사·실패·미완료 범위를 근거로 작성한다. 조사한 기능을 직접 사용한 경험으로 바꾸어 말하지 않는다. 측정 없는 성과 수치는 넣지 않는다.
