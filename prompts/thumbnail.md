## 제목·썸네일 규칙 (영상과 함께 만든다 — `02_script/hybrid.json` 의 `package`)

근거: 교양·상식 채널 상위 아웃라이어 영상 분석 (docs/10-knowledge-demand.md, 2026-11-07). 다른 채널의 썸네일·문구를 베끼지 않고 **구조만** 따른다.

### 제목 (`title` 1개 + `title_options` 3개, 유튜브 '테스트 및 비교'용)
1. **질문 하나** 또는 **숫자 두 개의 대비**로 만든다. ("스페인 독감은 왜 '스페인' 독감일까?", "11% 급락, 진짜 위험은 8%")
2. 사람들이 검색하는 단어(스페인 독감·코스피·반도체)를 **맨 앞 20자 안에**. 휴대폰 목록은 앞 40자 정도만 보인다.
3. 뒤쪽(| 뒤)은 답의 방향만 흘린다 — 답을 다 말하지 않는다.
4. '충격·소름·역대급' 같은 낚시 단어 금지(분석상 평균 이하). 사실에 맞는 단어만('폭락' 대신 실제 낙폭이면 '급락').
5. 투자 권유·단정 전망 금지(채널 규칙).
6. `title_why` 에 왜 이렇게 지었는지 3줄.
7. **호기심(curiosity) 채널**: 제목은 `topic_brief.hook` 에서 — 훅의 틈(gap)을 그대로, 답은 숨김, 훅에 없는 약속 금지. 3개는 ① 질문형 ② 장면·숫자형 ③ 상식 깨기형 (manual/04 §0-3).

### 썸네일 (`thumbnails` A/B/C — 각자 다른 '클릭 동기')
| 규칙 | 이유 |
|---|---|
| 큰 피사체 하나(사람 얼굴·군중·건물·숫자) | 상위 영상 대부분이 한 장면을 크게 씀 |
| 큰 글씨 **두 줄, 줄당 6~8자** | 휴대폰 목록(가로 168px)에서도 읽혀야 함 — 점검: 가장 작은 큰 글씨 ≥ 6px |
| 강조 단어 **하나만** 노란색 | 색이 여러 개면 작게 보면 뭉개짐 |
| 제목과 **같은 말 반복 금지**, 서로 보완 | 제목=질문, 썸네일=감정·반전·숫자 |
| 오른쪽 아래(1080~1280 × 630~720) 비움 | 재생 시간 표시가 덮음 — 자동 점검 |
| 채널 정체성: 오래된 사진 톤 + 빨간 손그림(동그라미·화살표·X·도장) 또는 종이 바탕 숫자 | 영상과 썸네일이 같은 얼굴 |
| 사진 장소·날짜를 틀리게 쓰지 않음 (다른 장소 사진이면 그 도시 이름을 쓰지 않는다) | 사실 규칙 |
| 글꼴에 없는 기호(−, –, —)는 자동으로 '-' 로 | 글자 빠짐 방지 |

배치: `layout: board` (**호기심 채널 이야기형 기본** — 종이 바탕 + 영상 그림판과 같은 선 그림 `drawings[{icon|pose, x, y, s, color, label}]` + 큰 두 줄 글씨, 강조 단어는 빨강, 2026-11-13) · `layout: photo` (사진 한쪽 + 반대쪽 큰 글씨, `photo_side: right|left|full`) 또는 `layout: versus` (종이 바탕 숫자 둘).
표시: `marks: [{type: circle|arrow|x|stamp, ...}]`. 변형마다 `why` 2~3줄.

### 만들기·점검
`python -m ytflow thumbnail <프로젝트>` (hybrid 만들기 끝에 자동) → `05_edit/thumbnail_A~C.png`, `thumbnail_preview.png`(실제·목록·휴대폰 크기),
`package.md`(제목·이유), `thumbnail_qa.json`. 미리보기를 **직접 눈으로** 보고 고친다. `upload` 가 릴리스에 함께 붙인다.
