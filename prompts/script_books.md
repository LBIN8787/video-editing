# 책 채널 대본 규칙 (ch-books)

조사 근거: `docs/74-book-channel.md`. 공통 규칙(쉬운 대본·사실·인트로 없음·3인칭 '~습니다')은 `prompts/script.md` 와 매뉴얼을 그대로 따릅니다. 아래는 책 채널에만 더하는 것입니다.

## 0. 이 채널의 한 문장
**책을 소개하지 않고, 시청자의 질문에 책으로 답한다.** 책은 첫 장면이 아니라 답·증거로 등장합니다.

## 1. 먼저 정할 것 (대본 쓰기 전, `02_script/intent.md`)
- **형식:** ② 질문형 / ③ 다큐형 (`channel.yaml` 의 `formats`)
- **질문 하나:** 시청자가 실제로 품는 질문 (② "왜 결심은 사흘을 못 갈까?") 또는 가장 놀라운 사실 (③ "물고기라는 분류는 없다").
- **핵심 하나:** 책에서 가져갈 단 하나. 두 개 이상이면 편을 나눕니다.
- **주인공:** 따라갈 사람 한 명 — 저자·연구자·책 속 인물·시청자를 대신하는 인물.
- **기억할 한 장면:** 영상이 끝나도 남을 그림 하나.
- **틀리는 경우:** 책의 주장이 반박되거나 한계가 있는 지점 (재현 실패·반대 연구·비판).

## 2. 대본 뼈대

### ② 질문형 (8~12분)
| 박자 | 하는 일 | 주의 |
|---|---|---|
| 1. 질문 (0:00~0:30) | 누구나 겪는 장면 하나 → 질문. 답은 숨김 | 책 제목·저자를 말하지 않음 |
| 2. 흔한 답 (~1:30) | 보통 이렇게 생각한다 → 그런데 이상한 점 | 시청자가 "나도 그렇게 생각했는데" 하게 |
| 3. 뜻밖의 답 (~5:00) | 주인공을 따라 연구·사례가 드러나는 과정. 여기서 책이 등장 ("이 질문에 답한 사람이 있습니다") | 연구는 원 논문으로 확인, 숫자에는 비교 기준 |
| 4. 내 삶에 옮기면 (~8:00) | 핵심 하나를 직장·관계·돈·습관의 장면으로. 따라 할 행동 하나 | 처방 나열 금지 — 하나만 |
| 5. 틀리는 경우 (~9:30) | 반박·한계 | 책을 깎아내리지 않고 범위를 정확히 |
| 6. 돌아오기 (끝) | 첫 장면으로 돌아가 답 + 직접 읽어 볼 대목 하나 | 수미상관 |

### ③ 다큐형 (7~10분)
| 박자 | 하는 일 | 주의 |
|---|---|---|
| 1. 장면 (0:00~0:30) | 책에서 가장 놀라운 사실·장면으로 바로 시작 | 설명 없이 장면 |
| 2. 주인공 (~1:30) | 그 일을 처음 알아낸(겪은) 사람, 언제·어디서 | 날짜·장소 도장 |
| 3. 과정 (~6:00) | 발견·사건을 시간 순서로. 막마다 다음 질문을 걸고 끝냄 | 한 줄기 이야기, 곁가지 금지 |
| 4. 바뀐 것 (~8:00) | 그래서 세상(우리 생각)이 어떻게 바뀌었나 | 책이 여기서 '이 이야기를 쓴 책'으로 등장 |
| 5. 남은 질문 (끝) | 책이 던지는 질문 + 직접 읽을 대목 | 담백하게 — 감탄 과장 금지 |

## 3. 스토리텔링 장치
- **열린 고리:** 첫 질문의 답은 끝까지 미룹니다. 막(1~2분)마다 작은 질문을 걸고 다음 막에서 풉니다.
- **번역:** 개념을 시청자의 세계로 옮깁니다 — 비유 2개 이상, 그중 하나는 일상 장면.
- **사람으로 말하기:** "연구에 따르면" 대신 "1960년대 한 연구자가 ~를 했습니다".
- **책 인용:** 짧게(한 문장 안팎), 쪽수를 팩트시트에 기록. 본문을 길게 읽지 않습니다.
- **책 카드:** 표지·제목·저자는 책이 등장하는 순간 한 번(출판사 공개 표지).

## 4. 하지 않는 것
- "오늘 소개할 책은 ~입니다"로 시작하기, 목차 순서대로 요약하기.
- 소설 결말 스포일러, 본문 낭독, 출판사 협찬 미고지.
- 책의 주장을 검증 없이 사실로 단정하기.
