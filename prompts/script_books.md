# 책 채널 대본 규칙 (ch-books)

조사 근거: `docs/74-book-channel.md`. 공통 규칙(쉬운 대본·사실·인트로 없음·3인칭 '~습니다')은 `prompts/script.md` 와 매뉴얼을 그대로 따릅니다. 아래는 책 채널에만 더하는 것입니다.

## 0. 이 채널의 한 문장
**책을 소개하지 않고, 시청자의 질문에 책으로 답한다.** 책은 첫 장면이 아니라 답·증거로 등장합니다.

## 1. 먼저 정할 것 (대본 쓰기 전, `02_script/intent.md`)
- **형식:** ② 질문형 / ③ 명작 서사형 (`channel.yaml` 의 `formats`)
- **질문 하나:** 시청자가 실제로 품는 질문 (② "읽고 나면 왜 하나도 기억이 안 날까?") 또는 작품의 여는 장면과 그 장면이 품은 질문 (③ "왜 그는 도끼를 들었을까?").
- **핵심 하나:** 책에서 가져갈 단 하나. 두 개 이상이면 편을 나눕니다.
- **주인공:** 따라갈 사람 한 명 — 저자·연구자·책 속 인물·시청자를 대신하는 인물.
- **기억할 한 장면:** 영상이 끝나도 남을 그림 하나.
- **틀리는 경우:** 책의 주장이 반박되거나 한계가 있는 지점 (재현 실패·반대 연구·비판).

## 2. 대본 뼈대

### ② 질문형 (10~15분) — 주제는 독서·뇌·심리·습관 (분석상 질문형이 강한 곳)
| 박자 | 하는 일 | 주의 |
|---|---|---|
| 1. 질문 (0:00~0:30) | 누구나 겪는 장면 하나 → 질문. 답은 숨김 | 책 제목·저자를 말하지 않음 |
| 2. 흔한 답 (~1:30) | 보통 이렇게 생각한다 → 그런데 이상한 점 | 시청자가 "나도 그렇게 생각했는데" 하게 |
| 3. 뜻밖의 답 (~5:00) | 주인공을 따라 연구·사례가 드러나는 과정. 여기서 책이 등장 ("이 질문에 답한 사람이 있습니다") | 연구는 원 논문으로 확인, 숫자에는 비교 기준 |
| 4. 내 삶에 옮기면 (~8:00) | 핵심 하나를 직장·관계·돈·습관의 장면으로. 따라 할 행동 하나 | 처방 나열 금지 — 하나만 |
| 5. 틀리는 경우 (~9:30) | 반박·한계 | 책을 깎아내리지 않고 범위를 정확히 |
| 6. 돌아오기 (끝) | 첫 장면으로 돌아가 답 + 직접 읽어 볼 대목 하나 | 수미상관 |

### ③ 명작 서사형 (10~20분) — 주력
조회수 분석(docs/74 §8)에서 구독자 대비 가장 강한 형식. 시청자는 평가가 아니라 **이야기를 읽은 것 같은 경험**을 원합니다.

| 박자 | 하는 일 | 주의 |
|---|---|---|
| 1. 장면 (0:00~0:30) | 작품 속 한 장면을 현재형으로 그림 ("7월 초, 몹시 더운 저녁. 한 청년이 다락방을 나섭니다.") | 제목·작가·인사 없이. 장면 삽화 한 장 |
| 2. 질문 셋 (~1:00) | 이 장면이 품은 질문을 시청자의 고민으로 ("왜 우리는 ~할까요?") | 셋을 넘지 않음. 답은 결말에서 |
| 3. 작품 한 줄 (~1:20) | 작품·작가·시대를 한두 문장, 책 카드 한 번 | 작가 연보 나열 금지 |
| 4. 이야기 (~13:00) | 주인공 한 명의 **마음**을 따라 시간 순서로 3~4막. 막마다 끝에서 다음 질문을 걸고, 장 사이는 페이지 넘김 | 사건 요약이 아니라 그 순간 주인공이 무엇을 원하고 두려워했나. 곁가지 인물은 주인공과 닿을 때만 |
| 5. 결말 (~16:00) | 결말까지 들려줌 | 제목·첫머리에 '결말 포함'. 짧은 원문 인용 1~2번(밑줄 인용) |
| 6. 마음이 묻는 것 (~18:00) | 주인공의 마음이 오늘 우리에게 묻는 것 — 질문 셋에 답 | 교훈 설교 금지, 해석은 '~로 읽을 수 있습니다' |
| 7. 돌아오기 (끝) | 첫 장면으로 돌아가 다르게 보이게 + 원문으로 읽어 볼 대목 하나 | 수미상관 |

**말투:** 3인칭 다큐 내레이터 '~습니다', 장면은 현재형으로. 등장인물의 대사는 짧게, 우리 말로 다시 씁니다.
**권리:** 저작권이 끝난 고전을 우선합니다. 현대 소설은 줄거리를 다시 쓰고 원문 인용은 한 문장 안팎만. 영화·드라마 장면은 쓰지 않습니다.

## 3. 스토리텔링 장치
- **열린 고리:** 첫 질문의 답은 끝까지 미룹니다. 막(1~2분)마다 작은 질문을 걸고 다음 막에서 풉니다.
- **번역:** 개념을 시청자의 세계로 옮깁니다 — 비유 2개 이상, 그중 하나는 일상 장면.
- **사람으로 말하기:** "연구에 따르면" 대신 "1960년대 한 연구자가 ~를 했습니다".
- **책 인용:** 짧게(한 문장 안팎), 쪽수를 팩트시트에 기록. 본문을 길게 읽지 않습니다.
- **책 카드:** 표지·제목·저자는 책이 등장하는 순간 한 번(출판사 공개 표지).

## 4. 하지 않는 것
- "오늘 소개할 책은 ~입니다"로 시작하기, 목차 순서대로 요약하기.
- 결말 포함 표시 없이 결말 말하기, 본문 전문 낭독, 영화·드라마 장면 짜깁기, 출판사 협찬 미고지.
- 책의 주장을 검증 없이 사실로 단정하기.
