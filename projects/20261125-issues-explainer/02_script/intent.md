# 의도 — 이사회는 내보냈고, 대통령은 다시 불렀다

**유형:** 시사 심층 · 이야기형 해설(11 §3-1 레퍼런스 딥텔러, 13 §6 '인물·실제 발언·행동' + '숨겨진 연결관계'). 중심축 = **결정한 주체가 바뀌는 흐름**(회사 → 국가 → 시장 → 다시 국가).
**목적 분간(11 §2-4):** 정보 습득형. 시청자가 얻는 것: 뉴스 제목 뒤에서 누가 결정했고 무엇이 남았는지.
**제작 목표 한 줄:** 엿새 만에 뒤집힌 의장의 말을 따라가며, 대표의 자리를 실제로 움직인 것이 회사 규칙에서 국가 판단으로 넘어간 과정을 보여 준다.
**기억할 한 장면:** 같은 날, 같은 정부가 '사람'에는 초록 체크, '거래'에는 빨간 자물쇠를 거는 두 칸 화면(5장).

## 쓰기 전 여섯 가지 (13 §1)
| 질문 | 답 |
|---|---|
| 시청자 | `01_research/audience.md` |
| 질문 | 엔비디아 대표는 누가 정한 걸까 — 이사회, 주주, 정부? |
| 기존 인식 (`known`) | 젠슨 황이 돌아왔고 주가가 30% 올랐다 |
| 새로운 발견 (`new_angle`) | 공시에 적힌 복귀의 외부 근거는 '정부 판단' 하나, 같은 날 정부는 칩 거래 쪽엔 문을 닫음, 돌아온 자리엔 감시 장치가 셋 |
| 근거 | `factsheet.md` F1~F19 |
| 결말 | 복귀를 '해피엔딩'이 아니라 '조건부 복귀'로 보게 된다. 다음 판가름(12-01·조사 결론)을 안다 |

## 지킬 것
사생활은 사임 계기로만 짧게. 상대 인물 이름·사진 없음. '스파이' 단정 없음. 정치 평가는 이름 있는 발언만. 투자 판단 없음.
