# 제작 의도

목적: 즐길거리형 + 이해(통념 점검)

**제작 목표** · "나는 의지가 약해서 무너진다"는 자책이 오래된 설명 하나에서 왔고, 그 설명이 큰 규모의 재검증에서 흔들렸다는 사실을 따라가며, 그 밤을 다르게 설명하고 다르게 바꿀 수 있다는 것까지 느끼게 한다.

**기억할 한 장면** · 서윤이 열한 시 냉장고 앞에 서 있는 장면이 마지막에 같은 자리, 다른 길(찻물 소리, 꺼진 부엌 불)로 돌아온다.

**시청자 경험** · 내 얘기 같은 밤을 본다 → 원 실험(쿠키·무)을 알게 된다 → 23곳, 36곳이 다시 해 보니 안 나왔다는 반전을 본다 → '그럼 의지력은 없다는 말?'을 한 번 막고 '확정할 수 없다'로 정리한다 → 다른 설명과 일상 자료를 거쳐 → '만약 ~하면' 계획까지 이어 '아 이래야겠구나'를 얻는다 → 마지막에 처음 장면이 다르게 읽힌다.

**이야기의 흐름 선택 이유** · 이 편은 '실험이 남긴 질문을 따라간다'가 중심이다. 원 실험의 결과(20분 vs 8분)만으로는 '왜'를 알 수 없어 재검증으로 넘어가고, 재검증 결과(효과가 일관되지 않음)가 '그럼 밤의 무너짐은 무엇인가'라는 다음 질문을 만든다. 서윤은 그 질문을 일상으로 되돌리는 인물이며 연구를 빼도 서윤의 행동이 그대로라면 그 연구를 넣을 이유가 없다는 기준으로 4·5·7·8장에 각각 새로운 사실(재검증, 더 큰 재검증, 일상 관찰, 습관)이 하나씩 들어가게 했다.

| 장 | 다 보고 나면 |
|---|---|
| 열한 시의 냉장고 | '의지가 바닥난 것일까'라는 질문이 생긴다. |
| 쿠키와 무 | 원 실험이 무엇을 비교했고 무엇을 쟀는지 안다. |
| 바닥난다는 설명 | 경험과 맞는다는 것이 증거가 아님을 안다. |
| 23곳이 다시 해 보니 | 같은 이론의 대규모 재검증에서 효과가 구분되지 않았다. |
| 36곳이 다시 해 보니 | 반론을 반영해도 결과가 같았다(d=0.06). |
| 그래도 의지력이 없다는 뜻은 아니다 | 확정할 수 있는 것과 없는 것을 구별한다. |
| 일주일의 호출기 | 일상 관찰은 누적 효과와 상황 노출을 모두 시사한다. |
| 습관이라는 단서 | 잘 참는 사람은 덜 참는 사람일 수 있다. |
| 만약 ~하면 | 연구가 가리키는 방향(길을 바꾸기)과 생활 예시를 구별해 받는다. |
| 다시 밤 열한 시 | 처음 장면이 다르게 읽힌다. |
