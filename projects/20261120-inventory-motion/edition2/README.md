# 수정본 — 출하 지연과 인도

초판과 같은 32초 내레이션 위에 장면을 다시 연출했다. 제작 도구는 내장 ImageGen, Pillow, FFmpeg다. 골판지 판면, 낡은 철제 셔터, 펜을 든 손, 인수증, 장부를 분리된 그림으로 제작했다. 동일한 상자 번호를 유지하며 셔터의 하강, 상자의 누적, 인수 서명과 도장 충격을 발화 시점에 맞췄다.

Google Drive의 `ytflow/영상/20261120-inventory-motion-v2`에 1080p 수정본, 동시 재생 비교본, 원본 그림 묶음 `illustration-plates.zip`이 있다.

## 다시 만들기

1. 쓰기 가능한 작업 폴더를 만들고 `INVENTORY_WORK`에 그 절대 경로를 지정한다. 그림 묶음을 작업 폴더에 풀면 `art/object-plate.png`와 `art/document-plate.png`가 생긴다.
2. 초판의 `voice.py`를 음성 작업 폴더에서 실행하거나 기존 `voice.wav`와 `time.json`을 사용한다. 그 두 파일이 있는 폴더를 `INVENTORY_AUDIO`에 지정한다.
3. 이 디렉터리의 `foley.py`를 실행해 스테레오 효과음을 합성한 뒤 `render.py`를 실행한다. `render.py --qa`는 장면별 프레임을 만든다. Windows 기본 글꼴, Noto Sans KR, 저장소의 나눔손글씨, Pillow, OpenCV, NumPy, FFmpeg를 사용한다.
