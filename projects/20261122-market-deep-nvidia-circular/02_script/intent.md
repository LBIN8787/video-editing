# 의도
- **제작 목표:** '엔비디아 순환금융'을 원리로 풀고, 위험이 어디에 쌓이는지 숫자로 보인다.
- **시청자 욕망:** 엔비디아 매출이 진짜인지, 고리가 끊기면 내 계좌(엔비디아·한국 메모리)는 어떻게 되는지.
- **기억할 한 장면:** 돈이 한 바퀴 도는 그림 — 엔비디아 → 고객 → 칩 주문 → 엔비디아.

| 장 | 출발점 | 다 보고 나면 새로 아는 것 |
|---|---|---|
| 0 | 보증 1,180억 + 흔한 생각 셋 | 오늘 고칠 세 생각 |
| 1 | 오해: 가짜 매출 | 갚으면 진짜, 위험은 겹침(매출+투자) |
| 2 | 오해: 대부분 자기 돈 | 1년 새 커진 크기, 그러나 위험은 몇 년 뒤 약속에 |
| 3 | 궁금: 예전에도? | 루슨트와 같은 점·다른 점 |
| 4 | 오해: 현금 많으니 무위험 | 고객 쪽에서 먼저 보이는 신호 넷 |
| 5 | 궁금: 한국 계좌는? | 메모리 약정 3,900억, 만약에 넷, 볼 것 넷 |
