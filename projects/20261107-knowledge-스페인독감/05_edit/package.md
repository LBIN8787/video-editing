# 제목·썸네일 — 20261107-knowledge-스페인독감

**제목(기본):** 스페인 독감은 왜 '스페인' 독감일까? 처음 말한 나라가 누명을 쓴 이유

**제목 후보 (A/B 시험용)**
1. 스페인 독감은 왜 '스페인' 독감일까? 처음 말한 나라가 누명을 쓴 이유
2. 스페인에서 시작되지 않은 '스페인 독감' | 숨긴 나라가 더 많이 죽었다
3. 1918년 세계 3명 중 1명이 걸린 병, 이름은 왜 '스페인'이 됐나

**제목을 이렇게 정한 이유**
- 잘 되는 교양 영상의 공통점인 '누구나 아는 것 + 모르는 이유' 질문형(docs/10). 모두 아는 이름(스페인 독감)을 제목 맨 앞에 둬 검색에도 걸림
- 앞 22자 안에 질문이 끝남 → 휴대폰에서 잘려도 궁금증이 보임. 뒤쪽은 답의 방향('처음 말한 나라', '누명')만 흘려 클릭 이유를 줌
- '충격·소름' 같은 낚시 단어 없음(분석에서 오히려 평균 이하). 사실(스페인이 출발지 아님, 중립국 보도)에 맞는 단어만

## 썸네일
### A — 누명 쓴 왕 (얼굴 + 감정)
![A](thumbnail_A.png)

- 사람 얼굴(스페인 국왕 알폰소 13세)이 가장 먼저 눈에 들어옴 — 상위 영상 다수가 인물 하나를 크게 씀
- '억울하다'는 감정 단어 + 제목의 질문이 서로 보완: 제목은 '왜?', 썸네일은 '스페인 편'이라는 반전
- 빨간 '누명' 도장 = 채널의 손그림 빨간 펜 정체성, 오른쪽 아래(재생 시간 자리)는 비움

### B — 숨긴 나라 (군중 + 결과)
![B](thumbnail_B.png)

- 영상의 핵심 근거(같은 조건, 다른 결과)를 그대로 약속 — 클릭 뒤 실망이 없음
- 실제 1918년 퍼레이드 군중 사진(워싱턴, 필라델피아와 같은 해 같은 종류 행사) + 빨간 동그라미로 '사람이 모인 것'이 문제라는 시선 유도. 사진 장소를 필라델피아라고 쓰지 않음
- 숫자(719 vs 347)는 작은 손글씨로만 — 큰 글씨는 두 줄 6자 이내로 휴대폰에서도 읽힘

### C — 3명 중 1명 (규모)
![C](thumbnail_C.png)

- 규모 숫자형(순위·숫자 제목이 평균 이상) — 행군하는 군인 영상 한 장면으로 '전쟁'과 '대유행'을 같이 보여 줌
- A·B 와 다른 각도(규모)라 유튜브 '테스트 및 비교'에서 어떤 동기가 더 먹히는지 알 수 있음
