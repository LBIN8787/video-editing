# 본편 인계 · 승인 대본 v2

- 대본과 화면 방향은 원격 main 공통 매뉴얼 v50으로 검토했다. 연출 수정에는 v52의 호기심 편과 장면별 스타일 기준을 적용했다.
- 레퍼런스별 관찰과 이번 편의 선택 이유는 [벤치마크](../01_research/benchmark.md)에 기록했다.
- 장면의 기본 원화는 〈첫 만남 뒤, 나만 대화를 망쳤다고 느낄까?〉의 선명한 구도와 손·소품의 가독성을 따른다. 서점과 동일한 옷·인물 대신 마트 환경에 맞는 원 그림을 만든다. 원화의 선과 조명은 고정하고 카메라를 안정적으로 둔다.
- 실제 사건을 보여줄 때는 창작 재연임을 밝힌다. 시식대의 색 표지를 기준으로 먼저 손님의 시선으로 진행하고, 무엇이 바뀌었는지는 뒤편의 손동작과 단면으로 밝힌다. 그림체 전환과 전체 화면 확대는 이 정보를 전달하는 데 필요하지 않다.
- 후속 컴퓨터 실험에서는 고르는 사람의 손, 화면에 돌아온 그림, 말로 보고하는 순서가 중요하다. 선택과 결과는 동일 위치에서 대조하고, 당장 한 말과 뒤늦게 한 말을 같은 반응으로 합치지 않는다.
- v2의 초콜릿은 반례가 등장하는 장면이다. 익숙한 포장과 물건이 실제로 바뀌는 동작을 보여 줄 때만 캐주얼 재구성을 사용한다. 참가자와 조건이 달라진 점은 대사에서 함께 짚는다.
- D2에서 [v2 대본](script_v2.md)을 통과했다. D3에서 사용자는 Drive의 `05_edit/sample_v2.mp4`를 보고 “이 방향으로 본편 제작 (추천)”을 선택했다.
- 현재 시청할 본편은 Drive의 `05_edit/final_direction_v3.mp4`다. [수정판 장면·글꼴 기준](direction_review_v3.md), [장면표](shotlist.md), [대사별 전환](full_cues.json), [원화 파일 정보](../04_assets/art_manifest.json)를 사용한다. 보이스는 InJoonNeural이다. [채널 보이스 후보](voice_types.md)
- 재생성에 필요한 원화와 시간표는 Drive의 `영상/20261119-curiosity-choice-blindness`에 있다. 새 제작 시 입력을 `E:/CodexWork` 아래 전용 작업 폴더에 놓고, 그 폴더를 아래 스크립트에 넘긴다. 완성본은 Drive에 보관한다. 원화 프롬프트는 [art_orders.md](art_orders.md)에 있다. 연구 도판은 Grassi 외 논문 CC BY 4.0의 그림 2B를 잘라 첫 시행을 표시했다.
