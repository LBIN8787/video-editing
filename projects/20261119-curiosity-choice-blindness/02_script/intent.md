# 제작 의도

목적: 즐길거리형

**제작 목표** · 내가 고른 것을 어디까지 안다고 말할 수 있는지, 한 병의 잼이 뒤집히는 사건을 따라가며 느끼게 한다.

**기억할 한 장면** · 카트 손잡이 너머로 붉은 표지가 보인다. 두 번째 숟가락을 받던 때도 같은 붉은색이었다. 시식대 뒤를 보여주자 한 병에 입구가 두 개 있었다.

**시청자 경험** · 시식대에 잠깐 멈춘다 → 자기 손가락이 가리킨 것을 기억한다 → 결과를 받고 설명한 사람이 어떻게 반응했는지 궁금해진다 → 후속 연구에서 말과 인지가 어긋날 가능성을 본다 → 돌아오는 길, 나도 놀라면 얼마나 바로 말하는지 떠올린다.

| 장 | 다 보고 나면 |
|---|---|
| 같은 빨간 병 | 내가 고른 대상과 두 번째 맛이 다를 수 있다는 질문이 생긴다. |
| 카드를 뒤집어 주세요 | 틀린 카드를 받은 사람도 그 카드에 맞는 이유를 말할 수 있다는 결과가 나온다. |
| 시식대 뒤에서 | 두 뚜껑, 색 표지, 연구자의 두 역할이 한 순서로 연결된다. |
| 맛이 달라졌는데 | 같은 조건 가운데 무엇을 바꿨는지, 어떤 반응을 ‘탐지’로 세었는지 알게 된다. |
| 말하지 않은 사람 | 후속 실험은 즉시 항의와 나중의 확인을 분리했다는 차이가 남는다. |
| 초콜릿을 건네자 | 익숙한 제품을 고른 어린이의 탐지는 한계 사례다. 잼 연구의 비율을 모든 선택에 붙일 수 없는 이유가 보인다. |
| 숟가락을 내려놓을 때 | 처음의 맛, 나중의 맛, 답한 이유를 서로 다른 것으로 돌아본다. |
