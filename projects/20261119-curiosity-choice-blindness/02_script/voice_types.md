# 호기심 채널 보이스 타입

채널 시청자가 장면을 떠올리며 이야기를 듣는 데 맞춰 고른 타입이다. 음질이나 성별을 스타일의 기준으로 삼기보다, 등장인물의 행동에서 연구의 근거로 넘어갈 때 말투가 자연스럽게 이어지는지를 본다.

| 타입 | 사용할 편 | 발화에서 확인할 것 |
|---|---|---|
| **담담한 이야기형** · 기본 후보 | 잼 시식, 첫 만남, 일상 행동에서 출발하는 관계 심리 | 인물 대사를 짧게 들려준 뒤 편하게 서술한다. 인물의 망설임과 결과가 밝혀지는 곳의 쉼이 들린다. 연구 부분에서도 문장 끝을 과하게 누르지 않는다. 현 잼 편 비교 기준은 인준. |
| **따뜻한 관찰형** | 어린 시절, 가족, 관계처럼 인물을 가까이 이해하는 편 | 인물의 마음을 대신 단정하지 않고 다정하게 관찰한다. 연구자명과 이유를 또렷하게 읽되 말끝을 매번 올리지 않는다. 청취 후보는 선희. |
| **절제된 다큐형** | 역사 기록에서 시작하거나 실제 사건과 자료의 신뢰가 중심인 편 | 인명과 연도, 원인과 결과를 읽기 쉽게 짚는다. 발성은 안정적이고 긴장은 자료나 장면 전환이 만든다. 청취 후보는 현수. |
| **경쾌한 관찰형** | 생활 속 감각·사물·짧은 실험처럼 관찰의 발견이 재미인 편 | 행동과 효과가 바로 이어질 때 말도 가볍게 이어 준다. 수치나 중요한 단서가 나오면 알아들을 여백을 둔다. |

잼 편의 우선 테스트는 담담한 이야기형과 따뜻한 관찰형이다. 첫 선택을 말할 때와 실험을 해석할 때를 같은 사람의 목소리로 자연스럽게 이어갈 수 있는지 듣는다. 세 후보를 같은 대사·같은 기본 속도 설정으로 생성했고 길이는 음성마다 조금 다르다. 실제 파일은 Drive의 `영상/20261119-curiosity-choice-blindness/voice_audition`에 있다. 공개용 보이스 선정은 별도 검토다.
