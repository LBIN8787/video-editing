# 화면 소스와 사용 범위

현재는 D2용 근거·권리 확인 단계입니다. 아래의 촬영물 후보를 원본에서 가져오거나 편집하지 않았습니다. 적용할 영상 소스는 선택한 판본과 권리 조건을 D3 전에 확정합니다.

| ID | 소스 | 사용 범위와 출처 |
|---|---|---|
| S1 | 헤스퍼러스호 선장 전보 | 전사본의 관찰을 근거로 날짜·발견 사실을 자체 조판. 기관 웹페이지 디자인과 전문을 복제할 필요 없음. [북부등대위원회](https://www.nlb.org.uk/history/flannan-isles/) |
| S2 | 조지프 모어 편지 | 내용 확인과 한국어 요약 인용. 현존하는 촬영본처럼 보이지 않게 ‘편지 내용 재구성’ 표시. [북부등대위원회](https://www.nlb.org.uk/history/flannan-isles/) |
| S3 | 로버트 뮤어헤드 보고서 | 고정줄과 천 조각, 높이와 확실성 구분을 자체 도해. [북부등대위원회](https://www.nlb.org.uk/history/flannan-isles/) |
| S4 | 1898년 조감 판화 | Commons의 퍼블릭 도메인 표기를 확인했습니다. 군도 전체의 지리 도입에 사용 가능. 1900년 사건 자료나 사진으로 표시하지 않습니다. [Flannan isles.jpg](https://commons.wikimedia.org/wiki/File:Flannan_isles.jpg) |
| S5 | 영국 Ordnance Survey 지형 데이터 | OS OpenData OGL 제품의 지형·외곽선으로 직접 지도 제작. 배포 전 제품별 약관과 필요한 크레디트 문구를 기록합니다. [OS OpenData](https://www.ordnancesurvey.co.uk/products/open-data) · [OS 지도 공개 조건](https://www.ordnancesurvey.co.uk/licensing/publishing-licence) |
| S6 | 현대 실제 장소 사진 5장 | 항로 접근, 등대 정면, 등대에서 내려다보는 길, 동서 분기, 서쪽 계단이 보입니다. Chris Downer의 Geograph 2012 사진으로 CC BY-SA 2.0 후보입니다. 전용 템플릿은 이 조건을 허용하지만 공통 검사기가 해당 라이선스를 차단하므로 영상 삽입은 보류하고 현재 지형 검증에만 씁니다. [접근](https://www.geograph.org.uk/photo/3201924) · [등대](https://www.geograph.org.uk/photo/3201899) · [큰 구도](https://www.geograph.org.uk/photo/3204860) · [분기](https://www.geograph.org.uk/photo/3201940) · [서쪽 계단](https://www.geograph.org.uk/photo/3204905) |
| S7 | 세 근무자와 조사관 단체 사진 | 국가기록원 페이지 하단 권리 표기와 별도 권리자 정보를 확인한 뒤 사용 여부 확정. 사진을 확보하기 어려우면 이름과 근무를 기록에서 자체 조판. [국가기록원](https://blog.nrscotland.gov.uk/2023/12/12/flannan-isles-lighthouse-keepers-the-disappearance/) |
| S8 | 빈 침상, 등실, 난간 | 동시대 사진으로 확인된 내부가 없어 문서에 적힌 대상만 재현하거나 자체 도식화합니다. ‘재현’ 표시. 남은 사람의 행동·파도에 휩쓸리는 인물은 확정 장면으로 그리지 않습니다. [모어 편지·조사 보고서](https://www.nlb.org.uk/history/flannan-isles/) |

초안의 핵심 장면은 공개 기록의 자체 조판, 공개 지도 데이터, 직접 제작 도해로 성립합니다. 현대 장소 사진 5장의 실제 사용은 공통 검사 조건과 재사용 허락이 맞는 판본이 있을 때 확정합니다.
