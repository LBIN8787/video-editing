# 카메라 워크 초안 — 단서가 드러나는 세 구간

대본 검토용입니다. 카메라 이동의 속도와 프레임은 승인본 내레이션에 맞춥니다.

| 대사에서 등장하는 단서 | 시작 → 도착 → 정지 | 시청자가 새로 보는 것 | 소재와 구현 |
|---|---|---|---|
| “침상은 비어 있었습니다 … 위층의 램프는 깨끗했고 기름도 가득했습니다.” | 교대원 뒤에서 복도를 트래킹 → 문틀 너머 빈 침상 공개 → 위층 램프로 컷 → 램프에 잠시 멈춤 | 빈 방과 등실의 정상 상태가 같은 등대에 있음을 한 호흡으로 읽음 | 문틀·침상과 등실을 분리한 재현. 확인되지 않은 역사적 내부 구조는 생략. 램프는 불이 꺼진 상태. |
| “동쪽에서는 … 서쪽은 달랐습니다.” | 교대원이 들어온 동쪽 길 추적 → 섬 전체로 물러남 → 같은 지도에서 카메라를 서쪽으로 이동 → 서쪽 길에 정지 | 발견자가 처음 올라온 쪽과 물건이 떨어져 나간 쪽의 거리와 방향 | 공개 지형으로 만든 지도. 동쪽과 서쪽의 표시를 처음부터 같은 방향으로 고정하고, 1900년 동선은 모어의 편지가 말한 범위로 표시. |
| “줄에는 작은 천 조각이 붙어 있었습니다.” | 난간 구도 유지 → 빈 구명환 자리에서 고정줄로 초점 이동 → 천 조각에 멈춤 → 해수면이 보이는 전체 구도로 컷 | 처음의 ‘누군가 떼어 갔다’는 생각이 바뀌고, 흔적의 높이가 보임 | 보고서에 근거한 도해와 공간 재현. 34m 라인은 난간과 해수면만 연결. 파도의 모양과 세 사람의 위치는 가설로만 표시. |
| “그날 밤, 같은 등대에서 불이 다시 켜졌습니다.” | 도입의 램프에 같은 구도로 복귀 → 불이 켜지는 순간 → 위치 변화 없이 빛이 바다를 스치는 장면으로 컷 | 처음 보인 램프가 실제로 다시 작동했다는 회수 | 빛은 26일 밤을 표시하고, 15일의 사고 장면과 화면을 섞지 않음. |

실제 지형과 방향이 맞는지 공개 지도로 확인합니다. 접근 영상과 사진은 권리가 확인된 경우 삽입하고, 공간이 바뀌는 말에 맞춰 트래킹·시차·전체 공개 타이밍을 잡습니다.
