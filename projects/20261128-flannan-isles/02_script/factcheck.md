# 대본 v1 사실 확인

대조일 2026-11-28. 1900년 자료의 공개 전사, 스코틀랜드 국가기록원 소장 안내와 전시 해설을 사용했습니다. 문장별 판정은 [근거 검수표](script_review.md), 번호별 원자료는 [팩트시트](../01_research/factsheet.md)에서 확인할 수 있습니다.

| 우선 검증 주장 | 판정 | 결정 |
|---|---|---|
| 세 사람 실종, 발견 당일 램프가 다시 켜짐 | 문서 확인 | 최초 전보, 모어 편지, 조사관이 읽은 육지 관측기록을 대조했습니다. |
| 15일 저녁 정확히 불이 꺼졌고 그때 실종 | 시각 확인 불가 | 15일 아침 기록, 바다에서의 미관측, 26일 발견으로 따로 말했습니다. |
| 해수면 약 34m의 난간에 고정줄과 천 조각 | 조사관의 직접 관찰 | 110피트×0.3048=33.528m. 높이 비교는 아파트 층고에 따라 달라지는 근사입니다. |
| 세 사람이 한꺼번에 쓸려 갔다 | 당시 가장 유력한 가설 | 조사관의 설명으로 표시합니다. 정확한 위치·시각·행동을 확인할 공개 기록은 찾지 못했습니다. |
| 먹지 않은 식사, 넘어간 의자 | 후대 시에서 확인 | 시로 명시했습니다. 교대원 발견 재현에 사용하지 않습니다. |

2026년 8~9월의 국가기록원 전시는 모어 편지를 처음 공개 전시한 계기입니다. 해당 전시 해설 역시 실종 시각과 마지막 행방이 해결됐다고 발표하지 않았습니다.
