# 대본 v1 검토 기록

**상태** D2 사용자 검토 대기. 대본 자가검수 완료. 발행·영상 제작 승인은 별도입니다.

**의도** 빈 등대의 첫 발견에서 서쪽 길의 물증까지 따라가며, 세 사람에게 무슨 일이 벌어졌는지 판단할 근거를 하나씩 얻습니다.

## 구성요소

| 항목 | 반영한 위치 | 검토 |
|---|---|---|
| 콜드 오픈과 질문 하나 | 1장 첫 문단 | 빈 침상과 작동 준비가 된 램프가 동시에 등장합니다. 불의 고장이 아니라 사람의 행방을 궁금하게 합니다. |
| 알려진 것과 새 발견 | 1~4장 | 실종 자체를 넘어, 양쪽 선착장의 차이와 매듭에 남은 천이 추론을 바꿉니다. |
| 시간선과 인물의 행동 | 1~3장 | 26일 발견을 먼저 본 뒤 15일 기록으로 돌아갑니다. 날짜 전환을 문장에 알립니다. |
| 단서와 반대 근거 | 3~6장 | 손상과 옷의 상태, 기중기가 온전했던 점, 목격 공백. |
| 먼저 던진 질문 회수 | 7장 | 처음의 등실로 돌아옵니다. 가능한 설명의 범위와 남은 질문을 한 문단으로 닫습니다. |
| 일반인용 풀이 | 2·4장 | 불빛을 볼 수 있는 조건을 흐린 날 맞은편 창으로, 34m를 건물 층수로, 구명환을 용도로 설명합니다. |
| 오늘과 연결 | 2·4장 | 불빛을 못 본 것과 소등은 서로 다른 관찰이라는 일상적 예와, 현대 독자가 가늠할 수 있는 높이 기준으로 연결했습니다. |
| 인식 지도 | 1장 → 2~4장 → 5~7장 | 행방 궁금증 → 섬과 관측 환경 → 파도 흔적과 사람의 행방 사이의 차이. |

## 대본 자체 검사

- 첫 문단에서 사건의 모순과 질문이 생깁니다. 인사와 예고 없이 당대 기록을 따라갑니다.
- 시청자·질문·기존 인식·새 발견·근거·결말은 주제 카드, 시청자 문서, 의도, 팩트시트에 연결했습니다.
- 원인에 가까워지는 단서가 장마다 추가됩니다. 후반에서 가능한 설명과 관측이 닿지 않는 곳을 함께 읽습니다.
- 사실 대조는 공개 전사와 기관 문서로 했습니다. 서신철 전체 및 등대 일지 실물은 직접 열람하지 않았습니다. 내레이션 길이는 낭독 뒤에 실측합니다.
- 검토할 핵심은 도입에서 모순이 바로 느껴지는지, 천 조각이 등장할 때 수사가 실제로 전진한다고 느껴지는지입니다.
