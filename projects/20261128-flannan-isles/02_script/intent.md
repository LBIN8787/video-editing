# 플래넌 제도 등대 실종 제작 의도

목적: 즐길거리형. 기록을 따라가며 관객이 무엇을 의심할지 장마다 바뀌는 역사 미스터리.

- **왜 보는가** 교대원이 도착한 텅 빈 등대에서 이상한 점을 먼저 발견하고, 범위가 좁아지는 경험이 재미입니다.
- **끝까지 무엇을 따라가는가** 불을 켤 준비가 된 날 마지막으로 어떤 일이 있었는가. 모어의 발견, 육지 관측 기록, 뮤어헤드의 현장 조사 순서로 이동합니다.
- **보고 나면 무엇이 남는가** 파도는 시설의 손상을 설명하지만, 세 사람이 함께 그 길에 있었다는 것은 확인되지 않았습니다.

| 장 | 장이 끝나면 이해하는 것 | 화면 역할 |
|---|---|---|
| 빈 방, 준비된 불 | 교대를 맞아야 할 세 사람의 부재와 등실의 정상 상태 | 발견을 동행 |
| 빛이 보이지 않은 날 | 불빛을 놓친 날과 실제로 사람이 사라진 날의 차이 | 시간과 관찰 위치 파악 |
| 같은 섬, 두 선착장 | 발견자가 들어온 길과 손상이 집중된 길이 다름 | 지리와 수색 방향 이해 |
| 고정줄에 걸린 천 조각 | 사라진 장비보다 남은 흔적이 더 많은 것을 말함 | 증거를 가까이 보고 전체 위치를 회수 |
| 있는 옷, 없는 옷 | 세 사람의 위치는 각자 남긴 물건만으로 확정하기 어려움 | 직접 대조 |
| 가장 그럴듯한 설명 | 큰 파도 가설이 설명하는 것과 빠진 증거 | 가설 검토 |
| 다시, 등실 | 첫 장면과 돌아온 불빛을 바라보며 남은 질문을 회수 | 수미상관 |

기억할 한 장면은 기름을 채워 둔 램프 곁에 불을 붙일 사람이 없는 등실입니다. 옷과 난간은 누가 어디에 있었는지 따져 볼 단서로 사용합니다.
