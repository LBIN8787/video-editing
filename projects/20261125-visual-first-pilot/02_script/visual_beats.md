# 그림 비트표 — 시각 먼저 시범 (2026-11-25)

> 같은 내용을 두 방식으로 만들어 비교합니다. 대상: 「'품절 임박'을 보면 왜 손이 먼저 나갈까」(20261123-curiosity-soldout) **3장 '눈앞에서 줄어든 병' 앞부분**.
> A판 = 이미 렌더된 대본 먼저 판(완성본 2:32~3:27). B판 = 이 문서 → 대본 → 렌더.
> 이 표는 **내레이션 문장을 쓰기 전에** 썼습니다. 칸마다 화면의 상태만 적고, 말은 적지 않습니다.

## 0. 이 장면이 끝나면 시청자가 화면에서 짚을 수 있어야 하는 것 (주장)
같은 두 개인데, **처음부터 적었던 병**과 **눈앞에서 줄어든 병**의 값표가 다르다. 맛 막대는 셋 다 같다.
→ "적어서"가 아니라 **"줄어드는 걸 봐서"** 더 원한다. 지우의 화면(5 → 3)도 '줄어드는 중'이다.

근거: 팩트시트 F3(숨은 버튼)·F4(병째 바꿈, 조건)·F7(맛 차이 없음)·F8(값 평균: 처음부터 10개 46.2¢, 처음부터 2개 45.8¢, 수요로 줄어든 2개 71.5¢ — 경쟁자 많다는 조건, 1파운드당 센트, 조건당 10~12명, OCR 판독).

## 1. 주인공 사물
병 세 개(같은 모양·같은 크기·같은 줄). 새 그림을 그리지 않고 이 셋 위에 값표·맛 막대·표시만 붙인다(E2). 지우의 휴대전화는 앞뒤를 잇는 다리.

## 3. 대본을 붙일 때 지킬 것
- 한 비트에 한 문장(길면 둘). 화면이 바뀌는 순간의 낱말을 `t`(말하는 순간 맞춤)로 적는다.
- 화면에 없는 정보를 말로 늘어놓지 않는다. 말은 화면이 못 하는 것만: **누가·왜·어떤 조건이었나**.
- 숫자는 화면에 이미 있으므로 말은 '거의 같았다 / 훌쩍 뛰었다'로 방향만. 단위·조건은 화면 아래 주석으로.
