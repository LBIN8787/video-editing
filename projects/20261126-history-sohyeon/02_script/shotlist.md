# 장면 기획 (S5) — 소현세자의 죽음, 대본 v2 기준

> 역할: 이야기 = 삽화(한 편 한 화풍) · 설명 = 그 삽화 위 움직임·지도 · 증거 = 실제 자료 · 마디 = 검은 화면 한 줄 (04 §0-7)
> 미스터리 표지(docs/75 §2): **사건 파일 보드** — 단서가 나올 때마다 종이 파일 위에 사진·문서 조각이 핀으로 꽂히고 ✅ 기록 / 🔍 해석 / 💭 전해지는 이야기 도장. 장 제목 "단서 ○ — …"은 화면에만.
> 재현 삽화에는 화면 구석 '재현' 표시. 실제 자료는 라이선스 확인한 것만(`04_assets/` 출처 기록).
> **화풍은 샘플 4칸(A안)·2칸(B안)을 사용자가 고른 뒤 확정** — 그 전에는 나머지 원화를 그리지 않는다(04 §0-7).
