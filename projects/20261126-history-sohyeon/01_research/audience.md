# 시청자 — 소현세자의 죽음

근거: [docs/73](../../../docs/73-history-channel-plots.md)(역사 채널 59곳·터진 영상 420편), [docs/74](../../../docs/74-history-topic-candidates.md)(주제별 성과·자동완성·댓글·검색 경쟁).

| 항목 | 이 영상 |
|---|---|
| 주 시청자 | 사극·역사 예능으로 '소현세자'라는 이름은 들어 본 30~60대. 밤에 긴 영상을 틀어 놓고 보는 사람(역사 채널 댓글: "영화 한 편 본 느낌", "77살인데 재미있다") |
| 유입 경로 | 검색('소현세자 독살·죽음') + 추천(사극·역사 예능을 본 뒤 옆에 뜸). 검색 상위가 TV 클립이라 **제목 앞은 검색되는 이름, 뒤는 장면** |
| 유입 이유 | "독살이라던데 진짜야?" — 소문 확인 + 그날 그 자리의 장면 |
| 끝까지 보는 이유 | 결론을 시청자 손에 쥐여 줌(청화수 을지문덕 편 최다 공감 댓글: "누군가 의도적으로 지운 것"). 가족이 하나씩 지워지는 이야기의 감정 |
| 다시 볼 곳 | 실록의 시신 묘사(1장·5장), 강빈과 아이들의 처분(6장, 60~70% 지점) |
| 하지 않을 것 | 독살 단정, 인조 악마화, 드라마·영화 장면을 사실처럼, 교과서식 연표 낭독, 인사·채널 소개 인트로 |
| 제목 후보 | ① 소현세자의 죽음 — 일곱 구멍에서 피가 흘렀다 ② 청나라에서 돌아온 지 두 달, 세자는 왜 죽었나 ③ 1645년 창경궁, 조선 왕가 최초의 의문사 |

## 인식 지도 (13 §1-1)
| 칸 | 시청자가 | 대본에서 |
|---|---|---|
| 모르는 것 | 세자가 심양에서 실제로 무엇을 했는지(인질이자 외교관·농장 경영), 1644년 베이징에서 명이 무너지는 현장에 있었다는 것 | 2장·3장 |
| 궁금한 것 | 진짜 독살이었나? 누가? | 5장·7장 — 기록이 말하는 것/아닌 것을 나눠서 |
| 오해하는 것 | '독살이 확정된 사실'이라는 생각(예능·드라마 영향), 반대로 '서양 문물 때문에 죽었다'는 단순화 | 7장: 병사 해석도 1차 기록(승정원일기)에 근거가 있다 |
