# 제작 의도

목적: 즐길거리형

**제작 목표** · "내 줄만 느리다"는 억울함이 눈의 착각이기도 하고 실제이기도 하다는 것을, 마트 계산대와 도로의 실사 위에서 두 연구를 따라가며 알게 한다. 끝나면 "내 눈은 앞질러지는 순간만 오래 본다"와 "나는 촘촘한 줄에 서 있을 확률이 높다"를 구별할 수 있다.

**기억할 한 장면** · 카트를 옮기자마자 방금 떠난 줄이 움직이는 순간. 처음(장 1)과 끝(장 8)에 같은 계산대 구도로 나오고, 끝에서는 카트를 돌리지 않는다.

**시청자 경험** · "나도 그랬는데"(끌림) → 실험 결과 열에 일곱이 틀렸다(따라감) → 6분과 1분 막대로 '아 그래서'(깨달음 1) → 반론, 촘촘한 줄 점 그림으로 '어? 진짜였네'(깨달음 2) → 두 답이 다른 것을 말한다 → 계산대로 돌아와 줄을 바꾸지 않음(연결).

**이야기의 흐름 고르기 (04 §0-6)** · '실험이 남긴 질문을 따라간다'. 첫 연구가 "착각이다"를 보여 준 뒤에도 "그럼 정말 내 줄이 느린 적은 없나?"가 남는다. 이 질문이 보스트롬의 반론으로 넘어가는 다리다. 반론은 첫 답을 지우지 않고 다른 층(서 있는 자리)을 말하므로, 장 7에서 둘을 나란히 놓고 장 8에서 계산대로 돌아온다. 연구를 빼면 '착각이니 참아라'로 끝나 버려 반전이 없다.

| 장 | 다 보고 나면 | 화면 (D3 에서 확정) |
|---|---|---|
| 금요일 저녁, 계산대 | 같은 억울함을 떠올리고 질문을 품는다 | 실사: 계산대 줄·카트, 초 세기 콜아웃 |
| 도로 위에서도 | 도로에서는 위험까지 걸린 문제임을 안다 | 실사: 정체 도로·차선 변경 |
| 토론토의 영상 | 열에 일곱이 실제와 반대로 판단했다 | 재구성 삽화(교육생이 영상 보기) + 100명 점 그림 70% |
| 6분과 1분 | 같은 속도여도 앞질러지는 시간이 길다 | 설명 무대: 두 차선 점, 시간 막대 6분 vs 1분 12초 |
| 잃는 쪽이 더 크게 | 손실이 더 크게 느껴진다 | 저울(손실/이득) 모션그래픽 |
| 그런데, 정말 착각일까 | 느린 줄은 촘촘해서 내가 거기 있을 확률이 높다 | 설명 무대: 촘촘한 차선 vs 듬성한 차선, 6명 중 5명 |
| 두 사람이 모두 옳다면 | 보이는 것과 서 있는 자리를 구별한다 | 검은 화면 두 칸 나란히 |
| 다시, 계산대 | 줄을 바꾸지 않아도 되는 이유 | 실사: 같은 계산대 구도, 줄이 한 칸 앞으로 |
