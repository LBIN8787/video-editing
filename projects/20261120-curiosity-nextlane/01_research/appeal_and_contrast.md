# 왜 흥미로운가 · 비슷한 채널과 무엇이 다른가 (2026-11-20)

근거: 같은 주제 영상 조사 [`benchmark.md`](benchmark.md)(vidIQ 조회수·길이·설명란, 자막은 크레딧 소진으로 못 받음), 호기심 채널 20곳 조사 [`docs/47`](../../../docs/47-curiosity-channel-benchmark.md), 시청자 조사 [`audience.md`](audience.md).
표시: ✅ 수치·설명란·챕터로 확인 · 🟡 채널의 알려진 형식이나 제목에서 미루어 본 것(영상을 재생해 보지 않음).

## 1. 사람들은 이 주제에 왜 흥미를 느낄까

| 끌림 | 시청자의 마음 | 근거 |
|---|---|---|
| **누구나 겪은 억울함** | "나만 그런 줄 알았는데" — 마트·은행·도로에서 매주 겪는다. 원래 궁금하지 않았는데 제목을 보는 순간 떠오른다(호기심 채널의 유입 방식, docs/29) | 같은 질문의 쇼츠가 2026년 9~11월에만 국내외 20편 넘게 올라옴 ✅ — 만드는 사람이 많다는 건 반응이 있다는 신호 |
| **내 탓도, 운 탓도 아니라는 위로** | 줄을 잘못 고른 내 판단이 문제였나? → "눈이 그렇게 보도록 되어 있다"는 답은 자책을 덜어 준다 | 쇼츠 제목들이 "착각"·"내 줄만"을 앞세움 ✅ |
| **실용적인 질문: 바꿔야 하나?** | 지금 옆 줄로 옮길까 말까 — 답이 내일 바로 쓰인다 | 같은 주제에서 가장 큰 한국 반응은 '실제로 바꾸면 빨라지나' 실험(픽플러스 39.6만, 댓글 1,862) ✅, 해외도 MythBusters 실험 165만 ✅ |
| **반전이 두 번 있는 지적 놀이** | "착각이래" → "아니, 진짜래" → "둘 다 맞대" — 친구에게 "이거 알아?" 하고 말할 거리 | 보스트롬 반론까지 간 한국어 영상은 33초·53초 쇼츠 2편뿐 ✅ — 아직 흔하지 않은 이야기 |
| **내 눈·마음이 속는다는 놀라움** | 같은 영상을 보고 열에 일곱이 반대로 판단 — "나도 그랬겠네" | Nature 1999 의 실험 장면(F1~F3) |

**정리:** 끌림은 '익숙한 억울함'에서 오고, 끝까지 보게 하는 힘은 '두 번의 반전'과 '바꿔야 하나'라는 실용 질문에서 온다. 반대로 위험은 **"착각이다"라는 답 자체는 이미 흔하다는 것** — 첫 30초에 '반론이 있다'는 갈림을 예고해야 넘겨지지 않는다(benchmark §6-2).

## 2. 같은 주제의 고조회 영상과 대조

| | engineerguy (125만, 3:43) | MythBusters (165만, 4:11) | 픽플러스 (39.6만, 9:23) | EasyExplain (19만, 1:48, 쇼츠 경계) | **우리 (11~12분 예정)** |
|---|---|---|---|---|---|
| 질문 | 왜 다른 줄이 빠를까 | 차선을 바꾸면 빠를까 | 끼어들기 vs 한 차선 | 왜 옆 차선이 빠를까 | 왜 옆 줄이 빨라 보일까 |
| 답의 각도 | 대기 이론·한 줄 서기(시스템) ✅ | 실험: 바꾼 쪽이 조금 빨랐다(2~25%) ✅ | 직접 운전 실험 ✅ | 유령 정체의 물결 ✅ | **눈의 착각(Nature 1999) → 실제로 느린 줄에 있을 확률(보스트롬) → 둘 다** |
| 대본 진행 | 전화 회사 문제 → 줄 설계 → 해법 ✅(설명란) | 신화 → 경주 → 판정 🟡 | 질문 → 두 차 경주 → 결과 🟡 | 질문 → 원리 → "바꿔도 별 차이 없다" ✅ | 장면(계산대) → 질문 → 실험 → 원리 → 반론 → 정리 → 같은 장면으로 돌아옴 |
| 반전 | 없음 🟡 | 끝의 판정 🟡 | 결과 공개 🟡 | 없음 🟡 | **두 번** (장 5 끝, 장 6) |
| 화면 | 진행자 + 도식 🟡 | 차 안 카메라·판정 자막 🟡 | 실제 주행 촬영 🟡 | 애니메이션 🟡 | 생활 실사 B-roll + 그 위 모션그래픽(줄 판·초시계·시간 막대) |
| 사람 | 진행자 얼굴 | 진행자 얼굴 | 진행자·차 | 없음 | 얼굴 출연 없음, 내레이터 |

**차이:** 고조회 영상은 '실제로 빨라지나'를 **직접 재 보거나(실험) 시스템으로 설명**한다. 우리는 실험을 직접 하지 않는 대신 **연구 두 편이 부딪히는 이야기**와 **실사 위에서 재 보는 화면**(초시계 두 개)으로 대신한다. "바꾸면 빨라지나"의 답(장 7)을 분명히 두어야 이 수요를 받는다.

## 3. 호기심 장르의 대표 채널과 대조 (편집 방법·대본)

| | 심리학 고양이 | 사물궁이 잡학지식 | EBS 지식채널e | Sprouts | Veritasium | **우리 (v60·v61 기준)** |
|---|---|---|---|---|---|---|
| 첫 30초 | 시청자를 장면 안에 세우는 문장 + 질문 ✅(docs/47) | 질문형 제목 그대로 🟡 | 일상 실사 + 가운데 짧은 글 ✅(references) | 문제 제기 🟡 | 예측을 시키고 뒤집기 🟡 | 계산대 장면(때·곳·사람) → 질문 하나, 인트로 없음 |
| 대본 말투 | 차분한 해설, 연구자 이름·연도 | 짧고 귀여운 설명 | 시처럼 짧은 문장 | 교과서식 설명 | 진행자 1인칭·대화 | 3인칭 다큐 '~습니다' (README §2-3) |
| 이야기 뼈대 | 장면 → 실험 → 이론 이름 → 내 삶 ✅ | 질문 → 답 🟡 | 장면 나열 → 한 줄 메시지 🟡 | 실험 순서 = 칸 순서 ✅ | 직접 실험·현장 🟡 | 장면 → 실험 → 원리 → 반론 → 수미상관 |
| 화면의 주인 | 한 편 한 화풍 일러스트 + 흑백 실제 사진 ✅ | 칠판 바탕 + 마스코트 ✅ | 실사 + 핵심어 ✅ | 칸 만화 ✅ | 진행자·실험 촬영 🟡 | **실사 B-roll + 모션그래픽**, 삽화는 기록 없는 실험 장면만 |
| 정리 장면 | 검은 화면 한 줄·번호 목록 ✅ | 마스코트 요약 🟡 | 검은 화면 한 줄 ✅ | 마지막 칸 🟡 | 진행자 결론 🟡 | 검은 화면 질문 한 줄, 장 7 두 칸 정리 |
| 배경음 | 잔잔한 음악 🟡 | 경쾌한 음악 🟡 | 피아노 🟡 | 음악 🟡 | 적음 🟡 | **없음** (2026-11-20 사용자) |

**차이:**
- 심리학 고양이·사물궁이·Sprouts 는 **그림이 이야기를 끌고** 간다. 우리는 v60 부터 **실제 사람이 나오는 짧은 실사**가 상황을 맡고, 그래픽은 숫자·관계만 맡는다 — 지식채널e 에 가깝지만, 지식채널e 가 글 한 줄로 끝내는 곳에서 우리는 그래픽으로 **재 보고 세어 본다**(줄 판, 초시계, 시간 막대).
- 대본은 심리학 고양이의 '장면 → 실험 → 내 삶'과 같은 뼈대에, Veritasium 식 '뒤집기'를 **두 번** 넣은 것이 다르다.

## 4. 우리가 약한 곳 (솔직하게)

| 약점 | 왜 | 대응 |
|---|---|---|
| '계산대 줄' 실사가 없음 | 무료 스톡(Mixkit)에 줄 선 계산대 클립이 없다 | 줄 상황은 줄 판(그래픽)이 맡음. Pexels·Pixabay 키를 등록하면 선택지가 늘어남 |
| 도형만으로 그린 장면이 싸 보임 | v1 의 두 차선 장면(사각형 차) — 사용자 판정 "허접" | v2 에서 **실제 도로·운전석 실사 위 초시계 두 개**로 교체. 도형 장면은 설명이 꼭 필요한 곳(시간 막대)만 |
| 직접 실험이 없음 | 얼굴·촬영 없는 채널 | 실험 장면을 재구성 삽화로(장 3), 화면 위에서 직접 재 보는 장치로 대신 |
| 길이 | 같은 질문의 고조회 영상은 2~9분 ✅ | 매뉴얼 기준(롱폼 10분 이상) 유지 여부는 사용자 결정 |
| 목소리 | 초안 edge-tts | 최종은 ElevenLabs |
