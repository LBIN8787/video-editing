## 사실과 해석 대조 (13 §4)

| 확인 | 대본에서 |
|---|---|
| 창작 재현 구분 | 지우는 창작 인물 — 설명란·장면표에 표시 (화면 꼬리표는 두지 않음, 04 §0-8) |
| 시료의 범위 | MIT 시료는 프리베르눔 유적 — 4장 끝 한 문장으로 "판테온 돔도 이렇게 메워졌는지는 아직 확인되지 않았다". 1장·6장 답에서도 '판테온이 메웠다'가 아니라 '로마의 콘크리트는 메울 재료를 품고 있었다' |
| 원인 단정 | 균열 원인은 "가능성이 크다고 봅니다"(2018 수치 모의) |
| 강도 비교 | "로마 콘크리트가 더 강하다" 쓰지 않음, 6장에서 반대로 밝힘 |
| 수치 | 43m·6m/1.2m·80%·2주·609년·1600년대 — 팩트시트 F1~F17 에 있음. 연대는 '약 1,900년'(126/128년 자료 차이) |
| ⚠️ 2차 자료만 | 치수(F1·F4·F5), 80%(F6), 609년(F13), 청동·대포(F14 — "전해집니다"), 라파엘로(F15). 장면표 전에 원 자료 대조 |

## 검토 질문 (사용자)
1. 창작 인물 지우(주차장 녹물 → 로마 여행)로 끌고 가는 방식이 괜찮은가, 아니면 실존 인물(마시치 교수 등) 중심이 나은가.
2. 이 편의 '아 이래야겠구나'는 생활 처방 대신 관점(금이 가도 버티게, 계속 쓰이게)으로 두었다 — 이대로 괜찮은가.
3. 5장(교회 전환·청동 대포)이 재료 이야기 흐름에서 벗어나 보이는지.
