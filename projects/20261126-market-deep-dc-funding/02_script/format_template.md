# 시장 심층 분석 — 합친 틀 (아이스먼 편 + 칩을 사는 쪽의 지갑 편, 2026-11-26)

사용자 요청: "두 템플릿을 보완해서 작성하시고 큰 숫자 코르크판은 최대한 사용 안했으면 해요 차라리 실제 자료가 나은거같아요"

## 1. 뼈대 (드러켄밀러 틀, 09 §5-00)
| 순서 | 장면 | 어디서 왔나 |
|---|---|---|
| 여는 30초 | 원본 발언 영상 (사는 쪽 결론) → 원문 자료 화면 (그 말의 크기) → 원본 발언 영상 (맞서는 결론) → 두 의견 맞대기 → **한 줄 결론 글자** | 아이스먼: 한 줄 결론 / 이번 영상: 원문 자료·맞대기 |
| 각 장 | 어두운 누아르 장 표지 → 근거(원문 자료·그래프·체크리스트) → 사람의 말(원본 영상·인용 카드) | 둘 다 |
| 끝 | 틀릴 수 있는 경우 → 다음에 볼 숫자 → **한 줄 결론 글자** → 마무리 | 아이스먼: 닫는 한 줄 |

## 2. 장면 고르기
| 하는 일 | 쓴다 | 되도록 안 쓴다 |
|---|---|---|
| 숫자 하나를 보여 줄 때 | **원문 자료 화면** (보도자료·공시·기사 줄에 빨간 상자) | 큰 숫자 화면(bignum) — 원문이 없을 때만 체크리스트 한 줄로 |
| 장 표지 | 어두운 누아르 카드 | 코르크판 |
| 돈·관계의 흐름 | 검은 배경 카드 그림 (motionboard) | 코르크판 인과 지도 |
| 두 값 이상 비교 | 먹색 그래프·표 (dark-doc) | 흰·연회색 표 |
| 목록·조건 | 베이지 종이 체크리스트 (newsprint) | 남색 기본 바탕 |
| 사람의 말 | 원본 발언 영상 → 없으면 인용 카드 (번역 + 원문) | 말을 큰 숫자로 바꾸기 |
| 결론 | 한 줄 글자 (kinetic) 여는 곳·닫는 곳 각 1 | — |

## 3. 말 (문구)
- 은유 말고 주어 + 직관적 주장: "AI 투자는 몇 년 뒤 돈 된다" vs "빅테크는 이제 빚으로 짓는다"
- 맞대기·썸네일·제목이 같은 말을 씀
