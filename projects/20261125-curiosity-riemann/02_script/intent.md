# 의도 — 아무도 읽을 수 없는 증명

**유형:** 호기심 · 인지과학·연구 논쟁형(13 §6: 통념 → 실험 → 반론 → 후속 검증 → 결론의 범위) + 인사이트 영상(11 §3-3). 주인공 = 리만의 한 문장(1859)과 그 문장의 167년.
**목적 분간:** 즐길거리형 + 정보 습득. 끝나면 시청자는 리만가설이 무엇인지 한 줄로 말할 수 있고, 'AI 가 풀었다'는 뉴스를 '맞다 ≠ 이해했다'로 읽는다.
**기억할 한 장면:** 같은 날 두 증명 — 쌓인 940쪽 종이 탑과 끝없이 흘러내리는 1,700만 줄 코드(R7).
