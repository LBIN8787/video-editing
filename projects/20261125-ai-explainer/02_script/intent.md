# 의도 — AI 가 다음 AI 를 만들기 시작했다

**유형:** AI 롱폼 · 기술·산업 트렌드 + 원리 해설(11 §3-1, 레퍼런스 3Blue1Brown docs/70). 중심축 = **고리 그림 하나**(연구 → 모델 → 더 나은 모델)의 칸이 하나씩 AI 로 바뀌는 흐름.
**목적 분간:** 정보 습득형. 시청자가 얻는 것: '스스로 똑똑해지는 AI' 뉴스를 들었을 때 어디까지가 사실이고 어디부터가 전망인지 가르는 눈.
**제작 목표 한 줄:** 회사가 낸 숫자와 회사가 스스로 붙인 단서를 같은 화면에 놓고, 고리의 어느 칸이 아직 사람 손에 있는지 보여 준다.
**기억할 한 장면:** 고리 그림에서 사람 손 아이콘이 칸마다 하나씩 빠지다가, 마지막 칸('문제 고르기·채점')에만 남아 있는 장면.

## 쓰기 전 여섯 가지
| 질문 | 답 |
|---|---|
| 시청자 | `01_research/audience.md` |
| 질문 | AI 가 다음 AI 를 만든다는 건 어디까지 사실일까? |
| 기존 인식 | AI 가 코드 대부분을 짠다 |
| 새로운 발견 | 숫자마다 회사가 붙인 단서, 고리의 마지막 칸은 아직 사람, 바깥 연구자의 시간표(2028 중앙값)와 반론 |
| 근거 | `factsheet.md` A1~A9, B1, C1~C5 |
| 결말 | 이런 뉴스를 '닫힌 고리냐, 짧아지는 손이냐'로 읽게 된다 |
