# 제작 의도

목적: 즐길거리형

**제작 목표** · 매일 하는 '넘기기'가 지루함을 피하는 방법이 아니라 키우는 원인일 수 있다는 것을 두 실험(빈 방의 전기 충격, 한 편 vs 일곱 편)으로 따라가며 알게 한다. 끝나면 "지루해서 넘겼는데, 넘겨서 지루했다"를 내 손가락의 일로 느낀다.

**기억할 한 장면** · 새벽 한 시, 불 꺼진 방에서 화면을 밀어 올리는 엄지. 처음(장 1)에는 멈추지 않고, 끝(장 8)에서는 멈춘다.

**지금의 고리** · 『트렌드 코리아 2027』 '권태사회'(장 2) — 입구로만 쓰고 본론은 실험.

**시청자 경험** · "나도 방금 그랬는데"(끌림) → 전기 충격을 고를 만큼 지루함이 싫다(따라감) → 열에 여덟은 넘기면 나을 거라 믿었다 → 넘긴 쪽이 더 지루(깨달음) → 주의와 의미가 끊긴다(납득) → 모두에게 그런 건 아니다(정직) → 엄지가 멈춘다(연결).

**이야기의 흐름 고르기 (04 §0-6)** · '실험이 남긴 질문을 따라간다'. 빈 방 실험이 "사람은 지루함을 피하려고 아픔까지 고른다"를 보여 주면 "그럼 요즘 우리가 피하는 방법은 괜찮은가?"가 남는다 — 이것이 2024 실험으로 넘어가는 다리. 2024 실험 안에서도 "지루하면 넘긴다 → 넘기면 나아질까?"로 질문이 이어진다. 빈 방 실험을 빼면 '왜 그렇게까지 넘기는가'의 무게가 사라진다.

| 장 | 다 보고 나면 | 화면 (D3 에서 확정) |
|---|---|---|
| 새벽 한 시 | 방금 내가 하던 행동이 질문이 된다 | 실사: 어두운 방·넘기는 엄지(얼굴 없음), 넘긴 횟수 카운터·흐르는 시계 |
| 즐길 거리가 넘치는 권태 | 지금의 고리, 두 가능성 | 실사: 지하철·카페에서 화면을 보는 사람들(뒷모습), 키워드 한 줄 |
| 아무것도 없는 방 | 지루함이 아픔보다 싫을 수 있다 | 재구성 삽화(빈 방·버튼), 18명 중 12명·24명 중 6명 점 그림, 190 카운트 |
| 지루하면 넘긴다 | 지루하면 넘기고, 넘기면 나을 거라 믿는다 | 넘긴 횟수 4 vs 8, 열에 여덟 점 그림 |
| 한 편과 일곱 편 | 넘긴 쪽이 더 지루 | 10분 타임라인 두 줄(한 덩어리 vs 잘게 잘린 일곱 칸), 7점 척도 막대 |
| 넘길 때 사라지는 것 | 주의·의미가 끊긴다 | 실사 위 '빠져드는 막대'가 차오르다 넘길 때마다 0으로 |
| 모두에게 그럴까 | 한계를 안다 | 실사: 다양한 연령, 검은 화면 한 줄 |
| 다시, 새벽 한 시 | 엄지가 멈춘다 | 처음과 같은 실사 구도, 카운터 멈춤 |
