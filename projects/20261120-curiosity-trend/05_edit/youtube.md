# 유튜브 업로드 묶음 — 넘기기 편

## 제목 (1번이 올라감)
1. 볼 게 이렇게 많은데, 왜 넘길수록 더 지루할까?
2. 못 넘기는 영상 한 편 vs 넘길 수 있는 일곱 편, 더 지루했던 쪽은?
3. 지루해서 넘겼는데, 넘겨서 지루했다
