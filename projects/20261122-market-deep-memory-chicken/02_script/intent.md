# 의도

- **제작 목표:** 앞 편 질문 '왜 손해 보면서도 다 파나'에 원리로 답한다.
- **시청자 욕망:** 메모리 주식의 큰 흔들림을 구조로 이해해 다음 소식(감산·계약)을 스스로 읽고 싶다.
- **기억할 한 장면:** 세 회사 매출 막대 — 혼자 줄여도 920→1,320, 그런데 경쟁사는 1,460.

| 장 | 출발점(인식 지도) | 다 보고 나면 새로 아는 것 |
|---|---|---|
| 0 | 질문 + 흔한 생각 셋 | 오늘 고칠 세 생각 |
| 1 | 오해: 5%면 5% | 메모리는 둔감해서 몇 %가 몇 배, 10% 과잉이면 1/4·원가 바닥 |
| 2 | 오해: 적자면 바로 줄인다 | 혼자 줄여도 이익이지만 치킨 게임, 감산이 늦는 네 이유 |
| 3 | 오해: 두 배 = 과잉 | 위험은 과잉이 아니라 5%p 예측 오차, 짓지 않아도 느는 공급 |
| 4 | 궁금: 해법은? | 장기 계약과 그 한계, 다음 소식을 읽는 네 가지 |
