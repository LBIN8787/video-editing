# 이미지 목록 — 대본보다 먼저 확인할 것 (docs/71 §4-3 '자산 먼저')

장면마다 이미지 1개 이상. 실 = 실제 사진·문서·화면(출처·라이선스 표기), 그 = 생성 그림 사물(Codex 구독, 메모리 image-gen-gpt), 재 = 재구성(화면에 '재구성' 표시).

| 장 | 이미지 | 종류 | 구할 곳 · 라이선스 |
|---|---|---|---|
| 1 | 외젠 드 보아르네 초상 | 실 | 위키미디어 공용(19세기 회화, 퍼블릭 도메인) — `python -m ytflow archive commons "Eugène de Beauharnais"` |
| 1 | 마르몽 장군 초상 | 실 | 위키미디어 공용(퍼블릭 도메인) |
| 1 | 밀랍 봉인 편지 · 말 탄 전령 · 자료실 서랍 · 모래시계 | 그 | 생성 — 종이 콜라주 화풍, 같은 그림체 |
| 1 | 숫자로 가득한 편지 | 재 | 생성 + '재구성' 표시 (원본 스캔 권리 미확인) |
| 2 | 처치 공개 기록 페이지 · 크립티아나 목록 | 실 | 공개 웹 화면 캡처(출처 표기) |
| 2 | 1809년 유럽 지도 | 실 | 위키미디어 공용 역사 지도(퍼블릭 도메인) |
| 2 | 노트북 앞 실루엣 · 네 단계 작업대 · 도장 | 그 | 생성 |
| 3 | 열쇠 꾸러미 · 자물쇠와 열쇠 더미 · 'e'에서 갈라지는 숫자 | 그 | 생성(예시 표시) |
| 4 | 에니그마 기계 · 블레츨리 파크 · 앨런 튜링 · 봄브 복원 기계 | 실 | 위키미디어 공용(CC BY-SA 등, 표기) |
| 5 | 슈나이어 블로그 화면 | 실 | 공개 웹 화면 캡처 |
| 5 | HMS 캔터베리 사진 | 실 | 위키미디어 공용/IWM — 라이선스 확인 |
| 6~8 | 저울 · 열쇠 건네는 손 · 달력 · 기계 손 · 서랍이 열리는 자료실 · 인용 쪽지 | 그 | 생성 |
- 실제 인물 얼굴은 역사 인물 초상(퍼블릭 도메인)만. 처치·도모키요는 사진을 쓰지 않음(실루엣·이름).
- 바탕: 구겨진 종이(`crumpled-paper`) + 장 사이 검은 종이. 움직임은 역할별 속도(등장 0.2~0.4초 · 강조 0.6초 · 과정 1~3초는 필요할 때만 · 카메라는 계속), 같은 움직임 세 번 연속 금지.
