## 꼭 고칠 것

1. **#23 (3장 L49) '27명이 보는 중'을 '남들이 가져가고 있다'로 실험에 짝지음** — 실험에서 효과가 있던 '남들'은 이미 먹은 사람들(수요), '지금 보는 사람·앞으로 올 경쟁자' 조건은 효과가 없었고 값에선 반대(F6 e, 쓰면 안 되는 것 3). 지우 화면 문구를 수요형('방금 5명이 구매' 등)으로 바꾸거나, '27명이 보는 중'은 실험에 없던 장면이라고 떼어 놓기.
2. **#43 (5장 L79) ◇ "알아채는 순간 줄어드는 숫자는 힘이 빠졌던 겁니다"** — 13명이 알아챈 건 가설(서두르게 한다는 것이 아님), 저자는 '비협조적 반응'으로 해석, 결과는 유의하지 않음. 저자 해석을 먼저 말하고, '줄어든 병이 더 좋아 보이는 일이 일어나지 않았다' 정도로 줄이기.
3. **#42 (5장 L77) "방향은 뚜렷했습니다"** — 유의한 결과 없음. "방향만 거꾸로였습니다".
4. **#50 (6장 L95) "서두를 이유가 없습니다 / 더더욱 없습니다"** — 할인·재고가 진짜인 경우엔 틀리고(4장 L67과 부딪힘), 비권유로 읽힘(쓰면 안 되는 것 12). 결정을 숫자 탓/내 선택으로 구분하는 문장으로.
5. **#47 (5장 L87) 소비자원 주의사항에 연도 없음** — F35 는 2021-11-25 게시물. "2021년 블랙프라이데이를 앞두고", '같은 줄' → '비슷한 당부'(쓰면 안 되는 것 13).
6. **#8 (2장 L25) "바로 이 장면이었습니다"** — 🎮의 '두 병 나란히 고르기'와 실제 절차(학생마다 병 하나, 맛본 뒤 평점)가 다름.
7. **#11 (2장 L31) "맛 점수는 달랐습니다. … 차이가 전혀 없었습니다"** — 앞 절이 귀로는 '맛 점수가 달랐다'로 들려 사실과 정반대. "맛 점수는 어땠을까요. 어느 병이든 맛 평가는 달라지지 않았습니다".
8. **#19 (3장 L41) "탁자 밑의 버튼"** — 팩트시트는 '숨은 버튼'까지. '탁자 밑'은 근거 없음 → "숨겨 둔 버튼".

## 고치면 좋은 것

1. **#6 (1장 L19) "갖고 싶은 건 패딩이 아니라 사라지고 있는 기회"** — 실험은 물건(쿠키) 자체를 더 원하게 됨을 보임. "패딩을 가질 기회가 줄어드는 것처럼 보인다는 것" 쪽으로.
2. **#53 (6장 L101) 마지막 ⬛ "기회가 줄어드는 걸 봤기 때문입니다"** — 실험은 평점·값을 쟀지 '손이 나가는' 구매가 아님, 원인 단정. "~아닐 수 있습니다 / 줄어드는 걸 보는 것만으로도 같은 물건이 더 좋아 보이기 때문입니다".
3. **#24·#25 (3장 L51)** — 반발 이론은 '자유를 되찾으려 해 물건이 더 좋아 보임'; 수요>실수 결과의 저자 풀이(편승 추론)가 빠짐. 메타분석 '에서도'가 메커니즘까지 확인한 것처럼 들림 + 가상 상황·작은~중간 효과 단서 없음.
4. **#35·#36 (4장 L65) Which?** — 작년(2024) 행사·판매처 8곳·(가전·IT 중심 — F26 줄엔 범주가 없어 확인 필요) 범위 표시. '그날만'이 블프 당일인지 4주 기간(11/15~12/12)인지 원문 문장 ⚠️ 미검수 — 대안으로 94% 문장.
5. **#51 (6장 L97) "그다음 화면이 어떻게 됐는지는, 오늘 밤 … 직접 확인해 보세요"** — 4장 '리셋 시계 157개' 바로 뒤라 '지우 화면도 가짜'로 읽히기 쉽고, '0이 될 때까지 기다려 보라'는 행동 권유로 읽힘. '오늘 밤'은 공개일(블프 전)과 어긋날 수 있음. 열어 둔 결말을 '화면만으로는 알 수 없다'로 맞추거나 줄을 빼기 — 판단 필요.
6. **#45 (5장 L83) "패딩에 대한 정보가 아닙니다 … 서두르게 하는 정보"** — 진짜 재고라면 남은 양이라는 정보이고(4장 L67), 연구상 사람들은 제한을 가치·인기 단서로 읽음(F14 ⚠️·F32). '따뜻한지 잘 맞는지는 알려 주지 않는다'까지로.
7. **#44 (5장 L81) "방법은 두 가지"** — 연구가 시험한 방법 아님 → '생활로 옮겨 보면 이렇게 해 볼 수 있다'(§4 생활 적용 행).
8. **#26 (3장 ⬛ L53) "줄어든 건, 지우에게 남은 기회"** — 4장 '알 수 없다'와 맞추려면 '남은 것처럼 보이는 기회'.
9. **#14 (3장 L37) 5→3 시점** — 1장(11:50)에서 이미 '3개 남음'; 3장 '방금 3이 됐다'와 엇갈림.
10. **#17 (3장 L39) "맛보려는 순간"** — 원 절차는 '첫 평가 대상은 쿠키'라고 말하는 순간 버튼. #16 '이번에는' → 같은 실험의 다른 조건임을 분명히.
11. **#2 (1장 L11) "살 생각이 없던 물건"** vs 지우의 두 주째 장바구니 패딩.
12. **#28 (4장 L59) "프린스턴대 연구진"** → "프린스턴대 등의 연구진". **#33** 535개는 '올해 1월' 상품. **#32** 시계(157)와 재고 가짜(무작위 1곳, 가짜 확인 17곳/632건)를 화면에서 구분.
13. **#39 (5장 L73) "잘 알려지지 않은"** — 확인 안 된 평가. **#12 (2장 L31) "같은 쿠키였으니까요"** → "모두 같은 쿠키였습니다". **#49** '백 개 쌓여/남아' 표현 통일.
