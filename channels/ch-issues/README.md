# ch-issues — 이슈의 구조

시사·사회 이슈와 역사 사건의 흐름을 실제 자료로 보여 주는 해설 채널입니다. [시사·역사 제작 매뉴얼](../../manual/08-issues.md)은 기존 스페인독감 편의 자료 사진·영상, 지도·연표, 비교 화면을 편집 기준으로 삼습니다. [장면별 표현 방식](../../manual/12-visual-storytelling.md)

- 시사 심층과 빠른 정리는 기준 시각·당사자 입장·미확인 사항을 확인합니다. 전날 이슈의 매일 정리는 `ch-issues-daily`에서 다룹니다.
- 역사 심층은 당대 기록과 독립적인 조사·연구를 대조합니다. [역사 주제 대기열](queue.md)
