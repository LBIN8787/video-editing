# (가칭) 1분 경제 상식 (`ch-money-shorts`)

- **형식:** shorts — 짧은 주제 안내 (formats/shorts.md)
- **편집 스타일:** 쇼츠 (9:16 고정 훅 + 큰 자막), 정보형: 숫자 카드·큰 글씨·비교
- **콘셉트:** 롱폼 채널의 주제 선정에서 '안내'형으로 판단된 짧은 소재(일정·용어·숫자 하나)를 30~45초에 알려 주는 쇼츠.
- **소재:** 롱폼 채널의 주제 선정에서 '안내'형으로 판단된 것이 `queue.md` 에 쌓입니다.

## 한 편 만들기
```bash
python -m ytflow make --channel ch-money-shorts                 # 대기열 첫 소재
python -m ytflow make --channel ch-money-shorts --topic "주제"
```
