## 1. 장 쓰는 법
- 사건 약 65% : 마음 해석 약 35%. 해석은 사건 바로 뒤, 그 인물의 감정으로.
- 심리 개념은 장마다 하나까지, 말로만. 화면에 띄우지 않는다.
- 장 끝 문장 = 다음 장의 질문 또는 예고.
- 한 문장은 자막 두 줄 안(약 15–35자). **한 문장 = 그림 하나.**
- 앞의 장면·말을 뒤에서 같은 말로 되풀이해 묶는다(프롤로그 ↔ 본문의 그 장면).
- 인물의 말은 짧게 옮긴다. 원문 낭독 없음. 실화는 사실 확인(팩트시트), 확인 안 된 일화는 쓰지 않는다.

## 1-1. 이야기가 있는 대본 (docs/76 §B — 인기 이야기꾼 9편 측정)
'읊는' 대본의 정체는 **'그리고'로 잇는 나열**이었다(우리 v1: 1천 자당 3.7~4.7번, 인과 접속 0.4~0.8번 ↔ 잘하는 이야기꾼 인과 1.4~3.5번).
1. **잇는 말은 '그런데·그러자·결국'** — 사건 사이는 반전 또는 인과. '그리고'는 한 장에 몇 번만.
2. **장면 문장(현재형, 몸짓·소리·빛 하나) + 요약 문장("그렇게 다섯 달이 흐릅니다")을 섞는다.**
3. **인물의 말**을 장마다 2~3번, 짧게 우리 말로. 말 앞뒤에 몸짓 하나.
4. **구체적인 사실 하나**(날짜·시각·나이·생활 디테일)가 형용사보다 강하다.
5. **열린 질문은 둘까지, 꼭 닫는다.**
6. **이야기꾼의 반응 한 줄**을 장마다 한 번("이상하지 않나요?").
7. **극적 아이러니** — 시청자는 알고 인물은 모르는 것("형은 아직 아무것도 모릅니다").
8. **문장 길이를 섞는다** — 긴 문장 뒤 짧은 한 문장.
**말투:** 기본은 낭독형(~습니다 + ~죠). 실화·미스터리처럼 친근함이 필요한 채널은 들려주기형(~거든요·~잖아요·~는데요를 섞음)을 고를 수 있다 — 채널마다 사용자가 정함(docs/76 §B-2).

## 3. 화면 규칙
| 요소 | 규칙 |
|---|---|
| 그림 | 문장마다 한 장(평균 약 7초). 인물 정면 얼굴은 감정의 정점에만, 평소엔 뒷모습·어깨 너머·손·그림자·빈 방·사물 |
| 카메라 | 한 장에 한 가지: 정지 4 : 천천히 밀기 4(끝 배율 1.08–1.18) : 빼기 2. 이동(팬)은 이유가 분명할 때만. 사인 가감속 |
| 전환 | 문장 시작 0.3초 전부터 약 0.7초 겹침. 검은 화면은 첫 1초와 이야기 속 밤·죽음 같은 순간뿐 |

| 자막 | 흰 글자 + 그림자, 상자 없음, 아래 가운데, 단어 시각 싱크, 한 자막 한 문장 |

| 소리 | 잔잔한 배경음악 끝까지(말보다 약 13dB 낮게), 효과음 없음. 목소리는 낮고 차분하게, 분당 약 440자 |

## 3-1. 그림 만드는 법 (재현 대조에서 배운 것, docs/75 §5)
- **무대마다 기준 그림 1장 → 그 무대의 모든 장면은 기준 그림을 참조로 '같은 방, 구도만 바꿔서'.** 같은 식탁·램프·창·벽지가 되풀이되어야 '그 집'이 생긴다.
- **비어 있고 어둡게.** 램프 하나, 빈 의자, 짙은 그림자, 가장자리 어둡게. 소품·꽃·노을 창을 매 장면 넣지 않는다.
- **그 장면에 있는 사람만.** 이야기에 없는 인물(웃는 가족 등) 금지. 정면 얼굴은 감정의 정점에만, 평소엔 뒷모습·어깨 너머·손·그림자.
- 숨 고르는 짧은 문장('그리고 덧붙입니다')에는 거의 검은 그림(어두운 복도·밤 들판).
- 자막: 큰 글자(1080p 에서 58px), 짧게(한 덩어리 30자 안, 26자 넘으면 두 줄), 글자 아래끝이 화면 높이 93%.
- 무대·인물 기준 그림 → 장면은 기준 그림 참조(`gen_v2.py` 가 자동). 인물 기준 그림은 얼굴이 잘 보이게, 장면에서는 뒷모습·손·그림자 위주.
- 장 제목: 프롤로그 포함 모든 구간 첫 그림 위에, 크게 두 줄.

## 3-2. 카메라 연출 — 언제 무엇을 (docs/76 §A, 예시 영상 `templates/camera_catalog.json`)
원칙: 움직임엔 이유가 있다 · 감정이 먼저 · 정지도 연출이다 · 같은 움직임이 세 번 이어지면 하나를 정지로.
| 문장이 하는 일 | 카메라 (`cam` / 렌즈) | 피함 |
|---|---|---|
| 장면 소개(시간·장소) | `pull` · `pan` · 외경 `static` | `snap` |
| 인물 등장 | `static`(뒷모습) → 다음 문장 `push` · 위압적 인물 `tilt_up` | `shake` |
| 행동·사건 진행 | `pan` · `push` · 시간 점프는 `tr: "whip"`(드물게) | 긴 정지 |
| 감정·속마음 | `push` · 깨달음은 `focus` | `pan` |
| 대사·인용 | `static` · 아주 느린 `drift` | 빠른 움직임 |
| 불안이 쌓임(비밀 직전) | `dread` + `vignette` | `pull` |
| 충격·반전 한 문장 | `snap`(편당 0~2번) 또는 `reveal` | 연달아 두 번 |
| 무너짐·죄책감 | `tilt_down` · `pull`(혼자 남음) | `tilt_up` |
| 희망·전환점 | `tilt_up` · 넓은 풍경 `pull` | `vignette` |
| 해석·심리 개념 | `drift` · `static`(빈 방·사물) | 새 사건 장면 |
| 도망·싸움·패닉 | `push` + `shake` | 차분한 정지 |
| 장의 끝 | `pull` · 어두운 그림 `static` | `snap` |
`at: [x, y]` 로 밀기·조여 오기·빠른 밀기·드러내기가 향할 곳(그림 기준 0~1)을 정한다. 모양 맞춰 넘기기(매치 컷)는 그림 주문 때 앞 장면과 같은 자리·같은 모양으로 그린다. 2.5D 시차·돌리 줌은 아직 못 함(층 분리 필요).

## 4. 작업 순서 (명령은 `scripts/story_video/README.md`)
0. 대본 틀 `templates/story_v2.example.json` 을 `projects/<날짜>-<제목>/02_script/story.json` 으로 복사.
1. 작품·사건 조사(팩트시트) → 2. 콜드 오픈 장면과 질문 하나 정하기 → 3. 장 구성(장 제목 = 감정 문장) → 4. 무대 목록(sets.md) → 5. 문장마다 그림 줄을 단 대본 → 6. **대본만 사용자 검토**(+무료 낭독) → 7. 무대별 대표 그림 2–4장 검토 → 8. 나머지 그림(GPT `$imagegen`, 같은 무대는 참조 그림으로) → 9. 렌더(`scripts/story_video`, v2 설정) → 10. 레퍼런스처럼 프레임 점검(장면 길이·카메라 비율·글자 겹침·싱크).
