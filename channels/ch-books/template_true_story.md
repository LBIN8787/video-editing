# 실화 서사형 템플릿 — 역사·미스터리 (v1 · 2026-11-27)

사용자: "이 책 리뷰템플릿처럼 역사나 미스테리 등을 스토리로 담아내는 대본도 작성해주세요".
③ 명작 서사형(`template_story.md`)의 뼈대 — **장면으로 열기 → 질문 셋 → 한 사람을 따라가는 네 막 → 답 → 처음 장면으로 돌아오기** — 를 실화에 옮긴 것입니다. 책 채널 밖(호기심 `ch-knowledge`, 이슈 `ch-issues`)에서도 쓸 수 있게 따로 둡니다.

## 0. 명작 서사형과 다른 점
| | ③ 명작 서사형 | 실화 서사형 |
|---|---|---|
| 재료 | 소설 원문 | 1차 기록(일지·편지·공식 보고서·재조사·논문) |
| 사실 기준 | 원작 부·장 | **출처 2곳 이상** 또는 1차 기록. 확인 안 된 전설은 "전해지는 이야기"로 표시하거나 뺌 |
| 화면의 증거 | 삽화만 | **실제 자료 먼저**(퍼블릭 도메인 사진·지도·문서), 사진이 없는 순간만 삽화 |
| 결말 표시 | `결말 포함` | 역사: 없음(결과가 알려진 이야기는 '어떻게'가 궁금증) · 미스터리: `답까지` |
| 삽화 화풍 | 작품의 시대 삽화 기법 | 사건의 시대·장소 기록물 느낌(예: 1910년대 극지 → 흑백 유리판 사진 톤의 잉크·담채, 1950년대 소련 → 흑백 신문 삽화·연필) |

## 1. 두 가지 갈래
### A. 역사 — "어떻게 해냈나 / 왜 그렇게 됐나" (13–16분)
| # | 박자 | 시간 | 하는 일 |
|---|---|---|---|
| 0 | 장면 | 0:00–0:35 | 가장 극적인 한 순간을 현재형으로 (결과는 말하지 않음) |
| 1 | 질문 셋 | –1:05 | ① 사람에 대한 질문 ② 우리에게도 해당하는 질문 ③ 결과가 궁금한 질문 |
| 2 | 시대 한 줄 | –1:25 | 언제·어디·무엇을 하려던 사람들인지 (지도 한 장) |
| 3–6 | 네 막 | –13:00 | 주인공 한 명의 **선택**을 따라감. 막마다 상황이 나빠지고, 그가 무엇을 지키려 하는지가 바뀜. 막 끝은 다음 질문 |
| 7 | 결과 | –14:20 | 무슨 일이 일어났나, 그 뒤 사람들은 |
| 8 | 이야기가 묻는 것 | –15:30 | 질문 셋에 답 ('~로 볼 수 있습니다') |
| 9 | 돌아오기 | –16:00 | 첫 장면을 결과를 아는 눈으로 다시 + 오늘의 흔적(유적·발견·기록) |

### B. 미스터리 — "무슨 일이 있었나" (13–16분)
| # | 박자 | 시간 | 하는 일 |
|---|---|---|---|
| 0 | 장면 | 0:00–0:35 | 발견의 순간 (가장 이상한 단서 하나) |
| 1 | 질문 셋 | –1:05 | ① 무슨 일이 ② 왜 그랬을까 ③ 지금은 답이 있나 |
| 2 | 사람들 | –1:40 | 그들이 누구였고 무엇을 하려 했나 — 피해자를 '사건'이 아니라 '사람'으로 |
| 3 | 1막 — 마지막 기록 | –4:30 | 남은 일기·사진·증언으로 그날까지를 시간 순서로 |
| 4 | 2막 — 발견 | –7:00 | 단서를 하나씩, 이상한 순서대로 (숫자·위치는 지도) |
| 5 | 3막 — 가설들 | –10:00 | 유명한 가설 3–4개를 공정하게. 각 가설이 설명하는 것/못 하는 것 표 |
| 6 | 4막 — 다시 조사하다 | –12:30 | 공식 재조사·과학 연구가 무엇을 확인했나, 무엇이 아직 남았나 |
| 7 | 가장 그럴듯한 답 | –14:00 | 지금 근거가 가장 많은 설명 + 반대 의견 |
| 8 | 이야기가 묻는 것 | –15:00 | 질문 셋에 답 |
| 9 | 돌아오기 | –15:30 | 첫 장면의 단서를 답을 아는 눈으로 다시 |

**길이:** 표의 시간은 15분 기준 배치입니다. 실화는 **10–16분(내레이션 약 3,200–5,000자)** 이면 충분합니다 — 조회수 분석에서 10–20분이 가장 좋았고, 실화는 사실 확인이 된 장면만 쓰므로 소설보다 짧아지기 쉽습니다. 늘릴 때는 사실을 더 넣지 말고 장면(그 순간의 몸짓·소리·날씨)을 늘립니다. (첫 두 편: 섀클턴 약 3,100자·10분, 댜틀로프 약 3,300자·11분)

## 2. 공통 규칙
- **사실:** 숫자·날짜·인용은 팩트시트에 출처(링크)와 함께. 출처끼리 다르면 범위나 "기록마다 다릅니다"로. 확인 안 된 유명한 일화는 쓰지 않거나 "확인되지 않은 이야기"라고 말함.
- **사람을 존중:** 실제로 죽거나 다친 사람의 이야기. 잔혹한 묘사로 끌지 않고, 이름과 나이로 사람을 먼저 소개. 미스터리는 음모론을 사실처럼 말하지 않음.
- **화면:** 실제 자료(퍼블릭 도메인·공식 공개) → 지도·시간 띠 → 삽화 순. 실제 사진은 출처·연도 표시. 사진이 없는 순간만 삽화.
- **말투·표기·검토 순서:** 명작 서사형과 같음 (3인칭 '~습니다', 장면은 현재형, 🎨/▣/쉼 표기, 대본 → 대표 삽화 → 편집 → 제목·썸네일).
- **제목:** 주어 + 질문, 비유 금지. 미스터리는 "~의 진실" 같은 낚시 대신 "~은 왜 ~했을까".
