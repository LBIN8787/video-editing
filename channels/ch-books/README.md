# ch-books — (가칭) 책이 답한다

책을 소개하지 않고, 이야기와 질문으로 책을 경험하게 하는 채널입니다. 형식은 구독자 대비 조회수 분석([docs/74 §8](../../docs/74-book-channel.md))으로 정했습니다.

- **③ 명작 서사형 (주력):** 작품 속 한 장면 → 질문 셋 → 주인공 한 명의 마음을 따라 결말까지 → 그 마음이 우리에게 묻는 것 → 첫 장면으로 돌아감. 10~20분, 장면 삽화 + 내레이션.
- **② 질문형:** 독서·뇌·심리·습관의 질문 → 흔한 답이 틀린 이유 → 책이 준 뜻밖의 답 → 내 삶에 옮기면 → 첫 질문으로 돌아감.

조사와 근거는 [docs/74](../../docs/74-book-channel.md), 대본 규칙은 [prompts/script_books.md](../../prompts/script_books.md), 주제는 [대기열](queue.md), 제작 기록은 [회차 기록](episodes.md)에 있습니다.

상태: 실험(채널 방향 조사). `research/book-channel` 브랜치에만 둡니다.
