# ch-books — (가칭) 책이 답한다

책을 소개하지 않고, 시청자의 질문에 책으로 답하는 채널입니다. 두 형식을 번갈아 운영합니다.

- **② 질문형** (책그림 참고): 일상 질문 → 흔한 답이 틀린 이유 → 책이 준 뜻밖의 답 → 내 삶에 옮기면 → 첫 질문으로 돌아감.
- **③ 다큐형** (북툰 참고): 가장 놀라운 장면 → 그 일을 알아낸 사람 → 과정 → 바뀐 것 → 남은 질문.

조사와 근거는 [docs/74](../../docs/74-book-channel.md), 대본 규칙은 [prompts/script_books.md](../../prompts/script_books.md), 주제는 [대기열](queue.md), 제작 기록은 [회차 기록](episodes.md)에 있습니다.

상태: 실험(채널 방향 조사). `research/book-channel` 브랜치에만 둡니다.
