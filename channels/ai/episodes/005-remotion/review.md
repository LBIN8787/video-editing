# 검수

- 공식 출처와 이번 로컬 실행을 근거로 작성했다.
- 고정 ElevenLabs Han Aim / eleven_v4, 대본별 1회 생성. 다른 TTS로 대체하지 않았다.
- ShortsGuideV1 1.0.0, 고정 폰트 해시·입력 검증 및 TypeScript 검사 통과.
- 최종 MP4 전체 디코딩 통과. 모든 장면의 대표 프레임을 직접 확인했고 잘린 글자나 패널 겹침을 발견하지 않았다.
- Whisper 인식 문장을 대본과 비교했다. 엠피포로는 MP4로로 표시한다.
- 직접 청취 검수는 수행하지 못했다. 인식 문장·타임스탬프·음량을 검사했다.
- 1080×1920, 30fps, 45.90초, H.264/AAC 48kHz. 측정 -16.83 LUFS, 최대 true peak -1.5 dB.
- 전환 효과음·배경음 없음. 화면은 자체 그래픽과 실제 파일 일부의 재구성.
