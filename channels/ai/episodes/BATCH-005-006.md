# 추가 쇼츠 005·006

기존 004 작업 초안은 덮어쓰지 않고 005와 006을 새로 제작한다. ShortsGuideV1 1.0.0 디자인은 변경하지 않는다.

- 005-remotion: 같은 디자인을 유지하며 내용만 바꾸는 Remotion 활용법.
- 006-whisper: 실제 쇼츠 음성을 Whisper로 인식해 자막 초안을 만드는 방법.
- 고정 내레이션: ElevenLabs Han Aim / eleven_v4, 각 대본 1회 생성. 대체 음성·전환 효과음·배경음 없음.
- 실제 작업 사례: work-cases/shorts-batch-005-006/case.json.
- 본편의 화면은 자체 그래픽과 실제 입력·인식 결과 일부를 재구성한 자료다. 서비스 UI 조작을 촬영한 영상은 아니다.

## 같은 편을 다시 출력하기

기존 음성 파일과 증거 이미지를 복원하면 TTS를 다시 생성하지 않는다. 미디어는 Git에 포함하지 않으며 Google Drive의 별도 제작 패키지를 사용한다. 스타일과 폰트는 기존 v1.0.0 보관본과 동일하다.

```bash
cd studio/renderer
npm ci
cd ../..
python scripts/render_short.py --props channels/ai/episodes/005-remotion/props.json --out studio/renderer/out/AI-Shorts-005-Remotion.mp4
python scripts/render_short.py --props channels/ai/episodes/006-whisper/props.json --out studio/renderer/out/AI-Shorts-006-Whisper.mp4
```

Chromium이 PATH에 없으면 --browser로 설치 경로를 전달한다. Windows에서는 UTF-8 모드(PYTHONUTF8=1)를 권장한다. 이번 MP4 생성은 Linux 작업 환경에서 실행했다.

## 자막 처리 재현

Python 전용 가상환경에 faster-whisper와 Pillow를 준비한다. 모델 최초 다운로드에는 인터넷이 필요하다. Whisper 인식은 로컬에서 수행하며 ElevenLabs 음성 생성과 분리되어 있다.

```bash
python studio/renderer/tools/transcribe_short.py --audio studio/renderer/public/episode-005/voice.mp3 --prompt channels/ai/episodes/005-remotion/narration.txt --out channels/ai/episodes/005-remotion/whisper-raw.json
python studio/renderer/tools/transcribe_short.py --audio studio/renderer/public/episode-006/voice.mp3 --prompt channels/ai/episodes/006-whisper/narration.txt --out channels/ai/episodes/006-whisper/whisper-raw.json
python studio/renderer/tools/prepare_005_006.py
```

모델·라이브러리 버전에 따라 새 인식 결과와 타임스탬프가 달라질 수 있다. 최종 검수한 props.json·captions.json을 보존하는 것이 같은 영상 재출력의 기준이다. prepare_005_006.py는 이 두 편의 장면 설계에 맞춘 도구이며 임의의 새 대본을 무인 제작하는 일반 파이프라인은 아니다.
