# (가칭) 장면의 이유 — 애니 리뷰·해석 (초안)

장면을 근거로 해석을 들려주는 애니 채널. 설계·수요 분석: [`docs/37-anime-review-channel.md`](../../docs/37-anime-review-channel.md)

- **본체:** 비교·연출 분석 (10~15분) — "A vs B", "○○가 좋은 N가지 이유"
- **시기성:** 보기 전 총정리 (새 시즌·극장판·실사화 직전, 30~60분) — 내 화면(관계도·연표) 중심
- **하지 않음:** 전편 몰아보기 (원작 영상이 본체 → 저작권·수익화 위험)
- **클립 규칙:** 1개 ≤ 8초, 전체 ≤ 40%, OST 안 씀, 탐지 회피 편집 안 함 (`channel.yaml` 의 `clip_rules`)
- **소스:** 사용자가 정식으로 본 에피소드 파일을 PC 에서 준비 → `rebuild`
