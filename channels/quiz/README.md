# 퀴즈 채널 (가칭)

반복 제작 채널. 고정 보이스는 channel.json이 원본이다. 두 채널 모두 우선 ElevenLabs Han Aim / eleven_v4를 사용하며 영상별 임의 변경과 음성 대체를 금지한다.

- 일일 목표: 3편. 예약·게시 완료 수가 아니다.
- 계정 미생성, 업로드 미연결. 샘플 피드백 전 정기 실행 중지.
- 사용할 편집 스타일: shorts-quiz-explain.
- episodes/에는 대본·장면·검수 기록을, 공통 조사와 글은 content/topics/에 보관한다.

초중등 학습형과 청소년·성인 오락형 중 대상이 아직 미정이다. 기존 문제를 타깃 검증 완료 사례로 취급하지 않는다.
