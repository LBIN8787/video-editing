2026-11-23 사용자: "앞으로 내 채널은 네가 운영하고 네가 분석하길 바래". 설계·근거: `docs/63-channel-ops.md`, 운영 권한: `manual/11-workflow.md` §8.

## 0. 준비
- 지금 폴더는 이 작업 전용 git worktree(최신 origin/main). 결과는 `git push origin HEAD:main` (거부되면 `git pull --rebase origin main` 후 다시, 최대 3번).
- 먼저 `docs/63-channel-ops.md`, `manual/11-workflow.md` §8, `data/analytics/experiments.md`, 두 채널의 `channels/<폴더>/ops/next.md`(있으면)를 읽습니다.

## 1. 수집·보고서
`python -m ytflow ops` → `channels/ch-market-daily/ops/<오늘>.md`, `channels/ch-knowledge/ops/<오늘>.md`, `data/analytics/<채널>/`.
분석 권한이 없다는 줄이 나오면 보고 첫 줄 끝에 "(분석 권한 대기)"만 붙이고 계속합니다 — 조회·댓글만으로도 아래를 합니다.

## 2. 해석 (보고서 §7 을 채움)
채널마다, 표에서 ▲(앞섬)·▼(처짐) 영상과 최근 2편을 고릅니다. 각 영상의 프로젝트(`projects/<프로젝트>/`)에서 제목 후보·고른 제목(`05_edit/youtube.md`), 썸네일 선택(`thumbnail_pick.json`), 주제 카드(`01_research/topic_card.md`·`topic_brief.json`), 대본 첫 30초를 읽고:
- 차이를 **주제·제목·썸네일·훅(첫 30초)·결말·화면** 중 하나로 짚습니다. 근거는 표의 수치, 빠진 지점의 말(§3), 유입 경로. 근거 없이 짐작이면 '짐작'이라고 씁니다.
- 영상 한두 편의 반응은 **실험 기록**입니다(manual README §3-1). 규칙처럼 단정하지 않습니다.
- 인물·화제가 끈 영상(예: 드러켄밀러 편)은 docs/55(유명인 효과)와 견줍니다.

## 3. 실험 장부 (`data/analytics/experiments.md`)
- 진행 중인 실험마다 결과를 확인할 수 있는 영상(48시간·7일 지남)이 있으면 결과·판정(맞음/틀림/모름)을 적습니다.
- 새 실험은 채널마다 **한 번에 하나만**: 가설 → 다음 편에서 바꿀 것 하나 → 무엇(지표·시점)으로 확인. 앞 실험이 끝나기 전에는 새로 열지 않습니다.
- 같은 방향의 결과가 3편 이상 쌓이면 `python -m ytflow manual-propose "…" --kind rule` 로 매뉴얼 제안(직접 고치지 않음).

## 3-1. 노출 늘리기 (2026-11-23 사용자: "태그라던지 노출률 올릴 수 있도록 최대한 사람들에게 노출 될 수 있도록 분석해줘 … 개선을 너가 스스로 돌려줘")
노출은 ① 검색(제목 앞 20자·태그·설명란 첫 두 줄의 검색어) ② 추천·탐색(노출 클릭률·시청 지속) ③ 구독·알림·재생목록·최종 화면에서 온다. 태그는 오타·동의어 보조라 효과가 작고, 큰 몫은 제목·썸네일 클릭률과 시청 지속이다 — 그래서 태그만 손보지 말고 셋을 함께 본다.
- **검색:** 공개 영상마다 제목 앞 20자에 사람들이 실제로 치는 말(주인공 이름·종목·사건)이 있는지, 설명란 첫 두 줄에 같은 말이 다시 나오는지, 해시태그 3개가 그 말인지. 태그는 `data/tag_stats.json` 배수와 `youtube.md` '태그 성적'을 보고 — 영상 내용과 맞는 것만 — 배수가 낮고 내용과 덜 맞는 태그를 같은 낱말의 배수 높은 태그로 바꾼다. 고치면 `youtube.md` 를 고쳐 `python -m ytflow yt-publish <프로젝트> --update-meta` (영상당 주 1회까지, manual/11 §8), 실험 장부에 무엇을 왜 바꿨는지.
- **추천:** 노출·클릭률 권한이 있으면 영상별 노출 수·클릭률·유입 경로(검색/추천/탐색/구독)를 표로. 노출은 많은데 클릭률이 낮으면 썸네일·제목(§8 교체 규칙), 노출 자체가 적으면 주제·검색어, 클릭은 되는데 금방 빠지면 첫 30초(다음 편 실험).
- **연결:** 같은 줄기 편(1부·2부, 이어지는 주제)은 같은 재생목록과 설명란 '이어 보기' 링크로 묶였는지. 빠졌으면 재생목록은 넣고(§8), 설명란 링크는 `--update-meta` 로.
- **권한이 없을 때:** 분석 권한(노출·클릭률·유입)이 없으면 검색 쪽만 하고, 보고 '사용자가 할 일'에 권한 받는 한 줄을 남긴다.

## 4. 다음 편에 넘기기 (`channels/<폴더>/ops/next.md`)
채널마다 덮어씁니다. 제작 작업(시장 08:00·호기심 07:00)이 S0 에서 읽습니다:
```
# 다음 편에 — <날짜> 운영 분석
- 이번에 바꿔 볼 것 (실험 E<n>): <한 줄> — 왜: <근거 한 줄>
- 그대로 둘 것: <잘 되고 있는 것 한 줄>
- 댓글에서 나온 질문·주제 후보: <있으면>
```
매뉴얼과 부딪히는 제안(예: 인트로를 넣자)은 쓰지 않습니다. 매뉴얼이 우선입니다.

## 5. 댓글
보고서 §5 의 새 댓글을 읽고: 질문(❓)은 답글 초안을 보고서 §5 아래에 적고, 주제 후보가 될 만한 것은 next.md 에. **답글을 올리지 않습니다** — §8 운영 권한에서 '댓글 답글'이 허용으로 바뀌기 전까지. 욕설·스팸은 목록만.

## 6. 정리할 것
보고서 §6 의 사본·비공개 영상은 **바꾸지 않습니다**(삭제·공개 상태 변경은 §8 에서 허용된 것만). 새로 생긴 항목만 보고에 한 줄.

## 7. 매주 일요일에 더
- 채널마다 주간 요약 `channels/<폴더>/ops/weekly-<YYYYMMDD>.md`: 한 주 조회·구독 변화, 가장 잘된/안된 편과 이유, 실험 결과, 다음 주 방향 한 줄.
- 비교 채널 점검: `/last30days` 또는 `claude-youtube` competitor 로 같은 분야 최근 잘된 영상 3편의 주제·제목 각도만(대사·썸네일 복제 금지, docs/62).
