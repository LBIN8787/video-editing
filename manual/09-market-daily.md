## 0. 한 줄 정의
전날 시장(미국·한국)을 **움직인 것**을 1차 출처로 확인하고, 그것이 **무엇으로 이어지고 무슨 뜻인지**까지 6~8분에 설명한다. 투자 권유는 하지 않는다.

| 하는 것 | 하지 않는 것 |
|---|---|
| 움직인 이유를 원인 종류(이슈·보고서·전망·실적)로 나눠 설명 | 사라·팔라·목표가 단정 |
| 공시·실적 자료·발언 **원문**을 보여 주기 | 출처 없는 '카더라', 찌라시 단정 |
| 사실과 해석을 나눠 말하기 ("여기서부터는 해석입니다") | 장중 값을 마감처럼 말하기 |
| 오늘 확인할 것(날짜·시각)으로 끝내기 | 하루 움직임으로 장기 결론 |

## 2. 브리핑이냐 심층이냐 (요일 고정 아님)
daily_brief 의 이야기마다 `depth`(브리핑 / 심층 후보)와 이유가 적힙니다. **최종 판단은 사람**. 아래 신호 **둘 이상**이면 심층:
1. 원인이 여러 갈래로 얽힘 · 2. 한 사건이 시장 전체를 움직임 · 3. 어닝콜·연준·정부 발표의 긴 설명이 핵심 · 4. 며칠째 이어지는 이야기의 전환점 · 5. 한국 시장으로 이어지는 고리가 김

| | 브리핑 (6~8분) | 심층 (7~12분) |
|---|---|---|
| 구성 | 시장 한 장 → 이야기 2~3개 → 한국 → 오늘 볼 것 | 앞 1분 시장 요약 → 한 주제를 4~5장으로 |
| 어닝콜이면 | 한 장(章)으로 요약 | `03 §0-1` 어닝콜 해부 (숫자·약속 → 경영진의 말 원문+번역 → 의미 → 남은 숙제 → 확인할 약속) |
| 1일 1편 | 이것 하나 | 그날 브리핑을 대신 |

주말: 토 = 주간 분석 (한 주를 움직인 흐름 3개 + 다음 주 일정), 일 = 분석글 (산업·테마 하나). 휴장일 = 쉬거나 주간 분석으로.

## 3. 조사 — 원인은 1차 출처로
### 3-1. 원인 종류별 어디서 확인하나
| 원인 종류 | 1차 출처 (먼저) | 보조 (보도) | 대본 표현 |
|---|---|---|---|
| **이슈** (사건·인사·규제·계약) | 회사 공시 (미국 SEC 8-K, 한국 DART), 보도자료, 당국 발표 | 통신사·주요 경제지 2곳 이상 | "회사는 공시에서 ~라고 밝혔습니다" |
| **실적** | 실적 보도자료·IR 자료, 10-Q | 실적 요약 기사 | 예상 vs 실제 vs 1년 전 |
| **전망** (가이던스·연준·지표) | 어닝콜 공식 녹취록(`earnings-call`), 연준 성명, 통계 원문 | | 원문 문장 + 번역 |
| **보고서** (증권사·기관) | 보고서 공개분 | 인용 보도(매체·날짜) | "○○는 ~로 봤습니다 — 한 기관의 의견" (목표가는 권유처럼 들리면 빼기) |

- SEC 공시: `https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&CIK=<티커>&type=8-K` (curl 은 `-L` 로 넘겨받기). 한국: DART.
- 어닝콜: 회사 IR 의 **공식 녹취록** → `python -m ytflow earnings-call <프로젝트> <PDF·주소> --ticker <티커> --period <분기>`
- 막힌 곳(403·봇 확인)은 **우회하지 않음** — 다른 1차 출처나 보도 2곳 일치로.

### 3-2. 팩트시트 쓰는 법 (`01_research/factsheet.md`)
- 번호 + 확인 표시: ✅ 1차 출처·시세로 확인 / ⚠️ 보도(1곳 또는 회사 확인 없음) / 💬 해석
- 모든 줄에 **출처 주소** (yt-pack 이 설명란 출처로 그대로 가져감)
- `## 해석` 칸 (check MUST): 해석마다 근거 번호
- `## 쓰지 않는 것`: 매체마다 다른 숫자, 1곳뿐인 주장, 사적 인물, 목표가

### 3-3. 데이터 함정 (실제로 겪은 것)
| 함정 | 막는 법 |
|---|---|
| 장중 값을 마감으로 씀 | `daily` 는 시장마다 **장이 끝난** 날만 씀. 대본에 날짜를 붙임 ("12일 마감") |
| 야후 지수·환율·원자재 갱신 늦음 (예: 11/13 아침 코스피가 11일 값) | daily_brief 의 ⚠️ 표시 확인 → 거래소·마감 기사로 대체, 팩트시트에 적기 |
| 미국 날짜와 한국 날짜 혼동 | "11월 12일 미국 장"처럼 시장 이름을 같이. 한국 장은 미국 발표보다 **먼저** 열림 (사건 순서 확인) |
| 시간외 vs 정규장 | 시간외 숫자는 "시간외"라고 말하고 정규장과 비교 |
| 숫자 반올림이 화면·대사와 다름 | 지수는 소수 둘째 자리까지 (차트 자동) |

## 4. 대본 — 브리핑 (6~8분, 14~18장면)
`scripts/daily_<날짜>/make.py` 로 `hybrid.json` 을 만든다 (재현 가능하게). 바로 앞 회차 스크립트를 복사해 시작.

| 순서 | 장면 type | 박자 | 말 (예시·고정 문구) | 화면 |
|---|---|---|---|---|
| 오프닝 (30~40초) | `intro` | 5 | ① **"안녕하세요. 어제의 시장을 이어 읽는, 이어 읽는 시장입니다."** ② "오늘은 ○월 ○일 미국과 한국 장을, 마감 기준으로 정리합니다." ③ **훅**: 그날의 반전·가장 큰 숫자, 답은 숨기고 질문으로 ④ 순서 예고 ⑤ "시작하겠습니다." | 시리즈 배지·기준 시각·제목 2줄·사진 |
| 시장 한 장 (30초) | `bars` | 2 | 지수 등락 → 한 문장 판단("업종 전체가 아니라 ○○의 일") | 지수 막대 + 지도(뉴욕) |
| 이야기 1~3 (각 1.5~2분) | `chapter` → `quote`/`checklist`/`chart`/`versus`/`map_causal`(board)/`analogy` | 각 2 | 무엇이 → 왜(원인 종류 + 출처) → 시장 전체와 같이/따로 → 어디로 번지나 | 장 표지는 대시보드·듀오톤 사진·증거판 돌려 쓰기 |
| 해석 장면 | `map_causal` look `board` | 2 | 첫 문장에 **"여기서부터는 해석입니다"** | 증거판(카드 + 실) |
| 한국 시장 | `bars` | 2 | 코스피·관련 종목 | 막대 + 지도(서울) |
| 한 줄 정리 | `kinetic` | 1 | 그날을 한 문장으로 | 큰 글씨 |
| 오늘 볼 것 | `checklist` | 2 | 날짜·시각이 있는 일정 2~3개 | label 에 "투자 권유가 아닙니다" |
| 마무리 | `outro` | 1 | **"오늘 이어 읽는 시장은 여기까지입니다. 출처는 모두 설명란에 남겨 두겠습니다."** | |

**말투 (README §2-2, check MUST)**: 문장은 "~입니다 / ~죠 / ~까요?"로 닫기, "~였고요."로 끝내지 않기, 장 번호를 말로 세지 않기(한 영상 한두 번), 숫자마다 비교 기준.
**대본 필수 칸**: `core_message`, `logic`, `compare_to`, 비유 2개(`analogies`), 과거 사례 1개(`past_cases`), `glossary`, `package`(제목 3·썸네일 3).

## 5. 대본 — 심층 (7~12분)
- **어닝콜 해부**: `03 §0-1` 표 그대로 (숫자와 약속 → 경영진이 한 말 N가지(원문+번역, quote `orig`) → 정리판(`recap`) → 무엇으로 이어지나(해석) → 남은 숙제 → 확인할 약속). 애널리스트 이야기보다 **경영진의 말**이 중심 (2026-11-12 사용자 판정).
- **사건 심층**: 무슨 일(공시) → 왜 지금 → 시장 반응(같이/따로) → 이어지는 곳(증거판) → 남은 불확실성 → 확인할 날짜.

## 6. 화면 문법 (시장 카테고리 개성, `05 §0-7`)
- 기본 팩 slate, 장 표지는 **대시보드 ↔ 듀오톤 사진** 돌려 쓰기, 관계는 **증거판**(`look: board`)
- 사진: 주제에 맞게 (회사 간판·건물·데이터센터·거래소), 위키미디어 공용 **PD·CC0·CC BY** 만 — `python -m ytflow archive commons "검색어"`. 출처 표시 자동. NASA 위성 사진 반복 금지.
- 눈요기(05 §0-3, check MUST): 글씨·도형뿐인 장면 3연속 금지 → 사진(`layers` photo)·지도(locator)·카메라 효과(`fx`: tilt·dolly·scan) 섞기. **겹친 장면(layers) 3개 이상**.
- 같은 스타일 3연속 금지, 한 스타일 40% 이하 (막대·숫자·차트는 data-report 로 묶여 셈).
- 차분하게(v12): 카메라는 한 방향 느리게, 배경음 기본 없음.

## 7. 제목·썸네일 (`prompts/thumbnail.md` + 시장판)
- 제목 3개: ① 훅(질문, 답 숨김) + "| ○월 ○일 이어 읽는 시장" ② 숫자 대비 ③ 장면 + 다룬 종목. 과장어·권유어 금지.
- 썸네일 3장: A 사진 + 질문 / B 숫자 둘 대비 (versus) / C 공시·다음 일정. 숫자는 영상과 똑같이.
- 유튜브 '테스트 및 비교'에 세 장 모두.

## 10. 업로드 (유튜브 스튜디오)

## 요약 + 움직이는 그림 (2026-11-13 사용자 확정 방향, docs/25 §8)
- 요약 장면(체크리스트·대결·막대·차트)이 뼈대. **바꾸지 말고 겹친다.**
- 체크리스트는 글을 왼쪽으로 좁히고(`x: 150`, `text_w: 860`) 오른쪽에 박자 `motion`(아이콘·화살표·숫자 세기)을 1~2개씩. 줄마다 `t`(핵심 낱말)로 말할 때 나타나게.
- 그림이 있는 장면은 `anchor` 로 기존 그림 위치를 잡고 화살표만 더한다. 화살표·숫자가 글자와 겹치지 않게 프레임으로 확인.
- 사물은 나타날 때만 움직인다(제자리 흔들림 없음). 색은 장면의 그래픽 팩을 따른다.
