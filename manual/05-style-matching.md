# 05. 편집 스타일 고르기 — 영상마다, 장면마다

편집 스타일 = **연출**(무엇이 언제 어떻게 바뀌나: 장면 type·박자·편집점) + **그래픽 팩**(색·글꼴·배경·차트 모양: `skins/<id>`). 둘은 따로 고릅니다 (docs/13).
한 영상 안에서도 연출은 섞습니다. 그래픽 팩은 **한 영상에 하나**(채널 정체성).

## 0-1. 조합 원칙 (가장 중요 — 2026-11-09 사용자 판정)
**한 스타일로만 영상 전체를 만들면 불합격입니다.** 스타일 하나하나는 재료이고, 영상은 상황에 맞춘 **조합**입니다.
1. **장면마다 다른 스타일:** 말하는 내용에 맞춰 장면 type 을 고릅니다(아래 §2 표). 같은 스타일이 3장면 연속되면 안 됩니다.
2. **한 장면 안에서 겹치기:** 바탕 장면 위에 다른 스타일 요소를 얹습니다 (`layers`). 롱폼은 3장면 이상.
3. **구간마다 다른 그래픽 팩 (선택):** 기본 팩은 영상에 하나, 특정 장면만 `"skin": "<팩>"` 으로 바꿀 수 있습니다 (지도 장면만 newsprint, 인용 한 줄만 dark-doc). 한 영상에 팩은 3개 이하.

| 검사 (`check` G5, MUST) | 롱폼 | 쇼츠 |
|---|---|---|
| 섞은 스타일 수 (장면 + 겹친 요소) | 4종 이상 | 2종 이상 |
| 한 스타일이 차지하는 시간 | 40% 이하 | 60% 이하 |
| 겹친 장면 (`layers`) | 3개 이상 | 1개 이상 |
| 같은 스타일 연속 | 2장면까지 | 2장면까지 |

### 강조는 아껴 쓰기 (2026-11-09 사용자 판정: "남용은 안 쓰는 것만 못하다")
- 강조 = 핵심 단어 띄우기(`words`)·큰 숫자 카드(`number`)·메모 쪽지(`vox`)·키네틱 장면(`kinetic`). **1분에 1번 이하, 한 장면에 1개까지** (`check` G5 MUST).
- **아래 자막과 같은 문장을 화면 위에 다시 쓰지 않는다.** `words` 는 문장이 아니라 핵심 단어 1~3개만, 그 말을 하는 순간 한 번 띄웠다 사라진다.
- 강조를 줄 곳: 영상 전체에서 시청자가 기억해야 할 숫자 하나, 반전 한 번, 결론 한 줄. 나머지는 화면(자료·도식) 자체가 말하게 둔다.
- 장면 안 겹치기는 강조가 아니라 **내용**으로 한다: 자료 사진 액자(`photo`), 날짜 도장(`stamp`), 위치 미니 지도(`locator`) — 말로 하는 것을 '보여 주는' 요소.

### 겹치기 요소 (`hybrid.json` 의 장면에 `"layers": [...]`, 코드 `ytflow/stages/directions.py` 의 `apply_layers`)
| kind | 무엇 | 어느 스타일에서 왔나 | 필드 |
|---|---|---|---|
| `words` | 핵심 단어 1~3개만 한 번 띄움 (문장 전체 금지 · 강조 예산에 포함) | 키네틱 | `beat`, `hit[1~3]`, `y`(0~1, 기본 0.16) |
| `photo` | 자료 사진·영상 액자 (화면 속 화면) | 아카이브 | `src`, `start`, `beat`, `side`, `caption`, `w`, `top`, `until` |
| `stamp` | 날짜·장소 타자기 | 아카이브 | `text`, `beat` |
| `line` | 영상 위 타자기 한 줄 띠 | 아카이브 | `text`, `beat` |
| `locator` | 위치 미니 지도 + 핀 | 지도 여정 | `at:[경도,위도]`, `label`, `beat`, `side`, `scale` |
| `number` | 큰 숫자 카드 (강조 예산에 포함) | 데이터 | `value`, `label`, `beat`, `side` |

좋은 조합 예: 자료 화면 + 위치 미니 지도(locator) · 지도 여정(journey) + 그곳 사진(photo) · 막대 비교(bars) + 비교 대상 사진(photo) · 원본 영상(footage) + 날짜 도장(stamp).
자리 겹침 주의: 오른쪽 위는 출처 라벨, 왼쪽 아래는 이름 자막(lower), 아래 가운데는 자막. 겹치기 요소는 `side`·`top` 으로 비킵니다.
견본: `projects/20261109-style-combo` (`styles/demos/combo.json`) — 14장면, 6가지 스타일, 겹친 장면 7개.

## 0-2. 배경은 장면 목적에 맞춰 바꾼다 (v8, 2026-11-09 사용자 판정: "배경색이 너무 단조롭다, 상황에 맞추어 쓰자")
그래픽 팩은 **색과 질감**만 정하고, 바탕의 **모양**은 장면의 목적이 정합니다. 코드 `ytflow/stages/backdrop.py`가 type 을 보고 자동으로 고르고, 대본 장면에 `"bg"`를 쓰면 직접 고릅니다.

| 바탕 | 언제 (자동으로 붙는 type) | 느낌 |
|---|---|---|
| `photo` | 오프닝·끝·키네틱 (`intro`, `outro`, `kinetic`) — `"bg_src"`로 자료 사진 지정 | 흐리고 어둡게 깐 실제 장소 → "이 이야기의 무대" |
| `grid` | 차트·막대·연표·맞대기 (`chart`, `bars`, `timeline`, `versus`) | 옅은 모눈 → "재는 중" |
| `spot` | 인용·발언·큰 숫자 하나 (`quote`, `bignum`) | 가운데 조명 → "여기에 집중" |
| `tint` | 비유·정리·질문·인과 지도 (`analogy`, `checklist`, `card_type`, `map_causal`) | **장마다 다른 색 기운** → 지금 몇 장인지 색으로 |
| `film` | 그 밖, 자체 바탕이 있는 장면 (자료 화면·지도·장 표지) | 팩 기본 |

- 롱폼은 **3종 이상**(MUST), 같은 바탕 3장면 연속 금지(SHOULD, film 제외). `check` G5.
- 새 바탕을 더하려면 `backdrop.py` 의 `KINDS`·`BY_TYPE` 와 이 표를 함께 고칩니다.

## 0-6. 바탕색을 돌려 쓴다 — 미색 종이만 쓰지 않기 (v13, 2026-11-11 사용자 판정)
> "배경색을 매번 같은 종이색으로 쓰지 않아도 된다."
그래픽 팩 이름이 달라도 paper-sketch·clean-flat·newsprint·kinetic-poster 는 모두 **미색**입니다. 바탕색이 다른 팩을 돌려 씁니다.
| 바탕 계열 | 팩 | 어울리는 곳 |
|---|---|---|
| 흰색 | `clean-white` | 설명·기술, 깔끔한 정보 |
| 회청색 | `slate` | 경제·데이터 |
| 남색 | `midnight` · `blueprint`(모눈) | AI·기술 최전선, 구조 설명 |
| 먹색 | `dark-doc` | 시사·위기·다큐 |
| 초록 | `forest` | 역사·이야기 |
| 미색 | `paper-sketch` · `clean-flat` · `newsprint` · `kinetic-poster` | 손그림·옛 신문 느낌이 꼭 필요할 때만 |
- 같은 바탕 계열을 **직전 두 편과 연속으로 쓰지 않습니다** (`check` G5 SHOULD).
- 한 영상 안에서도 장(章)마다 색 기운(§0-2 tint)과 사진 바탕으로 변화를 줍니다.

## 0-5. 차분하게 — 움직임과 소리는 '덜'이 기본 (v12, 2026-11-11 사용자 판정)
> "화면을 너무 정신없이 움직이고, 배경음도 꼭 안 넣어도 되는데 안 어울리는 걸 억지로 넣는 것 같다."
v10(§0-4)의 전환·카메라·소리를 **아래로 낮춥니다** (코드 `edit10.py`, 기본값):
| 항목 | v10 (너무 많았음) | v12 (기본) |
|---|---|---|
| 장면 사이 전환 | 덮기·밀기·확대·원형을 돌려 씀 + 매번 휙 소리 | **부드러운 겹침(0.3초)**. 장 표지로 넘어갈 때만 살짝 밀기 + 작은 휙 소리 |
| 장면 안 카메라 | 박자마다 방향을 바꾸며 다가감·옆으로 흔듦 | **장면 내내 한 방향으로 아주 천천히 다가가기(2.5%)만** |
| 장 표지 앞 상승음 | 있음 | **없음** |
| 배경음 | 기본으로 깔림 | **기본 없음.** 영상 분위기에 맞는 곡이 확실할 때만 대본에 `"bgm"` — 애매하면 넣지 않음 |
| 3D 기울기·먼지 효과 | 크게·많이 | 약하게·적게 (기울기 5° 안팎, 먼지 입자 적게) |
| 움직임 검사 | MUST: 화면 변화 ≥10/분 | **SHOULD**: ≥8/분 — 숫자를 채우려고 움직임을 더하지 않음 |

**원칙:** 볼거리는 '움직임'이 아니라 **내용**(그 장소 사진·지도·사물 그림·정리판)으로 만듭니다. 움직임은 내용이 바뀔 때만.

## 0-4. 편집 기준 v10 — 연출로 보여 준다 (2026-11-10 사용자 판정: 전후 비교에서 '후' 채택)
> "화면 전환이나 단순 그래프가 아닌 연출 등이 훨씬 마음에 든다. 화면 전환 때 배경도 바꾼 쪽이 더 낫다."
근거: `docs/19-manual-gaps.md` §5 — 같은 대본·같은 목소리로 편집만 바꿔 비교, 정지 화면 비율 0.39 → 0.18.

**기본으로 켜짐** (코드 `ytflow/stages/edit10.py`, 끄려면 대본 맨 위 `"edit_v10": false`):
| 항목 | 무엇 | 대본에서 |
|---|---|---|
| **장면 전환** | 덮기(wipe)·밀기(push)·확대(zoom)·원형(iris)을 돌려 씀. 앞 장면 끝과 다음 장면 처음이 이어짐 + 휙 소리 | 자동. 한 장면만 바꾸려면 `"tr": "iris"` |
| **장면 안 카메라** | 박자마다 방향을 바꾸며 끊임없이 천천히 다가가거나 옮겨 감 (멈춘 화면 없음) | 자동 (자료 화면·지도·키네틱·장 표지 제외) |
| **사진 장 표지** | 장 표지 바탕을 그 장의 자료 사진(흐리게)으로 — 전환 때 배경이 바뀜 | 자동 (자료 화면을 장 번호 순으로 돌려 씀). 고르려면 `"bg_src"` |
| **소리 층** | 전환음 · 장 표지 앞 상승음 · 표지 타격음 · 정리판 차임 · 배경 패드(목소리 나오면 자동으로 낮춤) | 자동. 배경은 `"bgm": "pad"`(임시, 직접 합성) — 음원 정해지면 교체 |

**그래프보다 연출** — 같은 정보를 '그림이 일하는' 장면으로:
| 이렇게 말하면 | v9 (단순 그래프) | v10 (연출) |
|---|---|---|
| 양이 줄었다 (10 → 7) | 막대 2개 | `isotype`: 사물 아이콘 10개 중 3개가 떨어져 나감 (`icon`, `total`, `lost`, `before`, `after`) |
| 여기까지 정리 | 체크리스트 | `recap`: 장 끝 정리판, 지난 줄은 흐리게·새 줄은 밝게 쌓임 (`items`, `new_from`) |
| 장이 바뀐다 | 노란 전면 카드 | 사진 장 표지 (자동) |

- **소리 기준 (2026-11-10 사용자 판정):**
  - 저음 타격음(impact-bass, '두웅')은 **쓰지 않음** — 분위기 문제가 아니라 소리 자체가 싫다는 판정. 코드에서 아예 뺌.
  - 배경음은 **음질**부터: 99% 에너지 대역 4kHz 이상(좁으면 먹먹하고 싸구려처럼 들림), 256kbps 이상, 음량 출렁임 ≤3dB. 등록부 `assets/bgm/bgm.yaml` 의 `measured` 로 확인.
  - 목소리 밑으로 누를 때는 **부드럽게**(약 3:1, 1.5초에 걸쳐 복귀) — 단어 사이마다 배경음이 들썩이면 어색함.
  - 곡이 영상보다 짧으면 이음매를 3초 겹쳐 이어 붙임(딱 끊기는 반복 금지).
- **장식 효과(dust·leak)는 영상당 2장면까지.** 내용이 담긴 볼거리(그 장소 사진·지도·사물 그림·정리판)를 먼저 씁니다 (멀티미디어 학습 '일관성 원칙', docs/19 §1-9).
- **검사:** G6 MUST(롱폼) — 완성본을 재서 화면 변화 ≥10회/분, 정지 화면 비율 ≤0.45. 대본에 효과를 적은 것만으로는 통과 못 합니다.

## 0-3. 반복 피로 막기 — 글씨·도형만 반복하면 금방 지루하다 (v9, 2026-11-09 사용자 판정)
> "매번 같은 패턴이면 금방 익숙하고 지루해진다. 자료를 다룰 땐 덜하지만, 글씨·인포그래픽 도형으로 만든 자체 제작은 더 심하다. 지도를 호평한 것도 특별한 시각 효과가 있어서다."

**원칙:** 화면은 '정보'와 함께 **눈요기(시각적 보상)**가 있어야 합니다. 글씨·도형뿐인 장면을 **plain**, 아래 중 하나라도 있으면 **눈요기 있는 장면**으로 봅니다 (`stylepick.visual_hooks`).

| 눈요기 종류 | 무엇 | 쓰는 법 |
|---|---|---|
| 자료 | 실제 사진·영상·화면 (kb, footage, zoomshot, chat, terminal) | 장면 type |
| 공간 | 지도 여정·나라 색칠 (journey, choropleth) | 장면 type |
| 겹치기 | 사진 액자·위치 지도·손그림 표시 (`layers`: photo, locator, mark) | 05 §0-1 |
| **시각 효과** (`"fx"`) | `tilt` 3D로 기울어 들어와 펴짐 · `dolly` 천천히 밀고 흐르는 카메라 · `dust` 빛 속 먼지 · `leak` 필름 빛샘 · `scan` 스캔 빛줄기 · `photofill` 큰 숫자 안을 자료 사진으로 채움(`fill_src`) | 장면에 `"fx": ["tilt","dust"]` (코드 `directions.apply_fx`) |
| 바탕 | 흐린 자료 사진 바탕 (`"bg": "photo"`) | 05 §0-2 |
| 그림체 | 장면만 다른 그래픽 팩(`"skin"`) — 손그림·청사진·신문 등 | 05 §0-1 |

**규칙 (`check` G5):**
- MUST: plain 장면 **3개 연속 금지** (장 표지·오프닝·끝 제외).
- SHOULD: 눈요기 있는 장면 **60% 이상**.
- SHOULD: 같은 효과 3장면 연속 없음, 롱폼은 효과 **3종 이상** — 효과도 반복하면 다시 패턴이 된다.
- SHOULD: **같은 채널 직전 편과 화면 구성(type·효과) 겹침 70% 이하** — 편을 넘어서도 돌려 쓴다.

**고르는 요령:** 숫자 하나 → `photofill`(그 숫자의 장소 사진으로 채움) · 연표·인과 지도 → `tilt` · 비유·인용 → `dust`/`dolly` · 전환·대비 → `leak` · 자료·목록 → `scan`. 효과는 내용과 어울려야 하며, **강조(05 §0-1)와 달리 정보를 더하지 않는 '분위기'라서 강조 예산에 들어가지 않습니다.** 대신 과하면 산만하므로 한 장면 2개까지.

## 0. 먼저 자동 추천을 받습니다
편집 스타일은 **등록부** `styles/recipes/*.yaml` 에 있습니다 (`python -m ytflow recipes` 로 목록). 각 레시피는 어떤 브랜드·질문 유형·분위기·소스에 맞는지(`fits`)와 영상 안에서 맡는 자리(`roles`: 전체·본론·훅·결론)를 적어 둡니다.
```bash
python -m ytflow style-pick <프로젝트>   # topic_brief.json → 영상 전체·훅·결론 스타일 + 이유 → 01_research/style_pick.md
```

## 1. 영상 단위: 그래픽 팩 고르기
| 그래픽 팩 | 느낌 | 어울리는 브랜드·주제 |
|---|---|---|
| `paper-sketch` (기본) | 종이 + 손그림 | curiosity 전반, market 칼럼(개념·인과) |
| `clean-flat` | 미색 평면, 굵은 막대 | market 데이터 리포트, ai 비교 |
| `dark-doc` | 어두운 다큐, 필름 | curiosity 사건·전쟁·재난, market 위기·폭락 |
| `newsprint` | 누런 신문, 먹색 | curiosity 근현대사, market '그때 신문은' 과거 사례 |
| `blueprint` | 남색 모눈, 흰 선 | ai 원리 설명, market 산업·공급망 구조 |
| `kinetic-poster` | 크림 + 검정 굵은 글자 (자막 숨김) | 쇼츠, 짧은 요약 영상 |

미리 비교: `python -m ytflow skin-preview <프로젝트> --skins paper-sketch,dark-doc,newsprint`.

## 2. 장면 단위: 연출 type 고르기 (말하는 내용 → 화면)
| 이 문장이 하는 일 | 1순위 type | 2순위 | 피할 것 |
|---|---|---|---|
| 사건의 **장면**을 연다 (사람·장소·날짜) | `kb` (자료 화면 켄 번스 + 도장) | `footage` | 글자 카드 |
| **질문·명제 한 줄**을 던진다 | `card_type` (타자기) | `chapter` | 그림 넣기 |
| 누가 **말했다** | `footage` + `lower` (원본) | `quote` (카드 + 형광펜) | 내레이션으로만 |
| **원인 → 결과**를 잇는다 | `map_causal` (같은 칸 위치 유지) | `analogy` | 장면마다 새 도식 |
| **어디서 어디로** 퍼졌다·움직였다 | `journey` (지도 여정) | `usmap` | 표 |
| 주가·지표가 **움직였다** | `chart` (실제 시세, 마지막 구간 확대) | `bignum` | 손그림 가짜 그래프 |
| 둘을 **비교**한다 | `versus` (숫자 두 개) | `bars`, `compare` | 숫자 나열 |
| **비율**을 느끼게 한다 | `people` (100명 중 N명) | `parking`, waffle | 퍼센트 글자만 |
| **시간 순서** | `timeline` | `checklist`(date) | |
| 신문·보도의 **차이** | `newspapers` | `quote` | |
| 모양·패턴 (U자·W자) | `shape` (개념도 표시) | | 숫자 축 있는 척 |
| 꼭 기억할 **한 문장** (결론·훅) | `kinetic` (단어가 말과 함께) | `card_type` | 9분 내내 kinetic |
| AI 에게 **어떻게 시키는지** (프롬프트·답) | `chat` (재구성 예시 표시) | `footage`(실제 화면) | 지어낸 대화 |
| **설치·실행 명령** | `terminal` (실제 실행 기록만) | `footage`(터미널 녹화) | |
| 화면의 **한 곳**을 가리킨다 | `zoomshot` (카메라 줌 + 테두리) | layers `mark` | 줌 3번 이상 |
| **여러 나라**가 나온다 | `choropleth` | `journey` | 출처 없는 값 |
| 따라 하기 **단계** | `footage`(화면 녹화) + `vox` 주석 | `checklist` | |

## 3. 리듬 규칙 (docs/15 근거, `check` 가 일부 자동 검사)
- 자료 화면(footage·kb·journey 사진)이 **45초 넘게 없으면 안 됨**.
- 같은 type 연속 금지 (chapter 제외 3연속은 실패).
- 첫 30초: 장면(닻) → 질문 → 오늘의 지도. 장면 길이 6~10초.
- 약 3분마다 질문형 장 표지 또는 반전 문장 (다시 붙잡기).
- 장면 평균 10~15초, 25초 넘는 장면은 박자 안에서 화면이 바뀌어야 함(reveal·focus·카메라).
