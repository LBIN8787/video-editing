# 02. ai — AI 더 잘 쓰기 (AI 트렌드와 활용법)

**욕망:** AI 를 더 잘 알고 더 잘 다루고 싶다 (뒤처지기 싫다 · 일을 덜고 싶다 · 남보다 먼저).
**약속:** "이번 주 바뀐 것 하나, 오늘 바로 써먹게." + **"AI 업계의 큰 흐름(돈·규칙·회사·칩)을 이용자 눈높이로."** (2026-11-11 사용자 요청: 단순 활용을 넘어 업계의 유용한 소식까지)
**시청자:** AI 를 몇 번 써 본 직장인·학생·크리에이터. 개발자가 아닐 수 있다 → 코드·영어 용어는 풀어서.

## 1. 주제 찾기
| 순위 | 트리거 | 어디서 | 시청자 질문 | 라인 |
|---|---|---|---|---|
| 1 | 큰 회사의 새 모델·기능 발표 | 공식 블로그·릴리스 노트, 공식 X | 이거 뭐야? 뭐가 달라졌어? | 롱폼 (72시간 안) |
| 2 | GitHub 14일 별 급증 저장소 (스킬·MCP·에이전트) | `python -m ytflow shorts` 의 후보 | 이거 어떻게 써? | 쇼츠 |
| 3 | 따라 하면 되는 활용법 (업무 자동화·문서·영상·코딩) | 공식 문서의 예제, 직접 해 본 결과 | 나는 어떻게 써? | 롱폼 실습 / 쇼츠 |
| 4 | 가격·무료 한도·지역 제한 변화 | 가격 페이지 | 무료로 되나? | 쇼츠 |
| 5 | AI 와 일자리·돈·규제 사건 | 정부·기관 발표, 주요 보도 | 내 일엔 무슨 변화? | 롱폼 해설 (market 과 겹치면 market 으로) |
| 6 | **AI 업계 소식** — 상장·투자·인수, 칩 공급, 규제, 큰 회사의 사건 | 회사 공식 발표(뉴스룸), 통신사(AP·로이터), 정부 발표 | 업계가 어디로 가지? 나에게 바뀌는 건? | 롱폼 '이번 주 업계' (2~3개 소식, 각 소식마다 '이용자에게 바뀌는 것' 한 줄). 주가 분석은 market 채널로 넘김 |

**판정:** 활용법 영상은 직접 실행해서 **결과 화면**을 보여 줄 수 없으면 롱폼으로 만들지 않습니다 (쇼츠 '소식'형으로 낮춤). **업계 소식 영상**은 결과 화면 대신 **1차 출처(회사 발표·공시) 2개 이상**과 '이용자에게 바뀌는 것' 장이 있어야 만듭니다.
**만들지 않는 주제:** 공식 출처 없는 루머 모델, 탈옥·약관 위반 사용법, 유료 강의 홍보처럼 보이는 것.

## 2. 깊은 조사 — 네 층
| 층 | 질문 | 출처 | 팩트시트에 남길 것 |
|---|---|---|---|
| ① 무엇 | 정확히 무엇이 나왔나 | 공식 발표·문서·README | 이름, 날짜, 대상(무료/유료/지역), 가격 |
| ② 무엇이 다른가 | 전과 비교해 뭐가 좋아졌나 | 공식 수치 + **독립 검증**(벤치마크 사이트, 직접 테스트) | 비교 기준(이전 버전·경쟁 제품), 회사 주장과 독립 결과 구분 |
| ③ 어떻게 | 시청자가 따라 하려면 | 직접 실행 | 단계 번호, 각 단계 결과 화면, 막히는 지점 |
| ④ 한계 | 무엇은 안 되나, 주의할 점 | 문서의 제한 사항, 직접 실패 사례 | 1개 이상 (없다고 쓰지 않음) |

회사 발표 숫자는 "회사 발표 기준"이라고 말합니다. 독립 검증이 없으면 ⚠️.

## 3. 대본 공식

> **모든 채널 공통 기준 (v11) — 이 문서의 대본 공식보다 우선합니다.**
> 롱폼은 **MC 오프닝**(인사 → 오늘 이야기 → 순서 예고 → 시작 멘트, README §2-1)으로 시작하고, 장 표지마다 진행 멘트를 넣습니다.
> 연출은 **조합**(05 §0-1) · **강조 아껴 쓰기** · **장면 목적별 배경**(§0-2) · **반복 피로 막기**(§0-3) · **편집 기준 v10**(§0-4: 전환·카메라·사진 장 표지·소리, 그래프보다 사물 그림·정리판) · **소리 기준**(저음 타격음 금지, 음질 좋은 배경음)을 따릅니다.
> 목소리·배경음은 채널 설정(`channels/<id>/channel.yaml` 의 `tts`·`bgm`)을 씁니다.

### 롱폼 (8~12분)
| 구간 | 내용 | 연출 예 |
|---|---|---|
| 오프닝 (20~30초) | MC 오프닝: 인사 → "오늘은 ○○를 해 보겠습니다" → 순서 예고 → 시작 | intro (바탕: 결과 화면 흐리게) |
| 0 훅 (30초) | **결과부터** — 완성된 결과 화면 + "이걸 말 한마디로 했습니다" | footage(화면 녹화) → kinetic 한 줄 |
| 1장 | 무엇이 바뀌었나 (한 문장 정의 + 비유) | analogy, versus(전/후) |
| 2장 | 왜 중요한가 (나에게) | bignum(시간·비용 절약 숫자, 직접 잰 값) |
| 3~4장 | **따라 하기**: 단계 번호, 화면마다 하이라이트 | footage(녹화) + vox 주석, checklist |
| 5장 | 한계·주의 (가격·개인정보·틀리는 경우) | checklist(warn) |
| 끝 | 오늘 하나만 해 볼 것 + 다음 주제 예고 | outro |

### 쇼츠 (30~45초) — `ch-ai-shorts`
결과 화면(0~3초) → 무엇 → 어떻게(3단계 이하) → 무료/유료 → 한 줄 CTA. 약 200자. `prompts/shorts_script.md`.

**쉬운 말:** 영어 기능명은 처음 한 번 "(무엇을 하는 기능)"으로 풀고, 이후 한국어 이름으로. API·토큰·컨텍스트 같은 말은 `glossary`.
**과장 금지:** "이거면 끝", "개발자 다 망함", "무조건" 금지. 직접 확인한 것만 "됩니다".

## 5. 포장
- 제목: `[결과/변화] + [나에게]` — "말 한마디로 엑셀 정리, 무료로 따라 하기"
- 썸네일 A: 전/후 결과 화면 / B: 큰 한 단어 + 제품 화면 / C: 단계 번호 1·2·3.
- 회사 로고는 사실 전달 범위(제품 이름 표시)에서만, 공식 제휴처럼 보이게 하지 않음.
