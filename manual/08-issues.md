# 08. issues — 이슈의 구조 (시사·사회 이슈·역사 해설)

**욕망:** 세상이 어떻게 돌아가는지 알고 싶다 — **그리고 그걸 재미있게 듣고 싶다.** (v7: 시사 = '재미있게 보는 뉴스')
- 뉴스 속 큰 사건을 '왜·어디로'까지 이해해서 불안을 줄이고 싶다.
- 대화에서 뒤처지고 싶지 않다(사회적 화폐).
- 내 삶에 올 영향을 미리 알고 싶다.

**약속:** "실제 자료로 사건을 따라가며 무슨 일이 왜 일어났는지 이해한다."

**범위 (2026-11-20 사용자 결정):** 지금의 정책·사회·국제 이슈와 과거 사건의 흐름·원인을 다룹니다. 현대인의 일상적인 행동이나 심리 기제가 중심인 이야기는 [호기심 제작 기준](04-curiosity.md)을 적용합니다.

**시청자:** 뉴스 제목은 봤지만 맥락이 없는 일반인. 정치 성향은 제각각이므로 **한쪽으로 기울면 신뢰를 잃는다.**

**근거:** `docs/18-issues-research.md` (비교 채널 8곳 640편 분석).

## 0-1. 시사는 '재미있게 보는 뉴스'다 (v7, 사용자 판단 + docs/18 근거)
시청자는 공부하러 오지 않습니다. **세상 돌아가는 소식을, 친구가 재미있게 풀어 주는 이야기로** 듣고 싶어 합니다. 뉴스와 같은 사실, 다른 말투.

| 재미의 장치 | 이렇게 | 이러면 안 됨 |
|---|---|---|
| **수수께끼로 시작** | 상식과 반대인 사실 하나로 훅 ("유가는 올랐는데 산유국이 작아졌다?") | 사건 개요부터 읽기 |
| **분석형 내레이션** | 차분하고 자연스럽게, '~입니다·~인데요·~거든요·~죠'를 문맥에 맞게 섞음 — 특정 어미를 강제하지 않음 (`11-workflow.md` §3-2, 2026-11-17) | 딱딱한 앵커 나열 · 지나치게 가벼운 친구 말투 · 억지 긴장감 · 반복되는 질문 패턴 |
| **장마다 작은 답** | 장 끝에 '그래서' 한 줄 → 다음 장의 새 궁금증 | 정보 나열 후 다음 장 |
| **장면이 있는 비유** | 손에 잡히는 비유 (과일 가게, 깔때기) — 추상적인 구조가 나올 때 | 추상적 설명만 |
| **사람·생활** | 당사자 말, 우리 생활(기름값·물가)로 이어지는 장 | 나라·기관 이름만 오가는 영상 |
| **숫자는 적게** | 한 장이 말하려는 것을 받치는 핵심 숫자만, 나머지는 말로 풀기 | 숫자 연속 (기억에 남는 것이 없어짐) |

**재미가 사실을 이기지 않습니다:** 과장어·낚시 금지, 양쪽 입장·기준 시각·'아직 모른다'는 그대로 지킵니다(§6). 재미는 **말투와 순서**에서 나오지, 사실을 부풀려서 나오지 않습니다.

## 0-2. 매일 이슈 정리 (v17, 2026-11-12 사용자 요청: "시사도 매일 실시간 분석이 중요")
1. `python -m ytflow daily --brand issues --project <YYYYMMDD>-issues-daily` → 전날 주요 뉴스를 묶어 다룬 언론사 수로 순위.
2. **구조가 있는 이슈 하나**를 고릅니다 (정책·제도·국제·기업). 개인 피해 사건·사고는 제도·구조 문제로 이어질 때만 (README §3).
3. 확인: 당국·기관 발표 원문, **양쪽 입장**, 기준 시각(“○월 ○일 ○시 기준”).
4. 대본: 빠른 정리 틀(§3, 길이는 README §2-4) — 무슨 일 → 왜 지금 → 양쪽 입장(같은 길이) → 앞으로·나에게 → 확인되지 않은 것. 실제 자료를 앵커로 삼는 §0-3의 화면 기준을 적용한다.
5. **무엇으로 이어지나·무슨 뜻인가** (v18, 03 §0-1 과 같은 원칙): 사실 정리에서 끝내지 말고 그 사건이 제도·다른 나라·한국·내 생활로 어떻게 번지는지, 사실과 해석을 나눠("여기서부터는 가설입니다", README §2-8).
6. 큰 국제 이슈가 시장을 움직였으면 시장 브리핑(03 §0)과 나눠: 시사는 '왜 일어났나', 시장은 '돈이 어떻게 움직였나'.

## 0-3. 시사·역사 편집의 기준 — 기존 스페인독감 편

2026-11-07 **기존 스페인독감 편**의 [장면 대본](../projects/20261107-knowledge-스페인독감/02_script/hybrid.json)과 [실제 제작 설정](../projects/20261107-knowledge-스페인독감/edit.yaml)을 기준으로 삼습니다. 하이브리드 편집에서 자료 영상·사진으로 사건을 따라가고, 지면·지도·연표·비교 도식으로 자료 사이의 관계를 이해시키는 방식입니다.

1. **자료 먼저.** 보여 줄 공식 발언 영상·현장 기록·사진·당시 지면을 찾아 날짜·장소·출처를 확인합니다. 장면표에 그 자료로 어떤 사실을 보여 줄지 적습니다.
2. **한 사건과 질문 하나.** 실제 장면에서 시작해 질문을 열고, 사건의 시간 순서나 인과를 따라 다음 장으로 갑니다. 예를 들어 스페인독감 편의 보도는 지면, 지역 차이는 지도, 두 도시의 차이는 같은 기준의 비교 화면으로 설명합니다.
3. **움직임은 이해를 돕는 순간에.** 지명·사람·문서에 내레이션이 닿으면 해당 부분을 보여 줍니다. 비교는 단위·기간·집계 범위를 먼저 놓고 차이를 읽을 시간을 줍니다. 기록 영상에서는 원본의 움직임과 발언이 장면을 이끕니다.
4. **화면 선택.** 실제 자료가 사건을 확인해 주는 컷과, 설명 사이에서 시대·공간·행동을 보여 주는 보조 컷을 상황에 맞춰 씁니다. 자료 사이의 관계나 수치 변화는 인포그래픽으로 설명하고, 두 방식으로 보여 주기 어려운 장면은 삽화로 담습니다. [표현 방식과 레퍼런스](12-visual-storytelling.md)

5. **사실 목록이 아니라 단서를 추적하는 순서로 (2026-11-21 사용자 제공 영상 진단·대본 검토).** 시대별 사실을 나열하기보다 제목의 질문(예: '왜 스페인이라는 이름이 붙었나')을 첫 화면의 원본 자료(당시 신문)에서 열고, 기록과 사람의 선택을 따라 답에 다가갑니다. 자료가 등장하는 것과 이야기가 전진하는 것은 다릅니다.
6. **원인을 나눠 말합니다.** 서로 다른 질문의 답을 한 인과로 묶지 않습니다 — 예: 병명이 잘못 붙은 이유(전시 보도 불균형)와 도시별 사망률 차이(방역 조치의 시점·강도)는 따로. 연구가 직접 분석하지 않은 인과(검열이 사망률을 갈랐다)는 결론으로 쓰지 않습니다. 기록 영상·사진은 촬영 연도·장소가 설명 중인 사건과 맞는지 확인하고, 다르면 '시대 참고 화면'으로 표시합니다.
7. **같은 화풍, 다른 연출.** 종이 배경의 인용문·지도·통계·챕터가 같은 모양으로 되풀이되지 않게, 자료의 역할에 따라 연출을 고릅니다(신문 원문은 해당 부분을 따라 읽기, 확산은 이동 경로가 변하는 지도, 두 도시 비교는 조치 날짜와 사망률을 같은 시간축에). 한 화풍을 편 전체에 쓰는 것은 괜찮습니다 — '한 스타일 40% 초과 실패' 같은 비율 기준은 품질의 척도로 쓰지 않습니다.

**시사:** 기준 시각, 당사자 입장, 확인되지 않은 사실을 §2·§6에 따라 확인합니다. **역사:** `topic_brief.json`에 `"issue_kind": "history"`를 적고 사건의 시기·장소와 자료의 작성 시점을 밝힙니다. 기록이나 해석이 갈리는 대목에서는 각각의 근거를 보여 주고, 확인 가능한 결론과 남은 쟁점을 설명합니다. 역사 소재는 `ch-issues` 심층 제작 라인에서 다룹니다.

## 0-4. 세계사 스토리와 자료의 움직임

세계사를 진행자 얼굴 없이 이야기할 때는 **시청자가 알아볼 대상과 그 대상에 일어난 뜻밖의 변화**를 먼저 찾는다. 유물, 광장의 한 장면, 사라진 전시물, 제도가 바꾼 한 사람의 일상처럼 화면에서 따라갈 대상을 정한다. 역사 사건 자체가 중심인 편은 `ch-issues` 심층 형식과 `topic_brief.issue_kind: history`를 쓴다.

### 주제 결정

1. **후보마다 첫 질문과 첫 원자료를 짝짓는다.** 시청자가 이미 아는 이름과 모르는 이유를 붙인다. 날짜·장소가 확인된 사진, 유물, 문서, 원본 영상 중 하나로 시작 장면을 실제로 만들 수 있는지 확인한다. 질문이 같아도 확인된 원자료에 따라 편집 형식이 달라진다.
2. **수요와 제작 가능성을 함께 비교한다.** [욕망 점수표](01-desire-map.md)를 쓰고 조회수·채널 크기·언어·공개 시점이 확인된 범위를 적는다. 누적 조회수는 관심의 단서로 사용한다. 원자료 확보 여부, 자료로 확인할 수 있는 결말, 다른 해설에서 보지 못한 질문까지 기록한 뒤 가장 강한 후보를 고른다.
3. **선정 이유를 인과 순서로 남긴다.** 누구의 어떤 궁금증인지 → 제목의 질문 → 첫 화면에 쓸 자료 → 본문에서 붙일 독립 자료 → 시청자가 이해할 답 → 가장 가까운 차점보다 유리한 이유 순으로 적는다. 증거가 약한 핵심은 불확실성을 정확히 설명할 수 있을 때 진행한다.

### 이야기와 카메라가 하는 일

| 중심 자료 | 서사의 흐름 | 화면이 바뀌는 이유 |
|---|---|---|
| 유물·기록물 | 물건 → 설명되지 않는 흔적 → 비교할 단서 → 확인된 해석 → 다시 물건 | 처음에 전체를 보여 준다. 시선을 디테일로 옮긴 뒤 자료와 뜻을 함께 읽을 시간을 준다. |
| 당대 기록 영상·사진 | 현장 → 관찰할 신호 → 행동과 반응 → 결과 | 영상 자체의 움직임을 우선한다. 같은 구도 안에서 사람이 어떻게 반응하는지 읽힐 때는 유지한다. |
| 도시·문명·경로 | 구체적인 한 장소 → 공간의 크기 → 이동 또는 선택 → 남은 흔적 | 지도 접근은 위치를 알려 줄 때, 와이드 전환은 규모 관계가 달라질 때, 확대는 다음 사실을 담는 부분을 찾을 때 쓴다. |
| 생활사·제도 체험 | 한 사람의 예상 → 현실의 장애물 → 당시 기록 → 바뀐 상태 | 카메라를 두고 인물·물건의 상태를 바꾸는 방식도 쓴다. 가상의 인물이나 장면은 화면에서 사례·재현임을 밝힌다. |

장면표에는 **대사에서 새로 생기는 사실, 화면의 시작 상태, 무엇이 움직이는지, 도착 프레임에서 더 보이는 것**을 적는다. 원본의 동작, 카메라 이동·편집 확대, 요소의 애니메이션, 컷을 각각 기록한다. 자료 위 출처·연도는 읽을 수 있게 두고, 시대 참고 화면과 재현은 실제 기록을 읽는 사람에게 구별되게 한다. 설명할 바가 모여 있으면 화면을 붙잡고, 관계나 관찰 대상이 달라지면 전환한다. 특정 컷 수나 줌 횟수를 목표로 두는 대신 앞뒤 프레임을 보며 이야기가 진행되는지 확인한다.

**편집 검토** · 첫 장면은 제목의 질문과 같은 대상을 여는가. 각 장의 새 자료가 무엇을 알아냈는지 화면이 보이는가. 확대 전에 전체 위치를 알 수 있고 확대 뒤 새로운 단서가 읽히는가. 서사 결말이 시작 화면에 새 의미를 부여하는가. 사실과 해석이 갈리는 곳에서 자료의 시기와 확인 범위가 보이는가.

## 1. 주제 찾기
| 순위 | 트리거 | 시청자 질문 | 형식 |
|---|---|---|---|
| 1 | 국제 큰 사건 (공습·제재·선거·정권 교체) | 왜 지금? 앞으로? | 48시간 안 **빠른 정리** → 1주 안 **심층** (길이는 README §2-4) |
| 2 | 강했던 것의 몰락·부상 (나라·도시·기업) | 왜 무너졌지? | 심층 (제목 '몰락·붕괴·위기' 1.41배) |
| 3 | 국내 제도 변화·사회 논쟁 | 나한테 무슨 상관? | 빠른 정리 |
| 4 | 사람 이야기 (피해자·당사자) | 그 사람은 어떻게 살고 있나 | 심층 (인터뷰는 직접 취재·공식 영상만) |
| 5 | 역사 사건·제도의 변화 (당시 자료가 남아 있는 것) | 그때 어떤 선택이 결과를 갈랐나? | 심층 |

**판정 기준 (01 §3 욕망 점수표 + 아래):**
- 시사는 서로 다른 입장 2개 이상을 출처와 함께 보여 줄 수 있어야 만든다(`sides`). 역사는 사건을 보여 주는 원자료와 교차 확인 자료의 조합을 먼저 본다.
- 확인 안 된 것이 핵심이면 '아직 모른다'를 영상의 한 장으로 둘 수 있을 때만 만든다(`unknowns`).
- 만들지 않는 것:
  - 개인(공인 아닌 사람)의 신상·사생활이 핵심인 사건
  - 수사 중인 사건의 범인 단정
  - 선거 기간의 특정 후보 유불리 해설
  - 혐오를 부를 수 있는 집단 일반화

## 2. 깊은 조사 — 다섯 층
| 층 | 질문 | 출처 | 팩트시트에 남길 것 |
|---|---|---|---|
| ① 사건 | 언제·어디서·무엇이 | 통신사 + 공식 발표 | **기준 시각** (`as_of`, "○월 ○일 ○시 기준") |
| ② 배경 | 왜 지금인가 | 과거 경과, 연표 | 시간 순서 3~6개 |
| ③ 구조 | 누가 무엇을 얻고 잃나 | 이해당사자 공식 입장, 통계 | 인과 지도 칸 4~8개 |
| ④ 입장 | 서로 다른 말은 | **성향이 다른 언론 2곳 이상** + 당사자 원문 | `sides` 2개 이상 (누가·무엇을·출처) |
| ⑤ 전망 | 앞으로 볼 신호 | 전문가 공개 분석(이름·소속), 예정 일정 | 신호 2~3개 + '이렇게 되면 틀린 것' |

**역사 팩트시트**는 사건·당시 조건·원인·서로 다른 기록·남은 영향으로 정리합니다. 당대 기록이 말해 주는 것과 후대 연구자가 해석한 내용을 자료의 작성 시점과 함께 적습니다.

**표현 규칙:**
- 확인된 사실 → 단정한다.
- 당사자 주장 → "○○는 ~라고 주장합니다".
- 의혹 → "~라는 의혹이 제기됐습니다(누가, 언제)".
- 모르는 것 → "아직 확인되지 않았습니다".

## 3. 대본 공식

> 공통 기준이 우선합니다: 인트로 없음(README §2-1), 말투 `11-workflow.md` §3-2, 자료 고르기 12 §0-1, 연출·움직임·소리 05 §0-1~§0-5, 목소리·배경음은 `channel.yaml`.

### 역사 심층

기록 속 장면 → 한 질문 → 당시 조건과 사건의 변화 → 원인과 자료 비교 → 남은 영향이나 오늘과의 연결(관련 있을 때) → 첫 질문에 답합니다. 자료가 확인해 주는 범위와 해석이 갈리는 지점을 내레이션에 반영합니다.

### 시사 심층 (길이는 README §2-4)
| 구간 | 위치 | 내용 | 연출 예 (조합 규칙 05 §0-1) |
|---|---|---|---|
| 훅 | ~1분 | 사건 장면(날짜·장소) → 수수께끼 질문 | kb(자료 사진) → card_type 질문 |
| 1 배경 | ~3분 | 시간 순서 | timeline, journey |
| 2 구조 | ~6분 | 누가 무엇을 얻고 잃나 | map_causal, choropleth |
| 3 입장 | ~9분 | 양쪽 말 (같은 분량, 같은 연출) | quote ×2 (같은 틀) |
| 4 우리에게 | ~11분 | 한국·생활 영향 | bars, photo 겹치기 |
| **결론 그림** | **끝 무렵** (다시 보는 구간) | 한 장 정리: 인과 지도 완성판 또는 지도 (다시 보는 구간) | map_causal 전체, 오래 머묾 |

### 빠른 정리 (길이는 README §2-4)
훅(사건 + 수수께끼, 인트로 없음 v24) → 무슨 일 → 왜 지금 → 양쪽 말 → 우리에게 → 볼 신호. 장마다 한 줄 결론. 대본 맨 위 `"format": "quick"` (길이 예외는 README §2-4).

## 4. 화면·그래픽

[§0-3 제작 기준](#0-3-시사역사-편집의-기준--기존-스페인독감-편)으로 주된 컷을 고른 뒤 아래 그래픽 팩을 선택합니다.
- **무거운 주제(전쟁·몰락):** `issue-dark-montage` — dark-doc 팩, 켄 번스 자료 사진, 지도, 인과 지도. 음악은 낮게.
- **생활 영향 주제:** `issue-quick-brief` — clean-flat 팩, 사진 액자, 숫자 하나.
- **인물 사진:** 공식·퍼블릭 도메인·CC BY 만 쓴다. 표정을 골라 조롱하는 사진은 쓰지 않는다. 합성이면 '재구성 이미지'라고 표시한다.
- **양쪽 입장은 같은 틀로** 보여 준다. 크기·색·길이를 같게 해서, 연출로 한쪽 편을 들지 않는다.

## 5. 포장 (제목·썸네일)
- **제목:** `[주체] + 왜/몰락/정리 + [지금]`. 예: "러시아 경제는 왜 지금 흔들리나 | 전쟁 3년의 계산서".
  - 감정어(충격·소름)는 쓰지 않는다 (01 §5).
- **썸네일:** 예: 큰 두 줄 + 강조 하나 + 피사체 하나(지도자 얼굴·국기·상징물). 제목은 질문, 썸네일은 결론 냄새.
- **썸네일 문구도 같은 사실 규칙을 따른다.** 의혹을 사실처럼 쓰지 않는다.
