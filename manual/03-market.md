# 03. market — 시장의 이유 (경제·주식·산업·기술을 연결해 깊이 있게)

**욕망:** 돈의 흐름을 남보다 먼저, 정확히 알아서 투자에서 이기고(잃지 않고) 싶다.
**약속(채널 한 줄):** "움직인 이유를, 연결된 것까지, 쉽게."
**시청자:** 주식을 하는 일반인(전문가 아님). 뉴스 제목은 봤지만 **왜**인지, **나에게 어떤 의미**인지 모른다.

## 0. 매일 아침 시장 브리핑 — 기본 운영 (v17, 2026-11-12 사용자 요청)
> "주식·시사는 매일 실시간 분석이 중요하다(특히 주식). 전날 주식시장을 보고 무슨 이슈·보고서·전망이 시장을 크게 움직였는지 분석하고, 이를 바탕으로 설명해 달라."

시장 채널의 **기본 주제는 '전날 시장을 크게 움직인 것'**입니다. 기획 영상(산업·과거 사례)은 큰 움직임이 없는 날이나 주말에.

**순서 (매일, 한국 시간 아침 — 미국 장 마감 06:00 KST, 서머타임 05:00)**
1. **훑기**: `python -m ytflow daily --project <YYYYMMDD>-market-daily` → `01_research/daily_brief.md`
   - ① 지수·환율·금리·원자재 마감 (시장마다 **장이 끝난** 가장 최근 거래일, 날짜 표시. 원본 갱신이 늦은 값은 ⚠️ — 거래소·기사로 확인)
   - ② 업종(미국 섹터 ETF) ③ 대형주 큰 움직임(±2% 이상)과 **기준 지수 대비**(회사만의 움직임인지 시장 전체인지)
   - ④ 움직임마다 국문·영문 뉴스 → 원인 종류 1차 분류: **이슈 · 보고서(증권사·기관) · 전망(가이던스·연준·지표) · 실적**
   - ⑤ 그날의 주제어 (관심 종목 밖의 이야기 — 예: 코어위브 실적) ⑥ 시장 전체 뉴스
2. **고르기**: 시장을 크게 움직인 이야기 **2~3개**. 기준 = 움직임 크기 × 보도량 × '우리가 1차 출처로 원인을 확인할 수 있나'. 하나는 시장 전체(지수·업종), 하나는 회사만의 이야기가 이상적.
3. **확인하기 (자동 분류는 단서일 뿐)**: 원인마다 1차 출처 하나 이상.
   | 원인 종류 | 1차 출처 | 대본에서 |
   |---|---|---|
   | 이슈 (사건·규제·소송·계약) | 회사 발표·SEC 8-K·DART 공시·당국 발표 | "회사는 ~라고 밝혔습니다 (○일 발표)" |
   | 보고서 (증권사·기관) | 보고서 원문 공개분, 또는 그 문장을 인용한 보도(매체·날짜) | "○○증권은 목표가를 ~로 올렸습니다 — 한 기관의 의견" (권유처럼 읽히지 않게) |
   | 전망 (가이던스·연준·지표) | 회사 실적 자료·연준 성명·통계 발표 원문 | 예상치와 실제를 나란히 (compare_to) |
   | 실적 | 실적 발표 자료(보도자료·IR) | 예상 대비 + 지난 분기 대비 |
4. **설명하기**: 아래 대본 틀 → `hybrid.json` (`brand: market`, 장 표지는 대시보드·듀오톤, 관계는 증거판 look)
5. **오늘 볼 것**으로 끝내기: 날짜·시각이 있는 일정(지표 발표·실적·연준 발언). "사라/팔라" 대신 "이 숫자가 ~면 이 설명이 맞았던 것".

**매일 브리핑 대본 틀 (10~12분, v24)**
| 순서 | 장면 | 내용 |
|---|---|---|
| 오프닝 | (없음, v24) | 인사·소개 없이 첫 문장부터 **훅 한 줄**(그날의 반전·가장 큰 숫자, 답은 숨김, 질문으로) → 순서 예고 (v18, README §2-1) |
| 어제 시장 한 장 (40초) | bars·versus (지수·업종) | 지수·업종 등락, 시장 전체 분위기 한 문장 |
| 이야기 1~3 (각 1.5~2분) | chapter(dash·photo) → chart(그 종목 시세) → quote/footage(발표·보고서 문장) → board/map_causal(연결) | 무엇이 → 왜(원인 종류 + 출처) → 시장 전체와 같이/따로 → 다른 종목으로 번졌나 |
| 오늘 볼 것 (30초) | checklist | 일정·지표·발표 시각 |
| 마무리 | outro | 기준 시각 + "투자 권유가 아닙니다" |

**하지 않는 것**: 장중(마감 전) 값을 '마감'으로 말하기 · 하루 움직임으로 장기 결론 · 보고서 목표가를 권유처럼 · 확인 안 된 원인 단정(“~때문으로 보입니다”는 출처가 있을 때만).

## 0-1. 어닝콜은 자세히, 그리고 '무엇으로 이어지나·무슨 뜻인가'까지 (v18, 2026-11-12 사용자 요청)
> "코어위브 어닝콜 내용까지 — 코어위브만이 아니라 다른 기업들의 어닝콜도 나중에 자세히." · "있던 내용을 다루는 것만이 아니라, 이 내용들이 무엇으로 연결되는지, 어떤 의미를 가지는지 자세히."

**어닝콜 = 실적 숫자 + 경영진의 설명·약속 + 애널리스트가 묻는 것(=시장의 걱정).** 큰 회사가 실적을 내면 숫자만이 아니라 콜을 다룹니다.

1. **원문 확보 (우선순위)**: ① 회사 IR 공식 녹취록(Proofread transcript)·웹캐스트 ② SEC 8-K 실적 보도자료(숫자 대조) ③ 녹취록 사이트(이름 오타 주의). 막힌 곳은 우회하지 않음.
2. **정리**: `python -m ytflow earnings-call <프로젝트> <녹취록 PDF·주소> --ticker <티커> --period 3Q26` → `01_research/earnings/<티커>_call.md`
   (준비 발언 핵심 문장, 애널리스트 질문표 + 첫마디(콜에 대한 반응), 질문 주제 집계 = 시장이 걱정하는 것)
3. **대본 구조 (어닝콜 해부 10~12분)**

| 장 | 무엇을 | 장면 |
|---|---|---|
| 숫자와 약속 | 실적 vs 예상 vs 가이던스, 마진 흐름, 회사가 내놓은 약속 | bignum · bars · checklist |
| 걱정과 답 | 애널리스트 질문에서 뽑은 **시장의 걱정 2~3개**와 경영진의 답 — **원문(영어) + 번역** | quote(`orig`) · checklist |
| 콜의 평가 | 주가 반응, 애널리스트의 첫마디·후속 보고서 | bars · quote |
| **무엇으로 이어지나 (해석)** | 그 답이 다른 회사·업종·한국 시장·내 일상으로 어떻게 번지나 → **무슨 뜻인가** | board(증거판) · analogy · versus |
| 남은 숙제 | 좋은 말 뒤의 위험 (손실·이자·희석·고객 집중) — 균형 | checklist |
| 다음에 확인할 약속 | 다음 분기에 맞았는지 볼 숫자와 날짜 | checklist |

**사실과 해석을 나눕니다**: 해석 장 첫머리에 "여기서부터는 해석입니다", 팩트시트 `## 해석` 에 💬 + 근거 번호. 해석은 "~로 볼 수 있습니다 / ~라고 봅니다"로, 단정·권유 금지.
**모든 시장·시사 영상에 '연결과 의미'**: 매일 브리핑도 이야기마다 "그래서 무엇으로 이어지나(다른 회사·업종·한국·생활) → 무슨 뜻인가"를 한두 문장 이상 (check: 팩트시트 `## 해석`).

## 1. 주제 찾기 — 트리거에서 질문으로
매일(또는 영상 만들기 직전) 아래 순서로 트리거를 모읍니다. 가장 강한 것은 **'움직임'**입니다.

| 순위 | 트리거 | 어디서 | 시청자 질문 |
|---|---|---|---|
| 1 | **하루 ±5% 이상** 움직인 대형주·업종 (한·미) | `python -m ytflow make --channel <라인> --plan` 의 트렌드, 야후 파이낸스 시세(`marketdata.py`) | 왜? |
| 2 | 실적발표·가이던스 (특히 예상과 크게 다를 때) | 실적 일정, 보도자료, 실적 콜 | 숫자가 뭐가 달랐지? |
| 3 | CEO·연준·유명 투자자 **발언** | CNBC·Bloomberg·Yahoo Finance 공식 채널, 공식 X | 누가 뭐라고 했어? 진짜 뜻은? |
| 4 | 공시: 지분·M&A·자사주·대량 매도 | SEC(8-K·13F·Form 4), DART | 누가 사고팔았지? |
| 5 | 거시: 금리·환율·유가·관세 결정 | FRED, 연준·한은 발표 | 내 주식에 어떻게 번지지? |
| 6 | 시장 소문 | 뉴스·커뮤니티 (출처 기록) | 그 얘기 진짜야? → **사실 확인형**으로만 (01 §4) |

**주제 문장 만들기:** `[트리거] → [시청자 질문] → [우리 답의 방향]`
예: "SK하이닉스 하루 +8% → 왜? → HBM 계약 소식보다 '엔비디아 실적 콜의 한 문장'이 원인이었다(발언 원본 + 공시 확인)."

**만들지 않는 주제:** 원인을 확인할 1차 출처가 없음 / 이미 48시간이 지나 모두가 같은 설명을 함(우리만의 답이 없으면) / 종목 추천으로만 읽힐 수 있는 주제.

## 3. 깊은 조사 — 다섯 층 (한 층이라도 비면 아직 얕다)
| 층 | 질문 | 출처 (1차 우선) | 팩트시트에 남길 것 |
|---|---|---|---|
| ① 사실 | 무엇이 얼마나 움직였나 | 시세 데이터(종가·거래량), 공시 | 날짜·숫자·단위, 비교 기준(평소 거래량, 52주 범위) |
| ② 직접 원인 | 그날 무슨 일이 있었나 | 보도자료, 공시, 실적 콜 녹취, 로이터·블룸버그 | 시간 순서 (발표 시각 vs 주가 움직인 시각) |
| ③ 인과 연결 | 그 일이 왜 주가를 움직이나, 어디로 번지나 | 산업 리포트(공개본), 회사 10-K 사업 설명, 공급망 | 원인 → 중간 단계 → 결과 (화살표 3~6개) |
| ④ 사람의 말 | 누가 무엇을 말했나 | 발언 원본 영상·녹취·공식 X | **원문 + 번역 + 날짜 + 자리(어떤 행사)**, 숫자는 공시로 교차 확인 |
| ⑤ 과거 사례 | 비슷한 일이 전에 있었나, 그때 어땠나 | 과거 시세, 당시 보도 | 같은 점 / 다른 점 각 1개 이상 |

- 사실마다 ✅(1차 출처 확인) / ⚠️(2차 출처만) / ❌(확인 실패) 를 붙입니다. ⚠️ 는 "~로 알려졌다", ❌ 는 쓰지 않습니다.
- 발언 속 숫자가 공시와 다르면 **공시 숫자로 바로잡아** 화면에 보여 줍니다 (`correct_speaker`).
- 팩트시트 맨 끝: **'이 판단이 틀렸다면 무엇이 먼저 꺾이나'** (반증 신호 1~2개) — 대본 마지막 장이 됩니다.

> 롱폼은 **인트로 없이** 첫 문장부터 본론(README §2-1, v24)으로 시작하고, 말투는 README §2-3. 장 표지마다 진행 멘트를 넣습니다.
> 연출은 **조합**(05 §0-1) · **강조 아껴 쓰기** · **장면 목적별 배경**(§0-2) · **반복 피로 막기**(§0-3) · **편집 기준 v10**(§0-4: 전환·카메라·사진 장 표지·소리, 그래프보다 사물 그림·정리판) · **소리 기준**(저음 타격음 금지, 음질 좋은 배경음)을 따릅니다.
> 목소리·배경음은 채널 설정(`channels/<id>/channel.yaml` 의 `tts`·`bgm`)을 씁니다.
 (롱폼 9~10분, 장 5~7개)
| 구간 | 시간 | 내용 | 연출 예 |
|---|---|---|---|
| 오프닝 | 없음 (v24) | 첫 문장부터 그날의 장면·숫자 → 질문 | intro (바탕: 시세 화면·자료 사진 흐리게) |
| 0 훅 | 0:30~1:00 | **움직임 숫자 + 모두가 아는 설명 + "그런데 진짜 이유는?"** → 오늘 볼 인과 지도 미리 보기 | chart(마지막 구간 확대) → map_causal 미리 보기 |
| 1장 | ~1:30 | 무슨 일이 있었나: 시간 순서 (발표 → 반응) | timeline, footage(발언) |
| 2장 | ~3:00 | 직접 원인: 숫자 하나를 비교 기준과 함께 | bignum / versus |
| 3장 | ~5:00 | **인과 연결**: 원인 → 중간 → 결과, 한 칸씩 쌓기 | map_causal (같은 칸 위치 유지) |
| 4장 | ~6:30 | 사람의 말: 발언 원본 + 진짜 뜻 풀이 | footage + quote + lower |
| 5장 | ~8:00 | 과거 사례: 그때는 어떻게 됐나 (같은 점·다른 점) | compare / chart |
| 6장 | ~9:30 | **확인할 신호**: 다음에 무엇을 보면 되나 + 반증 신호. 투자 권유 없이 | checklist |
| 끝 | | 첫 질문의 답을 한 문장으로 | outro |

**쉬운 말 규칙:** 숫자마다 `compare_to`(평소·작년·경쟁사), 비유 2개 이상, 어려운 말 풀이(`glossary`: 가이던스 → "회사가 스스로 내놓은 다음 분기 예상 성적표"). 약 3분마다 다시 붙잡기(질문형 장 제목).
**금지 표현 (자동 검사):** 사세요·파세요·매수 추천·매도 추천·지금이 기회·무조건·확실히 오른다·목표가 ○○원 단정·수익 보장·따라 사면.
대신 쓰는 말: "시장이 주목하는 것은", "확인할 신호는", "이 판단이 틀렸다면".

## 5. 소스 (보여 줄 것)

## 6. 포장 (제목·썸네일)
- 제목: `[움직임 + 숫자] + [진짜 이유 질문]`. 숫자는 영상과 같은 날짜·같은 기준.
- 썸네일 A: 인물 얼굴(감정) + 큰 숫자 / B: 시세 그래프 급등락 + 한 단어 / C: 원인 ↔ 결과 두 칸.
- 소문 주제는 썸네일에 소문 내용을 단정 문장으로 쓰지 않습니다.
