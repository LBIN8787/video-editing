# 01. 욕망 지도 — 주제보다 먼저 '왜 보는가'를 정한다

사람들은 '주식'이나 'AI'를 보고 싶은 게 아닙니다. **그것을 통해 채우고 싶은 욕망**이 있고, 주식·AI·역사는 그 욕망이 지금 드러난 모양일 뿐입니다.
그래서 주제는 아래 순서로 고릅니다.

```
상위 욕망 (변하지 않음)  →  지금 그 욕망을 건드린 사건 (트리거)  →  시청자가 머릿속에 떠올린 질문  →  주제 (= 그 질문 하나에 끝까지 답하는 영상)
```

## 1. 세 가지 상위 욕망
| 브랜드 | 상위 욕망 | 밑에 깔린 감정 | 영상이 주는 '보상' | 보상을 못 주면 |
|---|---|---|---|---|
| **ai** | **유능해지고 싶다** — AI 를 더 잘 알고 더 잘 다루고 싶다 | 뒤처질까 불안 · 일을 덜고 싶음 · 남보다 먼저 | 영상을 보고 나면 **하나를 할 수 있게 됨** (또는 무엇을 무시해도 되는지 앎) | "그래서 뭐 어쩌라고" → 이탈 |
| **market** | **이기고 싶다(잃기 싫다)** — 돈의 흐름을 남보다 먼저, 정확히 알고 싶다 | 놓칠까 불안(FOMO) · 손실 공포 · 남들은 아는데 나만 모를까 | **'왜'를 이해함** + 다음에 무엇을 보면 되는지(확인 신호) | 뉴스 요약에 그침 → 이탈 |
| **curiosity** | **알고 싶다** — 궁금증이 풀리는 쾌감 | 평소엔 몰랐지만 듣는 순간 '어? 왜지?' | **'아, 그래서였구나'** 하는 순간 + 남에게 말해 주고 싶은 이야기 | 정의·연대기 나열 → 이탈 |

### issues — 세상이 어떻게 돌아가는지 알고 싶다 (2026-11-09 추가, 근거 docs/18)
- 밑에 깔린 감정: 뉴스가 불안함, 대화에서 뒤처질까 걱정, 강한 것이 무너지는 이야기에 대한 긴장
- 영상이 주는 보상: **한 장의 구조**(지도·인과)로 '왜 지금·어디로'를 이해하고, 양쪽 말을 다 들었다는 안심
- 보상을 못 주면: 한쪽 편을 든다고 느끼면 바로 이탈 + 비난 댓글
- 질문 유형(정해진 단어): **원인**(왜 지금), **연결**(어디로 번지나), **과거 사례**, **숨은 장면**, **개념** — 그리고 issues 전용 표현으로 '몰락'(강한 것이 왜 무너지나)은 `원인`으로 적는다

## 2. 욕망별 '시청자 질문' 유형 (주제는 이 중 하나여야 함)
굵은 글씨가 정해진 이름입니다 — `topic_brief.json` 의 `question_type` 과 스타일 등록부(`styles/recipes/*.yaml` 의 `fits.questions`)가 같은 단어를 씁니다. 새 유형이 필요하면 여기, 스키마, 레시피에 함께 추가합니다.
### ai — 유능해지고 싶다
| 질문 유형 | 예 | 맞는 형식 |
|---|---|---|
| **정체**: "이거 뭔데 다들 난리야?" | 새 모델·기능·도구 출시 | 발표 72시간 안 롱폼 / 쇼츠 |
| **방법**: "나는 어떻게 써?" | 업무 자동화, 프롬프트, 에이전트 설정 | 롱폼 실습 / 쇼츠 1가지 |
| **영향**: "내 일·돈에 무슨 변화가?" | 직업·가격·규제 | 롱폼 해설 |
| **비교**: "뭐가 더 나아? 무료로는?" | 모델·도구 비교 | 롱폼 / 쇼츠 |

### market — 이기고 싶다
| 질문 유형 | 예 | 맞는 형식 |
|---|---|---|
| **원인**: "왜 움직였지?" (가장 강함) | 하루 ±5% 이상 급등락, 업종 동반 움직임 | 롱폼 (48시간 안) |
| **연결**: "어디로 번지지?" | 공급망·금리·환율·경쟁사로의 파급 | 롱폼 인과 지도 |
| **발언**: "누가 뭐라고 했어?" | CEO·연준·유명 투자자 발언, 실적 콜 | 롱폼 원본 소스형 |
| **과거 사례**: "예전에도 이랬나?" | 과거 비슷한 시기와 비교 | 롱폼 데이터형 |
| **소문 확인**: "그 얘기 진짜야?" | 시장에 도는 소문 | **사실 확인형**으로만 (아래 §4) |
| **개념**: "그게 무슨 뜻이야?" | 자사주 소각, 가이던스, 공매도 | 쇼츠 / 롱폼 칼럼 |

### curiosity — 알고 싶다
| 질문 유형 | 예 | 맞는 형식 |
|---|---|---|
| **이름의 이유**: "왜 그렇게 불러/해?" | 스페인 독감은 왜 스페인? | 롱폼 이야기 |
| **숨은 장면**: "그때 실제로 무슨 일이?" | 사건의 하루, 결정의 순간 | 롱폼 |
| **행동의 이유**: "사람은 왜 그럴까?" | 심리 실험, 착각 | 롱폼 |
| **오늘과 연결**: "그게 나랑 무슨 상관?" | 역사 사건 ↔ 오늘 한국 | 롱폼 마지막 장 |

분위기(`mood`, 스타일 고르기에 씀): 차분 · 긴장 · 위기 · 과거 · 미래 · 실용 · 빠름

## 3. 욕망 점수표 (주제 후보마다 채움 → `topic_brief.json` 의 `score`)
| 항목 | 0점 | 1점 | 2점 | 3점 |
|---|---|---|---|---|
| **욕망 강도** — 상위 욕망을 얼마나 직접 건드리나 | 안 건드림 | 간접 | 분명 | 보자마자 '내 얘기' |
| **질문 선명도** — 제목이 질문 하나로 되나 | 안 됨 | 질문 2개 이상 | 하나지만 김 | 15자 안의 질문 하나 |
| **지금성** — 왜 지금 봐야 하나 | 언제 봐도 같음 | 계절·기념일 | 1주 안 사건 | 48시간 안 사건 / 검색 급증 |
| **수요 증거** — 실제로 찾는 사람이 있나 | 증거 없음 | 검색 결과 있음 | 비슷한 영상 아웃라이어 2배+ | 아웃라이어 5배+ 또는 뉴스 상위 |
| **보여 줄 자료** — 화면 증거 | 없음 | 사진 몇 장 | 사진·문서 충분 | 원본 영상·발언·데이터 |
| **우리만의 답** — 남들 영상보다 깊은 것 | 같음 | 정리만 다름 | 인과·숫자 하나 더 | 남들이 놓친 원인·연결 |

- **합계 12점 이상**이고 **욕망 강도·보여 줄 자료가 각각 2점 이상**이어야 만든다. (G1 자동 검사)
- 동점이면: 지금성 → 수요 증거 → 우리만의 답 순서로.

## 4. 소문(찌라시)을 다루는 규칙 — market 만
시장 소문은 시청자 욕망(남보다 먼저)이 가장 강하게 걸린 소재지만, 틀리면 채널 신뢰가 무너집니다.
1. 제목·썸네일에 소문을 **사실처럼 쓰지 않는다** ("~라는 소문, 확인해 봤습니다" 형태만).
2. 대본에서 소문은 `rumor` 로 표시하고, 바로 뒤에 **확인한 것 / 확인 안 된 것 / 확인하려면 볼 것**을 말한다.
3. 1차 출처(공시·회사 발표·당사자 발언)가 반박하면 반박을 먼저 보여 준다.
4. 소문의 출처가 개인 SNS 라면 계정을 화면에 노출하지 않는다.

## 4-1. 성공 원인 나누기 — 모든 채널 공통 (근거: docs/18 §6)
주제를 고를 때 '이 영상을 무엇이 띄울지'를 먼저 정합니다. 모르고 만들면 운입니다.

| 원인 | 판단 질문 | 해야 할 일 |
|---|---|---|
| **소재** | 다른 채널들이 다뤄도 잘 되는 소재인가? (`demand` 아웃라이어, 브랜드별 '소재 표') | 빨리, 정확하게. 각도는 덜 중요 |
| **각도** | 소재는 평범한데 **반대 결과 · 생활 체감 · 추억·감정 · 사람**이 있는가? | 제목·첫 30초를 그 각도로 시작 |
| **형식** | 우리 채널의 고정 포맷(길이·시리즈·화면 문법)에 맞는가? | 매 회 같은 이름·같은 구조 — 채널 포맷이 조회수 차이의 가장 큰 몫 |
| (구독자) | 우리가 바꿀 수 없음 | 숫자 비교는 언제나 '채널 안 배수'로 (구독자 효과 제거) |

`topic_brief.driver` = `{type: 소재|각도|형식, why, angle}`. 셋 다 없으면 만들지 않습니다.

## 5. 제목 공식 (욕망별)
| 브랜드 | 공식 | 예 |
|---|---|---|
| ai | [결과/변화] + [나에게] | "이제 엑셀 자동화는 말로 합니다 — 따라 하기 3단계" |
| market | [움직임 + 숫자] + [진짜 이유는?] | "엔비디아 하루 -9%, 실적이 아니라 '이것' 때문이었다" (사실일 때만) |
| curiosity | [누구나 아는 것] + [모르는 이유 질문] | "스페인 독감은 왜 '스페인' 독감일까?" |

공통 금지: 사실이 아닌 과장, '충격·소름·경악'(분석에서 평균 이하), 영상에 없는 내용.
