# 세계사 주제 결정과 장면표

[시사·역사 제작 기준](../08-issues.md)의 세계사 심층 편에 사용한다. 한 편의 조사 폴더에는 후보 평가를, 대본 폴더에는 장면표를 복사해 채운다.

## 주제 카드

| 후보와 시청자 질문 | 지금의 연결 | 수요 신호와 한계 | 첫 화면 원자료와 사용 근거 | 본문에서 확인할 답 | 선택·보류 이유 |
|---|---|---|---|---|---|
| | | | | | |

**선정 논리** · 시청자 욕망 → 알아볼 대상 → 뜻밖의 질문 → 실제로 보여 줄 첫 자료 → 독립 자료로 확인되는 전환점 → 답과 한계 → 차점보다 적합한 이유.

## 장면표

| 시각·대사 동사 | 시청자가 새로 알아야 할 것 | 사용 자료·날짜·장소·출처 | 화면의 시작 상태 | 무엇이 어떻게 움직이는가 | 도착 프레임에서 더 보이는 것 | 다음 컷과 연결 |
|---|---|---|---|---|---|---|
| | | | | | | |

- 당대 기록에는 자료의 출처와 당시 날짜·장소를 붙인다. 복원·재현·시대 참고·자료 요약은 화면에서 식별할 수 있게 한다.
- 카메라나 리프레이밍을 쓰면 시작과 도착 상태를 기록한다. 원본 자체 또는 화면 요소가 움직이는 장면은 그 주체와 상태 변화를 적는다. 고정 구도에서는 머무르며 읽을 대상을 적는다.
- 질문과 단서가 붙는 시작, 자료가 처음 설명을 바꾸는 본문, 답을 보여 주는 끝을 각각 소리와 함께 점검한다.
