# 원본 발언 컷편집 (`styles/source-cut/STYLE.md`, 장면 type `bite`)

1. 원본(퍼블릭 도메인·공식·CC BY)을 `04_assets/footage/` 에 넣고, 대본 `footage` 에 파일·출처를 적는다.
2. `bite` 장면을 쓴다:
   - 앞 내레이션 1박자
   - `clip.cuts[]` 에 `find`(원문 그대로) 또는 `from`/`to` 와 번역 `ko` 를 넣는다.
3. `python -m ytflow cut <프로젝트>` 로 `02_script/cuts.json` 을 만든다. 각 구간의 `heard` 가 뜻을 바꾸지 않는지 읽는다.
   - 찾지 못한 구간은 문장을 고치거나 `start`/`end` 를 직접 넣는다.
4. `python -m ytflow hybrid <프로젝트>` 로 렌더한다. 프레임을 뽑아 이름 자막·원문·번역이 겹치지 않는지 본다.
5. 바로 다음 장면에서 그 말의 의미를 해설한다. 들려주고 끝내지 않는다.

- **금지:**
  - 앞뒤를 잘라 뜻을 바꾸는 편집
  - 라이선스가 확인 안 된 방송 화면
  - 사인의 발언
  - 다운로드 차단 우회
