사용자는 이 소스 정리·발굴·RSS 관리를 피클에게 맡기도록 최신 지시했습니다. 아래 기존 공용 수집 체계를 확인하고 인수 상태와 다음 수집 결과를 알려 주세요. 이 요청함은 조회·수집용이므로 코드·매뉴얼·스케줄 변경을 요청하는 것이 아닙니다. 필요한 변경은 별도 기존 승인 범위와 절차를 따르세요.

## 인계 상태
- 기존 Claude RSS 설정 있음: 373080eb07cd351669ae122542047c325022b7c6 (2026-11-18 기술·사업 RSS 11개 추가), d70094bc5a5164fb9b69a0e0f543bb186f7aa567 (11-17 SemiAnalysis/RFC822 수정).
- docs/36 §5 기록상 05:40 KST 수집은 Pickle/Super 담당, Claude 루틴 비활성. 실제 현재 활성 상태는 여기서 확인하지 못했습니다.
- 이번 추가: 0de2a06d3f0d73377c285031c7d16f8aea53a8b3 설정, d386425e9cd64ff2260ea330e634f455dec1c31f 공용 운영 안내. 기존 manual/코드/스케줄은 변경하지 않았습니다.
- Psyche, APS, Greater Good 공개 RSS 활성. PsyPost는 검증 환경403으로 blocked, 우회하지 않았습니다.
- 격리 검증에서 XML 20/10/50항목 파싱, 기존 최근2일 수집 4건(Psyche3, APS1), 호기심 show 확인, 2회차 중복 저장 0건. 운영 inbox는 덮어쓰지 않았습니다.
- 사용자는 모델에 관계없이 작업을 맡긴 에이전트가 같은 자료를 쓰길 원합니다. config/newsletters.yaml 및 inbox/newsletters JSON/MD가 공용 기준이고 특정 모델 플러그인이 아닙니다.
- 작은 설정/링크/분류는 Git, 큰 자료는 Drive. 전문·사진 이용권은 별도 확인하고 숫자/연구 주장은 원논문으로 검증합니다.

## 확인·수집 범위
1. 기존 수집 담당/실제 스케줄 활성 여부와 최신 main 반영 여부를 확인. 중복 예약 생성 금지.
2. 기존 허용된 수집 방식으로 새 심리·호기심 RSS 소재를 모으고 기존 공용 inbox에 중복 없이 합류했는지 확인.
3. 향후 호기심 소스 발굴은 심리학뿐 아니라 일상 원리·과학·행동·역사 등 폭넓게, 대중 호기심과 원자료 추적 가능성을 구분. 피드만 추가해 수집량을 늘리기보다 자료 품질과 활용 가능성을 검토.
4. 접근 실패는 그대로 남기고, 새 구독·계정·권한·결제·영상 제작·공개는 하지 않기.
