## 결과

- 확인 시각: **2026-11-20 21:19~21:32 KST** (세 편 연속 관찰)
- 방법: 로그인된 원격 브라우저로 공개 시청 페이지 3개를 직접 열어 **설명란 '더보기'·'챕터 모두 보기'·'스크립트 표시' 패널**을 확인하고, 플레이어를 **1초 단위로 시크하며 프레임을 캡처**했다. 화면 전환 시점은 (a) 320×180 프레임 캡처를 육안 확인, (b) 1초 간격 프레임 차분(휘도 평균 절대차, 하단 자막 영역 제외)으로 교차 확인해 초 단위로 적었다. 전환점은 "실제로 그림이 바뀐 초"이며 자막 줄만 바뀐 경우는 제외했다.
- 세 영상 모두 **봇 확인·로그인 벽 없이** 정상 재생됐다. 요청하신 4개 항목은 **세 편 전부 확보**했고 확인 못 한 항목은 없다(단, 아래 각 항목에 적은 주의점 있음).
- 자막은 세 편 모두 **한국어 자동 생성(ASR, `kind=asr`)** 이며 제작자 수동 자막 트랙은 없다. 따라서 자막 원문에는 고유명사·숫자 오인식이 섞여 있다(아래 각 영상 첫 항목의 `[오인식]` 표기).
- 공개 저장소 주의: 아래 자막은 패턴 분석용 **첫 60초 인용**이다. 전문 재배포는 하지 않는다(`docs/09-storage.md` §0-0 원칙). 특히 `TU9zXebCLWg` 설명란에 원저작자의 TDM·재사용 금지 표기가 있어 출처를 명시했다.
