# SAVE(오선) 알림이 쌓이는 곳

이 폴더의 `<YYYYMMDD>.md` 는 **지금 자동으로 채워집니다** (2026-11-14 부터, docs/28 §1).
아침 자동 제작(06:05)은 SAVE 를 직접 읽지 못합니다(봇 확인·AI 수집 거부 — 우회하지 않음). 대신 아래 경로로 쌓인 알림을 `python -m ytflow daily` 가 `01_research/save_check.md` 표에 옮기고 상태를 '확인함 (사용자 메모)'으로 바꿉니다.

- **누가 쓰나:** 휴대폰 **MacroDroid** 매크로(SAVE 앱 알림 → 본인 Gmail 로 `[save알림]` 메일) → **Pickle 30분 Gmail 감시**(스팸함 포함)가 이 저장소 `main` 에 커밋합니다. 설정은 이미 끝났습니다.
- **형식:** 한 줄에 소식 하나, `- <알림 내용> (알림 MM-dd HH:mm)`.
- **파일 이름:** `YYYYMMDD.md` (그날 영상 날짜). **한국 06:00 이후 알림은 다음 날 파일**로 갑니다 (예: 11-14 06:10 알림 → `20261115.md`).
- **Apps Script(`tools/save-forward/Code.gs`) 는 쓰지 않습니다** — 참고·백업용입니다. 30분 감시와 같이 켜면 같은 알림이 두 줄로 쌓이니 켜지 마세요. `script.google.com`·`GH_TOKEN` 설정을 새로 요청하지 않습니다.
- **에이전트(Claude Code·Codex)가 할 일은 없습니다.** 따로 설치·수집을 붙이지 말고 이 폴더를 그대로 읽으시면 됩니다 (`daily` 가 자동으로 표에 옮김, manual/09 §3-0).
- **손으로 적어도 됩니다:** GitHub 웹·앱에서 이 폴더에 파일 만들기(Add file). 05:50 전에 올리면 그날 영상에 반영됩니다. 여러 개면 `20261117-2.md`. 내 말로 짧게 씁니다 (알림 문구를 그대로 붙이지 않기).
- 여기 적힌 것은 **단서**입니다. 영상에 넣기 전에 1차 출처로 다시 확인합니다 (manual/09 §3-0).

예:
```
- 엔비디아, 실적 발표일 확정 — 11/19 장 마감 후 (알림 11-14 09:12)
- CPI 발표 11/13 08:30 ET, 예상치 상회 (알림 11-14 09:40)
- 모건스탠리, 반도체 업종 의견 상향 (알림 11-14 10:05)
```
