# SAVE(오선) 메모 받는 곳

아침 자동 제작(06:05)은 SAVE 를 직접 읽지 못합니다(봇 확인·AI 수집 거부 — 우회하지 않음).
SAVE 앱/웹(https://www.saveticker.com)에서 본 소식을 여기에 올려 두면, 그날 `python -m ytflow daily` 가
`01_research/save_check.md` 표에 옮기고 상태를 '확인함 (사용자 메모)'으로 바꿉니다.

- 파일 이름: `YYYYMMDD.md` (그날 영상 날짜, 예 `20261117.md`). 여러 개면 `20261117-2.md`.
- 한 줄에 소식 하나. 내 말로 짧게 (SAVE 요약문을 그대로 붙이지 않기).
- GitHub 웹·앱에서 이 폴더에 파일 만들기(Add file)로 올리면 됩니다. 05:50 전에 올리면 그날 영상에 반영됩니다.
- 여기 적힌 것은 **단서**입니다. 영상에 넣기 전에 1차 출처로 다시 확인합니다 (manual/09 §3-0).

예:
```
엔비디아, 실적 발표일 확정 — 11/19 장 마감 후
CPI 발표 11/13 08:30 ET, 예상치 상회
모건스탠리, 반도체 업종 의견 상향
```
