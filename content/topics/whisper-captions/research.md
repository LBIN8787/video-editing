# 음성에서 자막 초안 만들기

Whisper는 공개 음성 인식 모델이다. 이번 제작에서는 faster-whisper의 small 모델을 CPU int8로 로컬 실행해 실제 ElevenLabs 내레이션 두 개를 한국어로 인식했다. 원 인식 결과와 단어별 시간을 별도 JSON으로 남겼다.

음성 준비 → 언어 ko 지정 → word_timestamps=True로 인식 → 원문 대조 → 짧은 자막 묶음과 SRT 생성 → 영상에서 확인 순서다. 설명에 나온 AI 요청문은 원문을 함께 제공해 제품명과 숫자를 검수하도록 한다. 이번 원 인식에서 005편의 엠피포로를 표시 자막 MP4로로 정리했고 그 외 인식 문장을 확인했다.

로컬 음성 인식은 음성 인식 API 호출료가 없지만 설치, 모델 다운로드, 컴퓨터 자원이 필요하다. 이번 음성을 생성한 ElevenLabs와는 비용 항목이 다르다. 인식 속도는 이 실행의 관측값이며 타 기기 성능이나 인식 정확도를 보장하지 않는다. 실제 자료는 whisper-raw.json과 captions.json/SRT다.

## 확인 범위

공식 문서와 이번 로컬 실행을 확인했다. 최신 인기 순위나 다른 편집기 대비 우월성은 조사·주장하지 않는다. 실제 서비스 UI 녹화가 아닌 자체 그래픽과 파일 내용 재구성을 사용한다.
