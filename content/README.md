# 조사와 글: 콘텐츠의 공통 원본

주제 하나를 topics/<topic-id>/에 둔다. 영상 하나가 조사 자료를 독점하지 않는다.

- sources.json: 원문 URL, 확인일, 출처 ID. 발표일·사건일·확인일을 구분한다.
- research.md: 확인된 사실, 미확인, 비교 기준, 반론, 실행 조건.
- article.md: 독자에게 설명하는 글. AI 활용은 안내문, 롱폼은 근거와 해석을 갖춘 칼럼으로 정리한다.
- 채널별 episodes/: 그 글에서 파생한 대본·장면·검수 기록.

대화 전체를 무조건 복사하지 않는다. 사적인 내용·인증 정보·서명 URL을 제외하고 확인된 조사 내용을 정리한다. 글에 없는 기능·성과를 영상에서 만들어내지 않는다. 새 영상마다 달라진 소식과 사용 조건을 재확인한다.

기존 세 AI 주제의 article.md는 재정리용 템플릿이다. 장문 칼럼이 이미 작성됐다는 뜻은 아니다.
