# AI 활용 시각 안내형 쇼츠

현재 입력 규격은 1.1.1 / ShortsGuideTemplate이다. 사용자가 승인한 1.1.0 화면을 유지하며 편별 데이터를 바꾸는 패치다. `versions/1.1.1/style-lock.json`과 `studio/SHORTS-WORKFLOW.md`를 따른다.

- 질문 하나를 45~60초로 설명한다. 입력 자료 → 어디서 무엇을 요청 → 결과 예시 → 직접 확인할 일을 보여준다.
- 날짜·상단 회차 번호를 표시하지 않는다. 확인 날짜는 조사 메타데이터에만 둔다.
- 파일 선택, 복사할 요청문, 정리 전후 표, 편집 개체, 결과 화면을 사용한다. 글 목록을 반복하는 장면으로 채우지 않는다.
- 시각 블록은 flow/files/prompt/commands/browser/table/slides/image/check다. 제목·문구·visual_data·행동 한 줄만 바꾸고 폰트·색·좌표를 임의 변경하지 않는다.
- 실제 실행 결과와 설명용 재구성을 표시한다. 실행하지 않은 도구 결과·측정하지 않은 절감률·시청 효과를 만들지 않는다.
- 고정 음성은 채널 설정을 따른다. 전환 효과음과 배경음은 없다. 고정 음성 실패 시 대체 TTS를 쓰지 않는다.
- 음성이 없는 검토본은 명시적인 무음 미리보기로만 만든다. 최종 제작·게시 상태와 구분한다.
- 최종 파일의 모든 장면 중간과 끝, 자막·음량·전체 디코딩을 확인한다. 직접 청취 여부를 기록한다.

기존 1.0.0과 1.1.0 구성은 이전 영상 재현용으로 보존한다. 고정 폰트는 fonts.json의 해시, 라이선스는 FONT-LICENSE.txt로 관리한다.
