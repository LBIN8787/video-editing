# 현재 기본 스타일: 1.1.0

사용자 피드백을 반영해 날짜·회차 표시를 제거하고, 입력·행동·결과를 시각 자료로 보여 주는 ShortsGuideV2를 기본으로 사용한다. versions/1.1.0/README.md와 style-lock.json이 최신 규칙이다. 아래 1.0.0 설명은 이전 영상 재현을 위한 기록이다.

# AI 활용 안내형 쇼츠

상태: sample_review. 외부 채널을 복제한 스타일이 아니라 이번 프로젝트의 편집 규칙이다.

## 글과 영상의 구조

1. 불편 한 가지
2. 도구와 소식 맥락
3. 핵심 기능
4. 활용 단계와 입력
5. 적용 예시와 결과 확인
6. 지원 환경과 비용

## 화면과 소리

- 음성은 채널 설정을 따른다. 스타일이 보이스를 선택하거나 재정의하지 않는다.
- 전환 효과음 없음. 핵심 문장, 단계별 화면, 출처와 사례를 사용한다.
- 실제 실행 화면과 설명용 예시를 구분한다. 실제 결과가 없으면 효과·절감 시간을 실측처럼 말하지 않는다.
- 45~60초를 기본으로 한 가지 작업을 설명한다. 기존 AI 실전노트의 종이색·짙은 녹색·라임 강조를 사용한다.
- 문서 전체를 축약하는 대신 이해에 필요한 질문 하나를 선택한다. 상세 설치가 생략되면 별도 안내에 남긴다.

## 반복 제작 기준 v1.0.0

style-lock.json과 ShortsGuideV1 공통 템플릿을 사용한다. releases/shorts-ai-guide-v1.0.0/README.md가 복원·재사용 안내다. 내용 입력에서는 디자인을 덮어쓰지 않는다. 고정 폰트는 fonts.json의 해시로 확인한다.
