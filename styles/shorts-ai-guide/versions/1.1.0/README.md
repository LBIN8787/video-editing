# 쇼츠 활용 예시형 1.1.0

사용자 피드백에 따라 글 목록을 읽어주는 장면을 입력·행동·결과 중심 화면으로 바꾼 버전이다. 기존 1.0.0은 과거 영상 재현용으로 보존한다.

- 화면에 날짜와 회차 번호를 표시하지 않는다. 확인 날짜와 편 ID는 출처·작업 메타데이터에만 보관한다.
- 영상마다 고정 ElevenLabs Han Aim 음성을 유지한다. 전환 효과음·배경음은 없다.
- 파일 준비: 폴더·대본·음성 아이콘과 선택 강조.
- 요청: 사용자가 복사할 수 있는 짧은 요청문과 유지·교체 범위.
- 결과: 실제 수정본의 프레임 또는 실제 음성 파형·SRT 발췌.
- 검수: 제목과 자막 확인 위치, 입력 → 처리 → 결과의 흐름을 도식으로 제시한다.
- 재구성한 화면은 서비스 실제 UI 조작 녹화로 소개하지 않는다. 표시 문구로 실제 자료와 설명용 도식을 구분한다.
- 장면 하단에는 지금 할 행동을 한 줄로 표시한다.

컴포넌트: studio/renderer/src/template/ShortsGuideV2.tsx. 설정: 같은 폴더의 style-lock.json. 예시 입력은 005/006의 revisions/visual-v2/props.json이다. 입력 렌더는 scripts/render_short.py가 버전에 맞는 구성을 선택한다.

날짜·회차 제거와 시각적 활용 안내는 이후 제작에도 기본 적용한다. 새로운 디자인을 만들 때는 이 버전을 바꾸는 대신 새 버전으로 기록한다.
