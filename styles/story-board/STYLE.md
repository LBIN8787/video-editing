# 이야기 그림판: 말하는 순간 종이 위에 이야기가 그려진다

**한 줄 정의:** 큰 종이 한 장(3840×2160, 화면의 2배)을 지우지 않고, 내레이션이 사람·장소·날짜·사물을 말하는 순간 그것이 **선으로 그려지고**, 카메라가 이야기를 따라 종이 위를 옮겨 다닌다.

**언제:** 호기심 채널(curiosity)처럼 **이야기를 들려주는** 영상의 뼈대. "누가 · 언제 · 어디서 · 무엇을 · 그래서" 가 있는 대목.
**쓰지 않을 때:** 매일 시장 브리핑·숫자 요약(정보형 → 요약판 + 말에 맞춰 생기는 사물 `motion`, manual/09), 실제 현장이 중요한 시사(사진·원본 영상).

## 정보형(주식)과 이야기형(호기심)의 차이 — 2026-11-13 사용자 판정
| | 주식 채널 (정보 제공) | 호기심 채널 (이야기 들려주기) |
|---|---|---|
| 대본 | 보도·설명: 숫자 → 이유 → 오늘 볼 것 | 장면 → 인물 → 사건 → 이상한 점 → 반전 → 답 |
| 화면의 주인 | 요약판(체크리스트·막대·뉴스 카드) | 종이 한 장 위에 쌓이는 그림 |
| 애니메이션 | 요약 위에 사물이 튀어나옴 (`motion`) | 사람·사물이 **선으로 그려짐**, 도장·쪽지·말풍선, 카메라가 이야기를 따라감 |
| 전환 | 장면마다 새 판 | 한 장면 안에서 지우지 않고 카메라만 이동 (미주일기식 한 장 캔버스) |
| 썸네일 | 사진 + 큰 글씨, 숫자 맞대기 | 종이 + 선 그림 + 큰 글씨 (`layout: board`) |

## 참고 영상에서 가져온 구조 (미주일기 XE-9raLLQTQ, 자막 342줄 분석)
1. **여는 법:** 지금의 상식(AI는 들쭉날쭉) → "그런데 ~는 과연 합리적일까요?" 질문 → 그 질문을 던진 사람 → 오늘 따져 볼 것 예고 → 구독 부탁.
2. **본론은 시간 순 이야기:** 1950 튜링 → 1956 다트머스 → 2005 닐슨 → 2018 OpenAI → 최근 딥마인드. 해마다 **이름 있는 사람 + 그 사람이 한 일** 하나씩.
3. **증거는 장면으로:** 침팬지 아유무의 숫자 기억 실험(0.2초, 79%) 같은 구체적인 한 장면.
4. **반전과 비유:** "인간의 지능 역시 들쭉날쭉하다", 새의 날갯짓 vs 비행기 프로펠러.
5. **마무리:** 질문에 대한 답 한 문장 → 구독 부탁 → 채널 이름.
6. **화면 (styles/mijudiary 측정값):** 2초마다 요소 하나, 하드 컷 적음, 종이 칩·손글씨·형광펜·빨간 펜.

## v2 (2026-11-13 사용자: "졸라맨·품질 낮음·패턴 반복") — 조사: docs/26-story-craft.md
- **재료를 섞는다:** 실제 사진(`photo`: polaroid·cut·round) · 문서 캡처 + 형광펜(`doc` + `mark`) · 둥근 스티커(`sticker`) · 이름 카드(`card`) · 큰 글자(`big`) · 도장·쪽지.
  선 그림(`draw`)과 막대 인물(`figure`)은 도식에만, 한 장면에 하나 이하.
- **같은 손:** 모든 재료에 종이 테두리·그림자·살짝 기울임, 사진은 같은 색 보정, 이름표는 종이 띠.
- **깊이:** 뒤·가운데·앞 세 겹 패럴랙스. **움직임:** 과장 뒤 안착 + 그림자가 내려앉음, 등장 방식을 돌려 씀(같은 방식 연속 금지).
- **배경을 바꾼다:** `{"do": "bg", "mode": "paper|dark|photo"}` — 장면마다 하나 이상 바꾸거나, 장면끼리 다르게. 이야기 장면은 검은 화면에서 밝아짐.
- 점검: 한 장면에서 같은 재료가 50% 넘으면 `layout_qa` 경고(story/repetitive).

## 화면 문법 (story 장면, v1)
- **사람:** 막대 인물(`figure`, pose: stand·think·point·cheer·slump·walk·baby) + 손글씨 이름표 + 작은 직함. 실존 인물 얼굴은 그리지 않는다.
- **사물:** 선 아이콘(`draw`, Lucide ISC + 직접 그린 shirt·chess·board·cloth·pile·hand·book·eye2), 선이 그려지는 0.9초.
- **때와 곳:** 빨간 이중 테두리 도장(`stamp`) "1997. 5. 11 · 뉴욕".
- **핵심 낱말:** 종이 쪽지(`chip`, 어두운 쪽지 = 어려움·부정), 형광펜(`hl`).
- **생각·말:** 말풍선(`bubble`, 꼬리는 그 사람 쪽).
- **관계:** 빨간 손 화살표(`arrow`, 화살촉은 선이 다 그려진 뒤), 동그라미(`circle`), X(`cross`), 초록 체크(`check`).
- **숫자:** 명조 큰 숫자가 0에서 올라감(`count`) + 손글씨 설명.
- **카메라:** 그림이 생길 자리로 0.95초 이동(`cam: [x, y, 확대]`), 장면 끝 질문·정리 때 `full`(전체)로 빠져 지금까지 그린 것을 한눈에. 제자리 흔들림 없음.
- **선 질감:** 아주 약한 손 떨림(고정 변위 필터, 움직이지 않음).

## 대본 규칙
- 한 박자 = 그림 1~3개. 그림 하나는 그 낱말을 말하는 순간(`t`).
- 장면 하나에 이야기 한 토막(3~6박자). 장면 끝에는 카메라를 `full` 로 빼서 대비(체스 ↔ 빨래)를 한 화면에.
- 자막 자리(화면 아래 15%)에 그림을 두지 않는다 — 좌표는 카메라 기준 화면 y 900 위.
- 같은 사물은 다음 장면에서 다시 그려 '이어지는 이야기'로 (체스·티셔츠가 영상 끝까지 돌아옴).
