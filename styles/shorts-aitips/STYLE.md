# AI 꿀팁 쇼츠: 고정 훅 + 화면 시연

**한 줄 정의:** 9:16 화면 위쪽에 두 줄 훅을 끝까지 고정하고, 가운데에서 실제 도구·저장소 화면을 보여 주며, 아래에 큰 자막을 띄웁니다. 30~45초 동안 2~4초마다 화면이 바뀝니다.

**언제 쓰나:** AI 활용 팁, GitHub 화제 저장소(스킬·MCP·에이전트) 소개, 도구 비교에 씁니다.

## 벤치마킹 (이번 달 상위 쇼츠에서 관찰한 형식)
| 형식 | 예 | 조회수 | 이 파이프라인 |
|---|---|---|---|
| AI 비교 실험 (같은 프롬프트, 2×2 격자, "who won??") | ChatGPT vs Claude vs Gemini vs DeepSeek | 1,400만 | `compare` 장면 |
| **한국 꿀팁형**: 위쪽 두 줄 훅(흰 상자·검은 굵은 글씨) 고정 + 아래 화면 녹화 | "사업계획서 누가 요즘 직접 씀? / 원클릭 사업계획서 자동화" | 수만~수십만 | **기본 구조** |
| 밈 자막 (실사 장면 + 위쪽 자막) | "Me: sending a 4-word prompt / Claude: eating my entire token budget" | 수십만 | 범위 밖 (실사 소스 필요) |
| 3D 캐릭터 콩트 (토큰 % 표시) | 저폴리 캐릭터가 AI와 대화 | 수십만 | 범위 밖 (3D 제작 필요) |
| 실사 데모 (노트북·휴대폰 화면 촬영 + 반응 자막) | "HR is NOT ready for this 💀" | 수십만 | 범위 밖 (촬영 필요) |

## 화면 문법
1. **배경:** 검정입니다.
2. **훅:** 위쪽 두 줄(1줄 흰 상자, 2줄 노란 상자, 검은 굵은 고딕)이 영상 끝까지 고정됩니다.
3. **가운데 창(1000×900):**
   - GitHub 저장소 페이지를 전체 캡처해 천천히 스크롤합니다(화면 녹화 느낌).
   - 숫자는 검은 배경 애니메이션 카드로 보여 줍니다.
   - 핵심 한마디는 큰 흰 글씨와 노란 아이콘으로 보여 줍니다.
   - 비교는 2×2 격자로 보여 줍니다.
4. **자막:** 가운데 창 바로 아래, 70px 굵은 흰 글씨에 검은 외곽선입니다. 핵심 단어는 노랑, 한 줄 14자입니다.
5. **음성:** 빠른 TTS(+18%)입니다.

## 소재 (자동 수집: `python -m ytflow shorts`)
- **GitHub:** 검색 API로 최근 14일 안에 만들어진 저장소를 별/일 순으로 모읍니다(검색어: claude skills, agent skills, mcp server, ai agent ...).
- **보조 신호:** Hacker News, Google News(72시간)입니다.
- **선택 기준:** 따라 하기 쉬움, 전후 차이가 보임, 화제성 순입니다. 위험한 도구는 고르지 않습니다.
