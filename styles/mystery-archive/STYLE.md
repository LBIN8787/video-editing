## 0. 이 템플릿이 하는 일
조선·세계사의 **풀리지 않은 사건 하나**를 사건 파일처럼: 콜드 오픈(기록 속 기이한 장면) → 사건 개요 → 단서 1~5 → 반대 증거 → 판정(미해결) → 시청자에게 판정을 넘김. 기록이 확실히 말하는 것과 말하지 않는 것을 시청자가 가리게 한다.

## 1. 레퍼런스 실측에서 온 기준 (docs/78, 조회 110만~1,500만·구독 대비 7~197배 10편)
| 무엇 | 레퍼런스 | 이 템플릿(v3) | 왜 |
|---|---|---|---|
| 화면이 바뀌는 빈도 | 첫 1분 분당 36~100번(8/10편), 본문 11~111 | 첫 90초 24, 본문 40 | 2초마다 새 사실이 들어와야 '심심하지 않다'. 픽셀이 움직이는 것(필름 입자·느린 카메라)은 대신하지 못함 — v1 은 움직임 89% 인데도 0점 |
| 화면 재료 | 7/10 이 움직이는 영상, 8/10 이 실제 자료가 주인공 | 실제 사진·문서 + 실제 장소 영상 + 분위기 영상 + 재현 그림 | 기록 영상이 없는 시대는 오늘의 장소 영상·사료 사진·분위기 영상으로 |
| 소리 | 7/10 이 목소리보다 15~20dB 낮은 배경음, 효과음이 들리는 영상 0 | 배경음악 약 −18dB, 효과음은 장 전환의 부드러운 울림 하나 | v1 의 깔린 저음·흰소음 효과음 259번은 "거슬림", v2 의 완전 무음은 비어 들림 |
| 글자 | 아래 자막 + 장소·이름·숫자 정도 | 같음 + 어려운 말 풀이 쪽지 | 큰 글씨 카드는 결정적 순간에만 |

이 숫자들은 맞출 목표가 아니라 **다시 볼 곳을 알려 주는 측정값**이다(manual/05 §0-0). 문서를 읽어 주는 동안은 화면이 머물러도 된다(Barely Sociable).

## 3. 바탕·색·글꼴 (스킨)
- 바탕 `#111317` + 사료 한자(仁祖實錄 …)를 아주 옅게(3.5%) 깐 무늬. 필름 입자·촛불 깜빡임·먼지·비네트·화면 흔들림·빛 번쩍임 **없음**.
- 강조색 하나 `#e8503a`(핵심 낱말·경로·도장). 반대 증거는 회색(`rgba(70,74,82)`), 노랑·하늘색 섞지 않음.
- 글꼴: 맑은고딕 Bold(라벨·자막), 바탕(사료·표지). 자막은 아래 검은 반투명 상자 한 줄~두 줄.

## 5. 만들기 (engine/)
```
python engine/build_v3.py      # 대본 박자(S 목록) → edge-tts 낱말 시각 → Drive hf_v3/index.html + 목소리·배경음악
cd <Drive 에피소드>/hf_v3 && npx hyperframes check && npx hyperframes render -o ../<이름>.mp4 -q looks   # 10분 ≈ 25~30분
```
- `build_v3.py` 는 소현세자 편 박자·장면이 그대로 들어 있다 — 새 편은 `S`(대본 박자)와 `build()` 의 장면 호출을 바꾸고, `POOLS`(장별 분위기 영상)·`SKIP`(겹치기 그림이 있는 박자)을 맞춘다. 공통 조각은 `eng2.py`, 지도는 `geo.py`(world-atlas land-50m 을 `geo/` 에 내려받기).
- 목소리: 초안 edge-tts(InJoon +8%, 쉼 짧게 — "대사가 너무 느려요"), 최종은 사용자 결정(Gemini Knox·Riko 또는 ElevenLabs).
