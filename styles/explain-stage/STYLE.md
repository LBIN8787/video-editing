# 설명 무대 스타일: 글·숫자 대신 한 무대 위에서 바뀌는 물체로 설명

2026-11-20 사용자: "설명을 할때 단순 글과 숫자만이 아닌 이런 연출법을 사용하고싶어", "이 모션그래픽 스타일 저장해주시고 … 화면이 꼭 종이가 아니어도 … 애니메이션 효과 움직임이 필요한 연출에서 사용하려구요", "인물들이나 이런거도 나타낼 수 있는가".

**한 줄 정의:** 한 장면 = 한 무대. 앞 박자에 나온 인물·물체·기준선은 남기고, 대사의 동사에 맞춰 다음 요소만 나타나거나·옮겨지거나·강조되거나·흐려진다.
**언제 쓰나:** 숫자나 보도를 이해하는 데 **중간 과정**이 필요한 대목 — 누가 누구에게 무엇을 넘기나, 사건 이후 무엇이 늘었나, 두 값의 차이가 왜 줄었나, 전체 중 몫이 얼마인가. 진행자·기사·차트 화면 사이에 끼워 원리를 푸는 데 쓴다. 영상 전체를 이것만으로 만들지 않는다.

코드 `ytflow/stages/explain.py`(장면), `ytflow/stages/crumple.py`(바탕) · 장면 문서 `docs/51-explain-stage.md` · 디테일 조사 `docs/52-motion-quality-references.md`

## 장면 네 가지

| `type` | 이럴 때 | 화면 |
|---|---|---|
| `afterline` | "사건 **뒤에도** 계속됐다" | 시간선 + 붓 금지 표시 → 붉은 붓 구간 → 카드 1·2·3… 쌓임 → 수량 문구 |
| `spread` | 두 값의 **차이**가 이름을 가진 개념 | 재료→공정→제품 소품 → 두 가격 막대 + 점선 연장 → 괄호로 차이 → 값이 바뀌면 옛 높이 점선 윤곽 |
| `share` | 전체 중 **몫** | 전체 막대 → 부분이 차례로 채워짐 → 비교 눈금 → 괄호로 합계 |
| `motionboard` | 위 셋에 안 맞는 모든 것 — **인물**·물체가 등장하는 이야기 | 요소를 자유 배치하고 박자마다 동작 |

### `motionboard` — 자유 무대

```json
{"type": "motionboard", "title": "보호예수가 풀리면", "theme": "paper",
 "els": {
   "inv":   {"kind": "person", "x": 360, "y": 600, "name": "초기 투자자", "role": "상장 전에 산 사람", "tone": "gray"},
   "ceo":   {"kind": "person", "x": 1500, "y": 600, "name": "리사 수", "role": "AMD CEO", "photo": "assets/people/lisa_su.jpg"},
   "stock": {"kind": "card", "x": 640, "y": 640, "icon": "files", "label": "주식"},
   "chip":  {"kind": "card", "x": 900, "y": 640, "icon": "chip", "label": "MI300"},
   "drum":  {"kind": "img", "x": 300, "y": 500, "img": "assets/props/oil_drum.png", "w": 260},
   "free":  {"kind": "text", "x": 960, "y": 250, "text": "보호예수 해제", "size": 64, "color": "red"},
   "note":  {"kind": "text", "x": 640, "y": 470, "text": "묶여 있음", "pen": true, "color": "red"},
   "sell":  {"kind": "arrow", "from": "inv", "to": "ceo", "label": "매도", "color": "red", "bend": 0.2},
   "after": {"kind": "brush", "pts": [[400, 560], [1700, 556]], "width": 22},
   "ban":   {"kind": "ban", "x": 330, "y": 560, "r": 62},
   "base":  {"kind": "dashed", "pts": [[300, 700], [1600, 700]]}},
 "beats": [
   {"say": "…", "do": ["inv", "stock", "note"]},
   {"say": "…보호예수가 풀리면…", "do": ["free", {"hide": "note"}, {"move": "stock", "to": [1260, 640]}], "at": {"free": "보호예수"}},
   {"say": "…", "do": ["ceo", "sell", {"hi": "stock"}]},
   {"say": "…", "do": [{"dim": "ceo"}, {"swap": "free", "text": "물량 출회"}]}]}
```

| 요소 `kind` | 무엇 | 주요 값 |
|---|---|---|
| `person` | 인물 카드(인화 사진처럼 흰 테두리·그림자·살짝 기울기) + 이름·역할 | `photo` 가 있으면 실제 사진, 없으면 **얼굴 없는 실루엣**(`tone`: navy·red·gray·green·gold) |
| `card` | 소품 카드 | `icon`(lucide 이름 또는 `chip`) · `img`(투명 PNG) · `label` · `color` |
| `img` | 투명 PNG 소품을 그대로(그림자만) | `img`, `w` |
| `text` | 굵은 글자 / 손글씨(`pen: true`) | `size`, `color`(ink·red·muted·navy) |
| `arrow` | 두 요소 사이 휘는 잉크 화살표 + 손글씨 이름 | `from`, `to`, `label`, `bend`, `color` |
| `brush` | 붉은 붓 자국(두 겹) | `pts`, `width` |
| `ban` | 붓으로 칠한 금지 표시 | `x`, `y`, `r` |
| `dashed` | 점선 기준선 | `pts` |

| 동작(`do`) | 효과 |
|---|---|
| `"이름"` | 나타남 (인물은 아래에서, 카드는 위에서 떨어지듯, 화살표·붓은 그려지듯) |
| `{"move": 이름, "to": [x, y]}` | 옮겨짐 (뒤 동작은 옮긴 자리 기준) |
| `{"hi": 이름}` | 붉은 테두리 + 살짝 커졌다 돌아옴 |
| `{"dim": 이름}` | 흐리고 흑백 — 이야기에서 빠짐 |
| `{"hide": 이름}` | 사라짐 |
| `{"swap": 이름, "text": "…"}` | 글자 바꾸기 |

박자의 `at: {"이름": "대사 속 단어"}` 로 그 단어를 말하는 순간에 맞춘다. 없으면 0.45초 간격으로 차례로.

## 바탕 테마 (`theme`) — 종이가 아니어도 된다

| 값 | 바탕 | 글자·선 |
|---|---|---|
| `paper` (기본) | 실사 구겨진 종이 (ambientCG Paper003, CC0 — 처음 한 번 캐시에 받음, 못 받으면 직접 만든 주름 종이) | 먹색·붉은색 |
| `dark` | 숯색 무대, 가운데가 조금 밝음 | 밝은 회백색·밝은 붉은색 (카드 안은 그대로) |
| `light` | 그 영상 그래픽 팩(스킨)의 바탕 그대로 | 먹색·붉은색 |

연출(무엇이 언제 어떻게 움직이나)은 테마와 상관없이 같다. 새 테마는 `explain.py` 의 `THEMES`(색 바꾸기 표)와 `_setup` 의 바탕 한 줄을 더하면 된다.

## 화면 문법
1. **배경** — 위 테마. 종이는 주름이 있되 글자보다 약하게.
2. **배치** — 제목은 왼쪽 위 작게(Black Han Sans, 회색). 무대는 가운데 2/3. 같은 역할은 같은 줄·같은 간격.
3. **움직임** — 등장 0.35~0.45초 `back.out`(살짝 튕김), 이동 0.9초 `power2.inOut`, 붓·선은 그려지듯. 화면 전체 확대·흔들림 없음.
4. **반복 요소** — 흰 카드(3겹 그림자·±1.5° 기울기), 붓 금지 표시, 붉은 붓 구간, 점선 기준선, 괄호.
5. **글꼴·색** — 굵은 고딕 Black Han Sans(OFL) 제목·숫자, 나눔고딕 ExtraBold 라벨, 나눔손글씨 펜 주석. 먹 #1F242E · 붉은 #B5302B · 남색 #23418C.
6. **자막** — 하이브리드 공통(아래 상자 자막).
7. **소리** — 카드 `click-soft`, 붓·구간 `whoosh-short`, 강조 `pop`, 선 `pencil`.

## 어디까지 되나 / 안 되나

| 된다 | 아직 안 된다 · 다른 장면으로 |
|---|---|
| 인물을 카드로 놓고(실사진 또는 실루엣) 화살표로 관계, 흐리게·강조로 이야기에서 넣고 빼기 | 인물이 걷거나 표정·몸짓을 바꾸는 **캐릭터 애니메이션** → `stage`(관절 인형·그림 조각), `illust`, `story` |
| 물체가 A에서 B로 옮겨 가고, 도착하면 강조·글자 바뀜 | 물체가 여러 번 굽은 경로를 따라 이동(지금은 직선 이동) |
| 시간선·누적 카드·가격 막대·몫 막대·괄호·점선 기준선 | 실제 시세 차트 → `chart`, 지도 위 이동 → `journey`, 나라 색칠 → `choropleth` |
| 종이·어두운 무대·스킨 바탕 | 카메라가 무대를 따라 밀고 당기기(시장 브랜드는 확대·축소 끔이 기본, 매뉴얼 v31) |
| 투명 PNG 소품을 넣어 실물 느낌 | 소품 그림을 자동으로 만들기 → `art-gen` 으로 따로 만든 뒤 `img` 에 넣음 (크레딧이 들 수 있어 사용자 승인) |

**실제 인물 사진**은 권리가 확인된 것만: 위키미디어 공용(`python -m ytflow archive commons "Lisa Su"`)·기관 공식 보도 사진. 출처는 장면 `label` 에 남긴다. 실루엣은 특정인을 닮게 그리지 않는다(이름표로만 구분).

| 기법 | 상태 |

| 실사 구겨진 종이·어두운 무대 바탕 | 구현 (`crumple.background`, `crumple.dark`) |
| 붓 금지 표시·붉은 붓 구간 (SVG 변위 + 마른 붓 결 필터) | 구현 |
| 칩 그림 카드, 아이콘 스티커 카드, 3겹 그림자 | 구현 |
| 인물 카드 (사진·실루엣) | 구현 |
| 단어 시각에 맞춘 등장 | 구현 (`at`) |
| 소품 그림 생성 (드럼통·공장·주유기 등 실물 그림) | 미구현 — `art-gen` 연결 후보 |
| 종이 질감을 모든 요소 위에 한 번 더(multiply), 선이 주름을 따라 휨 | 미구현 — docs/52 §디테일 2 |
| 손그림·질감만 12fps로 끊기 | 미구현 — docs/52 |
