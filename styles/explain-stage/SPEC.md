# 설명 무대 — 구성요소별 제작 명세 (재구현용)

2026-11-20 사용자: "구성 요소별로 제작 메뉴얼같은거도 따로 작성한거야? … 그게 아니면 나중에 재구현 불가능할거아니야 또 예시사진으로는 사실 전부 보여주지 못하고 약간 괴리가 생기니까"

이 문서만 보고 **코드가 없어도 같은 화면을 다시 만들 수 있게** 값을 모두 적는다. 코드가 있으면 `ytflow/stages/explain.py`(장면), `ytflow/stages/crumple.py`(바탕)가 이 값의 원본이다. 값을 바꾸면 코드와 이 표를 함께 고친다.

- 화면: 1920×1080, 30fps. 좌표는 모두 이 화면 기준 px. 시간은 장면 시작 기준 초.
- 다시 만들기: `python styles/explain-stage/demo/render.py <출력 폴더> [--gallery]` — 대본 [`demo/scenes.json`](demo/scenes.json) 5장면 → 장면 mp4 + 합본. `--gallery` 는 구성요소 목록 페이지에 넣을 **실제 렌더 클립·정지 화면**을 캐시에 만든다(목록 페이지가 CSS 흉내 대신 이것을 보여 줌).
- 판정 기준 화면: 아래 '기준 프레임'을 같은 명령으로 다시 뽑아 비교한다. 장면 끝 0.25초는 공통 페이드아웃이라 그 전에서 뽑는다.

## 2. 바탕

| 테마 | 만드는 법 |
|---|---|
| `paper` | ambientCG **Paper003** 2K 색 지도(CC0, `https://ambientcg.com/get?file=Paper003_2K-JPG.zip`, 처음 한 번 캐시)를 흑백으로 → 정사각 2048 에서 16:9 높이(1152)를 seed 로 고른 위치에서 잘라 1920×1080 → 밝기에서 중앙값을 빼고 99퍼센타일로 나눠 −1.4~1.2 로 자름 → ×0.085 → 바탕색 `#E8E3D9` 에 (1 + 주름 + 잡음) × 가장자리 어둡게(1 − 0.13·r^3, r=정규화 거리²) 를 곱함. 잡음 = 화소 정규잡음×0.012 + 240px 격자 잡음×0.02. 그늘(주름<0)은 파랑 +18 (살짝 차갑게). seed 가 홀수면 좌우 뒤집기. 받을 수 없으면 직접 만든 주름 종이(34개 접힘선 tanh + 능선 잡음, 왼쪽 위 빛)로. |
| `dark` | 바탕 `#1B1D22` × (1 + 빛 + 잡음). 빛 = clip(1.45 − r, 0, 1)^1.6 × 0.55, 중심 (0.48W, 0.42H), 반지름 (0.62W, 0.7H). 잡음 = 화소×0.035 + 180px 격자×0.05. 글자·선 색은 §1 을 밝은 색으로 바꿈(먹→`#ECE8E0`, 붉은→`#E5533F` 등, `explain.py THEMES`). 카드는 그대로 밝게. |
| `light` | 그 영상 그래픽 팩(스킨) 바탕 그대로, 색은 paper 와 같음. |

## 3. 질감 필터 (SVG)

| 이름 | 정의 | 쓰는 곳 |
|---|---|---|
| `xbrush` 붓 | 화면 전체 영역(userSpaceOnUse 0,0,1920,1080). ① feTurbulence fractalNoise baseFrequency `0.03 0.08`, octaves 3, seed 3 → feDisplacementMap scale **9** (가장자리 흔들림) ② feTurbulence fractalNoise `0.012 0.55`, octaves 2, seed 11 → 알파 = −1.3·a + 1.55 (가로 결 = 마른 붓 자국) ③ ①을 ②로 잘라냄(composite in) | 금지 표시·이후 구간·붓 |
| `xink` 잉크 | 같은 영역, fractalNoise `0.06`, octaves 2, seed 5 → displacement scale **3** | 시간선·화살표 |

필터 영역을 도형 크기(objectBoundingBox)로 두면 **수평선은 높이가 0이라 사라진다** — 반드시 화면 전체 영역으로.

## 4. 구성요소

### 4-1. 붓 금지 표시 (`ban`)
반지름 r=62. 원 경로 `M x,y−r A r r 0 1 1 x−0.1,y−r` 를 **두 겹**: 아래 `#7E1C18` 굵기 24 불투명 0.55 (+0.02초 늦게), 위 `#C33A31` 굵기 17. 둘 다 `xbrush`, 0.5초 동안 그려짐(stroke-dashoffset 1→0, power2.inOut). 사선 (x−0.7r, y−0.7r)→(x+0.7r, y+0.7r) 굵기 17, 원 시작 +0.45초에 0.22초. 소리 `pop`.

### 4-2. 붉은 이후 구간 (`brush`)
두 겹: 아래 `#8E2420` 굵기 28 불투명 0.6, 위 `#C2463C` 굵기 22 (motionboard 의 brush 는 width, width+6). 끝 y 를 2px 올려 손으로 그은 기울기. 0.9초 동안 왼쪽→오른쪽(0.03초 차이). 소리 `whoosh-short`.

### 4-3. 칩 카드 (afterline 카드)
카드 폭 cw = min(168, 간격×0.8), 높이 1.2·cw, ±1.6° 무작위 기울기(seed = 장면 id×13). 안에 칩 그림(폭 0.66·cw)과 숫자(Black Han Sans 최대 56px, 남색).
칩 그림(100×100 단위): 다리 7개 × 4면, 다리 4.6×14 금색 그러데이션(`#F3D27A → #C9962E → #8A6418`, 테두리 `#7A5512`) · 몸통 (17,17) 66×66 둥근 5, 남색 그러데이션 `#2E4A8E → #121E44`, 금색 테두리 3 · 다이 (28,28) 44×44 방사 그러데이션 `#3F64B8 → #16244F` · 왼쪽 위 광택 삼각형 흰색 13% · 1번 표시 점 금색 r2.2.
등장: 위 36px·0.86배·투명에서 0.38초 `back.out(1.8)`. n 장의 간격 시간 span = min(max(박자 길이×0.75, 0.9), 0.45n + 0.4). 카드마다 소리 `click-soft`.

### 4-4. 시간선 + 사건 표식 (afterline 배치)
선 y=560. 사건 x=330. 왼쪽 먹선 170→370, 굵기 5, `xink`, 표식보다 0.15초 먼저 0.35초. 회사명 (x330, y420) Black Han Sans ≤56px. 날짜 (x370, y690) ≤36px `#4A4E55`. 이후 구간 405→1760. '제재 뒤' 손글씨 50px 붉은 (x540, y606), 구간 +0.3초. 카드 줄 590→1650, 카드 바닥이 선 위 22px. 수량 문구: 앞말 Black Han Sans 50px 먹, 강조 92px `#B5302B` + 글자 그림자(0 2px 3px), 두 덩어리를 (1160, 682) 중심으로 가운데 정렬, 앞말 → 0.2초 뒤 강조.

### 4-5. 소품 스티커 (spread 단계)
184×184 카드, 모서리 14, 기울기 (−1.4, 1.1, −0.8, 1.5)° 차례. 아이콘 112px(lucide, `#1E2330`). x = 330 / 860 / 1390, y=290. 이름 Black Han Sans ≤40px (y+130). 등장 위 30px·0.85배에서 0.4초 `back.out(1.8)`, 0.7초 간격. 사이 화살표 굵기 6 `#3A3F48` `xink`, 몸통 0.35초 → 머리 0.15초.

### 4-6. 가격 막대 + 점선 연장 + 괄호 (spread 아래)
바닥 y=970, 위 한계 y=545, 막대 폭 210. 높이 = 425 × 값 / (최댓값×1.08). 막대 색 면: 가로 그러데이션 (색 F2 → CC 55% → E6), 위 모서리 6, 그림자. 아래에서 0.6초 `power2.out` 으로 자람, 값 글자 Black Han Sans 52px 0.4초 뒤. 낮은 값 높이에서 점선(14/10, 굵기 3)을 제품 막대 오른쪽 170px 까지 0.8초에 왼쪽→오른쪽. 괄호 '}' 막대 오른쪽 30px, 굵기 4 붉은, 0.45초. 이름 Black Han Sans ≤54px, 식은 손글씨 ≤34px 그 아래.
값 바뀜: 옛 높이 점선 윤곽(3px dashed, 불투명 0.6) 0.2초 → 막대 0.9초 `power2.inOut` 로 새 높이 → 옛 값·옛 괄호 불투명 0.22 → 막대 왼쪽에 아래 화살표 → 새 값 +1.0초, 새 괄호 +1.1초, 설명 손글씨(막대 왼쪽 90px, 오른쪽 정렬) +1.3초. 소리 `whoosh-short`.

### 4-7. 몫 막대 (share)
흰 카드 막대 260→1660, y580, 높이 140, 0.2배→1배 0.6초. 부분 = 카드 안 (6px 안쪽), 위→아래 색→색 D9, 안쪽 아래 그늘, 왼쪽에서 0.7초. 색 차례 `#B8322E`, `#E08A3C`, `#23418C`, `#2E7D4F`. 이름은 아래(홀수 번째는 48px 더 아래). 비교 눈금 점선 굵기 4, 막대 위 70 ~ 아래 20, 이름 손글씨 58px (y−100). 합계 괄호 막대 위 14px 가로 '⌃', 이름 Black Han Sans ≤58px (y−175).

### 4-8. 인물 카드 (motionboard `person`)
폭 230(기본). 인화 사진처럼 흰 테두리 12px, 그림자, 기울기 `rot`. 사진 칸 (폭−24)×1.05·폭: `photo` 가 있으면 object-fit cover + `grayscale(.15) contrast(1.05)`, 없으면 연한 회색 칸 안 **얼굴 없는 실루엣**(머리 타원 17×19, 어깨 곡선, 흰 옷깃, 색 `tone`: navy `#4C6AA8/#22345F` · red · gray · green · gold). 이름 Black Han Sans ≤40px, 역할 나눔고딕 ExtraBold ≤24px `#5B606A`. 등장: 아래 40px·0.9배에서 0.42초 `back.out(1.7)`.

### 4-9. 화살표 (motionboard `arrow`)
두 요소 중심을 잇는 2차 곡선. 시작·끝을 각 요소 짧은 변의 절반 + 22/26px 만큼 안으로. 휨 `bend`(기본 0.12, 음수면 반대쪽) × 거리. 굵기 6 `xink`, 0.45초 → 머리(길이 24, 폭 ±14) 0.12초. 이름 손글씨 44px, 곡선 꼭대기(1/4·시작 + 1/2·조절점 + 1/4·끝)에서 바깥쪽 42px. 소리 `pencil`.

### 4-10. 동작 (motionboard `do`)
| 동작 | 값 |
|---|---|
| 이름(나타남) | 인물 아래에서, 글자 20px 아래에서, 그 밖은 위 34px·0.86배 → 0.42초 `back.out(1.7)` |
| move | 0.9초 `power2.inOut` (dur 로 바꿈). 뒤 동작은 옮긴 자리 기준 |
| hi | 요소 둘레 16px 바깥 붉은 테두리 6px 모서리 14, 1.15배→1배 0.35초 + 요소 1.06배 0.18초 왕복 |
| dim | 불투명 0.28 + 흑백, 0.4초 |
| hide | 아래 20px 로 사라짐 0.35초 |
| swap | 글자 0.15초 사라짐 → 바꿈 → 0.2초 나타남 |
| 간격 | 한 박자 안 동작 사이 0.45초 (`gap`) |

## 5. 시간 맞추기
- 박자 시작 t0, 부품 i 번째 기본 = t0 + 0.2 + 0.5·i.
- `at: {부품: "단어"}` 가 있으면 그 박자 음성을 받아쓰기(faster-whisper)해서 그 단어가 시작하는 시각 − 0.1초. 받아쓰기가 없으면 대사 글자 위치 비율.
- 박자 사이 쉼·장면 앞뒤 여백·페이드는 hybrid 공통(`hybrid.timing`, 편집 기준 v10).

## 6. 소리
카드 `click-soft` · 붓·구간·이동 `whoosh-short` · 표식·강조 `pop` · 선·괄호 `pencil`(직접 합성한 연필 소리). 파일은 `hybrid.sfx_files()`.

## 7. 기준 프레임
`render.py` 출력에서 장면 1의 9.5초(완성 구도), 장면 2의 12.6초(값이 바뀐 뒤), 장면 3의 9.2초, 장면 4의 14.2초, 장면 5의 9.5초. 다시 만든 결과를 이 시각에서 뽑아 이전 판과 나란히 비교한다.
