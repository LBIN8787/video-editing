# 원본 발언 컷편집 (source-cut)

> 레시피 `styles/recipes/source-cut.yaml` · 장면 type `bite` · 코드 `ytflow/stages/cutedit.py` · 시험작 `projects/20261113-style-cut`
> 2026-11-13 사용자 요청: "어닝이나 누가 발언했다 그러면 대본과 어울리는 부분만 컷편집하여 올린다".

## 1. 한 줄
내레이션이 "경영진은 ~라고 말했습니다"로 **전하는 대신**, 그 사람의 **목소리와 얼굴로 그 문장만** 3~20초 들려준다. 원문(영어)은 화면에 작게, 번역은 아래 자막.

## 2. 흐름 (자동)
1. **원본 넣기:** 긴 원본을 `04_assets/footage/` 에 넣는다. 대상은 어닝콜·기자회견·청문회·인터뷰이고, 몇 시간짜리여도 된다. 대본 `footage` 에 파일과 출처(`credit`)를 적는다.
2. **문장 고르기:** 대본의 `bite` 장면에 쓸 문장을 고른다. 문장은 공식 녹취록이나 받아쓰기에서 **그대로 복사**한다.
   - 짧은 한 문장은 `find` 에 넣는다.
   - 긴 구간은 처음 몇 단어를 `from`, 끝 몇 단어를 `to` 에 넣는다.
   - 여러 군데를 이어도 된다. 이어지는 곳은 흰 번쩍임 0.18초 + 작은 딸깍 소리로 '잘랐다'는 것을 숨기지 않는다.
3. **구간 찾기:** `python -m ytflow cut <프로젝트>` 를 실행한다.
   - 원본 전체를 받아쓰기한다(faster-whisper, 단어 시각, 캐시 `*.words.json`).
   - 문장마다 가장 비슷한 연속 단어 구간을 찾아 `02_script/cuts.json` 에 쓴다. 시작·끝·일치도와 실제로 들린 문장(`heard`)이 함께 들어간다.
   - 일치도가 0.6 미만이면 '찾지 못함'으로 남긴다. 이때는 문장을 고치거나 `start`·`end` 를 직접 넣는다.
4. **사람 확인:** `cuts.json` 의 `heard` 가 대본이 말하려는 뜻과 같은지 본다. 앞뒤를 잘라 뜻이 바뀌면 안 된다.
5. **렌더:** `python -m ytflow hybrid <프로젝트>` 를 실행하면 아래 순서로 장면이 만들어진다.
   - 구간을 잘라 이어 붙인다: 원본 소리는 −16 LUFS 로 맞추고, 앞뒤 0.06/0.12초 페이드를 준다.
   - 앞 내레이션 동안에는 멈춘 첫 화면을 어둡게 깔고 "직접 들어 봅니다 · 이름 · 직함"을 띄운다.
   - 이어서 원본 영상이 나오고, 이름 자막, 원문 한 줄, 번역 자막이 붙는다.
   - 번역 자막에는 이름 `bite` 가 붙어 싱크 점검(sync-qa)에서 빠진다.

## 3. 대본 쓰는 법
```json
"footage": {"fomc": {"file": "fomc_20230614_part.mp4", "credit": "Federal Reserve · 퍼블릭 도메인"}},
{"id": 5, "type": "bite", "chapter": 1, "who": "제롬 파월", "role": "연준 의장 · 2023년 6월 14일 기자회견",
 "label": "FOMC 기자회견 2023.6.14",
 "beats": [{"say": "파월 의장은 이번 결정을 이렇게 설명했습니다."}],
 "clip": {"src": "fomc", "lang": "en", "cuts": [
    {"find": "원문 문장 그대로", "ko": "번역 (한 구간 2줄 이내)"},
    {"from": "긴 구간의 처음 몇 단어", "to": "끝 몇 단어", "ko": "번역"}]}}
```
- **앞 내레이션:** 한 박자, 10초 이내로 쓴다. 누가, 언제, 어떤 자리에서 말했는지 알려 준다. 빈 배열 `[]` 이면 바로 원본으로 넘어간다.
- **길이:** 한 장면 3~20초로 잡는다. 25초가 넘으면 둘로 나누고 사이에 내레이션 해설을 넣는다.
- **뒤 해설:** 바로 다음 장면에서 "이 말의 뜻은…"으로 받는다. 들려주고 끝내지 않는다(manual 03 §0-1 연결과 의미).
- **번역:** 직역보다 뜻이 정확한 쉬운 말로 쓴다. 숫자와 고유명사는 원문 그대로 둔다.

## 4. 소스 규칙 (AGENTS.md 와 같음)
- **쓸 수 있는 원본:** 공공 기관 영상(연준·백악관·의회 = 미국 정부 저작물, 퍼블릭 도메인), 회사 공식 IR 웹캐스트·공식 채널 영상, CC BY 영상. 출처는 화면 오른쪽 위와 설명란에 적는다.
- **쓰지 않는 원본:** 뉴스 채널이 찍은 화면은 라이선스를 확인하기 전까지 쓰지 않는다. 사인(私人)의 발언도 쓰지 않는다.
- **막혔을 때:** 다운로드가 막히면(YouTube 봇 확인 등) 우회하지 않는다. 사용자 PC 에서 받아 `04_assets/footage/` 에 넣고 `rebuild` 한다.
- **보관:** 원본 파일은 커밋하지 않는다(미디어). 어디서 받았는지만 대본 `footage.*.url` 에 남긴다.

## 5. 검사
- `layout_qa.json` 이 비어 있어야 한다.
- 장면의 프레임을 뽑아 이름 자막, 원문 줄, 번역 자막이 겹치지 않는지 직접 본다.
- 일치도가 0.8 미만인 구간은 `heard` 를 꼭 사람이 읽는다.
