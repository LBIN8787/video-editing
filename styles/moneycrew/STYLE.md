# 머니크루 스타일: 평면 인포그래픽 모션

**한 줄 정의:** 무늬 없는 미색 화면 위쪽에 자막을 올리고, 그 아래에 주가 차트, 막대, 큰 숫자, 아이소메트릭 아이콘을 하나씩 띄워 설명합니다. 컷 없이 부드럽게 바뀌고, 화면 변화는 약 4초 간격입니다.

**언제 쓰나:** 산업·공급망·실적처럼 숫자와 구조가 많은 경제 해설에 씁니다. 과거 사례(예: 닷컴 버블)와 지금을 차트로 비교하는 영상에 특히 맞습니다.

## 화면 문법 (프레임 검토로 확인)
1. **배경:** 무늬 없는 미색 단색이 100%이고, 어두운 화면은 없습니다.
2. **자막:** 화면 **위쪽 가운데**에 어두운 고딕 한 줄을 둡니다. 핵심 숫자·단어만 빨강이나 파랑입니다. 상자와 외곽선이 없습니다.
3. **주가·지표 차트:** 캔들·꺾은선이 왼쪽에서 오른쪽으로 그려집니다. 차트 왼쪽 위에 '○○ 월봉' 같은 이름표를 달고, 꼭대기·바닥에 빨간 화살표와 값을 붙입니다.
4. **큰 숫자와 막대:** 빨강·파랑 굵은 숫자를 씁니다. 가로 막대(빨강·청록·남색)로 비율을 비교하고 '2배 넘게' 같은 글씨를 막대 안에 넣습니다.
5. **아이소메트릭 아이콘:** 칩 적층, 크레인, 트럭, 상자, 부품 같은 3D 아이콘을 씁니다. 단계 설명에는 ①~⑤ 타임라인을 쓰고, 지금 단계만 진하게, 나머지는 흐리게 둡니다.
6. **도장과 달력:** '장기 계약', '파산 보호' 같은 빨간 도장이 비스듬히 찍힙니다. 일정은 달력에 날짜 동그라미로 표시합니다.
7. **인물:** 정장 차림 선화 캐릭터 한 명이 설명 포즈를 취합니다(구조만 참고, 캐릭터는 복제하지 않음).
8. **전환:** 컷이 없습니다. 요소가 페이드 인·아웃되고 크로스페이드로 이어집니다. 앞 요소를 흐리게 남긴 채 다음 요소를 올리는 경우가 많습니다.

## Claude 가 장면 시트에서 읽은 규칙 (rules.json)
**움직임**
- 하드컷은 0회입니다. 장면 전환은 모두 크로스페이드이고, 움직임 띠에서 2~3프레임에 걸쳐 섞이므로 약 0.4~0.6초로 보입니다.
- 자막 문장도 함께 크로스페이드로 바뀝니다. 문장이 바뀌는 시점과 도식이 바뀌는 시점이 대체로 같습니다.
- 누적 빌드: 장면을 지우지 않고 같은 구도에 요소를 하나씩 더합니다. 예를 들어 층 쌓기 그림은 기판 → 필름+95% → 유리+90% → 국가별 괄호 순으로 10초 단위마다 하나씩 늘어나고, 막대 비교도 값 막대가 차례로 붙습니다.
- 캔들 차트는 왼쪽에서 오른쪽으로 봉이 하나씩 생기며 그려집니다. 움직임 띠에서 같은 차트의 끝 지점이 계속 오른쪽으로 늘어나는 것이 보였습니다.
- 막대 그래프는 0에서 목표 길이까지 가로로 차오르는 것으로 보입니다(추정: 10초 시트의 0%→값 상태 차이로 판단).
- 다음 장면으로 갈 때 이전 도식을 지우지 않고 반투명으로 흐리게 남겨 두는 장면이 있습니다. 예를 들어 과거 경로를 회색으로 남기고 현재 경로를 빨간색으로 겹쳤습니다(8:40, 9:00).

**반복 요소**
- 캔들스틱 차트: 오른 봉은 빨강, 내린 봉은 파랑(한국식)이고, 축 눈금은 연회색 작은 글씨로 씁니다. 차트 위에 빨간 세로선이나 짧은 텍스트로 이벤트 지점을 표시합니다.
- 가로 막대: 남색(#1E2838 계열)은 기준값, 빨강은 강조나 초과분, 파랑은 비교값, 베이지는 빈 칸으로 씁니다. 막대 끝에 굵은 숫자를 붙입니다.
- 세로 막대 2개 비교(1년 전 회색 vs 현재 청록·주황)이고, 막대 위에 '+62%', '3.6배' 같은 변화율을 붙입니다.
- 흑백 펜화(에칭풍) 사물 일러스트: 크레인, 트럭, 상자 더미, 공장, 은행 건물, 필름 롤, 서버 등입니다. 이 채널 고유 그림을 쓰지 말고, 같은 톤의 흑백 사물 아이콘을 새로 만들어 씁니다.
- 아이소메트릭 층 쌓기 도식: 연한 색 판을 비스듬히 위로 쌓고, 각 층 오른쪽에 라벨과 % 값을 붙입니다.
- 번호가 붙은 5단계 흐름 아이콘 줄과 진행 점 타임라인(빨간 원 안에 흰 숫자)입니다.
- 어두운 남색 둥근 칩에 노란 글씨를 넣어 회사·주체 이름 라벨로 씁니다.
- 빨간 테두리를 비스듬히 돌린 도장 박스('계약' 류 강조, 취소선 버전 포함)입니다.
