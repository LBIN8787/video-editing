# AI 분석 칼럼형 롱폼

상태: spec_only. 외부 채널을 복제한 스타일이 아니라 이번 프로젝트의 편집 규칙이다.

## 글과 영상의 구조

1. 질문과 핵심 주장
2. 배경과 변화
3. 근거와 작동 원리
4. 적용 사례와 비교
5. 반론과 한계
6. 누구에게 유용한가와 실행 방법

## 화면과 소리

- 음성은 채널 설정을 따른다. 스타일이 보이스를 선택하거나 재정의하지 않는다.
- 전환 효과음 없음. 핵심 문장, 단계별 화면, 출처와 사례를 사용한다.
- 실제 실행 화면과 설명용 예시를 구분한다. 실제 결과가 없으면 효과·절감 시간을 실측처럼 말하지 않는다.
- 6~10분은 초기 편집 가설이다. 분량은 근거와 논리 전개에 맞춰 정한다.
- 쇼츠를 느리게 늘이거나 기능 목록을 나열하지 않는다. 한 문장 주장 → 근거 → 사례 → 반론 → 판단을 연결한다.
- 장별 자료 화면과 도식으로 주장을 입증한다. 숫자 비교에는 기준과 기간을 표시한다.
- 롱폼은 명세 단계이며 새 렌더러와 자동 생성 연결은 미구현이다.
