# 손그림 삽화 (illustrated)

> 레시피 `styles/recipes/illustrated.yaml` · 장면 type `illust` · 코드 `ytflow/stages/illust.py` · 시험작 `projects/20261113-style-cut`
> 2026-11-13 사용자 요청: "손그림 애니메이션 삽화 (이 그림체만을 말하는게 아니라 포괄적으로)". 그림은 **사용자가 준비**(2026-11-13 선택).

## 1. 한 줄
**삽화 한 장**을 무대로 쓴다. 내레이션 박자마다 카메라가 '지금 말하는 곳'으로 옮겨 가고, 그 순간 손으로 그린 표시가 그려진다.

## 2. 그림체 (포괄적, 채널마다 하나로 통일)
| 그림체 | 느낌 | 어울리는 곳 |
|---|---|---|
| 미드센추리 구아슈 (1950~60년대 잡지 삽화, 따뜻한 원색, 붓 질감) | 낙관·회상·사람 이야기 | 시장 해설, 호기심 |
| 펜 + 수채 번짐 | 차분·기록·여행 | 역사, 교양 |
| 평면 에디토리얼 (단순한 면, 2~4색) | 깔끔·현대·개념 | AI, 경제 개념 |
| 크레용·색연필 (아이 그림책) | 친근·쉬움 | 쉬운 설명, 쇼츠 |
| 판화·목판 (굵은 선, 단색) | 무게·시대감 | 시사 배경, 옛 사건 |
| 잉크 스케치 (흑백 선 + 한 가지 강조색) | 빠름·메모 | 아이디어 설명 |

- **글자:** 그림 안에 글자를 넣지 않는다. 화면 글자는 편집이 넣는다.
- **실존 인물:** 닮게 그리지 않는다. 직함만 화면 글자로 쓴다.
- **레퍼런스:** 레퍼런스 채널의 그림·캐릭터·구도를 그대로 따라 그리지 않는다. 기법만 가져온다.

## 3. 움직임 (렌더러가 자동으로)
| 기법 | 대본 | 무엇을 하나 |
|---|---|---|
| **붓 쓸기 등장** | `"reveal": "paint"` (기본) · `fade` · `iris` | 그림이 붓으로 쓸듯 왼쪽에서 오른쪽으로 나타남 |
| **카메라 옮기기** | `moves[{beat, focus:[x,y,w,h]}]` (그림 비율 0~1) | 박자 시작 0.3초 전부터 1.4초 동안 그곳으로 확대·이동. 마지막 위치에서는 아주 천천히 계속 당김 (정지 화면 방지) |
| **boil (선이 살아 있음)** | `"boil": true` (기본) | 0.5초마다 아주 약한 일렁임 — 손그림 애니메이션의 'boiling line' 기법 |
| **손그림 표시** | `marks[{beat, kind, …}]` | `circle`(동그라미) · `arrow`(화살표) · `underline` · `note`(펜 메모) · `bubble`(생각 풍선). 카메라가 멈춘 뒤 그려지고 다음 박자에 사라짐 |

- **표시 좌표:** 화면 좌표(1920×1080)이고, 그 박자의 카메라 기준이다.
- **표시 개수:** 박자당 1~2개만 둔다. 많으면 그림이 가려진다.

## 4. 그림 준비 (사람)
1. 대본을 쓴 뒤 `python -m ytflow art-brief <프로젝트>` 를 실행하면 `02_script/art_brief.md` 가 나온다. 장면마다 파일 이름, 그릴 내용, 박자별로 카메라가 볼 곳, 표시가 들어갈 자리가 적혀 있다.
2. 그림은 가로 16:9, **2400×1350 이상**(카메라가 확대하므로)으로 그려 `04_assets/art/<파일 이름>` 에 넣는다.
3. `python -m ytflow hybrid <프로젝트>` 를 실행한다.
   - 그림이 없으면 '삽화 자리' 카드(그릴 내용이 적힘)로 렌더되고, `layout_qa.json` 에 `art/missing` 으로 남는다.
   - 그림만 바꿔 다시 렌더하면 그 장면만 새로 만들어진다.
4. **출처:** 직접 그린 그림은 `credit` 을 비우거나 '그림: 채널 자체 제작'으로 둔다. 퍼블릭 도메인 그림을 임시로 쓰면 작가·소장처를 `credit` 에 적는다.

## 5. 쓰는 곳 · 쓰지 않는 곳
- **쓰는 곳:** 사람들의 생각·행동·상황, 비유, 옛날 사례 재현, 두 갈래 선택. 영상당 2~5장면.
- **쓰지 않는 곳:**
  - 숫자가 주인공인 장면 → 차트
  - 실제 사건 현장 → 사진·원본 영상. 그림이 사실 기록처럼 보이면 안 된다.
  - 시사의 피해 장면
