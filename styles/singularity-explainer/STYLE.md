# 척추 그래프 해설: 그래프 한 장을 영상 전체의 뼈대로, 한 캔버스 위에서 풀어 가는 15분 해설

2026-11-27 사용자: "이 영상을 완전히 똑같이 템플릿부터 대본까지 작성해서 리버스 엔지니어링해 그대로 복제한 뒤 이 제작 매뉴얼을 세워"

**한 줄 정의:** 1차 출처 글 하나에 실린 **그래프 한 장**을 주인공으로 삼아, 도입에서 보여 주고 → 그 숫자의 뜻·원리를 일상 예시로 풀고 → 기울기를 재고 → 왜 위험한지 → 제안 → 구멍 → 마무리에서 같은 그래프로 돌아온다. 화면은 미색 모눈 캔버스 하나에서 끊지 않고 이어진다.
**언제 쓰나:** AI 연구소·기관이 **새 측정값·지표·그래프**를 공개했을 때(벤치마크, 스케일링 곡선, 안전 평가, 비용 곡선). 숫자 하나가 무엇을 재는지부터 풀어야 하는 주제. AI 채널 롱폼 '보고서 해부'.
**쓰지 않을 때:** 그래프·측정값이 없는 인물 이야기, 소식 나열(뉴스 데스크가 맞음), 쇼츠.

## 1. 대본 뼈대 (9칸, 15분 기준)

| 칸 | 비율 | 할 일 | 반드시 들어갈 것 | 끝 문장 |
|---|---|---|---|---|
| ① 훅 | 8% (≈75초) | 날짜·인물·글 제목 → 반응 한 줄(인용) → **"세로축엔 숫자 하나. 이 숫자가 내려갈 때마다 세상이 바뀐다"** → 점을 위에서 아래로 훑으며 능력 4~5개 → **"정말 ○○한 건 그 아래"** → 아직 모르는 구간 → 제안 | 숫자 3개 이하, 그래프는 화면에 계속 | 질문 2개: "이 숫자가 어떻게 X까지?" "왜 하필 지금 Y가?" |
| ② 인사 | 1줄 | "안녕하세요, ○○입니다." 바로 "우선 방금 본 ○○가 무엇인지부터" | 채널 소개·순서 예고 없음 | — |
| ③ 정의 | 19% | 이름 풀이(헷갈리는 동명 서비스 정리) → 흔한 통념 한 줄 → **일상 예시 하나**(음식·날씨처럼 누구나 아는 문장) → 채점 방식 → 전문 용어 한 번만(알 분은 아실 텐데) → 측정 데이터가 특별한 이유 → 대표 값 2개 | 예시는 확률 3개로, 정답/오답 두 경우 | "그런데 흥미로운 건 이게 ○○과도 이어진다" |
| ④ 원리 | 24% | **역사 퀴즈를 시청자에게 직접** → 그 실험의 숫자 2개 → 발상 하나 → **③의 예시를 다시 꺼내** 같은 원리로 → 공식 한 줄 → 사람 vs 모델 비교 → 실제 코드/글 한 조각으로 왜 이해가 필요한지 3단 → 외워선 안 되는 이유 → 일상 비유 | ③ 예시 재활용 필수 | "이 그래프의 기울기를 직접 재 보면…" |
| ⑤ 데이터 | 12% | 왼쪽 구간 기간·차이 → 정체기(당시 통념) → 꺾인 구간 기간·차이 → **배수 하나로 요약** → 그 지점에서 벌어진 일화 → 실제 발표 2건 → 지금 위치·남은 폭 → 당사자 경고 | 기간·차이·배수, 남은 폭 숫자 | "○○면 좋은 거 아닌가요? 왜 브레이크를?" |
| ⑥ 위험 | 8% | 지금까지의 안전장치를 **사물 비유 하나**로 → 어떻게 작동했나(구체 예) → 최근 연구 결론(인용) → 외부 평가 숫자 → 모르는 구간에서 더 약해짐 → "그래서 ○○ 전에 브레이크" | 원문이 링크한 다른 글을 '숨은 답'으로 | (끊지 않고 ⑦로) |
| ⑦ 제안 | 10% | 이미 나온 제안·합의 나열 → 열어 보니 빠진 것 → **중심 비유 사물**(빈 속도계) → 기존 규제 방식 2개와 그 약점(숫자) → 1인칭 평가 1줄 → 새 제안의 작동 방식(계단식 등) | 1인칭은 여기서만 | "하지만 구멍이 두 개" |
| ⑧ 반론 | 9% | 구멍 ①은 **같은 그래프 안에서** 증거 찾기(역전 사례) → 이유 → 본인도 인정 / 구멍 ② 비교 불가 → 실제 사례 → "그래도 의미는 있다" | 반론도 척추 그래프로 | "정말 다 같이 밟을까?" |
| ⑨ 현재+마무리 | 10% | 기준일 명시 → 참여한 곳/안 한 곳 → **첫 질문으로 돌아가 답 한 문장** → 한계 3개 요약 → 남은 폭 숫자 다시 → 시청자에게 양자택일 질문 → 구독·좋아요 1줄 | 수미상관 필수 | "다음 영상에서 만나요." |

**말투:** 3인칭 다큐 '~습니다' + 가끔 '~죠', '~거든요'(설명 끝). 분당 약 340~350자. 장 끝 질문 9개 안팎, 숫자에는 비교 대상.
**재활용 규칙:** 새 예시를 만들기 전에 앞에서 쓴 예시로 설명할 수 있는지 먼저 본다(③ 예시 → ④, 그래프 → ⑤⑧⑨, 물음표 → 전 장).

## 3. 장면 표 (문장마다 하나 고르기)

| 대사가 하는 일 | 장면 | 우리 엔진 |
|---|---|---|
| 원문을 처음 소개 | 원문 화면 → 그래프만 떠올라 종이로 | `zoomshot` |
| 누가 반응했다 | X 게시물 카드 + 번역 띠 | X 임베드 캡처 |
| 그래프 축·값의 뜻 | 척추 그래프 + 축 라벨을 알약으로 뽑아내기 | `motionboard` + 그래프 |
| 단계별 능력 | 척추 그래프 점마다 라벨 3단 + 아이콘 | 그래프 + 아이콘 열 |
| 정의·이름 | 큰 카드(영문 + 한글 + '뜻' 칩) | `kinetic` |
| 통념 인용 | 낱말 칩 + 큰따옴표 | `kinetic` |
| 확률·예측 | 마스코트 + 후보 3개 % 막대 | 가로 막대 |
| 평균·누적 | 흐르는 문제 → 저울 + 카운터 | 카운트업 |
| 두 데이터 구분 | 시험지 두 장, 같으면 빨간 사선 | `motionboard` |
| 대조 | 좌우 두 칸 | `motionboard` |
| 과거로 | 연도 큰 글씨 + 시대 그림(생성) → 누런 바탕 타자기 | `archive`·art-gen + `typewriter` |
| 원리 시연 | 같은 소품 두 대를 선으로 잇고 숫자가 이동 → 소품을 마스코트로 교체 | `motionboard` swap |
| 사람 vs 모델 | 사람 아이콘 군중 → 가로 막대, 사람 기준 점선 | waffle + bars |
| 코드 근거 | 코드창 한 줄씩 + 옆에 쌓이는 막대 | 코드창(있음) + 막대 |
| 기울기·기간 | 각도기·삼각자 소품 + 위 괄호(기간) + 차이 화살표 | 소품 PNG + 그래프 주석 |
| 일화 | 사내 채팅 창(✕ → ✓ 쏟아짐) | `chat` |
| 발표 | 발표 카드 + 숫자 카운트업 + 종이 더미 | 카운트업 |
| 시청자에게 묻기 | 마스코트 + 겨자 알약 질문 | 질문 카드 |
| 안전장치 비유 | 사물 하나(안전벨트, 돋보기 눈, 일기장) | 아이콘·삽화 |
| 중심 비유 | 계기판(빈 속도계 + 브레이크) — 장을 건너 다시 등장 | 소품 컴포넌트(추가 필요) |
| 정부·기관 | 실사 사진 배경 + 흰 카드 체크리스트 | 사진 + 카드 |
| 기준선(법·규제) | 가로 로그축 + 세로 선 + '대상' 영역 | `motionboard` |
| 단계적 절차 | 계단·문 그림 | 생성 그림 |
| 지금 상태 | 원탁 빈 의자 그림 + 라벨(채움/미공개) | 생성 그림 + 라벨 |
| 마무리 | 앞 장면들을 차례로 다시 불러와 물음표로 수렴 | 재사용 |

**하드 컷은 장 전환에서만**, 15분에 4~5번(시대 그림, 기관 사진, 단계 그림, 원탁 그림, B롤 1개). 나머지는 같은 캔버스에서 흐려짐·이동·교체.

## 6. 품질 체크리스트
- [ ] 척추 그래프가 ①⑤⑧⑨에 다시 나오고, 매번 다른 구간을 비춘다
- [ ] 장마다 끝 문장이 다음 장의 질문이다
- [ ] ③의 일상 예시를 ④에서 다시 쓴다
- [ ] 숫자마다 비교 대상(이전 값·사람·기간)이 붙어 있다
- [ ] 마무리가 훅의 질문에 한 문장으로 답한다(수미상관)

- [ ] 하드 컷 4~5번, 나머지는 같은 캔버스
