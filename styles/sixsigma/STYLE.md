# 식스시그마 스타일: 원본 발언과 숫자 해설

**한 줄 정의:** 해외 거물의 인터뷰, 방송, 키노트 원본 영상을 화면 중심에 두고, 그 사이를 검은 배경 인포 카드로 정리합니다.

**언제 쓰나:** 기업·투자 뉴스 해설, 실적·지분·딜 분석, 'A가 말했다 → 숫자로 보면' 구조의 영상에 씁니다.

## 화면 문법
1. **원본 소스 영상이 중심입니다.** 인터뷰, CNBC·Bloomberg 같은 방송, 컨퍼런스, 키노트를 전체 화면 그대로 씁니다. 내레이션 장면은 관련 영상을 소리를 끄고 깝니다.
2. **원본 발언(quote):** 원래 목소리를 6~20초 들려줍니다. 자막은 위에 작은 회색 영어 원문, 아래 흰색 한국어 번역입니다.
3. **출처 라벨:** 모든 화면 왼쪽 위에 `YYYY.MM.DD · 출처`, 오른쪽 위에 작은 채널 로고를 둡니다.
4. **검은 인포 카드**
   - 순수 검정 배경, 얇은 흰 글씨와 선, 강조는 빨강(`#E8402C`) 하나입니다.
   - 큰 숫자 비교, 흐름도, 빨간 박스로 강조한 표, 막대, 기사 헤드라인을 이렇게 보여 줍니다.
5. **기사 캡처:** "보도에 따르면" 문장은 검은 화면 위 헤드라인 캡처로 보여 줍니다.
6. **쓰지 않는 것:** 배경음악, 줌, 색 배경, 아이콘, 효과음.
7. **편집 리듬:** 내레이션 문장 단위로 화면을 바꿉니다(약 4~8초). 원본 발언은 통째로 씁니다.

## 대본 구조 (style_profile 의 script 규칙과 함께)
1. **훅:** 숫자 사실 콜드오픈 → 질문 하나 → "~의 말로 따라가 보겠습니다"
2. **본론:** 원본 발언 → "정리하면" → 숫자 카드를 반복합니다.
3. **반론:** 반론 섹션 하나를 넣습니다.
4. **마무리:** "다음에 볼 것" 일정을 예고합니다. 구독 요청은 하지 않습니다.
