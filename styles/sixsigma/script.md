# 식스시그마 스타일 대본 추가 규칙

- **계열:** 원본 소스형(source). 공통 화면 문법은 `prompts/script_source.md` 입니다. 이 파일은 식스시그마만의 추가 규칙입니다.
- **화면 비율:** 원본 영상(quote + source_video) 40~55%, card 30~40%, screenshot 10~20%입니다.
- **편집점:** 원본 발언 2~3개마다 검은 배경 핵심 요약 카드(beat=summary)를 애니메이션으로 넣습니다. 카드 다음 장면은 다시 원본 영상으로 돌아갑니다.
- **발언자:** 실적발표·인베스터데이의 CEO·CFO 발언을 1순위로, 방송 인터뷰를 2순위로 고릅니다. label 에 '날짜 · 행사/매체'를, 화면 아래에 이름·직함을 넣습니다(visual_brief).
- **원본 발언:** kind=quote 는 원문과 출처 영상·시각이 확인된 발언만 씁니다. quote_en 에 원문을, narration 에 번역을 넣습니다.
- **강조:** 카드 강조(highlight)는 한 카드에 하나만 둡니다.
- **장면 길이:** 내레이션 장면은 1~2문장(약 4~8초)입니다.
