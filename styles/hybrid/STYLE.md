# 하이브리드 스타일

**한 줄 정의:** 실제 인물·현장 영상 위에 이름 자막과 형광펜 주석을 얹고, 그 사이사이 종이 위 손그림으로 '인과 지도'를 한 칸씩 키워 가며 숫자와 논리를 보여 줍니다.

## 왜 이렇게 바꿨나 (이전 영상의 문제)
- 한 문장마다 같은 모양의 카드 한 장 → 100장이 같은 패턴으로 반복 → 단조롭고 성의 없어 보임.
- 숫자는 많은데 '무슨 이야기인지' 한 줄로 잡히지 않음.
- 실제 영상이 거의 없음.

## 화면 문법
| 요소 | 무엇 | 출처 스타일 |
|---|---|---|
| 원본 영상 | 전체 화면(아래 어둡게) 또는 종이 위에 테이프로 붙인 사진처럼. 천천히 다가감 | 식스시그마 |
| 이름 자막 | 왼쪽 아래 종이 띠: 이름(굵은 명조) + 직함·'자료 화면' | 식스시그마 |
| 복스식 주석 | 영상 위 종이 쪽지 + 형광펜 + 연결선 + 펜 메모 | (Vox 기법) |
| 인과 지도 | 손그림 칸·화살표. 영상 내내 같은 자리, 장마다 칸이 늘고 지금 칸이 빨갛게 | 머니크루의 논리 + 미주일기의 손그림 |
| 수치 도식 | 빗금 막대·깔때기·아파트 그리드·주차장·타임라인·지도 | 머니크루 + 미주일기 |
| 장 전환 | 종이 한 장이 밀려 들어오며 장 번호·질문 | 미주일기 |
| 장 표시 | 왼쪽 위 '1 선거 날, 무슨 일이' (지금 어디쯤인지) | — |
| 자막 | 아래 가운데 어두운 상자 | — |
| 효과음 | 장 전환 휙, 도장 쿵, 숫자 팝, 이름 자막 딸깍 (작게) | — |

## 규칙
- 같은 장면 type 을 연달아 쓰지 않는다. 원본 영상은 20~30초마다.
- 장면 = 1~3박자, 박자 = 1~2문장. 화면이 박자에 맞춰 바뀐다.
- 다른 시점·장소 영상은 반드시 '자료 화면 · 날짜 · 장소'.
- 대본 문법: `prompts/script_hybrid.md`. 렌더러: `ytflow/stages/hybrid.py`.
