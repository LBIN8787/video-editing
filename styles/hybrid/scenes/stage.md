# `stage` — 애니메이션 무대

**언제:** 호기심 채널 이야기형, 기억할 한 장면

**무엇:** 한 화면 한 생각 — 대본의 동사를 그림이 연기

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `stage` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/stage.jpg`, 영상 `ytflow/looks/scenes/clips/stage.mp4`
  - 예시와 실제의 차이: 예시는 그림 없이 렌더해 글자만 겹쳐 보임 — 실제는 준비한 그림 조각이 연기함

## 화면 구성·움직임 원리

- 한 화면 한 생각: 박자 act 에 적은 배우(그림 조각)·소품이 대본의 동사를 연기(들어옴·흔들림·바뀜)
- 02_script/intent.md 의 목표·기억할 장면이 먼저. 그림 조각이 없으면 글자만 남음

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only stage --force` (그림·영상·이 명세가 함께 갱신)
