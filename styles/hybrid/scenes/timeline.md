# `timeline` — 연표

**언제:** 사건의 순서, 과거 사례와 지금

**무엇:** 가로 시간선에 해마다 표식이 찍힘

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `timeline` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/timeline.jpg`, 영상 `ytflow/looks/scenes/clips/timeline.mp4`

## 화면 구성·움직임 원리

- 가로 연도 축(years) → 해마다 눈금·연도 → events 가 그 해 위에 표식·글로, spans 는 기간 막대(색)
- 박자 upto 로 어디까지 보일지

## 박자표 — 무엇이 언제 나타나나

예시 렌더(아래 대본)의 시간축을 그대로 옮긴 것입니다. 시각은 대사 길이에 따라 달라지고, 순서와 간격이 이 장면의 문법입니다.

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "timeline"`

```json
{
 "type": "timeline",
 "label": "2026.11.06 · 서스케하나 보고서 보도",
 "title": "위험은 언제 몰려 있나",
 "years": [
  "2026",
  "2027",
  "2028",
  "2029",
  "2030"
 ],
 "spans": [
  {
   "from": "2027",
   "to": "2027",
   "label": "대부분 허가 완료",
   "tone": "ok"
  },
  {
   "from": "2028",
   "to": "2030",
   "label": "취소·지연 위험이 몰린 구간",
   "tone": "risk"
  }
 ],
 "beats": [
  {
   "say": "그리고 '언제'가 중요합니다. 2027년에 들어설 물량은 대부분 이미 허가를 받았습니다.",
   "upto": 1
  },
  {
   "say": "위험은 2028년부터 2030년 사이에 몰려 있습니다. 그래서 서스케하나는 2027년이 가장 많이 짓는 해라는 전망을 바꾸지 않았습니다.",
   "upto": 2
  }
 ]
}
```
대본 공통 키: `edit_v10, map` (예: map_causal 의 `map`)

읽는 키 — 장면: `events, label, spans, title, years` · 박자: `upto` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only timeline --force` (그림·영상·이 명세가 함께 갱신)
