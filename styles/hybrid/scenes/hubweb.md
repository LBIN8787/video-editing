# `hubweb` — 질문 허브 관계망 (누아르)

**언제:** 흩어진 사건 여러 개가 한 질문(누가·왜)으로 모이는 시사·시장 심층 — 큰 사건 주간 · **피할 때:** 숫자 비교, 사건이 하나뿐일 때, 연결이 확인되지 않은 추측을 선으로 잇기 (선 = 확인된 관계만), 오신트의 "누군가?" 문구 그대로 쓰기 (구조만 가져옴)

**무엇:** 가운데 질문 원(그 편의 질문, 예 "누가?")에서 박자마다 사건·인물 가지가 하나씩 늘어남, 지금 말하는 가지만 빨강, 위쪽 날짜 눈금

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `hubweb` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/hubweb.jpg`, 영상 `ytflow/looks/scenes/clips/hubweb.mp4`
  - 예시와 실제의 차이: 예시는 가상의 회사·인물 (docs/57 §4)

## 화면 구성·움직임 원리

- 가운데 빨간 테두리 원에 큰 질문(hub.label) — 천천히 숨 쉬듯 빛남
- add 한 가지마다: 원(또는 from 의 상자)에서 빨간 선이 그려지고 → 관계 글(rel) → 상자(label·sub·date)가 튀어나옴
- 다음 박자가 오면 앞 박자의 빨강은 회색으로 물러남 (빨강은 지금 하나뿐), hi 로 앞 가지를 다시 빨갛게
- cut: 상자를 빨간 줄로 긋고 흐리게 (지우지 않음 — 쌓인 화면 유지)
- ruler: 위쪽 날짜 눈금, 빨간 점이 새 가지의 date 로 미끄러짐 · 화면 전체는 아주 천천히 다가감

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "hubweb", "skin": "noir"`

```json
{
 "type": "hubweb",
 "skin": "noir",
 "title": "누가 움직였나",
 "hub": {
  "label": "누가?",
  "sub": "이사회 뒤의 손"
 },
 "ruler": [
  "월",
  "화",
  "수",
  "목"
 ],
 "nodes": [
  {
   "id": "a",
   "label": "대주주 펀드",
   "sub": "지분 12%",
   "date": "월",
   "rel": "지분 매각"
  },
  {
   "id": "b",
   "label": "사외이사 2명",
   "sub": "동시 사임",
   "date": "화"
  },
  {
   "id": "c",
   "label": "경쟁사 대표",
   "sub": "같은 날 매수",
   "from": "a",
   "date": "수"
  },
  {
   "id": "d",
   "label": "익명 제보",
   "sub": "기사 한 줄",
   "date": "목"
  }
 ],
 "beats": [
  {
   "say": "월요일, 대주주 펀드가 지분을 팔았습니다.",
   "add": [
    "a"
   ]
  },
  {
   "say": "화요일, 사외이사 두 명이 함께 물러났습니다.",
   "add": [
    "b"
   ]
  },
  {
   "say": "같은 주, 그 지분을 산 사람은 경쟁사 대표였습니다.",
   "add": [
    "c"
   ],
   "hi": "a"
  },
  {
   "say": "그리고 목요일, 익명 제보가 나옵니다.",
   "add": [
    "d"
   ],
   "cut": [
    "b"
   ]
  }
 ]
}
```
대본 공통 키: `edit_v10` (예: map_causal 의 `map`)

읽는 키 — 장면: `hub, label, nodes, ruler, title` · 박자: `add, cut, date, hi` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only hubweb --force` (그림·영상·이 명세가 함께 갱신)

## 확인할 것

- 숫자 비교, 사건이 하나뿐일 때, 연결이 확인되지 않은 추측을 선으로 잇기 (선 = 확인된 관계만), 오신트의 "누군가?" 문구 그대로 쓰기 (구조만 가져옴)
