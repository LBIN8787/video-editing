# `docspot` — 기사 스포트라이트

**언제:** 기사·발표문·약관의 한 줄이 근거일 때

**무엇:** 기사 원문 카드에서 대사가 닿는 문단만 밝게(나머지 어둡게) + 형광펜 + 옆 숫자 카드

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `docspot` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/docspot.jpg`, 영상 `ytflow/looks/scenes/clips/docspot.mp4`

## 화면 구성·움직임 원리

- 왼쪽(숫자 카드가 있으면) 또는 가운데 흰 문서 카드: 출처 꼬리표 → 헤드라인 → 문단(paras, 34px, 줄 바꿈 자동) / 또는 캡처 그림(img)
- 박자 spot 마다 그 문단 둘레만 뚫린 어두운 막(box-shadow 3000px)이 새로 생기고 앞 막은 사라짐 → 그 줄들에 라임 형광펜이 차례로
- num 이면 오른쪽 흰 숫자 카드: 이름표 → 큰 숫자(세어 올라감) → 강조색 밑줄 바 → 비교 줄. 숫자 카드는 막 위

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "docspot"`

```json
{
 "type": "docspot",
 "source": "예시 신문 · 11.09",
 "headline": "AI 비서, 하루 수백 통 대신 전화 걸어",
 "paras": [
  "한 AI 비서 서비스가 출시 첫 주에 이용자 대신 건 전화가 크게 늘었다고 회사가 밝혔다.",
  "회사 쪽은 첫날 433통이던 발신이 닷새 만에 817통으로 늘었다고 설명했다.",
  "다만 전화를 받은 가게 상당수는 AI 라는 사실을 듣지 못했다고 답했다."
 ],
 "beats": [
  {
   "say": "기사 원문을 보겠습니다.",
   "spot": 0
  },
  {
   "say": "하루 발신이 433통에서 817통으로 늘었습니다.",
   "spot": 1,
   "num": {
    "value": "817통",
    "label": "닷새 뒤 하루 발신",
    "sub": "첫날 433통"
   }
  },
  {
   "say": "그런데 받은 쪽은 AI 인 줄 몰랐습니다.",
   "spot": 2
  }
 ]
}
```
대본 공통 키: `edit_v10` (예: map_causal 의 `map`)

읽는 키 — 장면: `headline, img, label, paras, source` · 박자: `mark, num, spot` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only docspot --force` (그림·영상·이 명세가 함께 갱신)
