# `compare` — 비교표

**언제:** 항목 여러 개를 두 대상으로 비교

**무엇:** 두 열 표가 줄마다 채워짐

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `compare` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/compare.jpg`, 영상 `ytflow/looks/scenes/clips/compare.mp4`

## 화면 구성·움직임 원리

- 두 열(cols) 머리글 → 행(rows)마다 왼쪽 이름·두 값이 차례로 쓰이고 손그림 가로줄
- 박자 upto 로 몇 행까지 보일지 정함 — 행을 박자에 나눠 공개

## 박자표 — 무엇이 언제 나타나나

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "compare"`

```json
{
 "type": "compare",
 "label": "자체 정리",
 "title": "그때와 지금",
 "cols": [
  "2022 북버지니아",
  "2026 지금"
 ],
 "rows": [
  {
   "label": "막힌 이유",
   "a": "전력망 (물리적)",
   "b": "정치·허가"
  },
  {
   "label": "범위",
   "a": "한 지역",
   "b": "여러 주"
  }
 ],
 "beats": [
  {
   "say": "다만 그때와 지금은 다릅니다. 그때는 전력망이라는 물리적 한계였고, 지금은 정치와 허가 문제입니다.",
   "upto": 1
  },
  {
   "say": "그때는 한 지역, 지금은 여러 주입니다. 그대로 되풀이된다고 볼 수는 없습니다.",
   "upto": 2
  }
 ]
}
```
대본 공통 키: `edit_v10, map` (예: map_causal 의 `map`)

읽는 키 — 장면: `cols, label, rows, title` · 박자: `upto` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only compare --force` (그림·영상·이 명세가 함께 갱신)
