# `spread` — 두 값 사이 간격

**언제:** 마진·스프레드·가격 차이가 어디서 생기나

**무엇:** 재료 → 공정 → 제품, 두 가격 높이와 괄호로 차이, 값이 바뀌면 옛 높이는 점선

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `spread` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/spread.jpg`, 영상 `ytflow/looks/scenes/clips/spread.mp4`

## 화면 구성·움직임 원리

- 위: 재료 → 공정 → 제품 아이콘(steps)을 화살표로 이음
- 아래: 두 값(low·high) 높이의 막대 + 점선 연장, diff 괄호에 이름·식
- change: 한쪽 값이 바뀌면 옛 높이는 점선 윤곽으로 남고 간격이 줄어듦

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only spread --force` (그림·영상·이 명세가 함께 갱신)
