# `statecard` — 상태 카드 (+ 가운데 주체)

**언제:** AI·앱이 '무엇을 대신 하나', 단계마다 결과가 나는 일 (AI 채널) · **피할 때:** 실제 화면 녹화가 있으면 그쪽 우선 — 재연에는 '연출' 고지가 자동으로 붙음

**무엇:** 같은 카드가 대기 → 진행(•••) → 성공(✓)·실패(빨간 X)로 바뀜, 가운데 주체와 연결선이 끊기기도

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `statecard` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/statecard.jpg`, 영상 `ytflow/looks/scenes/clips/statecard.mp4`

## 화면 구성·움직임 원리

- hub 가 있으면 가운데 원(아이콘·이름, 둥실)과 둘레 카드(최대 6, 좌우 배치), 선이 hub → 카드로 그려짐. 없으면 카드만 가로로
- 카드 = 흰 둥근 카드(아이콘·이름·작은 줄) + 오른쪽 위 상태 배지 4개(◷ 대기·••• 진행·✓ 성공·✕ 실패)가 겹쳐 있고 state 로 하나만 켜짐
- 상태가 바뀌면 테두리 색(파랑·초록·빨강)·배지 교체, 실패는 카드 회색 막 + 짧게 흔들림. text 는 작은 줄을 겹쳐 바꿈(프레임 탐색에도 안전)
- 좌상단 '*이해를 돕기 위한 연출입니다' 자동(notice: false 로 끔). 소리: 등장 pop, 상태 click

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "statecard"`

```json
{
 "type": "statecard",
 "title": "AI 비서가 대신 하는 일",
 "hub": {
  "label": "AI 비서",
  "icon": "bot"
 },
 "cards": [
  {
   "id": "hotel",
   "label": "호텔 예약",
   "icon": "phone",
   "sub": "대기 중"
  },
  {
   "id": "shop",
   "label": "쇼핑몰 결제",
   "icon": "shopping-cart",
   "sub": "대기 중"
  },
  {
   "id": "kakao",
   "label": "메신저",
   "icon": "smartphone",
   "sub": "연결됨"
  }
 ],
 "beats": [
  {
   "say": "AI 비서는 세 곳에 연결돼 있습니다.",
   "show": "all"
  },
  {
   "say": "호텔에 전화를 걸고 결제도 진행합니다.",
   "state": {
    "hotel": "run",
    "shop": "run"
   },
   "text": {
    "hotel": "통화 중",
    "shop": "결제 진행"
   }
  },
  {
   "say": "호텔은 끝났지만 메신저는 막혔습니다.",
   "state": {
    "hotel": "ok"
   },
   "text": {
    "hotel": "예약 확정",
    "kakao": "연결 끊김"
   },
   "cut": [
    "kakao"
   ]
  }
 ]
}
```
대본 공통 키: `edit_v10` (예: map_causal 의 `map`)

읽는 키 — 장면: `cards, hub, label, notice, title` · 박자: `cut, delay, show, state, text` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only statecard --force` (그림·영상·이 명세가 함께 갱신)
