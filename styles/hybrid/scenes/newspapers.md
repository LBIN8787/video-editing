# `newspapers` — 두 나라 신문

**언제:** 같은 사건을 다르게 다룬 매체 비교

**무엇:** 왼쪽은 검은 줄로 지운 지면, 오른쪽은 크게 보도한 지면 (재구성)

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `newspapers` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/newspapers.jpg`, 영상 `ytflow/looks/scenes/clips/newspapers.mp4`

## 화면 구성·움직임 원리

- 두 신문 지면을 좌우에(재구성): 왼쪽은 글줄 위에 검은 띠가 그어지고 '검열' 도장, 오른쪽은 큰 제목 보도
- 박자 show 로 왼쪽·오른쪽 순서

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "newspapers"`

```json
{
 "type": "newspapers",
 "label": "재구성 그림 · HISTORY, 위키백과 종합",
 "left": {
  "name": "전쟁 중인 나라의 신문",
  "sub": "1918 · 미국 · 영국 · 프랑스 · 독일",
  "stamp": "검열"
 },
 "right": {
  "name": "중립국 스페인의 신문",
  "sub": "1918 · 마드리드",
  "headline": "정체 모를 병이 도시를 덮치다",
  "note": "있는 그대로 보도"
 },
 "beats": [
  {
   "say": "그래서 전쟁 중인 나라의 신문은 침묵했습니다. 정부가 지우기도 했고, 신문사가 알아서 쓰지 않기도 했습니다.",
   "show": "left"
  },
  {
   "say": "그런데 스페인은 이 전쟁에 끼지 않은 중립국이었습니다. 전시 검열이 없었죠. 스페인 신문들은 병이 퍼지는 걸 있는 그대로 썼습니다.",
   "show": "right"
  }
 ]
}
```
대본 공통 키: `edit_v10, map` (예: map_causal 의 `map`)

읽는 키 — 장면: `label, left, right` · 박자: `show` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only newspapers --force` (그림·영상·이 명세가 함께 갱신)
