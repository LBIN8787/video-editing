# `funnel` — 깔때기

**언제:** 단계별로 줄어드는 수 (지원 → 합격 → 등록)

**무엇:** 단계마다 좁아지는 막대

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `funnel` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/funnel.jpg`, 영상 `ytflow/looks/scenes/clips/funnel.mp4`

## 화면 구성·움직임 원리

- 단계(bars)마다 가로 막대가 위에서 아래로 좁아지며 그려짐, 막대마다 값(세어 올라감)·설명
- 박자 upto 로 몇 단계까지 보일지

## 박자표 — 무엇이 언제 나타나나

예시 렌더(아래 대본)의 시간축을 그대로 옮긴 것입니다. 시각은 대사 길이에 따라 달라지고, 순서와 간격이 이 장면의 문법입니다.

## 대본(`02_script/hybrid.json`)에 쓰는 법

`"type": "funnel"`

```json
{
 "type": "funnel",
 "label": "2026.11.06 · Investing.com (서스케하나 보고서 보도)",
 "title": "AI 공장 계획, 전력으로 재면",
 "unit": "GW",
 "bars": [
  {
   "value": 148,
   "label": "2025~2030 계획 전체",
   "sub": "원전 약 148기 규모"
  },
  {
   "value": 60,
   "label": "아직 허가 대기",
   "sub": "전체의 40%"
  },
  {
   "value": 12,
   "label": "최악이면 취소",
   "sub": "전체의 8%",
   "highlight": true
  }
 ],
 "beats": [
  {
   "say": "서스케하나는 2030년까지 계획된 AI 학습용 데이터센터를 전력으로 셌습니다. 148기가와트, 원전 약 148기 규모입니다.",
   "upto": 1
  },
  {
   "say": "이 가운데 60기가와트가 아직 허가를 기다리고 있고,",
   "upto": 2
  },
  {
   "say": "최악의 경우 그중 12기가와트가 취소될 수 있다고 봤습니다. 전체의 8%입니다.",
   "upto": 3
  }
 ]
}
```
대본 공통 키: `edit_v10, map` (예: map_causal 의 `map`)

읽는 키 — 장면: `bars, label, title, unit` · 박자: `upto, value` (렌더러 코드에서 자동)

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only funnel --force` (그림·영상·이 명세가 함께 갱신)
