# `shape` — 모양 비교 개념도

**언제:** 정확한 수치 없이 패턴의 차이만 말할 때

**무엇:** 숫자 축 없이 곡선 모양만 (U자 vs W자)

**예시 (움직임):** [연출 예시 목록](https://claude.ai/artifact/SPHyXdpGmcdPwMQu7cpMdP) 의 `shape` 칸 ▶ — 실제 렌더 영상 · 세 컷 그림은 Drive `ytflow/looks/scenes/shape.jpg`, 영상 `ytflow/looks/scenes/clips/shape.mp4`

## 화면 구성·움직임 원리

- 숫자 없는 축 2개(xlabel·ylabel)·눈금 → 박자마다 곡선(curve.points, 0~1 좌표) 하나씩 손그림으로
- tone: red 면 강조 곡선, circle·note 로 부분 표시 — 정확한 수치가 아니라 모양 비교

## 박자표 — 무엇이 언제 나타나나

## 만들기

`python -m ytflow edit-plan <프로젝트>` → `hybrid.json` 에 위 장면 → `python -m ytflow check <프로젝트> --upto G5` → `python -m ytflow hybrid <프로젝트>`

예시를 다시 렌더: `python scripts/visual_catalog.py <작업 폴더> --only shape --force` (그림·영상·이 명세가 함께 갱신)
