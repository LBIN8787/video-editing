# 하이브리드 스타일 대본 추가 규칙

- **계열:** 원본 소스형(source). 대본은 장면 대본(scenes.json)이 아니라 `02_script/hybrid.json` 으로 씁니다 → `prompts/script_hybrid.md`.
- **이야기:** 질문 하나, 은유 하나, 인과 지도 하나. 장마다 지도로 돌아와 '지금 어디쯤인지'를 보여 줍니다.
- **리듬:** 원본 영상(footage) → 도식(chart·funnel·usmap…) → 인과 지도(map_causal) → 다시 원본 영상. 같은 type 연속 금지.
- **영상:** 공식·퍼블릭 도메인·CC BY 영상만. 자료 화면이면 날짜·장소를 이름 자막과 라벨에.
