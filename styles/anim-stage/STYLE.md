# 애니메이션 무대 (`anim-stage`, 장면 type `stage`) — 호기심 채널 이야기형 v22

> 2026-11-14 사용자 기각(v3 이야기 그림판): "중간중간 너무 난잡하다. 목표·시청자 욕망을 먼저 정의하고 매뉴얼을 쓴 뒤 시도하라.
> 대본을 소제목처럼 글로 쓰거나 사진을 무작정 붙이지 말고, 대본을 바탕으로 애니메이션을. 의도를 명확히."

## 순서 (어기면 렌더하지 않음)
1. `02_script/intent.md` — 제작 목표 한 줄 · 욕망 → 영상이 채울 것(끌림·따라감·깨달음·연결) · 기억할 한 장면(모티프) · 장면별 목표. (manual/04 §0-5 A)
2. 주인공 그림 주문 `02_script/art_plan.json` → `python -m ytflow art-gen <프로젝트> --backend codex|openai|manual` (같은 그림체 모델 시트 → 조각).
3. `hybrid.json` 의 `stage` 장면: 장면 `goal`, 박자마다 `why` + `act` (대본의 동사를 그림이 연기).
4. 렌더 → `layout_qa.json` 의 `stage/*` 가 비어야 함 → 프레임 확인 → 사람 검토.

## 화면 규칙 (manual/04 §0-5 C)
- 한 화면 = 한 생각: 주인공 1 + 소품 ≤ 2, 동시에 보이는 것 ≤ 4. 다음 박자에 필요 없는 것은 `out`.
- 글자는 한 번에 하나: 연도·숫자·이름·핵심어만. 자막 문장을 다시 쓰지 않는다.
- 사진·문서는 증거 순간에만, 하나, 말이 끝나면 퇴장. 실존 인물은 사진(그림으로 닮게 그리지 않음).
- 동사 → 움직임: 쓰러지다 `act tip`, 넘어지다 `act fall`, 자리를 뜨다 `act rise`, 문을 닫다 `cover`, 걷다 `to walk`, 집다 `pose`, 미끄러지다 `pose`+`fx sweat`, 배우다 `into`, 모양이 매번 다르다 `morph`, 뒤집히다 `seesaw`+`tilt`.
- 답은 은유 장치 하나로 (시소·긴 길과 한 점·렌즈 두 개). 카메라는 고정이 기본.

## 예 (모라벡 편 v4)
`scripts/curiosity_story/v4.py`, `projects/20261113-curiosity-moravec/02_script/intent.md`.
| 대본 | 움직임 | why |
|---|---|---|
| "열아홉 수 만에 자리에서 일어났습니다" | 체스 왕이 쓰러지고(`tip`), 카스파로프 사진이 위로 빠짐(`rise`) | 기권을 말 대신 그림으로 |
| "2019년, 도쿄의 한 회사가 문을 닫습니다" | 회사 건물의 셔터가 내려옴(`cover`) | '문을 닫다'를 동작으로 |
| "볼 때마다 모양이 다른 천 덩어리" | 로봇의 렌즈 안에서 티셔츠 모양이 계속 바뀜(`morph`) | '볼 때마다 다르다'를 글 없이 |
| "이 뒤집힌 이야기를 '모라벡의 역설'" | 시험 쪽이 내려가 있던 시소가 아기 쪽으로 넘어감(`tilt`) | 답을 시소 한 장면으로 |
| "맨 끝의 한 점" | 긴 진화의 선 끝에 아주 작은 체스 왕·계산기 + 점 | 시간 대비를 크기·위치로 |

렌더러: `ytflow/stages/stage.py` (문법은 파일 머리말).
