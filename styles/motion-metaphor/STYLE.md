# 움직이는 비유 애니메이션 (motion-metaphor)

> **위치 (2026-11-12 사용자 판정):** 기존 영상·매뉴얼의 기준이 아니라, **나중에 따로 골라 쓰는 스타일**입니다. `style-pick` 자동 추천에서도 빠져 있습니다(`standalone: true`).
> **품질 (같은 날 판정): "애니메이션 퀄리티가 아직 많이 낮다"** — 시험작(20261112-style-motion)은 도형 사람·탈것 수준. 쓰기 전에 아래 '품질 올리기'부터.

> **레퍼런스 재분석 (같은 날, `docs/22-motion-reference.md`)**: 실제 편집은 썸네일과 다릅니다 — **어두운 스튜디오 + 흰 3D 물체 + 스톡 인물 B-roll + 미니멀 아이콘**, 화면 글자는 거의 없음.
> 아래 v1(밝은 그림책 무대·평면 도형·의태어)은 썸네일만 보고 만든 것이라 다음 판(v2)에서 바꿉니다.

> **v2 (같은 날): `studio3d` 장면** — 어두운 스튜디오 + 반사 바닥 + 한 줄기 빛 + 흰 무광 3D 물체 (three.js, `tools/external.json` 고정).
> preset: `stack`(같은 크기 상자 1개 vs N개 — 'N배') · `swap`(타일 하나는 가라앉고 하나는 떠오르며 빛남 — 'A 대신 B') · `glow`(칩이 돌고 꼬리표가 떠오름 — '값이 오른다').
> `{"type":"studio3d","preset":"stack","left":"공급 가능한 용량","right":"검증된 수요","n":10,"beats":[...]}` — 첫 박자 등장, 둘째 박자 핵심 동작. 시험작 `20261112-style-3d`.

**언제:** 추상적인 흐름(사람·돈·데이터가 어디로 몰리나, 무엇이 남고 무엇이 비나)을 글 대신 **움직임**으로 보여 줄 때. 모든 채널 기본이 아니라 고를 수 있는 스타일입니다 (`styles/recipes/motion-metaphor.yaml`).

## 화면 문법
| 요소 | 규칙 |
|---|---|
| 바탕 | 밝은 하늘 + 회색 땅 (그림책 같은 밝은 일러스트 무대) — 장면 안에서 고정 |
| 갈라진 화면 | 가운데 흰 칸막이: 왼쪽 = 몰려드는 곳(큰 대상), 오른쪽 = 떠나는 곳(작은 대상 0~3개) |
| 무리 | 사람(동그란 머리 + 둥근 몸) 또는 아이콘(돈·데이터 등). 박자에 맞춰 **포물선으로 한 번** 옮겨 감, 시간차(0~1.4초) |
| 대상 반응 | 무리가 도착하면 대상이 살짝 출렁 (눌렸다 펴짐 2번) |
| 의성어·의태어 | 굵은 글씨 + 검은 테두리, 튀어나옴(back.out). 몰린 쪽 노랑, 빈 쪽 민트. 한 장면 2개까지 |
| 곡선 화살표 | 노란 손그림 선 + 작은 고리, 그려지듯 나타남 |
| 제목 | 위쪽 큰 글씨 + 강조 낱말만 노란 상자 (자막은 아래 그대로) |
| pop 모드 | 가운데 물건이 통통 튀어 들어오고, 꼬리표(숫자)가 떨어져 붙음 |

## 대본 (hybrid.json)
```json
{"type":"metaphor","mode":"migrate","title":"수요가 용량의 10배","hl":"10배",
 "target":{"label":"공급 가능한 용량","color":"#D9412B","kind":"bus"},
 "sources":[{"label":"AI 연구소","color":"#2F6FB3"}],
 "crowd":{"icon":"person","n":40,"start":"right","beat":1,"board":0.85},
 "words":[{"text":"바글바글","side":"left","beat":1},{"text":"줄 서는 중","side":"right","beat":1}],
 "arrow":{"beat":0}, "beats":[{"say":"..."},{"say":"..."}]}
```
`kind`: bus · building · box / `crowd.icon`: person 또는 아이콘 이름(banknote·database·cpu…) / `board`: 옮겨 가는 비율.

## 지킬 것
- 비유는 **사실을 단순하게** 보여 줄 뿐 — 숫자·주장은 팩트시트대로, 회사 주장은 label 에 "회사 발표".
- 움직임은 장면마다 한 번 (v12 차분하게). 한 영상에 4번 넘게 쓰지 않기.
- 레퍼런스 채널의 그림·캐릭터·문구·썸네일은 쓰지 않음.

## 품질 올리기 (다음에 이 스타일을 쓸 때 먼저)
| 약점 (시험작) | 올리는 방법 후보 |
|---|---|
| 사람·탈것이 평면 도형이라 단조로움 | 무료 라이선스 일러스트·로티(Lottie) 애니메이션 묶음 검토(라이선스 확인 후 `tools/external.json` 고정) 또는 장면당 AI 일러스트 1장 + 움직임은 코드로 |
| 움직임이 '이동' 한 가지 | 걷는 흔들림·그림자·앞뒤 깊이(크기·흐림)·카메라 따라가기·도착 반응(튀어 오름) 추가 |
| 무대가 고정된 하늘·땅 한 장 | 장면 주제별 무대(도시·사무실·서버실·항구) 몇 가지, 앞·뒤 겹(패럴랙스) |
| 템포 | 레퍼런스 실제 컷 길이 측정 필요 (아래) |
