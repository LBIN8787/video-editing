# 미주일기 스타일 대본 추가 규칙

- **장면 길이:** 한 장면은 내레이션 1~2문장(약 2~5초)입니다. 화면이 2초마다 변해야 하므로 문장을 짧게 끊습니다.
- **화면 비율:** card 60~70%(도식·숫자·문서), screenshot 15~20%(논문·기사 원문), source_video 10~20%(사진·실사 B-roll) 정도입니다.
- **카드 이어 쓰기:** 같은 도식을 여러 장면에 걸쳐 키웁니다. 이어지는 장면의 card 는 같은 title 을 쓰고 items 를 하나씩 늘립니다.
- **원문 강조:** 숫자나 원문 문장은 '문서 + 형광펜' 장면(headline 카드나 screenshot)으로 보여 줍니다. 강조할 단어는 emphasis 에 넣습니다.
- **장 전환:** 장이 바뀌는 첫 장면은 짧은 질문 한 문장의 text 카드로 엽니다.
- **고정 장면:** 1분 20초 무렵에 구독·좋아요 장면(text 카드 "구독과 좋아요")을 하나 넣습니다. 마지막 장면은 영상 제목 text 카드입니다.
