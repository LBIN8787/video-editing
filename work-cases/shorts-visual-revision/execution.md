# 적용 기록

1. 1.0.0 소스와 기존 MP4를 보존하고 ShortsGuideV2 / 스타일 1.1.0을 작성했다.
2. 일반 글 목록 패널을 휴대폰 비교, 프로젝트 파일 준비, AI 요청문, 출력 미리보기, 실제 결과 비교, 음성 파형, 인식 설정, SRT 타임라인으로 교체했다.
3. 기존 실제 내레이션 파일에서 파형 이미지를 만들고, 기존 실제 자막에서 문장과 발화 시간을 가져왔다. 서비스 UI를 실제 조작한 영상이라고 꾸미지 않고 재구성 화면은 표시했다.
4. 새 템플릿의 첫 장면을 실제 렌더한 포스터를 출력 미리보기와 두 편 비교 장면에 넣었다.
5. 헤더에 브랜드만 남겼다. 날짜와 회차는 영상에 표시하지 않고 조사 메타데이터에만 보관한다.
6. 각 장면에 당장 할 행동을 한 줄로 표시했다. 고정 음성은 기존 파일을 재사용했고 신규 TTS 생성·과금은 없다.
7. 버전별 렌더 선택과 새 편 생성기 참조를 갱신했다. 기존 스타일 4개 검사, 새 편 생성기 4개 검사 및 TypeScript 검사를 통과했다.

최종 MP4 검수·보관 증거는 evidence.json, archive.json에 기록한다. 직접 청취 검수·사용자 피드백·YouTube 업로드·정기 실행은 이번 화면 수정 완료와 구분한다.
