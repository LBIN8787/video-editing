# 적용 기록

1. 고정 스타일과 channel.json을 확인했다. 004 초안은 보존하고 005/006을 새로 만들었다.
2. 공식 문서의 기능·사용 조건을 읽고 짧은 안내 대본을 작성했다. 최신 출시나 인기 순위로 포장하지 않았다.
3. ElevenLabs Han Aim / eleven_v4를 각 1회 생성했다. 생성 크레딧은 각각 322와 350이었다. 무료 요금제를 새로 연결하거나 결제 설정을 바꾸지 않았다.
4. faster-whisper small 모델을 CPU int8로 로컬 실행했다. 실제 한국어 인식 결과와 단어별 시간을 JSON으로 기록했다.
5. 인식 문장을 대본과 비교했다. 엠피포로를 표시 자막 MP4로로 정리하고, 짧은 자막 묶음과 SRT를 만들었다.
6. 같은 ShortsGuideV1에 새 props를 입력했다. 실제 입력과 인식 결과 일부는 PNG로 가독성 있게 재구성했다. 서비스 UI 녹화가 아니다.
7. 고정 폰트 해시, 입력 검증과 TypeScript 검사를 통과했다. 요청문 장면과 증거 장면 스틸을 직접 확인했다.

## 효과의 범위

음성 인식 소요 시간은 해당 호스트에서의 관측값일 뿐 수작업 대비 절감률이 아니다. 조회수나 시청 지속률은 아직 측정하지 않았다. YouTube 업로드와 주기 실행은 이 제작과 구분한다. 최종 파일 QA와 보관 위치는 evidence/final-qa.json 및 archive.json에 기록한다.
