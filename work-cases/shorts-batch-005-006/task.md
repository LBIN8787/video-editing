# 실제 작업

사용자의 AI 실전노트 추가 쇼츠 2편 제작 요청을 수행한다. 고정 스타일과 보이스를 유지하며 사용자가 자신의 영상 작업에 적용할 수 있는 방법을 보여 준다.

## 완료 기준

서로 다른 활용 주제 2개, 동일 템플릿, 고정 ElevenLabs 음성, 자막, 효과음 없음, 검수한 MP4 2개를 제공한다. 조사·대본·입력·검수·재현 자료를 기존 GitHub/Drive 체계에 보관한다. 실제 YouTube 게시와 정기 실행을 이번 제작 성공으로 간주하지 않는다.

## 입력

자체 공개용 대본, 기존 ShortsGuideV1 1.0.0, 공식 Remotion/Whisper 문서. 사용자 계정 인증정보는 영상 제작에 사용하지 않는다.
