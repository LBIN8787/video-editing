# AI로 내 채널 운영 도구를 만들며 확인한 것

내가 해결하려던 일은 AI 채널의 반복 제작과 업로드 준비였다. AI에게 코드를 쓰게 하는 것에서 멈추지 않고, 다음 작업에서도 쓸 채널 설정과 검사를 만들었다.

Codex로 작업을 쪼개고 소스를 작성했다. 그중 업로드할 채널을 고정하는 기능, 같은 파일을 다시 올리지 않게 하는 원장, 로그인 권한을 연결하는 도구를 사례로 설명할 수 있다.

현재 확인한 결과는 코드와 로컬 검사다. 모의 API를 포함한 24개 검사가 통과했다. 실제 YouTube 업로드나 Windows에서의 성공을 입증한 결과는 아직 없다. 절감 시간도 측정하지 않았다.

다른 사람이 따라 한다면 자신의 실제 작업 하나와 완료 기준부터 적고, AI가 만든 결과물을 검사해야 한다. 다음 단계는 사용자 PC에서 Google 권한을 연결해 실제 한 편을 올리고 결과를 확인하는 것이다.
