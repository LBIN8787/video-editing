# 적용과 확인 기록

1. 사용자 요청을 채널 설정, 조사 글, 쇼츠/롱폼, 고정 음성, 미디어 QA, 업로드 작업으로 나눴다.
2. Codex로 실제 소스 파일과 재사용 명령을 작성했다. 사용자가 제공한 채널 ID를 대상 설정에 반영했다.
3. Google OAuth를 통한 채널 일치 확인과 승인 파일 업로드 코드를 만들었다.
4. 중복 원장과 불확실한 전송 상태를 두어 자동 재전송을 막았다.
5. Windows에서 JSON을 선택해 로그인하는 연결 파일을 작성했다.
6. 로컬 검사 출력은 evidence/checks.txt에 저장했다. 실제 Google 요청 대신 모의 API로 업로드 논리를 검사했다.

산출물은 저장소 코드와 Windows 전달 패키지다. 사용자 PC에서 연결된 상태나 게시 결과를 얻은 것은 아니다. 기능별 코드를 검사한 것과 업무 운영이 완성된 것을 구분한다.

다음 실제 적용: Windows에서 OAuth 연결 → 첫 업로드의 실제 ID 확인 → 같은 호스트에서 새 MP4 전체 제작 → 정기 실행 시험.

## 후속 실제 적용 확인

Windows PC에서 저장소·전용 Python·Google 업로드 라이브러리 설치를 마쳤다. 한글 설정 파일 인코딩을 UTF-8로 수정하고, 다운로드된 Desktop OAuth JSON으로 Google 동의를 완료했다. 별도 API 조회에서도 ai실전노트 채널 ID 일치와 유효한 인증을 확인했다. 토큰은 PC 로컬에만 저장했다. 실제 영상 전송·예약 공개는 아직 하지 않았다.
