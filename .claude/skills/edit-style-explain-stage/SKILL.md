# 설명 무대로 상황 설명하기

> 2026-11-20 사용자: "쉽게 설명해야 하는 부분이다 상황설명이 필요하다 = 모션그래픽 을 주로 사용합니다."

1. `styles/explain-stage/STYLE.md` 를 읽는다 (필드·예시·되는 것/안 되는 것).
2. 대본에서 **자료로 질문을 여는 박자 → 원리를 푸는 박자 → 자료로 확인하는 박자**를 표시한다. 원리를 푸는 박자가 설명 무대 자리다 (docs/31).
3. 틀 고르기: 사건 뒤에도 늘었다 → `afterline` · 두 값의 차이 → `spread` · 전체 중 몫 → `share` · 그 밖(인물·물체·누가 누구에게) → `motionboard`.
4. `hybrid.json` 에 장면을 쓴다. 박자마다 `show`(또는 motionboard 는 `do`)와 `at`(대사 속 동사·명사)을 적어 **말하는 순간** 바뀌게 한다. 앞에 나온 요소는 남긴다.
5. 바탕 `theme`: paper(기본) · dark(긴장·위기) · light(영상 스킨 그대로). 실제 인물은 권리가 확인된 사진(`photo`, `python -m ytflow archive commons "이름"`)만, 없으면 실루엣 + 이름표. 보고서 주장이면 title 에 출처.
6. `python -m ytflow hybrid <프로젝트>` → 프레임을 뽑아 겹침·잘림·색을 직접 본다(장면 끝 0.3초는 페이드아웃이라 피해서).
