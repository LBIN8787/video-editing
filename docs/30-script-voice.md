# 30. 대본의 형식·진행·말투 — 미주일기 문법 (2026-11-14)

> 사용자: "모든 채널 인트로는 일단 빼 주세요. 말투와 대본 작성에 먼저 귀 기울여 주세요. 대본들이 자연스럽기보다 억지스럽고, 억텐 같고, 어색한 말투가 보입니다.
> 차라리 미주일기와 같은 형식의 대본이 더 자연스럽고 좋습니다." · "사소한 문장보다 형식 자체와 진행 방식, 말투에 집중해 주세요."

## 0. 조사한 것
미주일기 4편의 자동 자막(받아쓰기, `.cache/mijudiary/`, 커밋 안 함 — 타 채널 자막): 트랜스포머의 탄생 · 앤스로픽의 2030 예측 · AGI 기준 · 준리만 가설.
대사는 가져오지 않고 **형식·진행·말투의 규칙**만 뽑았다 (AGENTS.md 스타일 규칙).

## 1. 형식 — 한 편의 뼈대
| 순서 | 하는 일 | 트랜스포머 편에서 |
|---|---|---|
| ① 여는 장면 | **날짜·사람·작은 일화**가 있는 한 순간. 거창하지 않은 시작 | 2017년 6월, 구글 연구자 여덟 명이 논문을 올림 · 제목은 마감 직전에 5초 만에 지음 · 학회에서는 저녁 포스터 자리에 배정 |
| ② 그 일의 크기 | 소박한 시작 → 지금의 결과로 한 번에 점프 | 29만 번 넘게 인용 · 챗GPT의 'T' |
| ③ 질문 하나 | 영상 전체의 질문. 이후 질문은 전환점에서 2~3번만 | "어떻게 탄생해 세상을 바꿔 놓았을까요?" |
| ④ 그 전의 문제 | 사람들이 무엇에 막혀 있었나 (당사자의 회고로) | 순서대로 처리하던 방식의 한계 |
| ⑤ 전환점 | "그렇다면 ~할 수는 없을까요?" → 누가 어떤 발상을 했나 | 순환 신경망을 빼고 어텐션만 남기자 |
| ⑥ 원리 | **생활 속 예 하나**로 (한 문단) | 'bank' 가 은행인지 강둑인지, '그것'이 동물인지 길인지 |
| ⑦ 결과 | 숫자는 비교와 함께 | 10배 빨라짐, 이전 모든 모델을 앞섬 |
| ⑧ 퍼져 나감 | 시간 순서로, 장면 하나씩 (학회장·회고·발표) | 학회장에 사람이 몰려 보안 요원이 나섬 → 오픈AI 가 받아들임 → GPT → 챗GPT |
| ⑨ 지금과 한계 | 한계·반론도 담담하게 | 길이가 두 배면 계산은 네 배 |
| ⑩ 닫는 장면 | **처음의 사람들이 다시 등장하는 장면** (수미상관) + 비유 한 마디 | 2024년 같은 저자들이 한 무대에 다시 앉음, '증기 기관과 내연 기관' |
| ⑪ 마지막 문장 | 제목·이름의 뜻으로 의미를 맺음 | "그 이름처럼 세상 자체를 바꿔 놓았습니다" |

토론형(AGI 편·2030 편)은 ①을 **엇갈리는 두 시각**("한쪽에서는… 반면 다른 한쪽에서는…")으로 열고, ⑩–⑪을 **태도에 대한 제안 + 조용한 질문**("~할 때가 아닐까요?")으로 닫는다. 뼈대는 같다.

## 2. 진행 방식
- **한 줄기 이야기:** 사례를 늘어놓지 않고, 하나의 사건·발상이 시간 순서로 퍼져 나가는 것을 따라간다. 장이 바뀌어도 같은 줄기 위에 있다.
- **사람이 이야기를 나른다:** 모든 사실이 "누가, 언제, 무엇을 했고, 무엇을 말했다"의 형태. 인물의 말은 직접 인용보다 "~라고 회고했습니다 / ~라고 말했습니다"로 전한다.
- **주장 → 근거 → 의미:** 한 문단은 주장(무엇이 일어났나) → 근거(숫자·장면·발언) → 의미(그래서 무엇이 바뀌었나)의 세 걸음.
- **질문은 문(門):** 질문은 다음 장으로 넘어가는 문으로만 쓴다 (한 편에 2~5번). 시청자에게 대답을 요구하지 않는다.
- **설명은 예 하나로:** 원리 설명은 한 문단, 생활 속 예 하나. 용어는 처음 나올 때 한 번 풀어 쓰고("즉 ~") 넘어간다.
- **수미상관:** 처음 장면의 사람·물건이 마지막에 다시 나온다.

## 3. 말투
| | 미주일기 | 우리 v4·v5 |
|---|---|---|
| 끝맺음 | '~습니다/~니다' 96~100% | ~습니다 47~58%, ~요·~죠가 많음 |
| 문장 길이 | 평균 62~71자, 연결어로 이어 붙인 긴 문장 | 평균 25~33자, 조각 문장("다시.", "같은 1초.") |
| 시점 | 3인칭 다큐 내레이터, 시청자에게 말 걸지 않음 | "계시죠?", "손을 펴 보세요", "부를게요" |
| 재미의 출처 | **구체적 디테일**(5초 만에 지은 제목, 보안 요원) | 말투로 만든 흥분 → 억텐 |
| 연결어 | 그리고 · 몇 년 뒤인 · 세월이 흘러 · 마찬가지였습니다 · 더 나아가 · 반면 · 바로 이 ~ | "그런데 말이죠", "여기서 이상한 점이 하나" |

## 4. 이전 기준과의 관계
- docs/29(시청자 조사)의 결론 — 시청자는 즐기러 온다, 사람·디테일·결론 한 줄에 반응한다 — 은 그대로다. 미주일기 문법은 그 재미를 **말투가 아니라 이야기의 디테일과 흐름**으로 만든다.
- manual/04 §0-6 의 '지식 문장 ≤30%' 는 사실을 빼라는 뜻이 아니라, **사실이 사람·사건 속에 있어야 한다**는 뜻으로 읽는다 (미주일기도 사실이 많지만 모두 누군가의 행동·발언으로 나온다).
- §0-6 의 '시청자의 하루에서 시작·말 걸기'는 폐지 → 여는 장면은 **때·곳·사람이 있는 한 순간** (README §2-3).
