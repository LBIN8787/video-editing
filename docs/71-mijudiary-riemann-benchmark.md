## 4. 다음 편에 적용하는 순서 (제안 — 사용자 확인 전)
1. **소재**: 미주일기가 이미 한 소재(리만·AI 치팅)는 각도를 바꾸거나 피한다. 같은 '큰 사건 + 큰 의미' 기준으로, 그 채널이 아직 안 한 사건을 하루 안에.
2. **대본 뼈대**: 이름 있는 사람의 말로 열기 → 사건 → 질문과 '볼 것 세 가지'(구독 부탁 없이) → 원리(비유 사물) → **경이의 장(이야기)** → 복선 회수 → 반전(전문가 예측 vs 현실) → 통찰 하나.
3. **자산 먼저**: 대본 다음에 장면마다 이미지 목록(실제 사진·문서·화면 캡처·그림 사물)을 먼저 모으고, 그림 사물은 생성. 이미지가 없는 장면은 다시 쓴다.
4. **움직임 표**: 등장·강조·과정·카메라의 속도를 나눠 쓰고, 같은 움직임이 세 번 연달아 나오지 않게.
