# 크몽·숨고 판매글 초안 — 설명 영상 제작 (docs/80 A)

> 올리기 전에 사용자가 확인할 것: 가격, 작업 기간, 샘플 링크(공개 영상만), ElevenLabs 요금제의 상업 이용 범위, 본인 정보.

## 제목 (30자 안팎, 하나 고르기)
1. 자료만 주시면 3분 설명 영상으로 만들어 드립니다
2. 보고서·글을 모션그래픽 설명 영상으로
3. 유튜브·교육용 해설 영상, 대본부터 자막까지

## 한 줄 소개
문서·보고서·블로그 글을 받아 **대본 → 내레이션 → 모션그래픽 → 자막 → 썸네일 3안**까지 한 번에 만듭니다. 숫자는 출처로 확인한 것만 씁니다.

## 이런 분께
- 회사 소개·제품 설명을 짧은 영상으로 바꾸고 싶은 분
- 강의·교육 자료를 유튜브용 해설 영상으로 만들고 싶은 분
- 블로그·뉴스레터 글을 영상으로 한 번 더 쓰고 싶은 분

## 무엇을 받나요
| | 기본 | 표준 | 프리미엄 |
|---|---|---|---|
| 길이 | 1분 내외 (쇼츠 9:16 또는 16:9) | 3분 내외 | 5~8분 |
| 대본 | 작성 1안 + 수정 1회 | 작성 + 수정 2회 | 작성 + 수정 2회 + 자료조사 |
| 내레이션 | AI 목소리 (한국어) | AI 목소리 | AI 목소리 · 목소리 후보 3개 중 선택 |
| 화면 | 큰 자막 + 카드 | 모션그래픽(차트·도식) + 자막 | 모션그래픽 + 자료 화면 + 장 표지 |
| 썸네일 | 1장 | 3안 | 3안 + 제목 후보 3개 |
| 기간 | 3일 | 5일 | 7일 |
| 가격(예시) | 5만 원 | 15만 원 | 35만 원 |

## 작업 순서
1. 자료와 목적(누가 보나, 보고 나서 무엇을 하길 바라나)을 받습니다.
2. **대본을 먼저 보여 드립니다** — 대본이 확정된 뒤에 화면을 만듭니다(수정이 적어지는 이유).
3. 가편집본 → 수정 → 완성본(mp4, 자막 파일 포함).

## 샘플
- (시장 채널 공개 영상 링크 1~2개 — 드러켄밀러 편 등)

## 안내
- 주신 자료의 저작권·사용 권리는 의뢰자께서 가진 것으로 봅니다.
- 다른 채널의 대사·캐릭터·로고를 그대로 따라 만들지 않습니다.
- 투자 권유·의료 효능처럼 단정할 수 없는 내용은 표현을 조정해 드립니다.
