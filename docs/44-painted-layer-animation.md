## 무엇을 바꿨나
| 전 | 지금 |
|---|---|
| 코드가 그린 도형·도표(원그래프·막대·흐름도), 멈춘 그림 한 장 위 이름표 | **화면의 모든 그림은 원화**(합격한 화풍). 코드는 움직임만 맡음 |
| 그림 한 장에 인물까지 그려 넣어 움직일 수 없음 | **배경 판(사람 없음) + 인물 자세 시트 + 소품 시트**를 따로 그려 층으로 겹침 |
| 숫자·비교는 크림색 바탕의 도형 | 숫자도 **그 세계 안의 물건**에: 발표장 화면, 환전 창구 시세판, 벽 달력, 하늘의 연 |

## 화풍 — 편마다 하나, 같은 편 안에서는 같은 인물·색
| 편 | 합격한 화풍 (참조 그림) | 왜 이 편에 |
|---|---|---|
| 호기심 | 캐주얼 셀 애니메이션 (`cel-ordinary.png`, `stop.png`) | 한 사람의 이야기를 따라가며 표정·몸짓으로 마음을 보여 줌 |
| AI | 민트색 플랫 제품 일러스트 (`product.png`) | 권한·결제처럼 눈에 안 보이는 흐름을 작은 주인공(에이전트 로봇)이 직접 겪게 함 |
| 시사 | 시사 지면 삽화 (`industry.png`) | 기관 발표·도시·산업처럼 실제 장소의 무게가 필요한 이야기 |

## 만드는 순서 (어느 에이전트든 같은 결과가 나오게)
1. **주문서** `scripts/anim/orders.json` — 화풍 문장 + 참조 그림 + 판/시트별 그림 설명. 배경 판은 사람 없이, 시트는 흰 배경에 조각을 한 줄로.
2. **그리기** `python scripts/anim/gen_art.py <폴더> [--video ..]` — Codex 구독의 이미지 생성(추가 요금 없음), 참조 그림을 붙여 화풍 고정. 시트는 `scripts/anim/cutout.py` 로 투명 조각.
3. **연출** `scripts/anim/ep_<편>.py` — 대사 낱말(받아쓰기 시각)마다: 장면 전환(밀기·원·지우기·나란히 나누기), 카메라(시점이 옮겨 갈 때만, 흔들지 않음), 인물 걷기·뛰기·자세 바꾸기(예비 동작 → 동작 → 자리 잡기), 소품 등장·날아감, 손글씨·명조·고딕 글자(편 화풍에 맞춰), 숫자 올라가기. 엔진은 `scripts/anim/anim.py`.
4. **렌더** `node scripts/anim/render.js scene.html video.mp4` → `python scripts/anim/finish.py` (승인된 목소리 + 효과음 + 자막).
5. **확인** `node scripts/anim/shots.js` + `python scripts/anim/sheet.py` — 정지 화면 묶음으로 가림·잘림·글자 겹침을 보고 고친 뒤 렌더.
