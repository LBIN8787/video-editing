# 78. 구독자 대비 조회수가 압도적인 역사 영상 10편의 템플릿 ↔ 소현세자 v1·v2 (2026-11-27)

> 사용자: "이 영상만이 아니라 구독자수 대비 조회수가 압도적으로 많은 영상들의 템플릿과 대조해주세요 기본 수십만으로요"
> 고른 방법: docs/73 의 터진 영상 420편(59채널) 가운데 **조회 30만 이상**, 구독 대비 조회 배수가 높은 순, 채널당 1편. 몰아보기·잠자리 영상(목적이 다름)은 뺐다. 캐볼역사(docs/77)를 더해 11편, 그중 '역사를 보다'는 출연자 대담(토크쇼)이라 템플릿 비교에서 뺐다.
> 잰 방법: docs/76·77 과 같음 — 사용자 Chrome 에서 2배속 재생, 0.25초마다 화면 차이와 소리 크기. **처음 약 90초**와 **영상 45% 지점 60초**. 우리 영상은 같은 잣대를 ffmpeg 로.
> 주의: 브라우저 측정은 일부 프레임을 건너뛰어(실제 잰 길이 50~60초) 컷 수가 조금 크게 나올 수 있다. 딥 호라이즌은 AI 영상의 빠른 카메라 이동도 '큰 변화'로 잡혀 컷 수가 부풀었다. 순위가 아니라 **크기의 차이**를 보는 표다.

## 2. 공통 템플릿 (10편 중 몇 편이 그렇게 하나)
1. **첫 1분은 아주 빠르다 — 10편 중 8편이 분당 36~100번 바뀐다.** 1~2초마다 새 화면. 우리는 v1·v2 모두 분당 11번(5~6초에 한 번). **가장 큰 차이.**
2. **재료가 '움직이는 영상'이다 — 7편.** 기록 영상(Penguin), 현장·드론 영상(김반월·Uncharted), 스톡 영상(Lost American), AI 영상(딥 호라이즌·기록 보관소 X). 정지 자료만 쓰는 채널(Epicano·캐볼·Barely)은 **그만큼 컷을 빠르게** 하거나(Epicano 분당 100번) 자료 자체를 읽게 한다(Barely, 문서).
3. **실제 자료가 주인공 — 8편.** AI 는 영상으로 쓰거나 '재현' 표시. 우리 v2 는 사진을 넣었지만 **한 장을 문장 하나 동안(5초 이상) 그대로** 둬서 v1 보다 오히려 정지 순간이 늘었다(첫 90초에 1.5초 넘는 정지 10회).
4. **소리: 말 아래 낮은 배경이 깔린다 — 7편**(가장 조용한 순간 −34 ~ −48 dB, 목소리보다 15~20 dB 아래). 완전 무음은 3편(Lost American·청화수·quack doc). **효과음이 들리게 쓰는 영상은 없다.** 우리 v1 은 저음이 너무 크고(−37 dB) 효과음이 많았고, v2 는 완전 무음(−100 dB)이라 오히려 비어 들린다.
5. **글자는 적다.** 아래 자막 한 줄 + 장소·이름 표시 정도. 강조는 자막 속 한 낱말 색(김반월·기록 보관소 X). 큰 글씨 카드는 드물다.
6. 예외: 청화수처럼 화면이 거의 정지해도 터지는 채널이 있다 — 강한 해석·이야기가 있을 때. 화면 템플릿만으로 결정되지 않는다는 뜻(대본은 D2 통과).

## 3. 소현세자 편 다음 판(v3)에 필요한 것
1. **컷을 3~5배로:** 문장 하나에 화면 2~3개(같은 사진의 다른 부분·다른 사진·자료 확대), 첫 90초는 1~2초마다.
2. **움직이는 영상 재료 확보:** 17세기 조선은 기록 영상이 없으므로 —
   - (가) **오늘의 장소 영상**(창경궁·남한산성·선양 고궁·베이징 고관상대·제주) — 무료 스톡(Pexels·Pixabay 동영상, Wikimedia Commons 동영상). 라이선스 확인 후 출처 표시.
   - (나) **AI 영상**: 승인된 A안 그림을 첫 장면으로 4~8초 영상 (딥 호라이즌·기록 보관소 X 방식) — 비용·도구 사용자 결정(앞서 '무료 엔진만' 선택).
   - (다) 정지 사진은 **빠른 밀기·확대**(지금보다 2~3배 빠른 카메라)와 잦은 교체로.
3. **소리:** 목소리보다 15~20 dB 낮은 배경음악(또는 공간 소리)을 깔고, 효과음은 넣지 않음. v2 의 완전 무음은 7/10 영상과 다름.
4. 글자는 지금 수준(자막 + 장소·이름 + 숫자 몇 개) 유지, 자막 속 핵심 낱말 한 색 강조 추가.
