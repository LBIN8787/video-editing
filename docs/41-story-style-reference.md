# 화풍 레퍼런스와 장면별 사용 기준

## 화풍은 편 단위로, 자료는 장면의 역할에 따라

영상별로 먼저 정할 것은 시청자가 따라갈 경험입니다. 인물의 반응을 따라가는 편, 공간을 발견하는 편, 작동 원리를 이해하는 편은 서로 다른 화풍을 기본으로 삼을 수 있습니다. 한 편 안에서는 인물 비례, 선의 굵기, 색 범위, 그림자 방향을 유지하고, 필요한 만큼 샷의 거리와 구도, 동작을 바꿉니다. 사진이나 문서가 증거인 순간에는 그 자료를 읽을 수 있게 보여 주고 같은 이야기의 화면으로 돌아옵니다.

## 세 편 적용

- 호기심 · 나이와 시간은 같은 2D 셀 계열의 선화와 색면을 사용합니다. 서재에서는 책장을 드는 손과 눈을 움직입니다. 기억과 현재를 바꿀 때는 고정 샷끼리 컷을 이으며, 설문과 케이크는 비유·사례를 실제 이미지로 보여줍니다. 전체 편집에서 카메라는 고정했습니다.
- AI · 에이전트 결제는 구매자 화면과 공식 발표를 중심으로 편집했습니다. 제품이 어떻게 작동하는지를 보여 주는 곳에는 작동 예시, 어떤 회사가 발표했는지를 확인하는 곳에는 공식 발표 화면을 배치했습니다.
- 시사 · 대만은 현장 사진, 한국·대만을 함께 보이는 지도, 발표 자료의 요지, 필요한 수치 비교를 섞었습니다. HBM 적층에만 공간 구조를 보여주는 모션을 사용했습니다.
- 공개 원본 영상인 타이베이와 유나이티드의 라이선스·저자 정보는 확인했습니다. 원본 파일 서버가 요청을 제한해 이번 조립에는 출처가 확인된 현장 사진을 사용했습니다. ## 이전 편집의 문제

- 호기심 매뉴얼 §0-5의 카메라 고정 원칙에 어긋나게 원화에 프레임마다 잘라 내는 위치가 달라지는 `zoompan`을 넣었습니다. 오프닝에는 수평 이동과 레이어 이동이 있는 패럴랙스 버전을 넣었습니다. 수정본은 고정 배경에 인물 자세만 바꾸는 방식과 대본에 맞춘 고정 컷을 사용합니다.
- AI와 시사에 기존 `hybrid`의 뉴스 카드, 체크리스트, 인과 보드를 반복해서 적용한 것은 제작 판단이었습니다. 실제 발표·제품 동작, 장소와 근거라는 각 대본의 화면 목적을 먼저 정해야 했습니다.
