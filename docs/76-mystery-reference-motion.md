# 76. 미스터리 역사 레퍼런스 — 실제 편집 측정 (2026-11-26)

> 계기: 소현세자 샘플(정지 그림 + 느린 확대 + 정지 카드) 사용자 기각 — "아무런 편집효과 모션그래픽도 없고 템플릿이 정말로 조회수가 높은 영상들의 템플릿이라구요? 0점입니다".
> 반성: docs/73 §4 의 '편집점'은 5~10초 간격 미리보기 이미지만 보고 쓴 것이라 **움직임·컷 길이를 재지 않았다.** 이 문서가 처음으로 실제 재생 화면을 잰 기록이다.

## 방법
사용자 Chrome(유튜브 프리미엄 로그인)에서 영상을 소리 끄고 2배속 재생, **영상 시간 0.25초마다** 64×36 흑백으로 줄인 화면의 평균 밝기 차이(0~255)를 재고, 1초마다 작은 화면을 한 장에 모음. 내려받지 않음.
- `움직이는 비율` = 0.25초 사이 차이 0.6 이상인 순간의 비율 (정지 화면이면 0에 가까움)
- `차이 중앙값` = 화면이 얼마나 크게 계속 변하나
- `큰 변화` = 차이 12 이상(컷·번쩍임·빠른 카메라)

## 결론 — 세 채널의 공통 템플릿
1. **화면이 멈추는 순간이 없다**(1.5초 넘는 정지 0회). 화면 재료가 처음부터 **움직이는 영상**이다 — AI 영상 클립(딥 호라이즌·기록 보관소 X) 또는 실제 기록 영상(기묘한 밤).
2. **한 장면 2~12초, 문장이 바뀌면 그림도 바뀐다.** 같은 그림에 여러 문장을 얹지 않는다.
3. **분위기 층을 늘 깐다**: 필름 입자·흔들림·비네트·빛 번쩍임·붉은 잉크 번짐(움직임).
4. **글자는 결정적 순간에만 크게**(숫자·이름·핵심 한 줄), 나머지는 아래 자막.
5. **지도로 위치를 잡고 시작**(기록 보관소 X 위성 지도 → 마을, 딥 호라이즌 지구 → 대륙).

## 우리 제작에 주는 뜻
- 정지 삽화 + 켄 번스로는 이 템플릿을 만들 수 없다. **재료를 움직이는 영상으로** 바꿔야 한다:
  - (가) AI 이미지 → 영상 변환(승인된 A안 그림을 첫 프레임으로 4~8초 클립) — 비용·도구는 사용자 결정
  - (나) 실제 기록 영상·사진(퍼블릭 도메인) — 17세기 조선은 기록 영상이 없어 일부(유물·장소·문서)만
  - (다) 정지 그림이라도 **층을 나눠 움직이기**(2.5D 시차, 촛불 깜빡임, 연기·먼지, 인물 누끼의 작은 움직임) + 문장마다 장면 교체 + 붉은 잉크·필름 층 + 지도·숫자 모션 — 저장소 엔진(`ytflow/stages/hybrid.py`·HyperFrames)으로
- (다)만으로는 딥 호라이즌 수준의 '살아 움직이는 화면'에 못 미칠 가능성이 크다. (가)+(다)가 레퍼런스에 가장 가깝다.
