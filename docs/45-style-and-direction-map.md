# 45. 화풍·연출을 상황에 맞춰 고르는 기준 (2026-11-18)

> 사용자: "화풍만 사용하지 말고 화풍을 적절히 알맞는 상황에 맞추어서 사용해주세요. 모션그래픽이나 다른 편집 연출 등을 언제 사용해야 하는지 분석 정리하고 상황에 맞추어서 사용해주세요 … 쿠르츠게작트 같은 화풍이나 gpt가 제작한 이런 2.5d같은 화풍 등도 … 어느 화풍이 언제 어울릴지도 분석 정의하시고 단순 삽화만이 아니라 애니메이션과 같은 연속적인 장면도 적절하게 사용해주세요." · "캐주얼한 화풍을 추가하고싶거든요" · "약간 귀엽고 캐주얼한 그런 화풍이요"

docs/44 의 세 편은 **한 편 = 한 화풍 + 한 가지 연출(원화를 층으로 움직이기)** 이었다. 이 문서는 그것을 **장면마다 '무엇을 보여 줘야 하나'에 따라 화풍과 연출을 고르는 기준**으로 바꾼다. 숫자 규칙이 아니라 목적·단서·넘치면/모자라면으로 적는다(manual 원칙).

## 1. 연출 도구 — 언제 쓰나
| 연출 | 시청자에게 주는 것 | 이럴 때 (대본의 단서) | 넘치면 | 모자라면 |
|---|---|---|---|---|
| **인물 연기 장면** (캐릭터가 걷고·멈추고·표정이 바뀜) | 감정·공감, "나 같은 사람" | 누가 무엇을 느끼거나 겪는다, 일상의 한 순간 | 정보가 묻히고 느려짐 | 숫자만 남아 차갑게 들림 |
| **연속 애니메이션** (프레임으로 이어지는 동작: 걷기 주기, 손이 책장을 넘김, 문이 열림) | 실제로 '움직이는' 세계 | 동작 자체가 이야기일 때(넘기다 멈춤, 달려감, 쌓여 무너짐) | 제작비·일관성 부담, 산만 | 그림이 '슬라이드'처럼 보임 (사용자 지적) |
| **모션그래픽** (도형·아이콘·화살표·흐름이 움직임) | 보이지 않는 구조를 한눈에 | 권한·돈·정보가 어디서 어디로, 비율·비교, 원리 | 'PPT 도형' 느낌 (사용자 지적) | 개념이 말로만 흘러감 |
| **데이터 그래픽** (막대·선·카운트) | 크기·변화의 정확한 비교 | 두 숫자 비교, 시간에 따른 변화, 출처 있는 통계 | 숫자 피로 | 숫자를 귀로만 들어 기억 못 함 |
| **키네틱 타이포** (말한 낱말이 튀어나옴) | 핵심 한 문장 각인 | 훅, 장 전환, 결론, 인용 | 화면이 자막 덩어리 | 핵심 문장이 지나감 |
| **지도·장소** | 어디서·어디로 | 나라·도시·이동·공급망 | — | 장소가 막연함 |
| **실제 자료** (발표 원문·사진·화면 녹화) | 신뢰·증거 | 누가 언제 무엇을 발표/말했나, 제품 사용법 | 지루함 | "지어낸 그림"처럼 보임 |
| **나누기·대비** (화면 둘로, 같은 틀 비교) | 차이를 동시에 | A와 B, 전과 후, 말과 행동 | 반복되면 공식처럼 보임 | 대비가 약함 |
| **매치 컷·변형 전환** (모양이 이어지며 장면 전환) | 생각의 연결 | 비유로 넘어갈 때(시계 → 케이크) | 기교 과시 | 장면이 뚝뚝 끊김 |

**원칙:** 한 박자에 '보여 줘야 할 것'이 *감정*이면 인물 연기, *동작*이면 연속 애니메이션, *구조*면 모션그래픽, *크기*면 데이터 그래픽, *증거*면 실제 자료. 같은 편 안에서 섞되, 바꿀 때는 **이유가 화면에 보이게**(같은 색·같은 소품으로 이어서) 바꾼다.

## 2. 화풍 — 어떤 화풍이 언제 어울리나
| 화풍 | 특징 | 잘 맞는 상황 | 안 맞는 상황 | 레퍼런스(구조·기법만) |
|---|---|---|---|---|
| **캐주얼 셀 애니메이션** (합격) | 손으로 칠한 배경, 가는 선의 인물, 따뜻한 빛 | 일상·기억·회상, 인물의 감정 | 정밀한 수치·기계 구조 | Hilda·지브리 계열의 배경과 연기 |
| **귀엽고 캐주얼한 그림** (신규 요청) | 큰 머리 3등신, 점 눈·볼터치, 굵고 부드러운 선, 파스텔 | 가벼운 호기심·생활 정보·쇼츠, 실수·코미디, 어려운 말을 부드럽게 | 무거운 사건·피해자가 있는 시사 | 그림책 웹툰, 마스코트형 설명 채널 |
| **플랫 벡터 과학 설명** (쿠르츠게작트 계열) | 원·둥근 사각형, 외곽선 없음, 진한 남색 바탕 + 빛나는 채도 | 원리·우주·몸속·규모 비교, 추상 개념을 '물건'처럼 | 실제 인물·사건의 사실감이 필요할 때 | 쿠르츠게작트 ([제작 과정](https://kurzgesagt.org/youtube/): 벡터 일러스트 + 2D/3D 혼합, [둥근 형태·밝은 팔레트](https://artsatmichigan.umich.edu/ink/2019/09/27/simple-bright-beautiful-the-work-of-kurzgesagt)) — 새·캐릭터는 쓰지 않음 |
| **2.5D 점토·펠트 미니어처** (보내 주신 그림) | 손자국·실밥 질감, 과장된 얼굴, 얕은 심도, 실제 재료 소품 | 역사 인물 재현, 옛날이야기, 한 사람의 하루를 '작은 무대'로 | 빠른 정보 나열, 데이터 | Aardman·Laika 계열 질감 ([프롬프트 관례](https://gptprompts.ai/ai-image-styles/claymation): 재료·흠집·미니어처 세트 명시) |
| **시사 지면 삽화** (합격) | 잉크선 + 평면 채색, 실제 장소의 무게 | 기관·도시·산업, 실제 장소 | 감정 코미디 | 신문·잡지 일러스트 |
| **민트 플랫 제품 일러스트** (합격) | 둥근 덩어리, 손·물건 중심 | 앱·결제·권한 같은 제품 설명 | 역사·감정 | 제품 설명 일러스트 |
| **실제 자료·문서 콜라주** | 원문·사진에 형광펜·표시 | 증거·인용·날짜 | 이야기 몰입 | 시사 다큐 |

**한 편 안에서 섞는 규칙(목적 기준):**
- 편의 *기본 화풍*은 시청자가 끝까지 따라갈 질문의 성격으로 고른다 (감정의 이야기 → 셀/귀여운, 원리 → 플랫 벡터, 사건 → 지면 삽화).
- *보조 화풍*은 '장면의 종류'가 바뀔 때만: 예) 호기심 편에서 1877년 자네·1890년 제임스의 재현은 **2.5D 점토 미니어처**(옛 인물을 작은 무대로), 케이크 비율·설명력 10% 같은 원리는 **플랫 벡터 모션그래픽**, 아이·직장인의 일상은 **셀/귀여운 화풍**의 인물 연기.
- 바뀔 때 시청자가 길을 잃지 않게: 같은 소품(케이크·달력·시계)을 두 화풍에 같은 색으로 두고, 매치 컷으로 넘긴다.

## 3. 연속 애니메이션을 만드는 길
| 길 | 방법 | 장점 | 한계 | 비용 |
|---|---|---|---|---|
| A. 자세 바꾸기 + 층 움직임 (지금) | 자세 4장 + 카메라·소품 이동 | 빠름, 일관성 | 동작이 '툭툭' 바뀜 | 무료(구독) |
| B. **동작 프레임 시트** | 걷기·넘기기 같은 동작을 6~8프레임 시트로 그려 12fps로 재생 | 진짜 이어지는 동작, 화풍 그대로 | 프레임 사이 흔들림 확인 필요 | 무료(구독) |
| C. **그림 → 영상 모델** | 원화(첫 프레임, 가능하면 끝 프레임)를 넣어 3~8초 영상 생성 ([Veo 3.1 은 시작·끝 프레임 지원, Seedance 2.0 은 인물 일관성 강점](https://www.atlascloud.ai/blog/ai-image-to-video-models-compared); [시작·끝 프레임으로 구도 고정](https://artlist.io/blog/ai-video-start-and-end-frame/)) | 손이 책장을 넘기는 연속 동작까지 | 화풍이 흔들릴 수 있어 프레임 점검 필수, 유료 | 유료 — 사용자 승인 후 |

**결정 (2026-11-18 사용자: "무료로 해주세요"):** C 길(유료 그림→영상 모델)은 쓰지 않는다. 연속 동작은 A·B 길(Codex 구독 이미지 생성 + 프레임 시트)로만.

**쓰임:** B·C 는 '동작이 곧 이야기'인 박자에만(한 편에 몇 장면). 나머지는 A 와 모션그래픽.

## 4. 이번 시안 (Drive `20261118-anim/styles/`)
같은 장면(케이크 비유 / 1877년 서재)을 화풍별로 — 주문서 `scripts/anim/orders_styles.json`.
- **귀엽고 캐주얼** (`cute_cake`, `cute_study`): 표정이 커서 감정·코미디가 바로 읽힘 → 호기심 편 일상·비유 장면의 후보.
- **플랫 벡터** (`flatvec_cake`, `flatvec_study`): 남색 바탕에 빛나는 조각 — '같은 크기의 조각'이 가장 또렷 → 원리·비율 설명 장면.
- **2.5D 점토** (`clay_cake`): 질감·인물의 과장이 가장 강함 → 옛 인물 재현(1877 자네·1890 제임스).
- **연속 동작 B 길** (`cute_walk_sheet` + `walk_test.mp4`): 8프레임 걷기를 12fps로 — 자세 바꾸기보다 '진짜 걷는' 동작. 장면 배치는 시험용.
- 주의: 1877년 서재 시안 두 장(귀여운·플랫 벡터)의 창밖 에펠탑은 1889년 완공이라 시대가 틀림 → 실제 사용 때 주문서에 "no Eiffel Tower" 명시(사실 규칙).
