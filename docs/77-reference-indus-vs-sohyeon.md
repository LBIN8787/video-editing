## 2. 화면 템플릿 대조
| 요소 | 레퍼런스 | 우리 v1 |
|---|---|---|
| **화면 재료** | **실제 자료가 주인공**: 발굴 현장 사진, 도장·유물 사진, 책·논문 표지, 위성 지도 — 모두 오른쪽 위에 출처(Wikimedia Commons, CC 표기·논문 이름). AI 그림은 '재현 일러스트' 표시를 달고 가끔만 | **AI 재현 그림이 주인공**(16장을 돌려 씀), 실제 자료 0장 |
| 바탕 | 어두운 남색 + 인더스 기호 무늬(주제와 같은 무늬), 화면은 밝고 깨끗 | 어두운 세피아 + 필름 입자 + 비네트 + 깜빡임 → 전체가 탁하고 한 톤 |
| 강조색 | **청록 하나**(숫자·핵심어) | 빨강·노랑·주황·하늘색이 섞임 |
| 숫자 | 화면 가운데 큰 숫자 + 한 줄 설명($1,000,000 / 해독 상금 · 약 13억 원, '약 60%') | 몇 곳만(33·25·1644) |
| 주제 사물 | 인더스 기호가 **한 줄로 하나씩 그려지고**, 개수가 세어지고(8개→10개), 자리를 바꿈 — 영상 내내 같은 사물을 가지고 논다 | 실록 종이·사건 파일이 같은 역할이나 횟수가 적고, 그 사이를 그림이 채움 |
| 비교·목록 | 체크 목록(AI ✔ 수학계의 난제 풀어냄), 연도표(약 4,480년 전·2022·2026), 자료 더미 | 판정표·연표 한두 번 |
| 장 구분 | 'CHAPTER 1' + 장 제목 큰 글씨 | 사건 파일 카드(비슷) |
| 첫 30초 | 질문(상금 100만 달러) → 현재(2025년 인물 사진·지도) → 과거(4,500년 전) → 지금(AI) 을 2초 단위로 | 촛불 염습 그림 위에 문장 4개, 8초 넘게 같은 그림 |
| 자막 | 아래 작은 검은 상자, 한 줄 | 같음 (비슷) |

## 4. 소현세자 편을 이 템플릿으로 바꾸면 (제안)
1. **실제 자료를 주인공으로** (퍼블릭 도메인·CC 만, 출처 오른쪽 위):
   - 조선왕조실록 인쇄본 사진, 삼전도비, 남한산성, 창경궁 환경전·통명전, 소경원(소현세자 무덤), 심양 고궁, 베이징 고관상대(천문대) 실제 사진, 아담 샬 옛 초상(판화), 시헌력 인쇄본, 강빈 관련 민회빈 묘(영회원) — Wikimedia Commons 에서 찾아 라이선스 확인.
   - AI 그림은 '재현 그림' 표시를 단 채 이야기 장면(염습·귀국·병상) 몇 곳에만.
2. **2초마다 새 사실** — 문장마다가 아니라 **구절마다** 화면에 하나씩 더함(날짜·이름·숫자·자료). 첫 30초는 실록 문장 → 실제 실록 사진 → 380년 숫자 → 소경원 사진으로 빠르게.
3. **바탕·색 정리** — 필름 입자·깜빡임·비네트를 걷고 깨끗한 어두운 바탕 + 주제 무늬(조선 문양 또는 실록 글자) 하나, 강조색은 하나.
4. **주제 사물 하나를 끝까지** — 실록 문장 한 줄을 영상 내내 다시 불러 단서마다 밑줄·동그라미를 바꿈.
5. **소리** — 저음 깔기·타자·째깍 소리 **모두 없앰**. 장 전환에만 낮고 부드러운 소리 하나. 배경음악은 넣는다면 아주 작게, 곡은 사용자 결정(무료 음원 라이브러리 또는 ElevenLabs 음악 API).
