# 22. 움직이는 편집 레퍼런스 재분석 (2026-11-12) — motion-metaphor v2 의 근거

사용자 요청: "제가 링크를 준 유튜브 채널의 편집영상을 다시 분석해주세요" (AI 자동화 해설 채널, 예: '내가 쓰는 앱들, 왜 죄다 러스트로 바뀌고 있을까' 9:10).

## 무엇으로 분석했나 (그리고 못 한 것)
| 방법 | 결과 |
|---|---|
| 영상 내려받기 (yt-dlp) | 403 → 미리보기(스토리보드)는 봇 확인 — **우회하지 않음** |
| vidIQ 영상 분석 | 크레딧 부족으로 실행 안 됨 (차감 없음) |
| **유튜브 공개 자동 캡처 3장** (`i.ytimg.com/vi/<id>/hq1·hq2·hq3.jpg`, 영상의 약 25·50·75% 지점) | ✅ 채널 영상 6편 × 3장 = 18장면 + 썸네일 |
| 채널 영상 목록 | 채널 공개 페이지에서 영상 ID |

한계: 컷 길이·전환·움직임 속도는 **정지 화면으로는 잴 수 없음**. 사용자 PC 에서 30초~1분 녹화를 주면 `python -m ytflow style` 로 측정.

### 썸네일만 보고 만든 v1 과 다른 점
| v1 (2026-11-12 시험작, '퀄리티 많이 낮음') | 실제 레퍼런스 |
|---|---|
| 밝은 하늘·땅 그림책 무대 | **어두운 스튜디오**, 검은 바닥 반사, 한 줄기 빛 |
| 평면 도형 사람·버스 | **입체(로우폴리·두께·그림자) 흰 물체** 한두 개를 크게 |
| 의태어·노란 손그림 화살표 | 글자는 거의 없음 (의태어는 썸네일 전용 장치) |
| 한 장면에 많은 요소(사람 40명) | **한 장면에 물체 1~2개**, 빛·카메라로 집중 |
| 사람 감정 없음 | **스톡 인물 B-roll** 로 감정(고민·좌절·안도) |

## v2 방향 (만들 때)
1. **어두운 스튜디오 무대**: 검정 그라데이션 + 바닥 반사 + 위에서 떨어지는 부드러운 빛(스포트) — CSS/캔버스로 충분.
2. **입체 물체**: three.js(WebGL)로 기본 도형(상자·정이십면체·원기둥·두께 있는 아이콘 타일·글자 판)을 흰·회색 무광 재질 + 한 줄기 빛으로. 움직임은 천천히 돌기·떠오르기·떨어져 쌓이기·빛나며 등장 — 장면당 한 동작. HyperFrames 레지스트리의 WebGL 블록(`code-3d-extrude`, `ui-3d-reveal`, `transitions-3d`)을 먼저 확인해 재사용.
3. **감정 B-roll**: 무료 라이선스 스톡(Pexels 라이선스 — API 키 필요, Wikimedia CC BY·PD)에서 '고민·좌절·안도' 인물 장면. 키·라이선스는 사용자 확인 후.
4. **미니멀 아이콘 장면**: 검은 바탕 + 흰 선 아이콘 + 강조색 하나 (우리 아이콘 세트로 바로 가능).
5. **배경 큰 글자**: 핵심 영어 낱말을 아주 흐리게 깔기.
6. 하지 않을 것: 채널 고유 캐릭터·스티커·썸네일 문구·레이아웃 복제.
