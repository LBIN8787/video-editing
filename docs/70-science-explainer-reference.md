## 3. 문법 (S1~S7)
| # | 문법 | 본 것 | 왜 효과가 있나 |
|---|---|---|---|
| S1 | **앞 그림이 다음 그림으로 변한다** | 손글씨 3 → 숫자 격자 → 한 줄로 풀린 입력층 → 망. 새 화면으로 바꾸지 않음 | 시청자가 "이게 아까 그거구나"를 눈으로 따라감. 추상(784개 입력)이 구체(그 3)에서 나왔다는 것이 증명됨 |
| S2 | **시청자 대역이 반론을 대신 말한다** | 작은 캐릭터 무리가 "학습은 어떻게 해?", "동그라미 알아보기도 똑같이 어렵잖아" | 설명이 일방통행이 아니라 대화가 됨. 다음 내용으로 넘어가는 이유가 생김 |
| S3 | **그림 등식** | 9 = ○ + │, 동그라미 = 짧은 선들의 합 | 분해·조립을 말 없이 한 줄로. 기억에 남는 형태 |
| S4 | **보이지 않는 숫자를 원래 대상의 모양 위에** | 가중치 784개를 숫자 목록이 아니라 같은 28×28 격자의 색으로 | 숫자의 의미("이 부분을 본다")가 바로 읽힘 |
| S5 | **식은 말하는 순서대로 한 항씩, 항마다 이름표** | w₁a₁ + w₂a₂ … → σ( ) 로 감쌈 → −10 에 'Bias for inactivity' | 식 전체를 한꺼번에 보여 주면 읽기를 포기함 |
| S6 | **아직 안 한 설명은 '?'로 자리만** | 숨은 층에 물음표를 붙여 두고 나중에 채움 | 지도를 먼저 주고 빈칸을 채워 가는 구조. 길을 잃지 않음 |
| S7 | **처음의 단순한 정의를 나중에 고친다** | '숫자를 담는 것'에 줄 긋고 '함수' | 처음엔 쉽게 들어오고, 끝에 한 단계 깊어짐. 이해가 자랐다는 느낌 |

## 4. 우리 쪽 대응
| 우리 상황 | 쓸 문법 |
|---|---|
| AI 기술 해설(모델·에이전트·칩이 어떻게 움직이나) | S1 실제 화면 → 구조도로 변신, S4 숫자를 원래 대상 위에, S6 '?' 자리 |
| 시장 분석(실적 구조·마진·주가의 원인) | S3 그림 등식(매출 = 값 × 개수, 이익 = 매출 − 비용), S5 식 한 항씩, S7 쉬운 정의 → 정확한 정의 |
| 시사(제도·법·갈등 구조) | S2 반론 대역 — 얼굴 없는 채널이라 캐릭터 대신 화면의 '질문 쪽지'로, S6 |
| 호기심(실험) | S1 실험 장면 → 결과 도식으로 변신 |

S2 는 고유 캐릭터를 만들지 않고, 화면 구석에 짧은 질문 문장이 붙었다 떨어지는 방식으로만 씁니다. 대본에서는 "그럼 ~는요?" 같은 질문 한 줄입니다.
