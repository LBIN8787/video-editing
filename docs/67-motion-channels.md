## 2. 공통점 (여러 채널에서 반복)

1. **한 화면에 한 사물·한 숫자.** 450만 회 채널도 아이콘 하나 + 여백. 꾸밈보다 '무엇을 보라'가 분명함.
2. **색은 바탕 + 강조 하나.** Vox 막대(주황 하나), LITTLE BIT BETTER(청록 하나), 칠판(빛나는 청록 하나).
3. **번호 카드로 구조를 보여 줌.** THEORY No.1, #4 — 시청자가 '지금 몇 번째'인지 앎. 우리 체크리스트 ①②③ 과 같은 역할.
4. **질문을 화면에 세운다.** 14F 말풍선, 칠판 '그래서 내 생활은?' 카드 — 답보다 질문을 먼저 보이게.
5. **실사 위에 굵은 겹치기 하나.** PolyMatter·Economics Explained — 자료 화면이 많은 채널도 숫자 하나만은 크게.
6. **비교는 화면을 반으로.** Vox·14F·LITTLE BIT BETTER 모두 가운데 선으로 A | B.

## 3. 우리 화면에 가져오는 것 (이번 작업)

| 가져올 것 | 어디에 | 구현 |
|---|---|---|
| 그림을 더 크게, 사물 하나 | 체크리스트 오른쪽 그림 전부 | 이미 v2 에서 키움, 새 종류도 같은 원칙 |
| 강조색 하나 | 그래프류 (`growth`·`shift`·`zoomline`) | 비교 대상은 회색, 지금 말하는 것만 색 |
| 시청자 질문 말풍선 `ask` | 장이 시작되는 체크리스트·설명 무대 첫 박자 | 사람 아이콘 + 말풍선이 튀어나오고, 답이 나오면 접힘 |
| 링 숫자 `ring` | 원본 영상·사진 장면, 체크리스트 그림 | 도넛이 그 비율만큼 차고 가운데 숫자가 올라감 |
| 점 격자 `waffle` · 게이지 `gauge` · 줌아웃 `zoomline` | 몫·비율·추세 | docs/66 |
| 어두운 칠판 스킨 `glowboard` | 사용자가 고를 때 (시장 채널 기본은 그대로) | docs/66 |
