## 3. 움직임 문법 (그래픽 구간만)
| # | 문법 | 레퍼런스에서 본 것 | 왜 효과가 있나 |
|---|---|---|---|
| A1 | **낱말 칩** | 한 단어 = 둥근 칩 하나. 문장 전체가 한 줄 | 추상(토큰)이 '집어 옮길 수 있는 물건'이 됨 |
| A2 | **읽는 순간 등장 + 아래 고리** | 칩이 왼→오 차례로 켜지고, 칩 아래 물결 고리가 다음 칩으로 이어짐. 카메라가 오른쪽으로 밀리며 앞 칩이 화면 밖·흐릿하게 | '순서대로 넘긴다'와 '잊는다'를 **프레이밍**으로 보여 줌 |
| A3 | **틀린 답 후보** | 영어 번역 줄이 타자로 쳐지다 빈칸 → 후보 세 줄(robbed the bank / shook the ginkgo tree …), 틀린 쪽이 먼저 | 문제가 '결과'로 보임. 시청자가 답을 먼저 짐작함 |
| A4 | **개념 이름 카드** | 검은 화면에 `ATTENTION` 글자가 하나씩 밝아지고 아래 작은 한글 풀이. 다음엔 `RNN` 아래 `ATTENTION` | 새 용어를 한 번만, 크게. 위·아래 배치로 **위계**를 말 없이 |
| A5 | **되돌아가는 빛줄기** | 출력 단어에서 원문 단어로 빛나는 곡선이 내려가고, 참고한 단어는 노란 테두리 | '주목'이라는 동사를 선이 연기 |
| A6 | **줄 → 그물 → 다시 줄** | 칩이 한 줄에서 흩어져 노드-링크 그림이 되고, 번호(위치 정보)가 붙은 뒤 다시 한 줄로 정렬 | 구조가 바뀌었다는 것을 **배치가 바뀌는 것**으로 |
| A7 | **액자 속 액자** | 파란 점선 판 '어텐션'을 보라 판 '트랜스포머'가 감쌈 | 포함 관계를 테두리로 |
| A8 | **모든 쌍의 호, 굵기 = 참고 정도** | 기울어진 유리판 위 모든 단어 쌍에 호. 한 단어(파랑) 기준으로 참고 단어(노랑)의 호만 밝게 | '동시에·서로'를 한 장면에. 강조로 한 단어씩 읽어 줌 |
| A9 | **2D → 3D 기울기** | 판이 기울며 원근이 생김 → 다음 장면에서 같은 판이 뒤로 여러 겹 | '층'이라는 말 전에 판이 먼저 겹쳐 보임 |
| A10 | **아이콘 격자 동시 점등** | GPU 칩 8개가 함께 켜짐 → 밝은 바탕 막대 비교로 톤 전환 | 병렬 = 동시에 켜짐. 성과는 톤을 바꿔 '결론'으로 |
| A11 | **갈래 + 확률 막대** | 앞말을 호로 잇고 끝 단어에서 후보 세 갈래 + 퍼센트 막대 → 하나가 칩이 되어 붙고 카메라가 밀림, 반복 | 생성 = '고르고 붙이기'의 반복 |

### 색과 글자
- 어두운 회색 그라데이션 바탕 + 은은한 질감, 칩은 **민트**(글로우), 강조는 **노랑**(지금 보는 것), 판은 **파랑**(어텐션), 감싸는 판은 **보라**(트랜스포머). 색이 맡은 뜻이 끝까지 안 바뀝니다.
- 아래 작은 **장면 이름표**("순환 신경망(RNN)의 원리", "어텐션(Attention)의 원리") + 자막 상자. 영어 번역 줄은 고정폭 글꼴.

### 이 편집의 핵심 세 가지
1. **예문 하나로 끝까지.** 뜻이 둘인 단어 하나(은행)가 문제(틀린 번역) → 해결(주목) → 확장(모두가 서로를·층) → 응용(다음 단어)까지 계속 나옵니다. 시청자는 새 그림을 배울 필요 없이 **같은 칩이 하는 일만 바뀌는 것**을 봅니다.
2. **같은 물건이 계속 산다(객체 연속성).** 장면이 바뀌어도 칩은 지워지지 않고 흩어지고·번호가 붙고·판에 올라가고·겹칩니다. 개념이 '진화'하는 것처럼 보입니다.
3. **동사를 움직임이 연기.** 읽는다(차례로 켜짐) · 잊는다(밀려나 흐려짐) · 주목한다(빛줄기가 되돌아감) · 동시에(한꺼번에 호) · 거듭한다(판이 겹침) · 고른다(갈래와 막대).

## 6. 시험 장면 (구현)
- 코드: `scripts/attention_scene/attention.html`(GSAP 타임라인, 1920×1080) + `render.py`(Playwright 프레임 캡처 → ffmpeg, 소리 없음)
- 예문은 우리 것: **「어제 과수원에서 딴 배를 깎아 먹었다」** — '배'(boat·belly·pear)가 헷갈리는 단어. 참고 정도·확률은 **이해를 돕기 위한 예시값**이라고 화면에 적었습니다(사실 규칙).

| 시간 | 장면 | 쓴 문법 |
|---|---|---|
| 0~11초 | ① 순서대로 읽기 | A1 칩 · A2 차례 등장 + 아래 고리 + 지난 칩 흐려짐 · A3 번역 줄 타자 → 후보 막대(boat 52%) → 틀린 번역 |
| 12~20초 | ② 어텐션 | A5 '배를'에서 '과수원에서·딴·어제'로 빛줄기(굵기 = 참고 정도) → 막대 재정렬(pear 88%) → 바른 번역 |
| 20~29초 | ③ 모두가 서로를 | A9 판 기울기 · A8 모든 쌍의 호 · 단어마다 차례로 노랑 강조 스윕 |
| 29~37초 | ④ 층 쌓기 | A9 같은 판 3겹 더 · 층마다 호 · '배 = 과일' 이름표가 흐림에서 또렷하게 |

```powershell
python scripts/install_tools.py   # GSAP (tools/hyperframes) 이 없을 때 한 번
python scripts/attention_scene/render.py <출력폴더>                      # 37초 mp4
python scripts/attention_scene/render.py <출력폴더> --stills 7.8,18.8,33  # 정지 화면만
```
출력은 PC 저장공간 규칙대로 `YTFLOW_DRIVE` 아래(또는 임시 폴더)에 둡니다. 영상·그림은 Git 에 올리지 않습니다.

### 한계 (다음 차례)
1. **목소리·큐 동기화 없음** — 지금은 시간이 고정. motion_explainer 의 '큐 단어가 들리는 순간' 방식으로 박자를 대본에 묶어야 합니다.
2. **A6 줄 → 그물 재배치, A11 다음 단어 갈래**는 아직 없음.
3. 예시값 대신 **실제 모델 값**(BertViz·Transformer Explainer 로 뽑은 가중치·확률)을 쓰면 '예시' 표시 없이 사실 장면이 됩니다 — 그때는 출처를 화면에.
4. 시각 카탈로그(갤러리) 등록은 hybrid 장면 종류(`type`)로 옮긴 뒤에 합니다(예시 그림은 Drive).

## 7. 어디에 쓰나
- **AI 채널 롱폼의 개념 설명**: 토큰·임베딩·컨텍스트 창·RAG·에이전트의 도구 호출처럼 '안에서 무슨 일이 일어나는지'를 보여 줘야 할 때. 영상당 1~2덩어리, 한 덩어리 15~30초, 사이에 자료 화면·인용으로 쉼.
- **호기심 채널**: 번역·언어·암호처럼 '단어 사이의 관계'가 이야기의 뼈대일 때.
- 넘치면: 한 영상 내내 칩·호만 나오면 지루함 — 레퍼런스도 그래픽은 3할이고 나머지는 사람·자료 화면. 모자라면: 개념을 말로만 설명하는 30초가 넘는 구간.

## 8. 시장 채널에 적용 — 다큐 개념 장면 `docu` (2026-11-24)
> 사용자: "전문 방송국들이나 편집방식처럼 모션그래픽과 연출 편집방법을 나도 이런 퀄리티로 제작하고싶어 / 내 시장채널도 이런 다큐멘터리 편집법을 활용하고싶어"

### 무엇을 가져오나 (시장 채널판)
| 레퍼런스 문법 | 시장 채널에서 | `docu` 동작 |
|---|---|---|
