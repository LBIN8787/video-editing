## 1. 방법
- `scripts/viral_research.py` — 1차로 분야 검색어 21개 + 벤치마크 이름 검색으로 개인 채널을 모은 뒤, 방송 재편집·오디오북·예능 클립 채널을 빼고 **30개 채널(겹침 포함) 최근 롱폼 50편씩, 1,610편**(쇼츠 제외)을 받음. 제목은 한국어 원문(`lang=ko`)으로.
- **배수 = 조회수 ÷ 그 채널 최근 영상 중앙값.** 터짐 3배+ / 바닥 0.5배 이하. 같은 채널끼리 비교해 구독자 차이를 지움.
- `scripts/viral_titles.py` — 제목 특징별 '3배+ 비율'과 **같은 채널 안 배수 비**(특징 있는 영상 중앙값 ÷ 없는 영상 중앙값, 채널별로 낸 뒤 중앙값).
- 썸네일 비교 시트: 채널마다 터진 4편 / 바닥 2편을 한 줄에 놓고 눈으로 봄. 원자료·이미지는 `.cache/viral/2026-11-20/` (커밋 안 함).
- **한계 — 대본·편집:** 이번에 클라우드에서 자막·영상 화면은 유튜브 봇 확인으로 막혔고(우회하지 않음), vidIQ 는 크레딧이 없었다. 그래서 **대본·편집 항목은 ① 제목·길이·썸네일에서 보이는 것 ② 앞선 화면 확인(docs/18·31·47·49, ● 표시)** 으로 썼다. 터진 영상의 실제 대본은 §6 의 피클 요청으로 2단계 확인.

### 2-3. 썸네일
- **얼굴 하나를 크게**(젠슨 황·머스크·대가) 또는 **회사 간판 하나**. 출연자형 채널은 **[인물 사진 + 위 따옴표 한 줄 + 아래 두 줄 결론]** 3단(머니인사이드·교양이를 부탁해 — 바닥 영상도 같은 틀).
- 머니크루식 **흰 바탕 + 검은 큰 글씨 + 차트 한 조각**: 터진 두 편은 숫자가 든 결론('30년 5번', '5대 1'), 바닥은 일반 경고('폭락 경고가 떴다').
- 미국회계사 EK: **검은 바탕 + 종목 기호 한 단어(JEPQ) + "재무제표를 까 봤더니.."** — 글자만으로 8.8배. 꾸밈보다 '직접 확인' 약속.
- 하지 않는 것: 지수 숫자(코스피 5,000), 물음표 시황, 매수 지시.

### 2-4. 대본·편집 (● 앞서 화면·챕터 확인 / ○ 제목·썸네일에서 추론)
- ● 머니크루(docs/31): **반전 숫자 → 원문(보고서·발언) 해부 → 메커니즘 → 직접 계산 → 같은 틀의 역사 비교 → 틀리는 경우 → 기준선 신호**, 끝은 한국 대표주. 화면은 흰 바탕 평면 인포그래픽, 차트가 그려지고 숫자가 올라감.
- ● 식스시그마(docs/49): 원본 인터뷰 영상 + 원문·번역 2단 자막 + 검은 정보 카드. 아는 얼굴일 때만 강함.
- ○ 유치한경제학·EK: '직접 뜯어봄·백테스트' 자체가 소재 — 화면 녹화·표가 증거.
- ○ 길이: **3~8분(3배+ 14%)과 60분+ 정리(19%, 중앙 배수 1.43)** 가 높고 8~30분은 평균. 같은 주제라도 '빨리 핵심' 또는 '한 번에 전부'로 극단을 고르는 편이 유리.

2. **"끝까지 보면 ○ 세 가지"** 약속이 터진 두 편(머니크루·이효석)에 모두 있다. 숫자를 박은 약속이 시청 유지 장치.
3. **증거는 원문 그 자체**: 본인의 과거 발언 원음(이효석 — 말과 행동 맞대기, docs/09 §2 와 같음), 발표문 문서에 형광펜, 재무제표 표에 빨간 박스. 시장 채널 '깊이'의 화면 정체는 *원문을 화면에 띄우고 짚어 주기*.
4. **다른 산업을 같은 틀로 붙인다**(머니크루 4개 산업 → 메모리): docs/31 '같은 틀 역사 비교'가 화면에서는 아이콘 4개 동시 배치 → 대응표.
5. **양자택일 질문**(EK "진짜 배당 vs 가짜 배당")은 3분짜리도 8.8배를 만든다. 답은 표 하나로.
6. 끝은 셋 다 **다음에 볼 것**(지표·날짜·위험)으로 닫는다. 구독 요청은 머니크루만, 결론 한 장 앞에.
7. 화면 속도는 이효석(44초 무전환) ~ 머니크루(약 3초)로 달라도 터졌다 — 호기심과 같은 결론(§3-4-1 5번).

### 3-3. 썸네일
- **심리학 고양이 — 검은 바탕 + 사물 하나(시계 두 개·찢어진 지폐·구겨진 종이 하트) + 흰 큰 글씨 한 줄 '○○의 역설'.** 터진 4편이 모두 이 틀, 바닥 2편은 Before/After 인물 그림·불상(처방·힐링) — 같은 채널 안에서 틀이 아니라 **약속(역설 vs 처방)** 이 갈랐다.
- 사물궁이: 진한 바탕 + 마스코트가 **그 상황을 연기**(굶은 뒤 쭈그러진 몸, 주사 맞고 길어진 몸) + 위쪽 질문 두 줄. 바닥도 같은 틀 — 질문이 몸의 극단이냐 생활 예절이냐가 가름.
- 지식해적단: 두루마리 바탕 + 실사 인물이 **그 물건을 먹거나 들고 있음** + 빨강 핵심어. 실사 사진의 얼굴 표정이 감정을 대신 말함.
- 어른이 심리학교: AI 웹툰풍 인물 한 명이 **그 행동을 하는 장면** + 위 혼잣말 말풍선 + 아래 두 줄(하늘색+흰).
- 출연자형(놀면서 배우는 심리학): 같은 의자·화분 틀, 위 말풍선 인용 + 왼쪽 위 상황 꼬리표 + 아래 두 줄.
- 공통: **글자 수가 시장보다 적다.** 한 줄(4~6자)~두 줄. 그림이 상황을 보여 주고 글은 질문 하나.

2. **첫 30초 = 시청자를 참가자로 만든다.** 예/아니오 질문 → "당신도 참가자" → 실험 상황을 2인칭으로 묘사. 제목에 '당신'을 넣는 것보다 효과적인 자리가 여기(§3-2 의 '당신' 0.44 와 맞음).
3. **심리학 고양이는 이 편에서 한 편 한 화풍이 아니었다.** 검은 타이포·실사풍·인포그래픽·논문 캡처·만화 캐릭터를 5초마다 섞음. docs/47 의 '한 편 한 화풍'(칼 융 장편)은 장편 이야기형, 이 편은 실험 설명형 — **형식에 따라 다르다.** 공통은 '검은 화면 + 흰 타이포 한 줄'이 장면 사이의 마디 역할.
4. **비유 하나로 끝까지 설명**: 공격수·수비수(놀면서 배우는 심리학), 용광로 3개(사물궁이), 머릿속 행진곡(심리학 고양이 — 실험의 행진곡을 '머릿속 걱정'으로 이어 붙임). 실험 소품을 그대로 비유로 다시 쓰는 것이 가장 매끄러웠다.
5. **화면 속도는 채널마다 2초~정지로 크게 달라도 다 터졌다.** 속도보다 **질문·비유가 바뀌는 곳에서 화면이 바뀌는지**가 공통점. 인터뷰형도 비유가 나오는 순간에만 스톡 영상을 썼다.
6. **처방은 마지막에 번호로**(심리학 고양이 ①②③). 처방이 제목이면 바닥(0.08배 '5분만 따라 하세요')이지만, 역설로 끌고 와 끝에 주면 터진다.
7. 세 편 모두 끝에 구독 요청이 없다. 챕터는 심리학 고양이만 운영.

### 7-3. 썸네일 — 더한 채널에서 본 것
- **출연자형 시장 채널(김작가·815머니톡·김광석·삼프로)은 터진 것과 바닥이 틀이 같다**: 위 따옴표 한 줄 + 인물 + 아래 두 줄. 가른 것은 문구 — 터짐은 "죽음을 부르는 ○○ 1위", "외인 선물 4조 매수", "-80%까지 가봤어요 / 5년 만에 30억", 바닥은 "'이 주식' 사세요", "손절해야 하나?". (docs/49 §4 와 같은 결론이 채널 12곳 더해서도 유지)
- **과학 채널(과학쿠키·과학드림)은 사진 한 장 + 빨간 화살표 + 한 줄**("99년간의 미스터리, 드디어 풀렸다!"): 사람 얼굴 없이도 111배. 가리키는 화살표가 '여기에 답이 있다'를 약속.
- **정신과 채널(뇌부자들·양브로)은 의사 얼굴 + 상황을 연기하는 사람 사진 + 두 줄 '○○한 사람 특징'**, 바닥은 같은 틀에 '역사'·'공부법'.
- **교양만두는 캐릭터가 그 상황을 연기**(감옥, 조선 옷, 독초 먹고 우는 얼굴) — 사물궁이(§3-3)와 같은 문법이 다른 채널에서도 확인.
- **시사 지구본 연구소는 국기를 얼굴에 붙인 캐릭터 + 나라 사진 + 두 줄**(위 흰 글씨 사실, 아래 빨강 판단 '살벌한 유럽 분위기'). 바닥은 같은 틀에 국경·환경 같은 추상 주제.
