목적은 **주제 선정 기준**을 세우는 것입니다. 원자료(검색 결과·채널 영상 목록 JSON)는 타 채널 자료라 GitHub 에 올리지 않습니다.

## 1. 방법
1. YouTube 검색 32개(8개 분야 × 4~5개 검색어, 각 40개 결과): 상식·역사·심리·과학·지리·경제생활·미스터리·교양인물.
2. 검색에 많이 걸린 **개인 창작 채널 25곳**(방송사 클립 채널 제외)의 최근 영상 80편씩, 약 1,900편.

## 2. 잘 되는 영상의 공통점 (배수 2배 이상 412편)
| 유형 | 예 (배수) | 시사점 |
|---|---|---|
| **몰아보기·총정리** | 조선 27왕 70분 (×700, 구독 1.9만 채널에서 140만), 고려 500년 15분 요약 (×26), 춘추전국 몰아보기 (×6.7) | 작은 채널도 터집니다. 시리즈의 '통합본'은 반드시 만듭니다 |
| **"왜 ~일까" 이유형** | 마추픽추를 이런 곳에 지은 과학적 이유 (×8), 왜 한국만 8촌까지 결혼 금지 (×4.6), 왜 삼겹살 (×5.4) | 모두가 아는 것 + 모르는 이유. 제목 = 질문 하나 |
| **"~면 생기는 일" 가정** | 조선시대 차은우로 태어나면 (×4.9), 조선으로 회귀하면 (×4.6) | 표본은 적지만 배수 중앙값이 가장 높음(1.40) |
| **전쟁·고난의 역사** | 체첸의 역사 (×28), 1차대전이 끔찍했던 이유 (×13), 아편전쟁 (×12) | 국가·인류가 겪은 큰 고통 + 지금과의 연결 |
| **고립·생존 실화** | 트로멜린섬 15년 고립 (×11, 370만) | 사람 이야기 하나로 끝까지 끌고 가기 |
| **심리 "우리는 왜"** | 손실을 견디는 이유 (×11), 빨리 자려 하면 역효과 (×9), 생각보다 호감 (×9) | 시청자 자신의 경험에 닿는 질문 |
| **데이터 순위 변화** | 국방비 순위 1890~2021 (×49), 재벌 순위 변화 (×17) | 짧은 그래프 영상. 우리 스타일의 막대·지도와 잘 맞음 |

길이별 배수 중앙값: 4분 미만 0.76 · 4~12분 1.00 · 12~30분 0.93 · **30분 이상 1.09**(2배 이상 비율 25%).
제목 유형별: 가정형 1.40, 몰아보기 1.09(2배 이상 33%), 순위·TOP 1.06, 왜·이유 1.00, 충격·비밀 0.90(낚시성은 오히려 낮음).

## 3. 주제 선정 기준 (교양 채널용)
1. **누구나 아는 것 + 아무도 모르는 이유** — 한 문장 질문으로 제목이 됩니다.
2. **이야기 하나로 끝까지** — 사람·장소·날짜가 있는 장면으로 시작합니다(정의·개요로 시작 금지).
3. **지금 우리와 연결** — 한국 이야기, 오늘의 제도·습관과의 연결이 한 장 이상.
4. **원본 자료가 있다** — 공공 기록 사진·영상(LoC·NASA·정부)이나 확인된 숫자가 있어야 하이브리드 스타일로 만들 수 있습니다.
5. **사실 확인이 가능하다** — 숫자마다 1차 출처(정부 통계·논문·기관)를 찾을 수 있는 주제만.
6. 낚시성 '충격·비밀' 단어보다 **질문형 제목**이 낫습니다.

## 5. 1번을 고른 이유
- **질문 하나**: "스페인 독감은 왜 '스페인' 독감일까?" — 모두 이름은 알지만 이유는 모릅니다.
- **답이 반전**: 처음 생긴 곳이 아니라 **처음 솔직하게 보도한 곳**이라서. 숨긴 나라들이 더 크게 당했습니다(필라델피아 퍼레이드).
- **전쟁·고난 + 심리(침묵·책임 떠넘기기) + 한국(무오년 독감, 인구 44% 감염, 김구)** — 잘 되는 유형 세 가지를 한 번에.
- **자료**: 미국 의회도서관의 1918년 사진(시애틀 마스크 전차, 세인트루이스 적십자, 독감 병동, 퍼레이드)과 1918년 행군 영상 — 모두 퍼블릭 도메인.
- **사실 확인**: CDC, 미국 국립보건통계센터, PNAS 2007 논문, WHO 2015 지침, 조선총독부 통계연보(언론 인용) 등 1차 출처로 검증.
