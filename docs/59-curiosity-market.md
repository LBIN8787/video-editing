## 4. 태그 — 관련은 보이지 않는다
**전제: 태그는 주제를 따라간다. 아래는 '같이 나타난 것'이지 원인이 아니다.**
- 한국 채널 영상의 **43.0%가 공개 태그 0개**(n=349). 2배 이상 영상의 태그 없음 비율 43.8% vs 0.5배 이하 36.1% — 오히려 태그 없는 쪽이 잘 된 쪽에 조금 더 많음. 영어는 4.9%만 태그 없음(중앙 25개) — 습관 차이.
- 한국 상위 효율 채널 **심리학 고양이·별별역사·지식한입·안될과학은 태그 0개**. BODA(6개)·닥터프렌즈(13개)·놀심(8개)은 **모든 영상에 같은 태그 묶음**.
- **같은 채널 안 태그 수 ↔ x 순위상관**: 태그 수가 달라지는 17채널, 중앙 **−0.05**(양수 7 / 음수 10). 같은 채널에서 태그 있음/없음이 섞인 5곳: 3곳은 태그 없는 쪽이 더 높음(미주일기·1분과학·Vsauce), 1곳 반대(Psych2Go), 1곳 n=3(약함).
- 태그 있는 한국 영상(n=199): 태그 수 중앙(11) 초과 x 1.00 vs 이하 0.98 · 총 글자 중앙(40자) 초과 0.92 vs 이하 1.00 · 제목 낱말 겹침 많은 쪽 0.99 vs 1.00 · 넓은 태그(심리학·과학·호기심 등) 섞인 쪽 0.83 vs 1.00(n=75 vs 124).
- 채널명 태그: 사물궁이·닥터프렌즈·Sprouts·Kurzgesagt 등은 100%, 심리학 고양이 0% — 성과와 무관해 보임.
- **x≥2 영상에서 3채널 이상 반복된 구체 태그: 영어 'neuroscience'·'brain' 두 개뿐**(BrainCraft·TED-Ed·Vsauce). **한국어 태그는 0개.** 2채널은 '비만'(닥터프렌즈·사물궁이), '우울증'(닥터프렌즈·장동선) 정도.
- 해시태그: 한국 있음 x 1.00(n=225) vs 없음 1.05(n=124) — 차이 없음. 설명란 길이(중앙 601자) 긴 쪽 0.99 vs 짧은 쪽 1.00 — 차이 없음.
- 내 영상: 태그 10~17개, 42~78자, 제목 낱말 겹침 0~0.08, 넓은 태그 15~20%. **시장 평균과 다르지 않다.**
- **결론: 이 데이터에서 태그는 조회수와 측정 가능한 관계가 없다.** manual/14 §6 의 '태그 영향은 작다, 같은 주제 안에서 어떤 말로 달지 고르는 데만'과 **일치**. 태그 정리에 시간을 쓰기보다 제목·첫 장면에 쓰는 편이 낫다.

## 6. 그래서 — 이 채널에 대한 시사점

### (a) 이 데이터가 받쳐 주는 것
1. **주제를 '인지 개념'에서 '몸·일상 장면에 걸린 역설'로 옮긴다.** 근거: 인지 묶음 x 0.79(n=14) vs 몸·건강·수면 1.36(n=59, 13채널, 31일+ 1.68). 같은 '애쓸수록 역효과' 원리도 '참을수록 더 생각나는 이유'는 0.77, '빨리 자려고 할수록 손해보는 이유'는 11.05(같은 채널). 실험·연구자 이야기는 그대로 두고, **입구를 잠·먹기·몸·폰 같은 매일의 장면**으로.
2. **제목에 '결과·가정형'이나 '이유'를 쓰고, 몸·일상 사물을 한 낱말 넣는다.** 근거: 결과·가정형 x 1.48(n=34, 같은 채널 5/5), '이유' 1.21(5/6), 몸·일상 사물 1.17(6/6), 나이를 빼도 유지. 물음표·쉼표 두 마디·2인칭·길이는 차이 없음(0.90~1.00) — 지금 제목에 많은 쉼표 두 마디(3/5)는 해도 안 해도 그만이다.
3. **'충격·소름' 같은 강한 말은 쓰지 않는다.** 근거: 있음 x 0.76(n=19, 약함), 31일+ 2.0% vs 7.8%. 대신 따옴표 발언(1.55, n=26, 3/3 — 약함)처럼 **실험 속 사람의 실제 말**을 쓰는 쪽이 낫다(사실 확인된 발언만).
4. **태그·해시태그·설명란 길이는 성과와 관계가 보이지 않는다** (태그 수 상관 −0.05, 17채널; 해시태그 1.00 vs 1.05; 설명 길이 0.99 vs 1.00). 태그는 편당 5분 이하로: 영상이 실제로 다루는 말을 **사람들이 치는 형태**(붙여쓰기 '자아고갈', '인지편향', '흰곰 효과' 등)로 몇 개 단다. 힘은 제목에.
5. **검색은 '열린' 작은 검색어를 확보하는 용도로만 기대한다.** 근거: 선택맹 검색에서 하루 만에 19위, 내 주제 검색 상위 긴 영상 조회 중앙 253~3.9천. 큰 조회는 검색에서 오지 않는다(docs/29 '홈 피드·추천' 결론과 일치).
6. **'반전된 실험'을 제목 틀로 쓸 수 있다.** 근거: 자동완성 '가짜로 드러난 심리학 실험들' + 그 제목의 26분 영상 37.5만(2개월); '의지력 문제가 아닙니다'도 자동완성에 있음. 1번 영상(재현 위기)이 정확히 이 내용이다 — 제목 또는 설명 첫 줄에서 그 각도를 드러낼 수 있다.

### (b) 그럴듯하지만 이 데이터로는 보이지 않은 것
7. **매일 1편 vs 주 1편.** 효율 좋은 내레이션 채널(심리학 고양이 0.62·별별역사 1.05)은 주 1.0~1.2편, 과학드림 0.5편. 매일 올리는 곳은 대담형(BODA 5.5, 안될과학 8.8). 업로드 빈도와 성과의 인과는 이 데이터로 알 수 없다. 다만 '한 편의 제목·첫 장면 품질'이 갈랐다는 위 결과로 보면, 매일 올리더라도 **제목·썸네일 테스트에 쓸 시간**을 남기는 편이 낫다고 추정한다.
8. **4편마다 몰아보기(채널 계획)에 '잘 때 듣는' 틀을 붙이기.** 데이터: 장동선 수면 몰아보기 5.07, 과학드림 '잠 못 이루는 밤 듣는 … 몰아보기' 2.44, '잠잘때 듣는 과학/자면서 듣는 과학' 자동완성 존재, '잠잘때 듣는 이야기' 검색은 새 긴 영상이 계속 상위. 반대 증거: BODA 몰아보기 ASMR 0.33·0.39. **과학·심리 수면 몰아보기 검색 결과는 받지 않았으므로 확인 필요.**
9. **같은 주제의 쇼츠를 긴 영상의 입구로.** 내 주제 검색 결과의 70~100%가 쇼츠라 쇼츠 칸에서 노출될 여지는 있지만, 쇼츠 → 긴 영상 이동은 이 데이터로 측정하지 않았다.

## 7. 신뢰도를 가장 크게 제한하는 것
1. **게시 후 기간 미보정**: 0~7일 영상 x 0.59 vs 31~90일 1.46. 31일+만으로 다시 봤지만 표본이 줄어(x≥2 n=51) 차이가 흔들린다.
2. **x 기준이 채널마다 약 25편**: 1분과학·썬킴·Vsauce·OverSimplified 는 몇 년치, 안될과학 20일·BODA 32일치. 채널마다 '평소'의 기간이 다르다.
3. **비교군이 대형 채널뿐**: 중앙 구독자 100만(한국). 새 채널의 첫 수백 회에 무엇이 효과 있는지는 이 자료가 직접 말해 주지 못한다.
4. **표본 작음**: 내 주제와 겹치는 영상은 묶음마다 2~16편, 제목 특징 일부(2인칭 n=20, 강한 말 n=19, 따옴표 n=26)도 작다. 주제 묶음·제목 특징은 내가 정한 정규식이라 오분류가 있다(미분류 76편).
5. **채널 정체 미확인 3곳**(Psych2Go·Sprouts·썬킴), **미주일기의 주제 변화**(AI) — 비교군 정의 자체가 바뀌었음.
6. **검색**: 비로그인·한 시점·상위 20건, 조회수는 반올림 근사, 구독자 수 없음. '조회수 없음' 쇼츠는 0으로 고쳐 셈. 자동완성은 순서만 있고 양은 없다.
7. 모든 결과는 **같이 나타난 경향**이지 인과가 아니다. 최종 판단은 Studio 의 실제 노출 클릭률·트래픽 소스와 '테스트 및 비교'로 확인해야 한다.
