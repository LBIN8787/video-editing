**구조 공식:** `훅(그래프 한 장의 위로→아래로) → 정의(일상 예시) → 원리(역사 실험 + 같은 예시 재활용) → 데이터(기울기 측정) → 왜 위험(안전) → 제안(비유 하나: 속도계) → 반론(구멍 둘) → 현재 상태(빈 의자) → 수미상관 + 열린 질문`

- 장 길이 비율: 개념 설명(1·2장)이 **43%**, 데이터·위험·제안·반론이 41%. 어려운 개념을 먼저 충분히 풀어 놓고 뒤에서 빠르게 쓴다.
- 장마다 **마지막 문장이 다음 장의 질문**이다. 12개 질문 중 9개가 장 경계에 있다.
- 같은 예시(점심은 김치 ○○, 0.732·물음표)를 2~3번 **재활용**한다 — 새 예시를 만들지 않아 시청자가 덜 지친다.
- 1인칭 평가는 딱 두 번("저는 이 부분이 가장 새롭다고 봅니다", "제가 찾아본 11월 24일까지") — 나머지는 다큐 내레이터.
- 인사("안녕하세요, ○○입니다")는 훅 **뒤** 76초 지점에 1줄. 채널 소개·순서 예고 없음.

## 3. 화면 문법

### 3-1. 척추 그래프 (영상 전체를 꿰는 한 장)
- 영상의 주인공은 **그래프 한 장**(기반 모델 로그 퍼플렉시티, 2022~2027). 도입·3장·6장·마무리에 같은 그래프가 다시 나오고, 매번 다른 부분을 확대한다.
- 점마다 **능력 이름(굵은 글씨) + 값(주황 고정폭) + 모델명(작은 회색)** 3단 라벨. 왼쪽 축 옆에 능력 아이콘(말풍선·전구·코드·방패·∑)이 줄지어 있다.
- 아직 없는 미래 구간은 **사선 빗금 띠 + 큰 남색 물음표**. 이 물음표가 영상의 상징으로 끝까지 반복된다.
- 측정: 기울기는 **각도기·삼각자 소품**이 그래프 위에 놓이며 재고, 기간은 위쪽 괄호(45개월), 차이는 오른쪽 화살표 + 주황 큰 숫자(-0.098).

### 3-3. 움직임 규칙
1. **한 캔버스**: 장면이 바뀔 때 자르지 않고, 앞 장면 요소가 흐려지며 다음 요소가 같은 자리에서 생긴다. 하드 컷은 실사 그림(1951, 백악관, 서버, 원탁)으로 들어갈 때만.
2. **카메라**: 그래프의 한 부분으로 천천히 밀어 들어가고(확대), 다음 장에서 빠져나옴. 흔들림·회전 없음.
3. **말하는 순간 생김**: 숫자·라벨·칩은 그 단어가 들릴 때 나타난다(박자 단위). 한 문장에 새 요소 1~2개.
4. **재사용**: 같은 소품(로봇 얼굴, 물음표, 계기판)이 장을 건너 다시 나와 기억을 잇는다.
5. **강조**: 주황 원으로 점 둘러싸기, 겨자 형광 밑줄, 빨간 사선 지우기. 흔들거나 번쩍이지 않음.
6. **실사·그림은 아껴서**: AI 생성 그림 장면 4개(1951 서재, 계단, 원탁, 백악관 사진), 스톡 1개 — 15분에 5번, 모두 장 전환 지점.

## 4. 패키징
- **제목**: `[회사]가 [기간] 숨겨온 [가치 있는 것]. "[인물의 경고 한 줄]"` — 비밀 + 직접 인용. 우리 '직관적 제목' 규칙과 부딪히는 점: '영업비밀'은 과장 소지(원문은 내부 측정값 공개) → 우리 판에서는 사실 범위 안에서 "5년 치 내부 기록" 등으로.
- **썸네일**: AI 그림 + 실존 인물 얼굴 참고(CC BY 사진 출처를 설명란에 명시). 우리 기준(Noto Sans KR Black, 2층 왼쪽 정렬)으로 다시 만든다.
- **설명란 블록 순서**: 요약 3~4문장 → 측정값 주의·기준일 → 썸네일 그림·사진 출처 → 챕터 → 📚 출처(1차 출처 링크 15개) → 🎞 재료 → 🤖 AI 사용 범위(주제 선정·최종 검토 운영자 / 조사·대본·연출 운영자+AI / 음성 AI / 화면 AI 코드 애니메이션) → 'AI 슬롭' 다짐 3줄 → 해시태그 3개.
