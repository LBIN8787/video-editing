# 20. 매뉴얼·채널별 검토 (2026-11-10, 매뉴얼 v11 기준)

매뉴얼 전체와 채널 문서(02 ai · 03 market · 04 curiosity · 08 issues)를 지금 기준(v11)과 맞춰 보고, 채널마다 더 필요한 스타일·연출을 정리했습니다.
**바로 고친 것**(기준은 그대로, 문서끼리 어긋난 것만)과 **제안**(사용자가 고르면 다음 판에 넣을 것)을 나눴습니다.

## 1. 공통 — 무엇이 어긋나 있었나 (고침)
| 문제 | 영향 | 조치 |
|---|---|---|
| 채널 문서 02·03·04 가 **v1 때 그대로**. v3~v11(조합·강조·MC 오프닝·배경·반복 피로·v10·소리)이 하나도 안 들어가 있음 | 새 세션이 채널 문서만 보면 **오프닝 없이 훅부터** 시작하는 대본을 씀 (README 규칙과 충돌) | 각 문서 대본 공식 앞에 **공통 기준 (v11)** 상자, 표 맨 위에 **오프닝** 줄 추가 |
| 시사 채널 설정의 배경음이 기각된 **Ether Vox** 그대로 | 다음 시사 영상이 음질 낮은 곡으로 나옴 | `digital-clouds` 로 교체 |
| 시사 채널 목소리 설정 형식이 다른 채널과 다름(`tts.voice_id`) | 파이프라인이 `tts.elevenlabs.voice_id` 를 읽어 못 찾을 수 있음 | 같은 형식으로 통일 |
| README "세 채널" | 채널은 넷 | "네 채널" |
| curiosity 4장 연출 `people` | v10 은 막대·사람 그림보다 사물 그림 통계 권장 | `isotype` 으로 |

## 3. 채널별 검토
### ai — AI 더 잘 쓰기 (`ch-ai-guide`, `ch-ai-shorts`)
| 항목 | 지금 | 보완 |
|---|---|---|
| 합격작 | 없음 (unslop 은 v3 기각 뒤 v9 이전 상태) | v11 기준 첫 합격작 필요 |
| 핵심 연출 | 화면 따라 하기(screen-demo)·대화 화면(chat)·터미널·화면 확대(zoomshot) — **모두 시험작 단계** | 실제 AI 영상 한 편으로 승인받기 |
| 더할 연출 | ① **전/후 나란히 화면**(B6): 손으로 한 것 vs AI 로 한 것 ② **기기 화면 목업**(B9): 휴대폰·노트북 안의 실제 화면 ③ **단계 진행 막대**: 따라 하기 3~5단계 중 지금 어디인지 화면 위에 항상 ④ **'막히는 곳' 경고 카드**: 실제 실패 화면 + 해결 | 이 채널의 보상은 '할 수 있게 됨' → 따라 하는 위치·실패 지점이 보여야 함 |
| 자동 검사 (P2) | 사람 눈 5개 | 결과 화면 장면(footage·zoomshot·chat·terminal) 1개 이상 · 가격/무료 한도 단어 · '한계' 장 · 회사 발표 숫자에 "회사 발표 기준" |
| 목소리·배경음 | 미정 | 목소리: 밝고 또렷한 30대(실용 톤) 후보. 배경음: 밝고 박이 있는 곡(Mixkit 측정 후보 'Wind Leaves' 등, 음질 기준 통과 곡) |

### market — 시장의 이유 (`ch-source-brief` · `ch-paper-column` · `ch-data-motion` · `ch-money-shorts`)
| 항목 | 지금 | 보완 |
|---|---|---|
| 합격작 | 데이터센터(하이브리드) — v9 기준 불합격(글씨·도형 8연속) | v11 로 다시 만들거나 새 회차 |
| 핵심 연출 | 시세 차트·인과 지도·발언·막대 | 대부분 승인 레시피 있음 |
| 더할 연출 | ① **공시·기사 증거 화면**(B2): 실제 공시·보도 제목을 잡고 한 줄 형광펜 — "회사가 이렇게 밝혔다"를 눈으로 ② **순위가 뒤집히는 막대**(B7): 시가총액·점유율 순위 변화 ③ **실적표 맞대기**: 예상 vs 실제(가이던스) 두 칸 + 차이 숫자 ④ **'틀렸다면' 신호판**: 마지막 장 반증 신호를 정리판(recap)처럼 쌓기 | 이 채널의 보상은 '왜'를 이해하고 다음에 볼 것을 아는 것 → 증거·비교·신호 |
| 주의 | 투자 권유 금지(자동 검사) | 순위·실적 연출이 "사라"로 읽히지 않게 — 마지막은 항상 '확인할 신호'로 |
| 목소리 | docs/08 에 Hyun Bin(차분한 남성)이 "하이브리드 경제"로 확정돼 있으나 채널 설정에는 없음 | `ch-source-brief`·`ch-paper-column`·`ch-data-motion` 에 같은 목소리로 넣을지 결정 |
| 배경음 | 없음 | Digital Clouds(시사와 같은 곡)를 같이 쓸지, 시장 전용 곡을 고를지 |

### curiosity — 몰랐던 이유 (`ch-knowledge`)
| 항목 | 지금 | 보완 |
|---|---|---|
| 합격작 | 스페인 독감 조합 시험작(3분)만 호평. 본편(9분)은 v9 기준 불합격 | v11 로 본편 다시 만들기 후보 |
| 핵심 연출 | 아카이브 다큐(켄 번스·도장)·지도 여정·키네틱 — 시험작 단계(지도는 v2 기각 뒤 고침) | 본편으로 승인 |
| 더할 연출 | ① **사진 오려 붙이기·입체 사진**(B5): 옛 사진에서 사람을 오려 앞뒤로 다르게 움직임 — 역사 이야기의 '장면감' ② **큰 판 한 장**(B4): 한 장(章)을 큰 그림 위에서 카메라가 이동 ③ **퀴즈 박자**(B12): "여기서 예상해 보세요" 3초 → 답 — 호기심 채널의 반전과 잘 맞음 ④ **신문 지면 장면**(newsprint 팩·newspapers): 당시 신문 제목으로 시대감 | 이 채널의 보상은 '아, 그래서였구나' → 반전 앞에 멈춤, 시대의 장면 |
| 자동 검사 (P2) | 사람 눈 5개 | 첫 장면 stamp(장소·날짜) · '쓰지 않는 것' 목록 · 한국/오늘 연결 장 · 마지막 문장과 question 비교 |
| 배경음 | 없음 | 박 없는 잔잔한 곡(등록부 rest-now) 또는 시대감 있는 곡 — 음질 기준으로 새로 고르기 |

### issues — 이슈의 구조 (`ch-issues`)
| 항목 | 지금 | 보완 |
|---|---|---|
| 합격작 | 사우디(v9 합격) + 앞부분 v10·Mina 시험 | 가장 앞서 있음 |
| 더할 연출 | ① **두 목소리 진행**(B1): 묻는 사람 + 풀어 주는 사람 — 시사 조사(640편)에서 근거가 가장 강함(대담형 1.6~3.8배) ② **양쪽 입장 나란히**: 한 화면을 둘로 나눠 같은 크기·같은 틀로 (공정함을 화면으로) ③ **기사 증거 화면**(B2) ④ **지구본·항로**(B8): 중동·해협 같은 국제 이슈 ⑤ **빠른 정리 형식 시험작**(issue-quick-brief, 아직 idea) | 대화형이 가장 큰 차이를 만듦 |
| 남은 결정 | 두 목소리를 하려면 두 번째 목소리 필요 | Mina + 남성 1명 |

## 4. 추천 순서
1. **P1 장면 길이 상한 + P2 채널 자동 검사** — 돈 안 들고, 새 영상이 처음부터 기준을 맞춤
2. **채널별 목소리·배경음 확정 (P3)** — ai·market 목소리, 각 채널 배경음 한 곡씩
3. **채널마다 v11 첫 합격작** — ai(화면 연출 승인), market(공시 증거·실적 맞대기), curiosity(사진 오려 붙이기·퀴즈 박자)
4. **시사 두 목소리 시험작 (B1)**
5. **쇼츠 방향 결정 후 v10 반영 (P4)**
