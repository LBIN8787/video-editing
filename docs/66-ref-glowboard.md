## 3. 왜 잘 읽히나 (우리 원리로)

1. **한 사물을 오래** — 시청자가 매번 새 판을 읽지 않아도 됨. 바뀌는 것만 보면 됨 (docs/65 §0 object constancy).
2. **어두운 바탕 + 빛나는 한 색** — 지금 보는 곳이 한 군데뿐. 빛나는 것 = 지금 말하는 것 (signaling).
3. **숫자는 덩어리로** — 997자리를 글로 쓰지 않고 점 덩어리 세 개로 나눠 크기를 느끼게 함.
4. **줌으로 설명** — '가까이 vs 멀리'를 컷이 아니라 같은 그래프의 카메라로.

## 4. 넘치면 / 모자라면

- 넘치면: 글로우·입자가 많아 화면이 어수선 (사용자 11-24 "어수선해요" 와 같은 함정). 빛나는 것은 한 화면에 하나.
- 모자라면: 어두운 바탕에 회색 글만 남아 답답. 청록 강조 하나는 늘 있게.

## 5. 적용 (이번 시안)

- 새 스킨 `glowboard` (짙은 청록 칠판 + 청록 글로우 + 금빛 보조, 고딕, 상자 없는 자막).
- 체크리스트 오른쪽 그림(pics)이 스킨의 밝기를 따라감 (어두운 무대에선 카드가 어두운 유리판, 선이 빛남).
- 새 그림 종류: `waffle`(점 격자 몫), `gauge`(세로 게이지), `zoomline`(가까이 계단 → 멀리 곡선) — 영상에서 쓸 자리가 있을 때만.
- 3D 도시 비유는 시안을 따로 (three.js 무대 필요).
