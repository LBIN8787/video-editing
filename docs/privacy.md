# ytflow 개인정보처리방침 (Privacy Policy)

마지막 수정: 2026-11-13

**ytflow** 는 유튜브 채널 '이어 읽는 시장' 운영자가 **자기 채널에 자기 영상을 올리기 위해 혼자 쓰는 도구**입니다. 다른 사람의 계정이나 데이터를 다루지 않습니다.

- **받는 권한:** YouTube Data API 의 업로드·관리 권한(youtube.upload, youtube.force-ssl) — 운영자 본인 채널에 영상·제목·설명·썸네일·자막·재생목록을 올리고 고치는 데만 씁니다.
- **저장:** 권한 토큰은 운영자의 GitHub 저장소 비밀값(암호화 보관)에만 저장하며, 다른 곳에 보내거나 공유하지 않습니다.
- **수집하지 않는 것:** 시청자·다른 사용자의 개인정보는 수집·저장·판매하지 않습니다.
- **삭제:** 운영자는 https://myaccount.google.com/permissions 에서 언제든 권한을 취소할 수 있고, 저장소 비밀값을 지우면 토큰이 사라집니다.
- **Google API 정책:** ytflow 의 Google API 데이터 사용은 [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) 를 따릅니다. YouTube API 이용은 [YouTube 서비스 약관](https://www.youtube.com/t/terms) 과 [Google 개인정보처리방침](https://policies.google.com/privacy) 을 따릅니다.

---

**English summary.** ytflow is a single-user tool the channel owner uses to upload and manage videos on their own YouTube channel via the YouTube Data API. OAuth tokens are stored only as encrypted GitHub repository secrets and are never shared. No data about viewers or other users is collected, stored or sold. Access can be revoked at any time at https://myaccount.google.com/permissions. Use of Google API data adheres to the Google API Services User Data Policy; YouTube API use is subject to the YouTube Terms of Service and the Google Privacy Policy.
