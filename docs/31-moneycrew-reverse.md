## 2. 대본 뼈대 — 챕터로 본 전개 (4편 공통)
| 순서 | 무엇 | 머니크루 챕터 예 (요지) | 시간 |
|---|---|---|---|
| ① 반전 숫자 한 쌍 | 같은 대상, 정반대 숫자 둘로 질문 | '이익은 최대인데 주가 -58%', '4일 +11.6%·5일 -7%', '목표가 160만 원, 그런데 본문에는' | 0:00~1:30 |
| ② 오늘 볼 것 (세 가지) | 무엇을 따라갈지 짧게 (인사 없이) | '오늘 볼 세 가지' | ~0:15 |
| ③ 사실을 날짜 순으로 | 무슨 일이, 회사별로 왜 | '10월 마지막 사흘: 구글·MS·아마존·인텔 각자 왜' | 1~2분 |
| ④ **원문 해부** | 헤드라인 vs 본문 — 기사에 없던 대목 | '이익은 올리고 목표가는 깎고', '목표가는 어떻게 매겨지나', '기사에 없던 대목' | 2~4분 |
| ⑤ **메커니즘** | 돈이 어떻게 흐르나 (엔진·공식) | '두 엔진', '1,143만 명이 기대는 네 공식', '빅테크의 현금 구멍 = 한국 메모리의 이익' | 2~3분 |
| ⑥ **숫자로 연결 + 민감도 계산** | A가 B의 몇 %, A가 10% 줄면 B는 | '메모리 몫 8% → 30%', '빅테크가 10% 덜 쓰면' | 2~3분 |
| ⑦ **역사 비교 (같은 틀)** | 비슷했던 2~4개 사례를 같은 지표로 | '해운·폴리실리콘·리튬', '대만 1990·일본 1989', '광섬유의 교훈' | 2~4분 |
| ⑧ 누가 들고 있나 / 수급 | 외국인·개인, 누가 바닥을 정하나 | '누가 들고 있나, 바닥은 누가 정하나' | 1~2분 |
| ⑨ **틀리는 경우 셋 / 걱정할 셋** | 반증 조건 | '틀리는 경우 셋', '걱정할 세 가지' | 1분 |
| ⑩ **신호 셋 (임계값·날짜)** | 숫자 기준이 있는 확인 신호 | '회사채 가산금리 1.9%p', '10년물 5% 아래', '12월 10일 감사 결과' | 1~2분 |
| ⑪ 결론 + 딱 하나만 기억한다면 | 한 문장 | '딱 하나만 기억한다면' | 1분 |

- 길이 11~23분, 챕터 14~20개(1~2분마다 장 전환). 장 제목이 **질문이거나 주장**.
- 설명란: 첫 두 줄 = 반전 숫자 + 질문 → '오늘 남는 세 가지' → '지켜볼 신호 ①②③(임계값)' → 댓글 질문 → 챕터 → 면책.

## 3. 깊이를 만드는 기법 7가지
1. **본문 대 헤드라인**: 보고서·공시 본문에서 기사 제목과 다른 문장을 찾아 보여 준다 (목표가 하향 기사 → 본문은 '이익 전망은 올렸고 하락 2단계는 기본 시나리오가 아니다').
2. **숫자 분해**: 결론 숫자를 만든 가정을 쪼갠다 (목표가 = 2029년 이익률 가정 60%→32%).
3. **연결 비율**: 남의 비용 = 우리의 매출 (빅테크 설비투자 중 메모리 몫 8%→30%).
4. **민감도 계산**: '10% 덜 쓰면 한국 이익은 얼마' 처럼 직접 곱한다.
5. **같은 틀 역사 비교**: 2~4개 사례를 같은 지표·같은 축으로 (주가 꼭대기 vs 이익 꼭대기 시차).
6. **반증 조건**: 이 판단이 틀리는 경우 셋.
7. **임계값 신호**: '볼 것'에 숫자 기준선을 붙인다 (기준선을 영상이 직접 정하고 밝힘).
