## 0. 본 방법
리만가설 편(HK6wSr1JdL0)의 다섯 구간을 **0.6~0.9초 간격으로 연속 20장씩** 펼쳐 봄(사용자 Chrome·프리미엄, 내려받기 없음): 여는 장면 0:00~0:35 · 소수 설명 1:48~2:03 · 이야기(폴리아·란다우) 4:04~4:21 · 규모(코드 → 25만 쪽) 7:38~7:55.
한 장면이 '무엇을 보여 주나'가 아니라 **문장이 바뀌는 동안 화면이 어떻게 이어지고 바뀌나**를 봄. 그림·대사는 옮기지 않음.

## 1. 진행 문법 열 가지
| # | 문법 | 실제로 본 흐름 | 우리 v1 |
|---|---|---|---|
| G1 | **한 장(章) = 한 판, 쌓아 간다** | 폴리아 이야기: 사진 → 봉투가 떨어짐 → 봉투에서 종이가 올라옴 → 종이가 괴팅겐 건물 그림이 됨 → 란다우 사진 → 란다우에서 영점 줄로 가는 가는 화살표. **앞의 것은 지우지 않고 작아지거나 옆으로 비켜 자리를 내줌.** 컷은 생각이 바뀔 때만 | 문장마다 새 장면, 앞 요소를 지우고 다시 그림 |
| G2 | **한 구절에 하나만 더한다** | 새 요소는 빈자리에 작게(떨어짐·미끄러짐·튀어나옴), 이미 있는 것은 그대로 | 한 문장에 여러 요소를 한꺼번에 |
| G3 | **바꾸지 말고 변하게 한다** | 봉투 → 편지 → 그림 / 웹 문서 → 그 문장으로 다가감 → 형광펜 → 번역 / 코드 창이 구석으로 작아지고 바탕이 코드로 차오름 | 요소를 없애고 다른 요소로 교체 |
| G4 | **카메라가 세계를 따라 이동하는 것이 전환** | 소수 격자·원자 → 화면 전체가 옆으로 흘러 수직선이 드러남 → 수직선을 따라 계속 이동 → 빽빽한 곳 · 빈 곳에서 멈춤 / 종이 더미가 자라면 카메라가 위로 따라 올라감 | 정지 구도에 요소만 등장 |
| G5 | **긴 과정 하나를 문장 여러 개에 걸쳐 그린다** | 어두운 화면의 파동 한 줄이 6초 넘게 끊김 없이 그려지고, 축을 지날 때마다 점이 켜짐 | 그리기를 짧게 끊어 반복 |
| G6 | **세계 위에 표시를 얹는다** | 빽빽한 구간에 손그림 타원 · 빈 구간에 괄호 + 실제 숫자(31397~31469) + 숫자 세기(44 → 72) · 문서에 형광펜 · 두 요소를 잇는 가는 화살표 + 작은 손글씨 질문 | 설명용 도식을 따로 그림 |
| G7 | **형용사를 화면 상태로 연기** | '천 년 동안 잠들었다가' → 사진이 어두워지고 시계·숫자가 994 → 1,000 · '깨어난다면' → 다시 밝아짐 · '잔인한 신기루' → 파동 오른쪽이 희미하게 사라짐 | 형용사를 글자로 띄움 |
| G8 | **규모는 사람과 나란히, 숫자와 함께 자란다** | 사람 실루엣 옆 종이 더미가 한 장씩 쌓이며 25만 쪽 → 카메라가 더미를 따라 올라가 사람이 작아짐 · 코드 창 '0 → 16만 8천 개 파일' | 숫자를 막대로만 |
| G9 | **바탕의 밝기 = 이야기의 종류** | 수학의 아름다움·추상은 어두운 바탕에 빛나는 선, 역사·증거는 종이 | 장면마다 섞임 |
| G10 | **때·곳 이름표가 한 장 내내 남는다** | '1910년대 초반 · 괴팅겐'이 위에 계속 | 없음 |

**속도:** 새 요소 등장은 짧게(0.3초 안팎), 화면 전체는 거의 쉬지 않고 천천히 흐름(카메라·밀림). 큰 변화는 생각이 바뀌는 곳에서만 — 그래서 '바빠 보이지 않는데 지루하지 않다'.

## 2. 우리가 바꿀 것
1. 대본의 장마다 **판 하나**를 설계한다: 처음 놓을 것 → 문장마다 하나씩 더할 것 → 변할 것 → 카메라가 갈 곳. (`02_script/boards.md`)
2. 전환은 지우고 새로 그리기가 아니라 **카메라 이동·확대·변신**으로.
3. 형용사·동사는 화면 상태로(어두워짐·희미해짐·쌓임·흔들림).
4. 사물은 3D(빛·그림자, docs 기각 비교), 표시는 가는 선·괄호·형광펜·실제 숫자.
