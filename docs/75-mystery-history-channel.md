# 75. 미스터리 역사 채널 — 정체성·형식·첫 시즌 후보 (2026-11-26)

## 0. 한 줄

**"기록은 남았는데, 답은 없다."** — 한국사·세계사·고대사에서 *실제 기록·유물이 남아 있는데도 풀리지 않은* 사건을 그날 그 자리에서 따라가고, 기록이 말하는 것과 말하지 않는 것을 나눠 시청자에게 판정을 넘기는 채널.

**왜 이 선인가 (데이터):**
- 한국어 역사 채널에서 '풀리지 않은·미스터리' 제목은 평소의 3배 이상 터질 확률 13.7%(나머지 10.0%), 영어권 18.2%(13.0%) — 73 §4·74 §1.
- 반대로 '초고대 문명·외계' **주장형**은 평균 아래(한국어 x 0.86) — 74 §1. → **신비함은 '아직 모른다'에서 나오게, '사실은 외계인이었다'에서 나오게 하지 않는다.**
- 터진 미스터리 영상의 공통점: 날짜·장소가 박힌 한 장면 + 상식과 맞지 않는 조각 + 결론 유보(73 P2·P3), 시청자가 직접 가설을 고르는 댓글(74 §3 을지문덕 편).

## 1. 미스터리의 여섯 갈래 (편성할 때 섞는다)

| 갈래 | 시청자가 품는 질문 | 예 |
|---|---|---|
| ① 의문의 죽음 | 누가, 왜? | 소현세자, 단종, 경종, 이순신의 마지막 |
| ② 사라진 것 | 어디로 갔나? | 로마 제9군단, 로아노크 115명, 메리 셀레스트호, 조문국 |
| ③ 읽지 못한 글·풀지 못한 물건 | 무엇이라 쓰여 있나 / 누가 만들었나? | 보이니치 필사본, 선형문자 A, 롱고롱고, 안티키테라 기계, 나스카 지상화 |
| ④ 정체불명 | 그들은 누구였나? | 바다 민족, 을지문덕(기록의 공백) |
| ⑤ 이유 모를 붕괴 | 왜 한꺼번에 무너졌나? | 기원전 1177년 청동기 붕괴, 인더스 문명, 발해 |
| ⑥ 조작인가 진실인가 | 기록을 믿어도 되나? | 정여립 모반, 광개토대왕릉비 변조설 |

## 2. 형식 — 매 편 같은 틀 (시리즈 문법)

| 자리 | 하는 일 | 근거 |
|---|---|---|
| **콜드 오픈** | 사건의 가장 이상한 한 장면을 현재형으로. 인사·채널 소개 없음 | 73 P1 첫 15초 |
| **사건 개요** | 누가·언제·어디서·공식 기록은 뭐라 하나 (30초 안팎) | 시청자가 '무엇이 미스터리인지' 먼저 알아야 따라옴 |
| **단서 1·2·3…** | 장 제목을 '단서 ○ — 장면 이름'으로. 단서마다 ✅ 기록 / 🔍 해석 / 💭 전해지는 이야기 표시 | 73 §5, 74 §3 (시청자가 직접 가설 고르기) |
| **피해자·주인공을 알기** | 왜 이 사람(이 나라)이 문제였나 — 동기의 배경 | 탐정물의 '동기' 자리 |
| **클라이맥스 (60~70%)** | 가장 무거운 단서·사건의 결과 | 73 §4-0 다시 본 구간 |
| **반대 증거** | 일부러 반대편 해석을 세워 저울을 맞춤 | 공정성 — 빼면 '단정 영상'이 됨 |
| **판정** | "기록이 확실히 말하는 것 / 말하지 않는 것 / 해석" → **판정: 미해결** → "여러분은 어느 쪽입니까" | 고정 맺음 — 채널의 표지 |
| **같은 시기의 세계** | 매 편 한 번, 같은 해 다른 대륙(또는 한반도) | 딥 호라이즌 댓글 "같은 시기 한반도와 비교해 줘서 좋다" (74 §3) |

**화면 표지(제안, S5 에서 확정):** 이야기는 한 편 한 화풍의 시네마틱 삽화, 단서가 나올 때마다 **사건 파일 보드**에 사진·문서 조각이 핀으로 꽂히고 ✅/🔍/💭 도장이 찍힘(issues 채널의 '증거판'과 겹치지 않게 종이 파일 질감으로), 판정은 검은 화면 한 줄 "판정: 미해결".
**제목 틀:** `[검색되는 이름] — [가장 이상한 한 장면]` 예) "소현세자의 죽음 — 일곱 구멍에서 피가 흘렀다", "단종의 죽음 — 실록마다 다르게 적힌 마지막 날".

## 4. 하지 않을 것 (미스터리라서 더 조심)
- '사실은 외계인·초고대 문명' 결론, 근거 없는 '은폐' 악당 만들기(73 §5).
- 해결된 사건을 미해결처럼(예: 소머턴 맨). 각 편 S2 에서 "최근에 풀렸나?"를 먼저 확인한다.
- 실존 인물·후손·참전자가 있는 사건(이순신·근현대)은 💭 전설과 ✅ 기록을 화면에서 분명히 나눈다.
- 무서운 분위기는 소리·화면의 어둠으로 — 과장된 말투(억텐)로 만들지 않는다(04 §0-6 ② 3).
