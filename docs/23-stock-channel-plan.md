# 23. 주식 채널 개설 계획 (2026-11-12)

> "매일 주식시장의 변화와 그 변화를 이끈 기사·어닝콜·실적 발표 등을 조사해 현재 상황을 브리핑 — 단순 정보가 아니라 어떻게 연결되고 무슨 의미인지까지.
>  1일 1영상. 장이 열리는 날은 매일 아침 전날 시장 브리핑, 필요할 땐 심층 분석, 주말에는 분석."

## 2. 운영 (1일 1영상)
| 요일 | 영상 | 내용 | 업로드 |
|---|---|---|---|
| 월~금 (장 열리는 날) | **아침 브리핑** 6~8분 | 전날 미국 장 + 전날 한국 장: 지수·업종 → 크게 움직인 이야기 2~3개(이슈·보고서·전망·실적) → **무엇으로 이어지나·무슨 뜻인가** → 오늘 볼 것 | 한국 시간 08시 전후 (미국 마감 06:00, 서머타임 05:00 → 한국 장 09:00 전) |
| 큰 실적·어닝콜·사건이 있는 날 | **심층 분석** 7~10분 (그날의 1편을 대신) | 어닝콜 해부: 숫자·약속 → 경영진이 한 말(원문+번역) → 의미 → 남은 숙제 (manual/03 §0-1) | 같은 날 아침 또는 저녁 |
| 토 | **주간 분석** 8~12분 | 한 주를 움직인 흐름 3개 + 다음 주 일정(실적·지표·연준) | 토 오전 |
| 일 | **분석글** 8~12분 | 산업·테마 하나를 깊게 (공급망·과거 사례·데이터) | 일 오전 |
| 휴장일 | 쉬거나 주간 분석으로 대체 | 미국·한국 휴장 달력 기준 | — |

### 매일 만드는 순서 (manual/03 §0, §0-1)
1. `python -m ytflow daily --project <YYYYMMDD>-market-daily` — 전날 시장 훑기 (지수·업종·큰 움직임·뉴스 원인 분류·주제어)
2. 이야기 2~3개 고르기 → 원인마다 1차 출처 확인 (회사 발표·공시·보고서·연준) → 팩트시트에 `## 해석`
3. 어닝콜이 있으면 `python -m ytflow earnings-call <프로젝트> <공식 녹취록>` → 경영진의 말 원문+번역
4. 대본(`hybrid.json`, `brand: market`) → `check` → `hybrid` 렌더 → 프레임 확인 → 업로드 패키지(제목 3·썸네일 3)

### 지킬 것
- 투자 권유 금지(자동 검사), 장중 값을 마감으로 말하지 않기, 기준 시각 밝히기, 확인 안 된 원인 단정 금지, 사실과 해석 구분.
- 화면: 시장 카테고리 개성(대시보드·듀오톤 사진 표지, 관계는 증거판), 영상 전체에 같은 패턴 반복 금지(05 §0-3).
