### 브리핑이냐 심층이냐 — 매일 주제로 정함 (고정 아님, 사용자 판정 2026-11-12)
심층은 요일·이벤트로 정하지 않고 **그날 주제가 얼마나 복잡한가**로 정합니다. 아래 중 **둘 이상**이면 심층:
| 신호 | 예 |
|---|---|
| 원인이 여러 갈래로 얽힘 (원인 종류 2개 이상: 이슈+실적, 실적+전망 …) | 실적 발표 + 같은 날 규제 뉴스 |
| 시장 전체를 움직인 한 사건 (지수·업종이 한 이야기로 크게 움직임) | 반도체 지수 ±5% 이상이 한 회사 실적에서 |
| 경영진·당국의 긴 설명이 핵심 (어닝콜·연준 기자회견·정부 발표) | 어닝콜에서 가이던스·자금 계획이 바뀜 |
| 며칠째 이어지는 이야기의 전환점 | 연속 보도된 사건에 결정·발표가 나옴 |
| 한국 시장에 직접 번지는 연결 고리가 김 | 미국 실적 → 공급망 → 한국 반도체 |
`python -m ytflow daily` 가 이야기마다 `depth`(브리핑/심층 후보)와 그 이유를 적어 줍니다 — 최종 판단은 사람이.
심층인 날에도 1일 1영상: 앞부분 1분에 전날 시장 요약(지수·업종)을 넣고 본론을 심층으로.

### 매일 만드는 순서 (manual/03 §0, §0-1)
1. `python -m ytflow daily --project <YYYYMMDD>-market-daily` — 전날 시장 훑기 (지수·업종·큰 움직임·뉴스 원인 분류·주제어)
2. 이야기 2~3개 고르기 → 원인마다 1차 출처 확인 (회사 발표·공시·보고서·연준) → 팩트시트에 `## 해석`
3. 어닝콜이 있으면 `python -m ytflow earnings-call <프로젝트> <공식 녹취록>` → 경영진의 말 원문+번역
4. 대본(`hybrid.json`, `brand: market`) → `check` → `hybrid` 렌더 → 프레임 확인 → 업로드 패키지(제목 3·썸네일 3)

### 지킬 것
- 투자 권유 금지(자동 검사), 장중 값을 마감으로 말하지 않기, 기준 시각 밝히기, 확인 안 된 원인 단정 금지, 사실과 해석 구분.
- 화면: 시장 카테고리 개성(대시보드·듀오톤 사진 표지, 관계는 증거판), 영상 전체에 같은 패턴 반복 금지(05 §0-3).
