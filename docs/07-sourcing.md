# 07. 벤치마킹 채널은 소스를 어떻게 찾나 (2026-11-06)

각 채널 최근 영상 12편의 **설명란(출처 목록·챕터)** 과 자막을 모아 봤습니다(yt-dlp 메타데이터 조회, 영상 다운로드 없음).
결론: 네 채널 모두 **소스가 먼저이고 편집은 그 소스를 보여 주는 방식**입니다. 다만 출발점이 다릅니다.

| 채널 | 출발점 | 편당 소스 | 대표 소스 | 편집이 소스를 따라가는 방식 |
|---|---|---|---|---|
| 식스시그마 | **인물의 원본 발언 영상** | 원본 1~4개 + 자료 5~15개 | CNBC Television·블룸버그·폭스 비즈니스, 회사 IR 실적 콜(알파벳), 투자사·기관 공식 채널(브리지워터, 노르웨이 국부펀드, Fed FOMC), 대학 강연(콜럼비아), 팟캐스트(Invest Like the Best, Excess Returns) | 발언 구간을 그대로 틀고 자막 → 그 말을 공시·데이터로 확인하는 카드 |
| 미주일기 | **1차 문서** (연구·논문·공식 발표) | 주요 자료 2~4개 + CC 사진 5~10장 | 앤스로픽·딥마인드·OpenAI 연구 페이지와 PDF, arXiv·NBER·Science, IR 보도자료, SEC 상장신고서, php.net·AWS 보안 공지, IMF, 인물의 X 게시물 | 문서의 개념을 손그림 도식으로, 인물·장소는 위키미디어 공용 CC 사진 콜라주 |
| 머니크루 | **숫자 계열** (직접 계산) | 시세·통계 + 과거 사례 | 일봉 데이터로 대가 20명 규칙을 2,930개 종목에 돌려 봄, 공급×수요 곱셈, 1970년대 원전·2000년대 가스터빈·메모리 30년 사이클 | 계산 결과를 차트·막대로, 끝에 "오늘 남는 세 가지 / 앞으로 볼 신호(날짜)" |
| AI비즈PT | **해외 창업자 사례** | 인터뷰·팟캐스트·블로그 | 창업자가 공개한 매출 숫자, 팟캐스트 인터뷰 | 한 사람의 이야기 순서대로 |

## 식스시그마: 발언 원본 → 확인 (원본 소스형 채널 `ch-source-brief`)
설명란 형식이 일정합니다.
```
[원본]
1. CNBC Television – Fundstrat's Tom Lee: Today looks like someone's getting liquidated (2026.10.30, Power Lunch) https://youtube.com/…
2. Alphabet Investor Relations 공식 유튜브, Alphabet 2026 Q3 Earnings Call (2026.10.28)
[자료] / [숫자 출처]
알파벳 3분기 실적 보도자료·실적 콜 녹취, 넷플릭스 10-Q(SEC), FRED, 야후 파이낸스 종가, 트렌드포스 시세 …
```
- **원본은 '말한 사람 본인 또는 방송사·주최 기관의 공식 채널'** 입니다. 다른 해설 유튜버의 영상은 쓰지 않습니다.
- **최근 1~10일** 안의 발언입니다(10/30 발언 → 10/31 영상).
- **말을 공시로 바로잡습니다:** "애크먼이 '3% 정도'라고 기억한 넷플릭스 자사주 매입은 10-Q 의 실제 숫자(분기 초 주식의 약 1.5%, 48억 달러)로 바로잡았습니다."
- **틀릴 조건을 적습니다:** "발사비가 500달러 아래로 내려오면 강세론이, 2035년에도 200달러 위면 신중론이 맞습니다."
- 제목: `주장 | 인물` (예: "재무장관이 AI 빚을 걱정하지 않는 이유 | 스콧 베선트").

## 미주일기: 1차 문서 → 개념 칼럼 (칼럼형 채널 `ch-paper-column`)
```
주요 자료
- 앤스로픽, The AI expectations gap (2026-10-16) · https://www.anthropic.com/research/…
- Imas·Koh·Legg, Organizing Intelligence (Google DeepMind, 2026-10-29) · PDF
사진 출처 및 이용 조건
- Dario Amodei at TechCrunch Disrupt 2023 · TechCrunch · CC BY 2.0 · commons.wikimedia.org/…
```
- 문서 2~4개로 **하나의 질문**을 깊게 팝니다(챕터 5~7개, 장 제목이 질문).
- 사진은 **위키미디어 공용의 CC 라이선스 사진만** 쓰고, 저작자·라이선스를 설명란에 모두 적습니다.

## 머니크루: 숫자 계열 → 계산 (데이터형 채널 `ch-data-motion`)
- "말 대신 곱셈으로 봅니다", "대가 스무 명의 규칙을 2,930개 종목 실제 일봉에 올려 봤습니다" — **직접 계산한 결과가 소스**입니다.
- 과거 비슷한 시기를 같은 틀로 맞댑니다(메모리 30년 다섯 번의 붕괴, 1970년대 원전).
- 끝: "오늘 남는 세 가지", "앞으로 볼 신호(날짜)".

## ytflow 에 반영한 것
| 반영 | 어디 |
|---|---|
| **소스 먼저 단계 `scout`**: 트렌드 → 화제별 소스 찾기 → 소스가 강한 주제를 고름 | `ytflow/stages/scout.py`, `prompts/scout.md` |
| 채널마다 출발점: statement / document / data / repo / queue | `channels/<id>/channel.yaml` 의 `sourcing` |
| 원본 소스형: CNBC·블룸버그·야후·폭스 비즈니스 공식 채널의 최근 10일·4분 이상 영상 목록을 먼저 훑음 | `sourcing.video_channels` |
| 칼럼형: 인물·장소 사진을 위키미디어 공용 CC 사진으로 받아 콜라주, 저작자 표기 | `scout.commons_photos`, clips 단계 |
| 소스 목록(S번호) → 원고·대본이 이 목록으로 장면을 짓고(`source_ref`), 편집 스타일은 그 위에 얹음 | `00_source/inventory.md`, `prompts/script*.md` |
| **형식 판단**: 서술할 내용이 많은 분석 → 롱폼, 한 가지 안내 → 쇼츠 (다른 형식 소재는 맞는 채널 대기열로) | `select`, `channels/<id>/queue.md` |

## 이 환경의 한계
- YouTube 는 이 클라우드에서 **자막·영상 다운로드를 봇 확인으로 막습니다**(목록·제목·설명 조회는 됨). 우회하지 않습니다.
  - 원본 발언의 정확한 구간은 사용자 PC 의 `rebuild` 가 자막을 받아 맞춥니다.
  - 공식 녹취(실적 콜 녹취, CNBC 녹취록, 대학 녹취 PDF)가 있으면 그것으로 먼저 확인합니다.
  - 이 세션에 연결된 vidIQ 의 자막 도구(`vidiq_video_transcript`, 1회 5크레딧)로 받을 수도 있습니다 — 크레딧이 들어 사용자 승인 후에만.
