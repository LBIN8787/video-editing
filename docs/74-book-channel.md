# 74. 책 채널 — 인기 북튜버의 형식·대본·스토리텔링 (2026-11-27)

사용자: "책 리뷰채널을 만들려고 해 … 어떤 책 리뷰채널의 대본과 편집스타일이 인기가 많은지 … 핵심은 스토리텔링 능력이야" → 다섯 형식 중 **"2와 3으로"**.

## 3. 고른 형식: ② 질문형 + ③ 다큐형

> **2026-11-27 바꿈:** §8 조회수 분석에 따라 ③ 다큐형(과학)을 **③ 명작 서사형**(소설·고전을 주인공의 마음을 따라 결말까지, 10~20분)으로 바꾸고 주력으로 둠. ② 질문형은 독서·뇌·심리·습관 주제로 좁힘. 사용자: "그대로 고쳐주세요". 아래 표는 처음 고를 때의 기록.
**왜 이 둘인가:** 얼굴 없이 만드는 우리 체계(삽화·모션그래픽·실제 자료, 호기심 채널 문법)와 그대로 맞고, 둘 다 '책 소개'가 아니라 '이야기'가 뼈대라 사용자가 말한 핵심(스토리텔링)과 같은 방향입니다.

| | ② 질문형 | ③ 다큐형 |
|---|---|---|
| 맞는 책 | 심리·자기계발·행동경제 (시청자의 행동과 닿음) | 과학·역사·인물 (사건·발견이 있음) |
| 여는 것 | 시청자의 질문 | 가장 놀라운 장면·사실 |
| 주인공 | 시청자를 대신하는 인물 + 연구자 | 발견한(겪은) 사람 |
| 책의 자리 | 답의 근거 | 이 이야기를 쓴 책 |
| 위험 | 처방 나열(자기계발 요약)로 흐름 | 사실 나열(위키 낭독)로 흐름 |
| 대응 | 핵심 하나·행동 하나, '틀리는 경우' 박자 | 한 줄기 이야기, 막마다 다음 질문 |

대본 뼈대는 `prompts/script_books.md`, 채널 설정은 `channels/ch-books/channel.yaml`.

## 4. 스토리텔링 — 잘되는 채널의 공통점
1. **질문으로 연다** — "이 책은"이 아니라 "왜 나는". 책은 도구.
2. **요약보다 번역** — 시청자의 세계(직장·게임·시사)로 옮김. 정지 화면 낭독은 오디오북과 다를 바 없다는 지적.
3. **주인공** — 정보를 사람의 사건으로.
4. **긴장 반복** — 설정 → 긴장 → 답을 1~2분마다, 첫 질문의 답은 끝에.
5. **책을 집게 하는 결말** — 다 말하지 않고 읽을 대목 하나를 남김 (겨울서점식, 신뢰 + 구매 전환 '유튜버셀러').

## 5. 기존 체계와 연결
- 연출: 호기심 채널과 같은 hybrid(이야기 삽화·설명 모션그래픽·증거 실제 자료). ③ 다큐형의 도입·과정은 archive(켄 번스·날짜 도장)·story-board 도 후보.
- 매뉴얼: 별도 책 매뉴얼은 아직 없음 → 우선 `manual/04-curiosity.md` 문법(주인공 한 명, 수미상관, 대본 먼저 검토)을 따름. 채널이 굳으면 `topics/books/` 주제 레포를 잠금 잡고 만듦(지금은 실험이라 만들지 않음).

## 6. 주의
- **저작권:** 본문 낭독·긴 인용 금지, 짧은 인용과 다시 쓴 설명. 표지는 출판사 공개 자료.
- **협찬 고지:** 북튜브 협찬 미고지가 비판받는 관행 → 첫머리·설명란 고지.
- **책의 주장 검증:** 자기계발·심리 책은 재현 실패 연구가 많음 → '틀리는 경우' 박자에서 정직하게.

## 8. 조회수 기준 다시 보기 — 구독자보다 많이 본 영상 (2026-11-27)
사용자: "단순 구독자가 많은 채널보다 조회수가 높은 영상을 바탕으로 … 공통분모 어떤 주제와 어떤 영상템플릿이 조회수가 높은지".

**방법:** 책 관련 검색어 22개(책 리뷰·추천·요약·인생책·줄거리·오디오북·심리학 책 …) × 50편 → 863편·384채널. 채널마다 구독자 수와 최근 40편 조회수 중앙값을 받아, 영상마다 **구독자 대비**(조회수 ÷ 구독자)와 **채널 평소 대비**(조회수 ÷ 채널 중앙값)를 계산. 롱폼(3분+)·구독자 1천+·조회 5천+, 영화 리뷰·동화·게임은 뺌 → **649편**. 형식·주제는 제목 낱말로 나눔(근사). 상위 12편은 자막·스토리보드(미리보기 격자)로 화면과 첫 1분 대본 확인. 원자료는 커밋하지 않음(타 채널 자료).
**한계:** 검색 결과라 이미 잘된 영상 쪽으로 쏠림(그래서 전체 중앙값도 평소 대비 3.3배). 절대값보다 **형식·주제끼리의 차이**를 봄.

### 8-4. 공통분모 — 시청자가 좋아하는 것
1. **이야기를 끝까지 들려주는 영상.** 책 '소개'보다 줄거리·결말을 **읽은 것처럼** 경험하게 하는 형식이 구독자 대비 가장 높음. 시청자가 원하는 건 평가가 아니라 이야기.
2. **소설·고전을 인물의 마음으로 읽기.** 소설·문학이 구독자 대비 1위, 심리를 얹으면(주인공 심리) 평소 대비 16배. 철학도 이야기로 풀 때(5.2) 강함.
3. **장면이나 질문으로 연다.** 상위 영상 대부분이 첫 문장에서 장면("도쿄의 거리…") 또는 시청자의 질문으로 시작하고 책 제목은 그 뒤.
4. **얼굴 없이 장면 삽화 + 자막**이 작은 채널의 대박 공식. AI 삽화(애니풍·실사풍)를 박자마다 바꾸고 내레이션. 구독자 1천~6천 채널이 10만+ 를 냄.
5. **10~20분.** 질문형·서사형 모두 이 길이에서 평소 대비가 가장 높음.
6. **질문형은 '독서·뇌·습관' 주제에서만 강함** — 시청자 자신의 고민이 곧 주제일 때.

### 8-5. 앞서 고른 ②·③ 에 미치는 영향
- **② 질문형:** 유지. 다만 주제를 독서법·뇌·심리·습관 쪽으로(데이터상 강한 곳).
- **③ 다큐형(과학 책):** 과학이 가장 약한 주제(구독자 대비 0.56). → **명작 서사형**(소설·고전을 주인공 한 명의 마음을 따라 결말까지 들려주는 10~20분 이야기, 장면 삽화 + 내레이션)으로 바꾸는 것을 제안. 데이터상 가장 강하고, 스토리텔링이 곧 상품이며, 우리 삽화·이야기 그림판 체계와 그대로 맞음.
- **주의:** 드라마·영화 장면 짜깁기(삼체), 본문 전문 낭독(수면 오디오북)은 권리 문제 → 우리는 자체 삽화와 다시 쓴 서사로. 결말까지 다루는 편은 제목·첫머리에 '결말 포함' 표시.
