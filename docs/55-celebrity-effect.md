# 55. 유명 인물 효과 — 시장 채널에서 '아는 사람'이 나오면 더 터지나 (2026-11-20)

> 사용자 (2026-11-20): "이 시장 관련해서 말이야 보면 유명인사가 썸네일에 나오거나 유명인사를 다룬 주제 내용들이 조회수가 높은 것 같은데 이 특징들을 조사하고 이를 반영해서 분석하고 썸네일이랑 썸네일 제목 생성에 고려해줘"

## 0. 결론
**유명인이면 무조건 터지는 것은 아니다. '누가, 어떤 자리로' 나오느냐가 갈랐다.**
1. **사건의 당사자인 기업가·투자 대가**는 같은 채널 안에서 확실히 더 봤다. 빅테크 CEO 가 제목에 나온 영상의 중앙 배수 **1.54배**(34편), 그중 젠슨 황 **2.26배**(16편), 일론 머스크 2.25배. 투자 대가·책 저자(모건 하우절·나발 라비칸트·빌 게이츠)는 표본은 작지만 터진 비율 20%, 안 된 비율 0%.
2. **정치인을 배경으로 붙인 제목은 오히려 덜 봤다.** 정치 지도자 96편(그중 트럼프 89편)의 중앙 배수 **0.82배**, 터진 비율 3%(전체 평균 12%). 트럼프가 거의 모든 시황 제목에 들어가 '또 그 얘기'가 된 것으로 보인다. 정책 결정자(파월·워시)도 0.94배.
3. 그래서 인물이 나온 제목 전체(152편)를 묶으면 보통 제목과 중앙 배수가 같다(1.0배). 다만 **크게 망하는 비율은 인물 쪽이 낮다**(14% vs 21%) — 아는 얼굴은 바닥을 받쳐 준다.
4. **썸네일 얼굴은 크게.** 인물이 제목에 나온 영상 중 터진 영상의 **42%** 가 썸네일에 큰 얼굴(화면의 8% 이상)을 썼고, 안 된 영상은 **10%** 뿐이었다(전체로도 터진 18% vs 안 된 10%).
5. 잘 된 제목의 모양: **인물 + 그 사람의 결정·말 + 숨은 계산 / 내 계좌로 번역.** "일론 머스크가 말한 미래 30가지, 한국 주식으로 바꾸면 이 28개"(8.2배), "케빈 워시가 흘린 '진짜 신호'"(3.5배), "젠슨 황 사임에 흔들린 엔비디아, 반사이익에 AMD·브로드컴 5% 급등"(2.6배).
   안 된 모양: 인물이 **배경**이고 이야기는 속보·일정("트럼프 '14일 이란과 합의'" 0.18배, "트럼프, 한국 관세 25% 인상 위협 - 오늘장 이슈 5가지" 0.30배).
6. 가장 많이 터진 인물 영상 몇 편은 **사생활 소재**(불륜설)였다. 우리는 쓰지 않는다(영구 원칙 — 사생활, manual/README §3). '큰 인물 + 숨은 계산' 구조만 가져온다.

## 1. 방법
- 자료: `scripts/thumb_research.py --per 200` — 시장·경제 해설 개인 채널(검색 12개 + 벤치마크 9곳) **27곳, 최근 영상 4,807편**(쇼츠 제외, 영어 개발 채널 제외).
- **배수 = 조회수 ÷ 그 채널 최근 영상 중앙값.** 같은 채널끼리 비교해 구독자 수 차이를 지움. 터진 = 3배+, 안 된 = 0.5배 이하.
- `scripts/celeb_research.py` — 제목에서 이름 사전(빅테크 CEO·투자 대가·정책·정치·한국 재계·역사 인물, 약 120개 표기)으로 인물을 찾고 갈래별로 비교. 썸네일은 터진·안 된 영상 1,540장에서 얼굴 수·크기를 잼(opencv). 원자료는 `.cache/thumbs/2026-11-20/` (타 채널 자료라 커밋 안 함).
- 한계: 이름 사전에 없는 인물은 '인물 없음'으로 셈. 얼굴 검출은 진행자 얼굴과 유명인 얼굴을 구분하지 못함(진행자 채널이 섞임). 표본이 작은 갈래(투자 대가 10편·역사 인물 3편)는 방향만 참고. 상관이지 인과가 아님.

## 3. 이어 읽는 시장에 적용 (manual/09 §7-1, prompts/thumbnail.md)
1. **당사자가 있는 사건이면 그 사람을 앞에.** 결정·발언·퇴진·상장처럼 한 사람의 행동이 사건의 중심이면 — 제목 앞 20자 안에 이름, 썸네일 A 는 그 사람 얼굴을 크게(`layout: person`). 기업가·투자 대가·중앙은행 수장 순.
2. **정치인을 장식으로 붙이지 않는다.** 트럼프·시진핑 등은 그 사람의 결정이 이야기의 축일 때만(관세 결정이 그 회사 실적을 바꿨다 등). 시황에 이름만 얹은 제목은 덜 본다.
3. **인물 + 숨은 계산 / 내 계좌로 번역.** "○○가 말한 □□, 한국 주식으로 바꾸면" · "○○의 결정 뒤에 숨은 숫자". 사람 이름만 있고 무엇을 약속하는지 없는 제목은 효과가 없다.
4. **사진은 권리가 확인된 것만** — 위키미디어 공용 PD·CC0·CC BY(`python -m ytflow archive commons "이름"`), 출처를 썸네일에 작게 적음(CC BY 표시 의무). 뉴스 사진·방송 캡처는 쓰지 않음(manual/09 §13). 사진이 없으면 인물 썸네일을 만들지 않고 숫자 대비(versus)로.
5. **사생활·소문은 쓰지 않는다**(영구 원칙). 인물의 공개 발언·공식 행동·회사의 결정만.
6. **썸네일 얼굴 크기**: 휴대폰 목록에서도 누구인지 보이게 얼굴이 화면 높이의 40~50%(썸네일 점검 `face_area` ≥ 0.06).

## 4. 다시 하기
```bash
python scripts/thumb_research.py --per 200      # .cache/thumbs/<날짜>/videos.json + img/
python scripts/celeb_research.py                # 같은 폴더 celeb.json + 콘솔 표
```
`opencv-python-headless<5` 가 필요(얼굴 크기, 조사용).
