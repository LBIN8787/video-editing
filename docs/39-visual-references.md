## 2. 화풍 계열 — 무엇이 어떤 목적에 맞나
| 화풍 | 특징 | 맞는 곳 | 우리에게 |
|---|---|---|---|
| **플랫 2D** | 그라데이션·질감을 빼고 모양·실루엣·색으로 승부, 부품 재사용 쉬움 ([atlabs](https://www.atlabs.ai/ko/스타일/flat-2d-modern), [moonb 스타일 12](https://www.moonb.io/blog/animation-styles)) | 정보형 설명 | AI·시사의 도식·차트. **단, 모양 언어(각/둥근)·팔레트를 디자인해야** 클립아트를 벗어남 |
| **2.5D·패럴랙스** | 평면 그림을 층으로 나누고 카메라가 사이를 지나가며 깊이 흉내 ([moonb 2.5D](https://www.moonb.io/blog/2-5d-animation)) | 분위기·장소·역사 장면 | 호기심의 '1877년 파리' 같은 장면. 그림 1장 + 레이어 분리로 가능 |
| **컷아웃·종이 콜라주** | 종이 조각이 층으로 움직임, 스캔한 자료와 섞음 ([moonb 설명형 8스타일](https://www.moonb.io/blog/animated-explainer-video)) | 이야기·역사, 사진 자료가 있을 때 | 호기심·시사에 잘 맞음. 공공 기록 사진(PD) + 종이 질감 |
| **아이소메트릭** | 정육면체 시점의 작은 세계 | 시스템·공급망·도시 | 시사(반도체 공급망)·AI(결제 흐름) 한 장면용. 제작 부담 큼 |
| **손그림·화이트보드** | 선이 그려지며 설명 | 개념 설명 | 이미 미주일기·story-board 계열. 선의 질(굵기 변화·떨림)이 관건 |
| **레트로·바랜 색** | 낮은 채도, 굵은 외곽선, 오래된 교육 영상 느낌 | 호기심·역사 | 호기심 채널 정체성 후보 |

**채널별 1차 제안:** 호기심 = 2.5D 패럴랙스 + 컷아웃(레트로 색) / 시사 = 컷아웃 콜라주(자료 사진) + 정돈된 플랫 도표 / AI = 실제 화면 캡처 + 플랫 UI 도식(사람 그림 최소).

## 4. 생성형으로 화풍을 고정하는 자료
- **[Futurepedia AI Style Atlas](https://www.futurepedia.io/resources/ai-style-atlas)** — 설명형 애니메이션 86개 화풍(수채·화이트보드·클레이·블루프린트·Manim 수학 등 14계열)을 같은 15초 주제로 미리 보기, 각 화풍의 Claude 프롬프트(HTML 한 파일로 애니메이션) 제공. 3D 37개는 [별도](https://www.futurepedia.io/resources/3d-style-atlas). **우리 HyperFrames(HTML→MP4) 흐름과 같은 방식**이라 화풍 비교표로 가장 바로 쓸 만함. 다만 코드로만 그린 화풍은 docs/38 의 '도형 모음' 한계를 그대로 가질 수 있어, 화풍 '고르기'에 쓰고 그림 자체는 §3·생성 이미지로.
- **인물 일관성** — 정면·측면·뒷면 시트를 먼저 만들고 장면마다 참조로 ([fal.ai](https://fal.ai/learn/tools/ai-character-consistency), [Scenario](https://help.scenario.com/en/articles/generate-character-turnarounds/), [Lemonlight](https://www.lemonlight.com/blog/how-to-create-consistent-ai-characters/)).
- **Midjourney 스타일 코드(sref)** — 플랫 벡터·에디토리얼 화풍 묶음이 공유됨 ([Underwood Xie](https://underwoodxie.substack.com/p/3-flat-vector-sref-codes-for-cleaner), [Moodboard](https://moodboard.beehiiv.com/p/10-midjourney-style-codes-you-can-copy-paste)). 모델 버전마다 결과가 달라 직접 시험 필요, Midjourney 는 유료.
- **부품 나누기** — Qwen-Image-Layered(그림 1장 → 투명 레이어 여러 장, fal.ai 약 $0.05) · **벡터로 생성** — Recraft V4 Vector($0.08/장). docs/38 §2.
