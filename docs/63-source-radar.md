# 63. 원본 레이더 — 사람의 말·큰 날 추적 (2026-11-23)

> 사용자: "우리도 사람의 말이나 사건형 원본형처럼 이를 추적할 수 있었으면 해요"

## 왜
식스시그마·월가인사이드·월터의 월가노트(이번 주 같은 소재로 26만~72만 회)를 보면 소재의 출발점은 지표가 아니라 **이름 있는 사람의 말**이고, 올리는 때가 둘로 나뉩니다.

| 형 | 언제 | 무엇을 | 예 |
|---|---|---|---|
| **원본형** | 거물의 인터뷰·팟캐스트·행사 발언이 **공개되고 2~9일 안** | 그 원본 한 편을 깊게 (원문 해부 → 한국 계좌로 연결) | 식스시그마 팔란티어 CEO 편 12만 · 월가인사이드 드러켄밀러 편 28만(원본 공개 다음 날) |
| **사건형** | 지수가 **±3% 넘게** 움직인 **다음 24~48시간** | "이름 있는 사람들은 뭐라 했나" 여러 명 | 월가인사이드 〈금요일 급락 뒤 월가 10명〉 72만 · 월터의 월가노트 45만 |

우리 드러켄밀러 편은 같은 원본을 **나흘 늦게** 올려 1,530회였습니다(월가인사이드 28만). 레이더는 이 '늦음'을 없애기 위한 것입니다.

## 쓰는 법
```bash
python -m ytflow radar                         # 매일 아침 daily 전에 (약 5~8분, 영상은 내려받지 않음)
python -m ytflow radar --people 드러켄밀러,젠슨   # 몇 사람만
python -m ytflow radar --no-kr                 # 국내 해설(경쟁) 확인 생략
python -m ytflow radar --mark <영상id> made|skip|watch   # 만들었음·안 함·지켜봄
```
결과: `inbox/radar/<날짜>.md`(사람이 읽음) · `<날짜>.json` · `tracker.json`(원본마다 처음 본 날·상태). `daily` 를 돌리면 `daily_brief.md` 맨 끝에 **⓪ 원본 레이더** 판단 줄이 붙습니다.

## 무엇을 보나
1. **사람** — `config/ceo_watch.yaml` 의 CEO·투자자·중앙은행 + `config/radar.yaml` 의 `extra`(손정의·베센트·테퍼 등). 사람마다 무게(`weight`, 기본 2·거물 3).
2. **원본 찾기** — 사람마다 YouTube '이번 주' 검색 결과 목록. 원본다움 점수:
   - 방송·행사·팟캐스트·회사 공식 채널(`originals`) +3, 인증 채널 +1, 제목의 interview·summit·keynote 등 +1
   - 해설 말투(just sold·here's what…) −2, 한국어·다른 나라 말 제목(남의 해설) 제외, 'A on B'(남이 그 사람을 말함) −2, 옛 영상 재업로드(제목 연도) −3
   - 성만 맞는 제목은 원본 채널일 때만(같은 성의 다른 사람 방지). 2점 이상만 후보.
3. **점수** = 사람 무게 × 새로움(공개 0~1일 1.0 → 9일 0.5) × 조회(이미 찾는 사람이 많은가) × 원본다움.
4. **국내 해설** — 그 사람 한국어 이름으로 이번 주 검색: 몇 편, 최고 조회, 경쟁 채널(`competitors`) 이름.
   - 0편 → **선점** · 이미 크게 터짐 → 같은 말 반복 대신 **다른 각도**(원문 해부·한국 계좌 연결·다른 대목).
5. **큰 날** — `event_indices`(반도체·나스닥·S&P·코스피·코스닥)의 마지막 거래일 등락이 ±3% 넘으면 사건형 먼저, 무게 2.5 이상 사람의 지난 36시간 발언 보도 제목을 단서로.
6. **마감** — 공개 +3일까지 '좋음', +9일 넘으면 '늦음'.

## 지키는 것
- 레이더 결과는 **단서**입니다. 대본의 발언은 원본 영상·공식 기록에서 직접 확인하고 인용은 짧게(한 장면 20초·한 편 60초 안팎, manual/09 §3-5).
- YouTube 봇 확인·차단은 우회하지 않고 그 사람을 건너뜁니다. 영상·음성은 받지 않습니다(목록·정보만).
- 사생활 보도는 소재로 쓰지 않습니다(ceo_watch 규칙).
- 레퍼런스 채널의 대사·썸네일은 베끼지 않고, '언제·누구의 말을 고르나'만 가져옵니다.

## 한계
- '이번 주' 검색 필터라 7일 넘은 원본은 추적표(tracker)에 남은 것만 보입니다.
- 원본 채널 목록은 사람이 늘려 갑니다(`config/radar.yaml` → `originals`). 목록에 없는 공식 채널은 인증+행사 말로만 잡힙니다.
- 조회수는 수요 신호일 뿐 — 주제·시점·구독자 영향이 섞여 있습니다.
