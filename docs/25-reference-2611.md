## 5. 사용자 피드백 (2026-11-13): "요약문 느낌 — 폴더·스킬·스크립트 같은 애니메이션이 적다"
두 레퍼런스의 핵심은 **요약 카드가 아니라, 대본의 낱말을 말하는 순간 그 사물이 생기고·열리고·날아가고·도는 것**이다(빠른 템포).
→ **모션 무대** `ytflow/stages/motion2.py` 추가 — 박자 음성을 받아쓰기해 **낱말 단위 시각**에 사물을 움직인다. 훅 쇼츠·뉴스 데스크 카드 둘 다에서 박자에 `motion` 을 쓴다.

| 동작 `do` | 화면 | 쓰는 말 |
|---|---|---|
| `folder` | 폴더가 튀어나와 뚜껑이 열림 | "폴더", "모음", "프로젝트" |
| `file` (`from`) | (폴더에서) 문서가 날아 나와 줄이 써짐 | "문서", "SKILL.md", "보고서" |
| `gear` (`from`) | 톱니가 날아 나와 계속 돎 | "스크립트", "자동", "도구" |
| `icon` | 동그란 아이콘이 튐 (색 `bg`) | 사람·회사·기능 이름 |
| `arrow` (`a`→`b`) | 두 사물 사이에 휜 화살표가 그려짐 | "꺼내", "옮겨 갔다", "이어진다" |
| `count` | 숫자가 0에서 올라가고 반짝임 | 숫자 |
| `type` | 터미널에 명령이 한 글자씩 쳐짐 | "한 줄", "입력" |
| `check` (`on`) | 초록 체크 도장 | "끝", "전부", "확인" |
| `pulse` / `out` | 한 번 커졌다 돌아옴 / 사라짐 | 강조 / 퇴장 |
들어온 사물은 살짝 떠 있음(정지 방지), 사물이 나올 때 pop·whoosh 효과음(작게).

시험작 다시: `20261113-style-hookshort`(25초, 박자 10개 — 폴더→SKILL.md→톱니→클로드로 화살표, 아이콘 3개→체크 3개, 터미널 타자→체크),
`20261113-style-ref2` 2번 카드(돈 아이콘에서 AMD·브로드컴으로 화살표, 반도체 지수 체크).

## 6. 스타일별 장단점 한눈에
| 스타일 | 장점 | 단점 | 쓰는 곳 |
|---|---|---|---|
| **뉴스 데스크 카드** (+모션) | 한 소식 = 한 장으로 빨리 만들고 한눈에 이해, 출처 항상 보임, 남은 개수 보임 | 카드만 이어지면 지루(→ 모션·다른 장면 섞기), 인과를 그리기 어려움, 글자 많음 | 주간 소식 정리(시장 토요일·AI 위클리), 브리핑의 소식 2~3개 |

## 8. 최종 방향 (2026-11-13 사용자): "한눈에 — 중요 내용을 정리(요약)하고, 애니메이션·그림을 덧붙여 혼용"
요약 장면(체크리스트·대결·막대)을 **바꾸지 않고 뼈대로 두고**, 그 위에 말에 맞춰 생기는 사물을 겹친다.
- **어느 장면이든** 박자에 `motion` 을 쓰면 겹쳐진다 (`motion2.apply`, 색은 그 장면의 그래픽 팩).
- **체크리스트:** `"x": 150, "text_w": 860~880` 으로 글을 왼쪽으로 좁히고 오른쪽(x 1400~1780)에 사물. 줄마다 `"t": "핵심 낱말"` → 그 낱말을 말할 때 줄이 나타남. 확인된 줄(`state: ok`)은 체크 표시.
- **대결·막대처럼 그림이 있는 장면:** `do: "anchor"` 로 기존 그림 위치(막대 위 등)를 기준점으로 등록 → 돈이 날아가는 화살표를 그 사이에.
- 시험 (11/13 비교판 v2): #5 공시 4가지 + 'CEO 자리 ← 크레스'·의장·후보 아이콘 / #9 대결 막대 + 엔비디아 막대에서 AMD·브로드컴으로 돈 화살표 / #14 네이버 3줄 + 매출 숫자 세기·6분기·물음표.
- 측정: 화면 전체 변화량은 기존과 비슷(3.4→3.4, 5.2→5.2, 2.1→4.2) — 요약 화면은 차분하게 유지되고, 움직임은 말하는 순간 오른쪽 일부에서만 생긴다(v1 처럼 화면 전체가 바뀌지 않음).
