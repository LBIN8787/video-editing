## 1. 1분코딩 — 「Claude 5시간 제한 끝·Codex 12월부터 한도 한 통 | 이번 주 AI 뉴스 13가지」 (롱폼)
https://youtu.be/LxonB5WnVVU · 채널 @illbuncoding

### 관찰 (프레임 4장)
| 요소 | 무엇 |
|---|---|
| 틀 | 어두운 바탕(#0E0F11 근처) 위 **모든 소식이 같은 틀** — 위 왼쪽 `NEWS 2 / 7 — OPENAI`(순번·전체·출처 회사), 위 오른쪽 채널 칩(`1분코딩 WEEKLY`), 위 가장자리 노란 진행 막대 |
| 왼쪽 글 블록 | 색 꼬리표(주의=빨강·사례=초록·지금 할 일=노랑) + 날짜 → **큰 제목, 핵심 낱말만 노란색** → 한 줄 요약 → **숫자 3칸**(작은 이름표 + 큰 색 숫자: '변화 없음/인증 계정/5시간 유지') → 노란 네모 점 목록 1~2개 |
| 오른쪽 증거 패널 | 하나만: ① 기사·공식 문서 원문 캡처(흰 종이, 살짝 기울임, 아래 출처) ② 큰 숫자 하나(`6,454`) ③ 도장(`월말에 안 막힌다`, 초록 테두리 기울임) |
| 아래 | 가운데 자막(짧은 한 줄), 왼쪽 `출처: …`, 오른쪽 채널 주소 |
| 썸네일 | 픽셀 아트 그림 + 큰 두 줄 문구(흰 + 노랑), 'AI 뉴스 위클리' 칩, '1분코딩 WEEKLY · 11월 1주차' |
| 구성 | 한 주 소식 13가지 → 소식 하나 = 카드 한 장, 꼬리표로 '그래서 나는 뭘 하나'(지금 할 일)까지 |

### 기존 스타일과 다른 점
| 비교 대상 | 기존 | 이 레퍼런스 |
|---|---|---|
| data-report · dash-cover (시장) | 차트·대시보드 중심, 장마다 화면 종류가 바뀜 | **모든 소식이 한 틀** — 시청자가 '어디를 보면 되는지' 학습됨 |
| statement-brief · quote (발언) | 인용 카드·원본 영상이 화면 전체 | 원문 캡처는 **오른쪽 증거 칸 하나**, 왼쪽은 요약·숫자 |
| hybrid-causal · evidence-board | 원인→결과 지도로 '연결'을 보여 줌 | 연결은 말로, 화면은 **사실 요약표** |
| 꼬리표 | 없음 | '주의·사례·지금 할 일' — 소식의 **쓸모**를 먼저 밝힘 |
| 순번·진행 막대 | 장 표지(chapter)로 구분 | `NEWS n / N` + 막대 → **남은 양**이 보여 이탈이 줄어듦 |

### 장단점
- **장점:** ① 만들기 빠름(틀이 고정 — 매일 브리핑·위클리에 최적) ② 한눈 요약(정지 화면만 봐도 소식 하나가 이해됨 → 모바일·소리 끄고 보기에 강함) ③ 출처가 항상 보임(신뢰) ④ 순번이 '몇 개 남았나'를 알려 끝까지 보게 함.
- **단점:** ① 화면 변화가 적음(시험작 측정 4.6회/분 — 기준보다 낮음) → 길게 쓰면 지루함, 증거 패널 움직임·장 사이 다른 장면으로 보완 필요 ② '왜·어떻게 이어지나'(인과)를 그리지 못함 → 시장 채널의 '연결과 의미'(manual 03 §0-1)는 인과 지도와 섞어야 함 ③ 글자가 많아 휴대폰 작은 화면에서 숫자 3칸 이름표가 작음.
- **우리 채널에서:** 이어 읽는 시장의 **주간 정리(토)**·여러 소식 브리핑에 그대로, 매일 브리핑은 '시장 한 장 → 뉴스 데스크 카드 2~3장 → 인과 지도 → 오늘 볼 것'으로 섞음. AI 채널 위클리(업계 소식)에도 맞음.

## 2. PICKIT — 「해커톤 우승자가 만든 모든게 가능한 클로드 스킬!!」 (쇼츠)
https://youtube.com/shorts/62xDokE5kyY · 채널 @PICKIT_OFFICIAL-f9u

### 관찰 (프레임 4장)
| 요소 | 무엇 |
|---|---|
| 뼈대 | **사람이 카메라 앞에서 직접 말함**(홈 스튜디오: 책장·조명·마이크) — 세로 9:16 |
| 훅 | 첫 화면에 도구 로고(둥근 사각) + 세 줄 제목 '클로드(주황) / 우승자가 만든 / 최고의 스킬' — 한 낱말만 색 |
| 컷 | 같은 촬영에서 **크기가 바뀌는 점프 컷**(넓게 ↔ 얼굴 가까이) — 말 사이 쉼을 잘라 빠른 리듬 |
| 자막 | 화면 가운데 아래, 굵은 흰/노란 글씨 + 검은 테두리, **두세 어절씩** 말하는 순간 바뀜('충격받았습니다.') |
| 끼워 넣기 | 말하는 낱말에 맞춰 **위쪽에 흰 카드 묶음**(아이콘 + '마케팅·콘텐츠·시장조사') — 사람은 아래에 그대로 보임 |
| 브랜드 | 위 왼쪽 작은 'PICKIT' |

### 기존 스타일과 다른 점
| 비교 대상 | 기존 | 이 레퍼런스 |
|---|---|---|
| shorts-card · shorts-guide-codex | 고정 훅 + 큰 자막 + 설명 카드, **AI 목소리** | **사람 얼굴과 목소리** — 신뢰·개성이 영상의 중심 |
| shorts-claude | 실제 녹화 화면이 가운데 고정 | 화면은 가끔 끼워 넣는 카드, 중심은 사람 |
| kinetic-type | 말하는 단어가 화면 글자로 튐 | 자막은 아래 고정, 강조는 색으로만 |
| 리듬 | 박자마다 TTS 쉼 0.28초 | 실제 말의 쉼을 잘라 낸 **점프 컷 + 펀치 인** |

### 장단점
- **장점:** ① 사람 얼굴 = 신뢰·친근(같은 정보라도 '누가 말하나'가 생김, 구독 전환에 유리) ② 제작 단가 낮음(1분 촬영 → 자동 편집) ③ 점프 컷·펀치 인으로 정지 화면이 거의 없음 ④ AI 목소리 티가 없음(사용자 기준 'AI 티 덜 나는' 목소리 문제를 근본적으로 해결).
- **단점:** ① **사람이 매번 촬영해야 함** — 매일 자동 제작(06:05)과 맞지 않음 ② 얼굴 공개 부담 ③ 촬영 품질(조명·소리)이 그대로 영상 품질 ④ 사실 근거(공시·차트)를 길게 보여 주기 어려움 → 카드로 짧게만.
- **우리 채널에서:** 본인이 찍을 수 있을 때의 **쇼츠 전용**(주 1~2편, 롱폼 하이라이트·한 줄 의견). 롱폼 매일 브리핑은 그대로 자동.
