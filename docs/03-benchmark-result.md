# 03. 벤치마킹 결과 (2026-11-05)

`python -m ytflow benchmark --no-llm` 로 낸 수치와, 아웃라이어 상위 영상 자막을 직접 읽고 분석한 결과입니다.
규칙 원본은 `data/style_profile.json` 에 있고, 이후 대본·편집 단계가 이 파일을 그대로 참조합니다.

> **측정하지 못한 것:** 컷 속도(분당 화면 전환 수)는 재지 못했습니다. YouTube가 클라우드 서버 IP의 영상 스트림을 403으로 막았습니다.
> 개인 PC에서 `python -m ytflow benchmark --video` 를 돌리면 이 값이 채워집니다.
> 자막 상세 분석은 채널당 자막이 있는 영상 3편 기준이라, 말 속도 같은 수치는 대략적인 값으로 봐 주세요.

## 무엇이 터졌나

**식스시그마**
- **잘된 영상:** 화제 인물이나 리서치 이름 + 짧은 주장이 붙은 '큰 그림' 주제입니다. 빌 게이츠, 젠슨 황, 세미애널리시스, 중국 오픈모델 전략이 상위에 있었습니다.
- **안된 영상:** FOMC나 분기 실적처럼 매번 오는 이벤트, 바이오 주제, 영어 제목이었습니다.
- **해석:** 숫자를 빼고 **짧고 단정한 주장 + 권위 있는 이름**을 쓴 제목이 클릭을 만듭니다.

**AI비즈PT**
- **잘된 영상:** 'AI 여러 개를 비교한 실험' 영상이 다른 사례 영상의 2~3배로 가장 크게 터졌습니다.
- **나머지:** 상위 영상은 모두 **[검색 키워드], [인물 설명]이 [조건]으로 [금액]** 공식을 썼습니다.
- **안된 영상:** 인물 서사가 길고 검색 키워드가 앞에 없는 제목이었습니다.

## 대본 구조 (두 채널 공통 뼈대)

1. **훅 (0~30초):** 첫 두 문장에 날짜, 회사, 금액, 등락률을 몰아넣습니다. 또는 실험의 최종 숫자를 먼저 공개합니다.
   - 예) "엔비디아는 루멘텀에도 20억 달러를 넣었습니다… 루멘텀 8.6% 상승, 마벨 8.4% 하락"
   - 예) "1달러가 2,400달러로, 꼴찌는 445달러까지"
2. **질문 브리지:** "다음 레이저는 누구 차례가 될까요?" 같은 질문 하나를 던진 뒤 "~의 말로 따라가 보겠습니다"로 시청 약속을 합니다.
3. **기초 설명:** "돈은 이렇게 흐릅니다"처럼 처음 보는 사람을 위한 구조를 짚습니다.
4. **근거 블록 3~5개:** 원문 발언 → "정리하면 ~" → 숫자 순서입니다.
5. **반전:** "그러자 예상 못한 일이 생깁니다."
6. **마무리:**
   - 식스시그마는 "다음에 볼 것은 ~ 11월 6일 실적입니다"처럼 다음 확인 일정을 예고합니다.
   - AI비즈PT는 "가져갈 건 세 가지입니다… 오늘 해 보세요"처럼 실천 과제를 줍니다.
7. **구독·좋아요 요청은 없습니다.**

## 화면 분석 (2026-11-05 추가)

식스시그마 2편의 장면 미리보기(스토리보드)를 직접 보고 확인한 내용입니다.
- **원본 소스 영상이 중심입니다.** 인터뷰, 방송(CNBC·Fox Business), 컨퍼런스, 키노트를 전체 화면으로 그대로 씁니다.
- **출처 라벨:** 모든 화면 왼쪽 위에 `날짜 · 출처`, 오른쪽 위에 작은 로고가 있습니다.
- **2단 자막:** 회색 영어 원문 위에 흰색 한국어 번역을 놓고, 핵심어는 빨간색으로 칠합니다.
- **인포 카드:** 원본 영상 사이에 **검은 배경 인포 카드**를 넣습니다. 얇은 흰 선과 글씨를 쓰고 강조색은 빨강 하나입니다. 큰 숫자 비교, 흐름도, 강조 표, 기사 헤드라인을 이렇게 보여 줍니다.
- **쓰지 않는 것:** 배경음악, 줌, 색 배경, 아이콘이 없습니다.

첫 가편집(남색 배경, 청록 차트, 줌)은 자막만 보고 화면 규칙을 추측해서 만든 결과라 폐기했습니다.
지금 파이프라인은 위 규칙대로 동작합니다(`ytflow/stages/cards.py`, `clips.py`, `media.py`).

## 두 번째 스타일: 종이 손그림 애니메이션 (미주일기, 2026-11-06)

[미주일기](https://www.youtube.com/@mijudiary) 영상 12편의 공개 미리보기 프레임(영상의 약 25·50·75% 지점)을 보고 정리했습니다.
- **배경과 선:** 크림색 구겨진 종이 배경에 남색 잉크 손그림 선을 쓰고, 강조는 빨간 펜으로 합니다.
- **글씨:** 제목과 큰 숫자는 명조체, 짧은 메모와 밑줄은 손글씨입니다.
- **사진:** 인물·뉴스 사진은 종이 위 콜라주로 붙이거나, 전체 화면 사진 위에 흰 명조 글씨를 얹습니다.
- **자막:** 하단 가운데 반투명 어두운 상자 안에 넣습니다.
- **움직임 (추정):** 정지 프레임이라 움직임은 직접 보지 못했습니다. 그래서 이 장르의 관행대로 다음처럼 설계했습니다.
  - 선과 상자가 그려지며 등장하고, 글씨는 아래에서 떠오릅니다.
  - 숫자는 0부터 올라가고, 강조 숫자에는 빨간 밑줄이 그어집니다.
  - 사진은 기울어진 채 붙고 테이프가 얹힙니다.

구현은 `ytflow/stages/paper.py` 에 있고, 프로젝트 폴더에 `edit.yaml` (`edit: {style: paper}`) 을 두면 적용됩니다.
폰트는 나눔명조·나눔손글씨 펜·나눔고딕(SIL OFL)을 저장소에 함께 넣었습니다.

## 우리 채널에 적용할 것 (`style_profile.json` 에 반영)

- **분량과 속도:** 9분, 분당 약 260자로 정했습니다. 대본 단계의 분량 계산에 이 값이 자동으로 쓰입니다.
- **훅:** 숫자 콜드오픈이나 결과 선공개 → 질문 하나 → 따라가겠다는 약속 순서입니다.
- **근거:** 인터뷰 원문 클립은 저작권 위험이 있습니다. 그래서 **공식 자료(실적 자료, 공시, 통계) 화면 + 한국어 해설**로 대체합니다.
- **차별화:**
  - AI비즈PT에서 가장 잘 터진 'AI 비교 실험' 형식을 **직접 실험하는 오리지널 시리즈**로 만듭니다.
  - 두 채널 모두 쇼츠가 0%입니다. 숫자 콜드오픈 부분을 잘라 **쇼츠 유입 경로**를 만듭니다.
