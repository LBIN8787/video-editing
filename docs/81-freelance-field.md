## 3. 왜 '문서·보고 업무'인가
1. **수요가 확인됐고 개발사가 덜 붙는 조각.** 챗봇은 크지만 개발사 영역, 문서·보고 자동화는 규모가 작아 1인이 들어갈 틈이 있다.
2. **이미 하는 일과 같다.** 이 저장소는 매일 '자료 모으기 → 1차 출처 확인 → 사실·해석 나눠 정리 → 정해진 시간에 보내기'를 자동으로 돌린다. 회사의 주간 보고·경쟁사 동향·시장 자료 정리·회의록·견적·엑셀 취합이 같은 모양이다.
3. **코드를 반만 알아도 된다.** 구글 시트·메일·드라이브와 Claude 를 잇는 작은 자동화가 대부분. 큰 서버 개발은 맡지 않는다.
4. **실패 이유를 우리가 메운다.** 중소기업이 막히는 곳은 기술이 아니라 '무엇부터·누가 맡나'. 진단으로 목표를 정하고, 담당자를 교육으로 세운다.

## 5. 첫 30일
1. 포트폴리오 한 장: 이 저장소의 매일 브리핑 자동화(무엇을·전후 시간·도구)를 '사례 1'로.
2. 지인 회사 1~2곳에 진단을 무료·저가로 → 후기와 절약 시간 숫자.
3. 위시켓·원티드 긱스·숨고에 프로필, 'AI 업무 자동화·컨설팅' 공고에 지원.
4. 과정을 스레드·링크드인에 공개(영업 비용 0).
5. 소득이 생기면 사업자등록·소득 신고 확인(세무서·세무사).
