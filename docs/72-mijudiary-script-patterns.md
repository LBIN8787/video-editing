# 72. 미주일기 대본의 반복 패턴 — "공부 자료"가 아니라 "아, 그렇구나" (2026-11-25)

> 사용자 (불안 편 대본 v1 뒤): "지금과같은 대본보다는 미주일기의 대본의 반복되는 패턴을 조사하고 이런 방식으로 이야기를 전개해주세요 너무 지금은 어렵고 자연스레 아 그렇구나 하고 알게되는 느낌보다는 그냥 공부를 위한 자료같아요"

## 0. 본 것
미주일기 자막(유튜브 스크립트 패널, 사용자 Chrome·프리미엄)으로 세 편을 새로 읽고, docs/30(4편)·docs/71(리만)과 겹쳐 봄.
- AI가 인간을 추월하는 법칙, 쉬운 일부터 대체된다는 건 착각입니다 (13만)
- 인간도 AGI가 아니다? 낯선 지능을 마주하는 방법 (2만)
- 앤트로픽 수학자 리만가설 증명 발표 (94만)
대사는 옮기지 않고 **반복되는 진행 방식**만 적는다 (AGENTS.md 스타일 규칙). 자막 원문은 커밋하지 않음.

## 1. 일곱 가지 반복 패턴
| # | 패턴 | 어떻게 하나 (구조) | 왜 '아 그렇구나'가 되나 |
|---|---|---|---|
| P1 | **역설 한 장면으로 연다** | 최근의 구체적 사건 하나 → "재밌는 일은 ~에서 벌어졌습니다" → 그 사건 속 어긋남(물리학자의 정답지를 고치는 AI 가 바늘 시계는 못 읽음) → "이 역설 속에 ~이 숨어 있습니다" → 질문 두 개 | 설명을 듣기 전에 '이상하다'를 먼저 느낌. 이후 설명은 그 이상함을 푸는 답이 됨 |
| P2 | **예가 먼저, 이름은 나중** | 익숙한 장면(알파고가 자기 자신과 둬서 이김)을 먼저 보여 주고 "이를 ~라고 부릅니다", "즉 ~" 로 용어를 한 번만 붙임 | 용어가 낯선 단어가 아니라 방금 본 장면의 이름표가 됨 |
| P3 | **법칙은 'A가 아니라 B' 한 문장** | 한 장(章)마다 "~한 까닭은 ~가 아니라 ~ 때문입니다" 로 맺음 | 통념(A)을 뒤집는 순간이 곧 깨달음. 장마다 하나씩만 |
| P4 | **모든 주장은 이름 있는 사람이 나른다** | "~ 연구원은 ~라고 설명했습니다 / 지적했습니다 / 밝혔습니다". 한 문단 = 사람 + 주장 + 구체적 예 | 교과서 문장이 아니라 누가 한 말이 됨. 믿을 근거도 함께 |
| P5 | **눈에 그려지는 생활 예** | 바늘 시계, 열 자리 곱셈 암산, 점 잇기(가장 짧게/가장 길게), 웃는 아기·원숭이·로봇 사진, 철새의 자기 나침반 | 추상 개념을 머릿속 그림 하나로 바꿈 → 화면도 그 그림을 그림 |
| P6 | **사다리 연결어로 한 단씩** | 더 나아가 · 마찬가지입니다 · 반대로 · 이 원리를 뒤집어 보면 · 문제는 ~ 때 벌어집니다 · 그렇다면 ~ | 앞 문단이 다음 문단의 발판. 새 개념을 한꺼번에 쏟지 않음 |
| P7 | **맺음은 통념 뒤집기 + 태도** | 처음 역설로 돌아와 'A가 아니라 B'를 다시 말하고, "~할 때 비로소 ~" 같은 태도 한 줄 | 처음의 이상함이 풀린 채 끝남 |

말투(docs/30 그대로): '~습니다' 3인칭 내레이터, 연결어로 이은 긴 문장(평균 60~70자), 시청자에게 말 걸지 않음.

## 2. 우리 대본 v1 이 '공부 자료'처럼 읽힌 이유
| v1 | 미주일기 패턴과의 차이 |
|---|---|
| 해마·배쪽 해마·현미경·뉴런·메타분석·PTSD·패턴 분리… 한 편에 새 용어가 많음 | P2: 용어는 장면 뒤에 한 번, 꼭 필요한 것만 (해마 하나면 충분) |
| 조각 문장("그 뱀은 퍼프애더.", "귀찮죠.") | 말투: 연결어로 이어지는 긴 문장 |
| 장마다 '정의 → 설명' 순서 (연기 감지기 원리 소개 → 의미) | P1·P2: 이상한 장면 → 왜? → 예 → 이름 |
| 실험 절차를 순서대로 자세히 (경기장 → 훈련 → 현미경) | 미주일기는 절차보다 **'예상이 빗나간 순간'** 하나를 사건처럼 들려줌 |
| 반론 장이 따로 (르두·네스 한계) | 반론도 사람의 말 + 생활 예로 이야기 속에 (르두의 '막대기와 뱀') |
| 한 장의 결론 문장이 흐림 | P3: 장마다 'A가 아니라 B' 한 문장 |
