# 51. 설명 무대 — 글·숫자 대신 바뀌는 물체로 설명하기

2026-11-20 사용자: "설명을 할때 단순 글과 숫자만이 아닌 이런 연출법을 사용하고싶어" (월텍남 〈앤트로픽 대실망에, AMD 공매도까지〉 4:57 '제재 뒤 펌웨어 6개 버전' 화면을 보여 주며).

영상 분석은 [31-motion-grammar](31-motion-grammar.md)에 있다. 거기서 반복해 쓰인 문법 가운데 세 가지를 하이브리드 장면으로 만들었다(`ytflow/stages/explain.py`). 공통 원칙은 하나다. **한 장면이 한 무대다. 앞 박자에 나온 물체와 기준선은 남기고, 대사의 동사에 맞춰 다음 요소만 바뀐다.**

| 장면 `type` | 이럴 때 | 화면 순서 | 벤치마크 위치 |
|---|---|---|---|
| `afterline` | "사건 **뒤에도** 계속됐다", "그 이후 몇 번" | 시간선 위 사건 표식(손그림 금지·날짜) → '이후' 구간이 붉게 열림 → 카드가 하나씩 쌓임 → 수량 문구(강조 붉게) | 4:52~4:57 |
| `spread` | 두 값의 **차이**가 이름을 가진 개념일 때 (마진·스프레드·괴리) | 재료 → 공정 → 제품 소품과 화살표 → 두 가격 높이 + 낮은 쪽 점선 연장 → 괄호로 차이(이름·식) → 한쪽 값이 바뀌면 옛 높이는 점선 윤곽, 간격이 줄어듦 | 9:09~10:15 |
| `share` | 전체 중 **몫**, "3분의 1 넘게" | 전체 막대(0~100%) → 부분이 차례로 채워짐 → 비교 눈금 → 관련 구간을 괄호로 묶어 합계 | 4:35~4:43 |

`hybrid.json` 의 다른 장면과 똑같이 `say` 박자를 쓰고, 박자마다 `show` 로 **그 박자에 나올 부품**을 적는다. `at` 에 대사 속 단어를 적으면 그 단어를 말하는 순간에 맞춘다(없으면 박자 시작부터 0.5초 간격). `show` 가 없는 박자는 화면을 그대로 둔다.

```json
{"type": "afterline", "title": "헌터브룩 보고서의 주장",
 "event": {"name": "IEIT시스템즈", "date": "2025년 3월 블랙리스트", "tag": "제재 뒤", "mark": "ban"},
 "items": {"count": 6, "icon": "microchip"},
 "headline": {"pre": "AMD 펌웨어", "emph": "6개 버전 이상"},
 "beats": [{"say": "…블랙리스트에 올랐습니다.", "show": ["event"]},
           {"say": "그런데 제재 뒤에도 펌웨어는 계속 나왔습니다.", "show": ["after", "items"], "at": {"after": "제재"}},
           {"say": "…여섯 개 버전이 넘습니다.", "show": ["headline"]}]}
```

```json
{"type": "spread", "title": "정제마진은 어디서 생기나",
 "steps": [{"icon": "droplet", "label": "원유"}, {"icon": "factory", "label": "정유 공장"}, {"icon": "fuel", "label": "휘발유·경유"}],
 "low": {"label": "원유값", "value": 70, "text": "$70"}, "high": {"label": "제품값", "value": 95, "text": "$95"},
 "diff": {"label": "정제마진", "formula": "제품값 − 원유값"},
 "change": {"value": 82, "text": "$82", "label": "제품값만 내려가면 간격이 줄어듦"},
 "beats": [{"show": ["steps"]}, {"show": ["low", "high"]}, {"show": ["diff"]}, {"show": ["change"]}]}
```

```json
{"type": "share", "title": "매출 중 두 지역의 몫", "total": "매출 전체", "of": 100,
 "parts": [{"label": "중국·홍콩", "value": 22}, {"label": "싱가포르", "value": 14}],
 "mark": {"value": 33.3, "label": "3분의 1"},
 "sum": {"parts": [0, 1], "label": "합치면 3분의 1 넘게"},
 "beats": [{"show": ["total", "p0"]}, {"show": ["p1"]}, {"show": ["mark", "sum"]}]}
```

- 아이콘은 `ytflow/assets/icons/` 의 이름(lucide)을 쓴다. 칩 `microchip`, 원유 `droplet`, 공장 `factory`, 주유 `fuel`, 상자 `package`, 트럭 `truck` 등.
- 숫자와 주장은 다른 장면과 같은 사실 규칙을 따른다. 보고서의 주장이면 제목이나 라벨에 출처('○○ 보고서의 주장')를 남긴다. 개별 카드에 날짜를 붙이지 않는 한 카드 간격은 시간 간격이 아니라 **개수**다.
- 화면 글자는 주체·단위·날짜·결론만. 나머지는 물체의 위치·높이·색이 말하게 한다.

## 아직 없는 것 (다음 후보)

벤치마크에 있었지만 이번에 만들지 않은 문법. 필요해지면 같은 모듈에 더한다.

- **물체 이동** — 출발점·목적지·옮겨지는 물체, 도착하면 목적지 상태가 바뀜(3:25 바구니에서 상자 빼기, 4:48 공정이 넘어감). 지금은 `map_causal` 의 화살표나 `stage` 로 대신한다.
- **비유로 같은 구도 반복** — `spread` 를 한 번 더 써서 참깨 → 방앗간 → 참기름처럼 소품만 바꾸면 된다(9:35). 두 장면을 이어 붙이는 전환은 아직 없다.
- **앞 도식 다시 불러오기** — 공정 도식과 시간선을 위아래로 다시 놓는 요약 화면(5:05).
