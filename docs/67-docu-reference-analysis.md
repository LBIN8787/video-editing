**R3 의 선택 요약:** 시각 언어(부품 목록)를 먼저 정하고 30분 동안 늘리지 않는다. 카메라는 **규모가 바뀔 때만** 움직인다(하나 → 여럿, 차트 안으로). 영상 전체에 돌아올 '기준 차트' 하나.

## 6. 시장 채널에 — 결정 기록에서 고를 수 있는 선택지로
`direction`·`decide` 를 쓸 때 아래를 '고려한 대안'으로 놓고 고른 이유를 적습니다(05 §0-9). 지금 렌더러에 있는 것과 없는 것을 함께 적었습니다.

| 상황 (situations) | 레퍼런스 선택 | 우리 장면 | 언제 고르나 / 언제 버리나 |
|---|---|---|---|
| 물가·가치가 시간에 따라 변함 (`metric`·`change`) | R2-1 고정 틀 + 한 변수 | `bars`·`bignum` 으로는 '같은 돈의 힘'이 안 보임 → **없음(후보: 고정 틀 비교 장면)** | 같은 대상의 시점 비교일 때 고름. 대상이 여럿이면 버리고 `bars` |
| 통념을 고친다 (`explain`) | R2-3 통념 먼저 그리고 고침 + 이름표 | `motionboard` + 이름표 | '사람들이 생각하는 것' vs '실제'가 대본에 있을 때 |
| 연쇄·누적 (`cause`·`hub-event`) | R2-4 사슬 + 누적 합계, R1·`docu` pulse | `docu`(pulse·count), `map_causal` | 과정이 늘어나며 합계가 쌓이면 R2-4, 관계가 그물이면 `docu`, 원인→결과 두세 단계면 `map_causal` |
| 영상 전체의 기준 (`direction`) | R3-3 기준 차트 하나를 층층이·다시 부름 | **없음(후보)** — 장마다 같은 차트로 돌아와 지금 위치 표시 | 심층·주간처럼 한 논증이 긴 영상. 매일 브리핑은 버림(이야기가 여러 갈래) |
| 하나 → 시장 전체 (`explain-market`) | R3-2 하나를 보여 주고 물러나며 복제 | `docu` 에 추가할 후보(`replicate`) | '한 사람(한 회사)의 일이 모두의 일'일 때. 카메라 움직임 이유 = 규모 변화 |
| 숫자가 움직였다 (`metric`) | R4-2 정면·평면·일관된 차트 판, 강조 대상만 다른 색 | `bars`·`chart` (지금 방식과 같음) | 기본. 카메라 고정(v31)과 일치 |
| 숫자에 장소·맥락을 입힘 | R4-1 세트 안의 차트 판 (세트만 움직임) | **없음** — 장 표지 사진·identity 가 일부 | 국가·업종이 이야기의 주인공일 때 시험 가능. 데이터 판은 정면 고정(v31 취지 유지) |
| 숫자의 실물 근거 | R4-4 시세판·앱 실사, R2-2 원본 지면 | `docspot`·`newspapers`·`footage` | 숫자가 처음 나올 때 한 번. 그래픽만으로 끝내지 않음 |
| 숨 고르기·사람 | R4-5 2초 몽타주, R2-5 소품 매크로 | `footage`·`kb` | 차트가 길게 이어진 뒤. 자료가 없으면 만들지 않음(지어낸 B-roll 금지) |

### 바로 쓸 판단 세 가지 (결정 기록의 why 로)
1. **카메라 움직임의 이유는 '규모가 바뀐다'(R3-2)·'구조가 바뀐다'(R1)·'맥락 세트'(R4-1) 셋 중 하나여야 한다.** 셋 다 아니면 버린다 — v31 이 막은 '남용'의 경계가 여기.
2. **한 편의 부품 목록(`vocabulary`)을 먼저 정하고, 기준 그림 하나(R3-3)가 있으면 장마다 그리로 돌아온다.** 같은 상황 같은 장면(05 §0-9)의 레퍼런스 근거.
3. **개념마다 매체를 짝짓는다(R2).** 물가 = 고정 틀 비교, 통념 = 고쳐 그리기, 과정 = 사슬 누적, 숫자 = 정면 차트 판, 근거 = 원본 실사. 화려한 쪽이 아니라 정확한 쪽을 고르고 그 이유를 적는다.
